Vue 性能优化详解 ​

一、Vue3 编译优化 ​

1.1 Vue2 vs Vue3 渲染对比 ​

方面Vue2Vue3
响应式definePropertyProxy
虚拟 DOM普通 diffBlock Tree
静态处理无静态提升
更新粒度组件级块级

1.2 静态提升（Hoist Static） ​

Vue3 将静态节点提升到渲染函数外部，只创建一次。

html
<!-- 模板 -->
<div>
  <span>静态内容</span>
  <span>{{ message }}</span>
</div>

Vue2 编译结果：

javascript
// 每次渲染都创建静态节点
render() {
  return h('div', [
    h('span', '静态内容'),      // 重复创建
    h('span', this.message)    // 动态节点
  ])
}

Vue3 编译结果：

javascript
// 静态节点提升到函数外部
const _hoisted_1 = h('span', '静态内容')

render() {
  return h('div', [
    _hoisted_1,  // 复用节点
    h('span', this.message)
  ])
}

1.3 PatchFlag（动态标记） ​

Vue3 为动态节点添加标记，diff 时只比较标记的部分。

html
<div>
  <span class="static">静态</span>
  <span>{{ dynamic }}</span>
  <span :class="active">动态 class</span>
</div>

编译结果：

javascript
render() {
  return h('div', [
    h('span', '静态'),  // 无标记，完全静态

    h('span', this.dynamic, 1 /* TEXT */),  // 文本动态

    h('span', { class: this.active }, 2 /* CLASS */)  // class 动态
  ])
}

PatchFlag 枚举：

值含义说明
1TEXT动态文本
2CLASS动态 class
4STYLE动态 style
8PROPS动态 props（不含 class/style）
16FULL_PROPS完整 props 变化
32HYDRATE_EVENTS事件监听
64STABLE_FRAGMENT稳定 Fragment
128KEYED_FRAGMENT有 key 的 Fragment
256UNKEYED_FRAGMENT无 key 的 Fragment

1.4 事件缓存 ​

Vue3 缓存事件处理函数，避免重复创建。

html
<button @click="handleClick">点击</button>

未缓存：

javascript
render() {
  return h('button', {
    onClick: _ctx.handleClick  // 每次渲染都是新引用
  }, '点击')
}

缓存后：

javascript
render() {
  return withCtx((_, _cache) => [
    h('button', {
      onClick: _cache[0] || (_cache[0] = ($event) => (_ctx.handleClick($event)))
    }, '点击')
  ], this)
}

1.5 Block Tree ​

Vue3 使用 Block Tree 减少虚拟 DOM 遍历。

Vue2 的 diff：
遍历整个模板树

Vue3 的 diff：
只遍历有动态节点的 Block
跳过静态区域

二、响应式优化 ​

2.1 Vue3 响应式原理 ​

javascript
// Vue2
Object.defineProperty(obj, 'prop', {
  get() { track() },
  set(newVal) { trigger() }
})

// Vue3
const proxy = new Proxy(obj, {
  get(target, key) { track(); return Reflect.get(target, key) },
  set(target, key, newVal) {
    const result = Reflect.set(target, key, newVal)
    trigger()
    return result
  }
})

2.2 Vue3 Proxy 优势 ​

javascript
// Vue2 问题
const obj = { items: [] }
obj.items[0] = 'new'  // ❌ 不触发响应式（需用 $set）
obj.newProp = 'value' // ❌ 不触发响应式

// Vue3 解决
const arr = reactive([])
arr[0] = 'new'  // ✅ 触发响应式
arr.newProp = 'value' // ✅ 触发响应式

2.3 避免深度响应式 ​

typescript
// ❌ 过度响应式：大对象深层响应式开销大
const state = reactive({
  user: {
    posts: [
      { comments: [...] } // 每个嵌套都变成响应式
    ]
  }
})

// ✅ 使用 shallowRef
const state = shallowRef({
  user: {
    posts: []
  }
})

// ✅ 或使用 markRaw
const user = markRaw({
  posts: []
})
const state = reactive({ user })

2.4 shallowRef vs ref ​

typescript
import { ref, shallowRef, triggerRef } from 'vue'

// ref：深度响应式
const deepRef = ref({ count: 0 })
deepRef.value.count = 1 // 触发更新

// shallowRef：浅响应式
const shallow = shallowRef({ count: 0 })
shallow.value.count = 1 // ❌ 不触发更新

// 需要手动触发
shallow.value = { count: 1 } // ✅ 触发更新
// 或
triggerRef(shallow)

2.5 toRaw 性能优化 ​

typescript
import { toRaw, reactive } from 'vue'

const state = reactive({ count: 0 })

// 访问原始对象，避免代理开销
const raw = toRaw(state)

// 在大量操作时使用原始对象
for (let i = 0; i < 10000; i++) {
  toRaw(state).count++
}

三、组件优化 ​

3.1 v-memo ​

缓存模板的子树，只有当依赖变化时才更新。

vue
<div v-memo="[scrollTop]">
  <div>{{ content }}</div>
  <div>{{ timestamp }}</div>
</div>

使用场景：

vue
<!-- 列表项：只有选中状态变化时更新 -->
<div v-memo="[isSelected]">
  <div>{{ item.title }}</div>
  <div>{{ item.description }}</div>
</div>

3.2 v-once ​

只渲染一次，之后不再更新。

vue
<!-- 静态内容 -->
<div v-once>
  <ExpensiveComponent />
</div>

<!-- 或 -->
<template>
  <div v-once>{{ staticData }}</div>
</template>

3.3 函数式组件 ​

无状态、无实例的轻量组件。

typescript
// 函数式组件
const MyComponent = (props, { slots, emit, attrs }) => {
  return h('div', props.class, slots.default())
}

// 使用
<MyComponent class="wrapper">
  <span>content</span>
</MyComponent>

3.4 KeepAlive ​

缓存组件实例，避免重复销毁和创建。

vue
<template>
  <KeepAlive :include="['Home', 'About']">
    <router-view />
  </KeepAlive>
</template>

<!-- 配合 max 控制缓存数量 -->
<KeepAlive :max="10">
  <component :is="currentComponent" />
</KeepAlive>

使用场景：

  • 切换 Tab
  • 多步骤表单
  • 记住滚动位置

四、列表优化 ​

4.1 虚拟滚动 ​

使用 vue-virtual-scroller 或 vueuc:

vue
<template>
  <RecycleScroller
    class="scroller"
    :items="items"
    :item-size="50"
    key-field="id"
  >
    <template v-slot="{ item }">
      <Item :item="item" />
    </template>
  </RecycleScroller>
</template>

4.2 使用唯一 Key ​

vue
<!-- ❌ 使用索引 -->
<div v-for="(item, index) in items" :key="index">

<!-- ✅ 使用唯一 ID -->
<div v-for="item in items" :key="item.id">

4.3 滚动到指定位置 ​

vue
<template>
  <div ref="container">
    <div v-for="item in items" :key="item.id" :ref="el => setRef(el, item.id)">
      {{ item.title }}
    </div>
  </div>
</template>

<script setup>
const itemRefs = {}
const setRef = (el, id) => {
  if (el) itemRefs[id] = el
}

const scrollToItem = (id) => {
  itemRefs[id]?.scrollIntoView()
}
</script>

七、缓存优化 ​

7.1 computed 缓存 ​

typescript
import { computed } from 'vue'

// ❌ 方法每次调用都重新计算
const displayName = (user) => user.firstName + ' ' + user.lastName

// ✅ computed 只在依赖变化时重新计算
const displayName = computed(() => user.value.firstName + ' ' + user.value.lastName)

7.2 Watch vs WatchEffect ​

typescript
// watchEffect：立即执行，追踪依赖
watchEffect(() => {
  console.log(user.value.name) // 立即执行，追踪 user.name
})

// watch：惰性执行，明确依赖
watch(user, (newUser) => {
  console.log(newUser.name)
}, { deep: true })

九、Vue2 vs Vue3 优化对比 ​

9.1 响应式 ​

typescript
// Vue2：需要 $set
this.$set(this.user, 'name', 'new name')

// Vue2：函数式组件

📝 小结 ​

  • Vue 3 的性能提升来自三块:编译期(重写模板编译、静态提升、Patch Flag)、运行时(Proxy 相比 defineProperty 更高效)、体积(摇树友好)。
  • 响应式开销的本质是「任何被监听的属性访问都要走 Proxy 陷阱」,因此要缩小响应式数据的范围。
  • 组件层面用 v-memo、<KeepAlive>、异步组件减少重复渲染与首屏体积。
  • Vue DevTools 的 Performance 面板能直接看到组件树更新耗时,配合 performance.mark 定位更精确。
