推荐深入阅读 ​

书籍 ​

  • 《Web 性能权威指南》(High Performance Browser Networking) —— Ilya Grigorik 著,Google 性能团队出品。网络、HTTPS、HTTP/2、缓存的"圣经"。
  • 《高性能网站建设指南》(High Performance Websites) —— Steve Souders 提出"14 条性能规则",影响后续所有前端性能工作。
  • 《设计数据密集型应用》(Designing Data-Intensive Applications) —— Martin Kleppmann。涉及后端缓存、批处理、流式处理,理解"数据"性能的本质。

在线文档 ​

Google / web.dev ​

  • web.dev/performance —— 体系化最佳实践
  • web.dev/vitals —— Core Web Vitals 详解
  • web.dev/learn/performance —— 入门到进阶学习路径
  • Chrome User Experience Report —— 真实用户性能数据集

MDN ​

  • MDN Web Performance
  • MDN Performance API

工具 ​

  • Lighthouse —— 综合性能评分 + 改进建议
  • WebPageTest —— 多地点多浏览器测试
  • Chrome DevTools Performance 面板 —— 火焰图定位长任务
  • Bundle Analyzer / rollup-plugin-visualizer —— 包体积分析
  • web-vitals —— 官方 Core Web Vitals JS SDK
  • Sentry Performance —— 商业 APM,自带 Session Replay

社区 / 博客 ​

  • Chrome for Developers 博客 —— V8 / Chrome 团队的最新动态
  • web.dev 案例研究 —— 真实业务优化的复盘
  • Vercel Blog / Next.js Blog —— React 框架层面的性能优化

视频 / 课程 ​

  • Google Chrome 官方 YouTube —— 大量性能主题讲解
  • JSConf / performance.now() —— 性能专题会议

📝 小结 ​

  • 必读:Google 的 web.dev/web-vitals 与 Web.dev Learn Performance、MDN Performance API、Chrome 团队博客的性能专题。
  • 工具链:Chrome DevTools Performance 面板、Lighthouse、WebPageTest、Performance Insights、React DevTools Profiler、bundlephobia。
  • 书籍推荐《高性能浏览器网络》《Web 性能权威指南》,重点读渲染与网络两章。
  • 深入方向:Core Web Vitals 的采集原理与噪声处理(CrUX 真实用户数据)、INP 的归因模型。
  • 社区:web.dev 的年度性能报告(如 Web Almanac)是最新的数据来源,面试引用最新数字很加分。
  • 学习路径:先指标定义 → 再测量工具 → 再各框架优化 → 最后 RUM 与性能预算,和本专题章节顺序一致。
