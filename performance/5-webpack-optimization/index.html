Q1: 如何减少首屏加载时间？

Section titled “Q1: 如何减少首屏加载时间？”
  1. 代码分割：路由级/组件级分割
  2. 压缩：JS/CSS/图片压缩
  3. Tree Shaking：移除未使用代码
  4. CDN：静态资源放到 CDN
  5. 缓存：合理设置缓存策略
  6. 预加载：preload/prefetch

Q2: 如何分析包体积？

Section titled “Q2: 如何分析包体积？”
  1. 使用 webpack-bundle-analyzer
  2. 查看各个模块的体积占比
  3. 找出大依赖
  4. 考虑替换或分割

Q5: Tree Shaking 不生效？

Section titled “Q5: Tree Shaking 不生效？”

检查：

  1. 是否使用 ES modules（import/export）
  2. package.json 是否有 sideEffects
  3. 是否开启了 usedExports
  4. 是否有动态 import

📝 小结

Section titled “📝 小结”
  • 构建优化分两条线:构建速度(多进程、缓存、持久化缓存)和产物体积(Tree Shaking、分包、压缩)。
  • splitChunks 是分包的核心,配合动态 import 把路由级代码切出来,首屏 JS 才能真正变小。
  • 压缩要选对算法:Brotli 比 gzip 小 15~20%,但需要服务端协商 Accept-Encoding。
  • 分析体积必须用可视化工具,webpack-bundle-analyzer / source-map-explorer 才能定位到具体是哪个包。
