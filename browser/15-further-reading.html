浏览器原理:推荐深入 ​

经典书籍 ​

  • 《How Browsers Work: Behind the scenes of modern web browsers》 —— Tali Garsiel & Paul Irish。最权威的浏览器原理入门(基于 Chrome/Safari/Firefox)。免费在线版本,有完整中文翻译。强烈建议通读。

  • 《WebKit 技术内幕》 —— 朱永盛。WebKit 内核架构深度讲解(适合 Safari/iOS 工程师)。基于 WebKit 源码剖析渲染、JS、布局、动画。

  • 《浏览器工作原理与实践》 —— 李兵(极客时间)。从工程师视角讲解浏览器原理,实战案例丰富,涵盖性能优化、安全、网络。

  • 《Web 性能权威指南》(High Performance Browser Networking) —— Ilya Grigorik。Google 性能团队出品,网络层(HTTP/HTTPS/缓存)圣经。

  • 《High Performance Websites》 —— Steve Souders。"14 条性能规则"开山之作。

推荐路径 ​

入门(1~2 周) ​

  1. Inside look at modern web browser 4 篇
  2. 《How Browsers Work》对应章节
  3. web.dev/performance 入门

进阶(1~2 月) ​

  1. 《WebKit 技术内幕》或《浏览器工作原理与实践》
  2. web.dev/learn/performance 全套
  3. Chrome DevTools Performance 面板实战

高级(2~3 月+) ​

  1. 读 Chromium 源码(content/renderer/)
  2. 读 V8 源码(TurboFan 编译器)
  3. 跟踪 Chromium 邮件列表 / GitHub Issue

关键问题清单(面试常考) ​

  • 从输入 URL 到页面渲染,经历了哪些阶段?
  • 浏览器为什么多进程?每个进程内有哪些线程?
  • JS 单线程,异步怎么实现的?(事件循环)
  • 微任务 vs 宏任务区别?
  • DOM 是怎么构建的?渲染树是什么?
  • Layout / Paint / Composite 分别在哪个线程?
  • reflow vs repaint 区别?
  • transform 为什么性能好?
  • 浏览器怎么管理缓存?

读完推荐资料,这些问题都能答上来。
