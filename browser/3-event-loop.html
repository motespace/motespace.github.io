浏览器事件循环（与 JS 的区别） ​

3.1 浏览器事件循环 vs JS 事件循环 ​

JS 事件循环（ECMAScript 标准）：

  • 微任务：Promise.then、queueMicrotask
  • 宏任务：setTimeout、setInterval、I/O

浏览器事件循环（HTML 标准，更完整）：

执行栈（同步代码）
    ↓
微任务队列（清空）
    ↓
判断是否需要渲染
    ↓
渲染阶段（如果需要）
    ↓
requestAnimationFrame 回调
    ↓
宏任务队列（取一个）
    ↓
回到执行栈

核心差异：浏览器事件循环在"微任务 → 宏任务"中间多了渲染阶段，给浏览器机会更新 UI。

3.2 requestAnimationFrame ​

js
// 在浏览器下次重绘前调用，60fps 下约 16.67ms 一次
function animate() {
  element.style.transform = `translateX(${pos++}px)`
  requestAnimationFrame(animate)
}
requestAnimationFrame(animate)

与 setTimeout 对比：

特性setTimeoutrequestAnimationFrame
时机至少 N ms 后浏览器下次重绘前
帧率同步❌ 不一定✅ 自动同步
后台标签页仍然执行自动暂停
性能可能掉帧流畅

js
// 大屏动画必须用 rAF，不用 setTimeout
function startRotation() {
  function tick() {
    angle += 0.5
    radarChart.setOption({ series: [{ data: getNewPoints(angle) }] })
    requestAnimationFrame(tick)
  }
  requestAnimationFrame(tick)
}
