Vim 文本编辑器快速上手

Vim 是从 vi 发展而来的文本编辑器，几乎所有 Linux 服务器都预装了 vi/Vim。掌握基础操作后，比 nano 等编辑器效率高得多。

一、三种模式

Section titled “一、三种模式”

Vim 有三种工作模式，模式切换是理解 Vim 的核心：

模式 能做什么 如何进入
Normal 移动光标、删除、复制、粘贴 Esc
Insert 插入文字 i / a / o
Command-line 保存、退出、搜索、替换 :

首次使用记住：90% 的时间在 Normal 模式，只有编辑文字时才进入 Insert 模式。

🎯 面试常考

Section titled “🎯 面试常考”

Q1：Vim 里怎么不用鼠标完成日常编辑?

Section titled “Q1：Vim 里怎么不用鼠标完成日常编辑?”

最小够用集(记住这些能覆盖 90% 的场景):

思路:Vim 有模式(normal/insert/visual/command), 核心是「在 normal 模式用 hjkl + 动词 + 宾语」组合,比如 dw(删词)、2dd(删两行)。

Q2：Vim 的四种模式分别干什么?

Section titled “Q2：Vim 的四种模式分别干什么?”
  • Normal(普通):默认,用来移动和执行命令
  • Insert(插入):打字,Esc 退出
  • Visual(可视):选中文本,y 复制、d 删除、c 改写
  • Command(命令行):以 : 开头,执行命令

最常忘的一点:粘贴有两种模式——

  • 普通的 p:粘贴到光标后面
  • 块模式的 Ctrl+v 选中多行后 p:把内容替换到每行

以及:在 Insert 模式里按 Ctrl+v 可以粘贴系统剪贴板, 而普通的 Vim 里 p 粘的是 Vim 自己的寄存器(需要 "+p 才是系统剪贴板)。

📝 小结

Section titled “📝 小结”
  • 最小够用集:i/a/o/Esc/:wq/dd/yy/p/u/搜索替换,靠 hjkl + 动词 + 宾语组合。
  • 四种模式:normal(移动执行)、insert(输入)、visual(选择)、command(: 命令)。
  • 粘贴有两个坑:普通 p 粘 Vim 寄存器、块粘贴替换每行;系统剪贴板要 Ctrl+v 或 “+p。
  • :set paste 可以临时关掉自动缩进,粘代码时很有用。
