Vim 文本编辑器快速上手 ​

Vim 是从 vi 发展而来的文本编辑器，几乎所有 Linux 服务器都预装了 vi/Vim。掌握基础操作后，比 nano 等编辑器效率高得多。

一、三种模式 ​

Vim 有三种工作模式，模式切换是理解 Vim 的核心：

Normal 模式（默认）───── i ─────→ Insert 模式
       ↑                              │
       │←───────────── Esc ←──────────┘
       │
       └── : ─────→ Command-line 模式
模式能做什么如何进入
Normal移动光标、删除、复制、粘贴Esc
Insert插入文字i / a / o
Command-line保存、退出、搜索、替换:

首次使用记住：90% 的时间在 Normal 模式，只有编辑文字时才进入 Insert 模式。

二、Normal 模式（命令模式） ​

进入 Vim 后默认是 Normal 模式。此模式下每个键都是命令。

2.1 光标移动 ​

vim
h            ← 向左移动（也可方向键）
j            ↓ 向下移动
k            ↑ 向上移动
l            → 向右移动

w            跳到下一个单词词首
b            跳到上一个单词词首
e            跳到单词词尾

0            跳到行首
$            跳到行尾
^            跳到行首（非空白字符）

gg           跳到文件开头
G            跳到文件末尾
:<N>         跳到第 N 行

Ctrl+o       后跳（返回上一个位置）
Ctrl+i       前跳（进入下一个位置）

hjkl vs 方向键：hjkl 在手指主键区，盲打时无需移动手。

2.2 删除 ​

vim
x            删除光标所在字符
X            删除光标前一个字符
dd           删除整行（并保存到寄存器）
d<N>w        删除 N 个单词
d0           删除到行首
d$           删除到行尾
dgg          删除到文件开头
dG           删除到文件末尾

2.3 复制与粘贴 ​

vim
yy           复制当前行
y<N>w        复制 N 个单词
y0           复制到行首
y$           复制到行尾

p            粘贴到光标后
P            粘贴到光标前

"+y          复制到系统剪贴板（外部粘贴）
"+p          从系统剪贴板粘贴

2.4 撤销与重做 ​

vim
u            撤销
Ctrl+r       重做
U            撤销整行所有修改

2.5 搜索 ​

vim
/关键词       向下搜索
?关键词       向上搜索
n            下一个匹配
N            上一个匹配
#            向上搜索光标下的词
*            向下搜索光标下的词

# 搜索时忽略大小写
:set ignorecase
/keyword\c   单次搜索忽略大小写

2.6 替换 ​

vim
# 单次替换
:s/old/new           替换当前行第一个匹配
:s/old/new/g         替换当前行所有匹配

# 全局替换
:%s/old/new/g        替换文件中所有匹配
:%s/old/new/gc       全局替换（需确认）

三、Insert 模式（插入模式） ​

从 Normal 模式进入 Insert 模式：

vim
i            在光标前插入（insert）
I            在行首插入

a            在光标后插入（append）
A            在行尾插入

o            在下方新建一行并进入插入模式
O            在上方新建一行并进入插入模式

s            删除光标字符并进入插入模式
S            删除整行并进入插入模式

# 退出 Insert 模式（回到 Normal）
Esc
Ctrl+[       Esc 的快捷键（更快）

四、Command-line 模式（命令行模式） ​

从 Normal 模式按 : 进入：

4.1 保存与退出 ​

vim
:w            保存（write）
:wq           保存并退出
:x            保存并退出（等价于 :wq）
:q            退出（未修改时）
:q!           强制退出（不保存）
ZZ            保存并退出（Normal 模式下直接用）
ZQ            不保存退出

4.2 文件操作 ​

vim
:w newfile.txt    另存为
:e filename       打开文件
:e.               打开当前目录
:r filename       读取文件内容到光标位置
:r !ls            读取命令输出到光标位置

4.3 行号 ​

vim
:set number      显示行号
:set nonumber    隐藏行号
:<N>             跳到第 N 行
:N               同上

五、Visual 模式（可视化选择） ​

vim
v            字符选择（按字符选中）
V            行选择（按行选中）
Ctrl+v       块选择（矩形区域）

# 选择后可用
y            复制选中内容
d            删除选中内容
>            向右缩进
<            向左缩进
u            转为小写
U            转为大写

六、分屏 ​

vim
:sp filename      水平分屏（上下）
:vsp filename     垂直分屏（左右）
Ctrl+w w          切换窗口
Ctrl+w h/j/k/l    切换到左/下/上/右窗口
Ctrl+w c          关闭当前窗口
:only             只保留当前窗口

七、Vim 配置 ​

7.1 基础配置（~/.vimrc） ​

vim
" 显示
set number         " 显示行号
set relativenumber " 显示相对行号（移动命令更方便）
set cursorline     " 高亮当前行
set showcmd        " 显示命令（底部）

" 缩进
set tabstop=2      " Tab 宽度 2 空格
set shiftwidth=2   " 自动缩进宽度
set expandtab      " Tab 转空格
set smarttab       " 智能 Tab

" 搜索
set incsearch      " 增量搜索
set ignorecase     " 忽略大小写
set smartcase      " 搜索有大小写时区分

" 外观
syntax on          " 语法高亮
colorscheme desert  " 颜色主题

" 其他
set scrolloff=5    " 光标上下保持 5 行上下文
set wrap           " 长行自动折行
set mouse=a        " 支持鼠标

7.2 插件推荐（可选） ​

插件用途
vim-plug / Vundle插件管理器
NERDTree文件树侧边栏
vim-fugitiveGit 集成
coc.nvimLSP（代码补全、跳转）
vim-goGo 语言支持

八、快速入门路径 ​

1. vim filename     打开文件
2. i                进入编辑模式，敲几下字
3. Esc              回到 Normal 模式
4. :wq              保存退出
练习步骤：
1. h j k l          移动光标（记住）
2. i                进入编辑，输入文字
3. Esc               退出编辑
4. x                 删除字符
5. dd                删除整行
6. yy / p            复制粘贴
7. /                 搜索
8. :wq               保存退出

记住：少用方向键，多用 hjkl 和 w/b/e，效率提升立竿见影。
