🎯 面试常考

Q1：Linux 文件权限 rwx 的含义?umask 是什么?

Section titled “Q1：Linux 文件权限 rwx 的含义?umask 是什么?”

rwx 对应 owner / group / others 三组,每组三位: r=4 读、w=2 写、x=1 执行。

umask:新文件创建时要减掉的权限。默认 022 →

  • 文件:666 - 022 = 644
  • 目录:777 - 022 = 755

面试要点:目录的 x 权限含义和文件不同 —— 目录的 x 表示「可以进入/列出」, 没有 x 就 cd 进去也 ls 不出来。

Q2：软链接和硬链接的区别?

Section titled “Q2：软链接和硬链接的区别?”

硬链接:和原文件指向同一个 inode。

  • ln a.txt b.txt → b 和 a 是同一个文件的两个名字
  • 删除原文件不影响硬链接
  • 不能跨文件系统,不能给目录建硬链接

软链接(符号链接):存的是目标路径。

  • ln -s a.txt b.txt → b 里存的是 “a.txt” 这个字符串
  • 删除原文件 → 软链接变成失效链接(悬空)
  • 可以跨文件系统、可以指向目录

判断:看 inode 号,ls -i 相同就是硬链接;readlink 能读出内容的是软链接。

📝 小结

Section titled “📝 小结”
  • 权限是 owner/group/others 三组 × rwx,数字 r=4 w=2 x=1。
  • umask 是新文件要减掉的权限,默认 022 → 文件 644、目录 755。
  • 目录的 x 是「可进入/可列出」,含义和文件不同。
  • 硬链接 = 同一个 inode(不能跨文件系统/不能指向目录);软链接 = 存路径(可跨盘、可指向目录,但原文件删了会悬空)。
