Linux Shell 脚本基础

Shell 是 Linux 内核与用户之间的命令行接口，既可以交互执行命令，也可以编写脚本批量执行。前端工程师掌握 Shell 脚本，能显著提升部署、自动化和排查效率。

一、常见 Shell 类型

Section titled “一、常见 Shell 类型”

Linux 启动后显示的默认程序就是 Shell，常见类型：

Shell 说明
sh（Bourne Shell） 最古老，所有 Unix/Linux 都支持
bash（Bourne Again Shell） sh 的增强版，Linux 默认，功能最全
zsh bash 的进阶版（主题、插件生态好，macOS 默认）
fish 交互友好，自动补全强大，但脚本语法不兼容 bash

Q1：Shell 脚本里 set -euo pipefail 是什么意思?

Section titled “Q1：Shell 脚本里 set -euo pipefail 是什么意思?”

三个是生产脚本的标配:

  • set -e:命令失败(非 0)立即退出
  • set -u:引用未定义变量时报错(而不是当空串)
  • set -o pipefail:管道中任一命令失败,整条管道就失败

三个的坑:

  1. set -e 在 if、&&、||、管道中间等场景不会触发(这是 POSIX 规定的行为)
  2. set -e 配合 $(cmd) 时,cmd 失败不会退出,要用 || true 或显式判断
  3. set -u 对空数组 "${arr[@]}" 在 bash < 4.4 会报未绑定,要用 ${arr[@]+"${arr[@]}"}

最关键的一点:这些只是「快速失败」,不能替代错误处理。重要的步骤要显式判断并给友好提示。

Q2：Shell 脚本怎么调试?

Section titled “Q2：Shell 脚本怎么调试?”

shellcheck 是最有价值的:能查出未加引号的变量展开、 [[ ]] 和 [ ] 混用、cd 失败后继续执行等真实 bug。

调试技巧:在关键位置 echo "step: $?" 打印上一步的退出码, 或者用 trap 'echo "line $LINENO"' ERR 打印出错行号。

📝 小结

Section titled “📝 小结”
  • set -euo pipefail 是生产脚本标配:失败即退、未定义变量报错、管道任一环节失败即失败。
  • set -e 在 if/&&/||/管道中间不生效,不能当成完整的错误处理。
  • 调试三件套:bash -x 跟踪、bash -n 语法检查、shellcheck 静态检查(最值)。
  • 用 trap 'echo $LINENO' ERR 打印出错行号。
