集合

一、是什么

Section titled “一、是什么”

集合（Set），指具有某种特定性质的事物的总体，里面的每一项内容称作元素

在数学中，我们经常会遇到集合的概念：

  • 有限集合：例如一个班集所有的同学构成的集合
  • 无限集合：例如全体自然数集合

在计算机中集合道理也基本一致，具有三大特性：

  • 确定性：于一个给定的集合，集合中的元素是确定的。即一个元素，或者属于该集合，或者不属于该集合，两者必居其一
  • 无序性：在一个集合中，不考虑元素之间的顺序，只要元素完全相同，就认为是同一个集合
  • 互异性：集合中任意两个元素都是不同的

三、应用场景

Section titled “三、应用场景”

一般情况下，使用数组的概率会比集合概率高很多

使用set集合的场景一般是借助其确定性，其本身只包含不同的元素

所以，可以利用Set的一些原生方法轻松的完成数组去重，查找数组公共元素及不同元素等操作

🎯 面试常考

Section titled “🎯 面试常考”

Q1：Set 和数组的区别?什么时候该用 Set?

Section titled “Q1：Set 和数组的区别?什么时候该用 Set?”

Set 是不允许重复的集合,底层是哈希表,查找/插入/删除平均 O(1); 数组是连续内存,按下标 O(1),但查「是否包含某值」要 O(n)。

该用 Set 的典型场景:

  • 数组去重:[...new Set(arr)]
  • 列表成员判断:用 Set 代替 arr.includes(x)(O(1) vs O(n))
  • 两个数组求交集/差集:new Set(a) 后遍历 b 判断
  • 计数:Map 统计出现次数,或 Set 配合先排序再比较相邻

Q2：Set 的遍历顺序是什么?插入顺序吗?

Section titled “Q2：Set 的遍历顺序是什么?插入顺序吗?”

是插入顺序(JS 规范保证:字符串按插入顺序,整数按数值升序)。

这个细节会咬人:如果插入的是整数键,遍历顺序不是插入顺序, 因为规范要求「整数索引键」按数值升序排在前面。

Map 同理。

依赖遍历顺序的代码在重构后可能静默出错 —— 比如把 Set 转成数组再取 [0]。

注意:这个顺序保证是 ES2015 之后才有的,老引擎不保证。

Q3：Set、Map、WeakMap、WeakSet 的区别?

Section titled “Q3：Set、Map、WeakMap、WeakSet 的区别?”
Set Map WeakMap WeakSet
键 值 任意 对象引用 对象引用
弱引用 否 否 是 是
可迭代 是 是 否 否
size 有 有 无 无

WeakMap/WeakSet 的关键价值:键是弱引用,键对象被回收时条目自动消失, 不会造成内存泄漏。

典型用法:

  • 用 DOM 节点当 key 存数据(el._data),节点被移除后数据自动回收
  • 缓存与对象关联的结果

限制:不能遍历、不能清空、key 必须是对象。

📝 小结

Section titled “📝 小结”
  • Set 是哈希集合,查重和成员判断都是 O(1),数组是 O(n) —— 这是选它的主要理由。
  • 遍历顺序:字符串按插入序,整数键按数值升序(规范要求),别依赖插入顺序。
  • WeakMap/WeakSet 的键是弱引用,对象被回收时条目自动消失,避免内存泄漏。
  • 两个数组求交集/差集时先转 Set,能把 O(n²) 降到 O(n)。
