常见排序算法详解 ​

一、是什么 ​

排序是程序开发中非常常见的操作，对一组任意的数据元素经过排序操作后，就可以把他们变成一组一定规则排序的有序序列

排序算法属于算法中的一种，而且是覆盖范围极小的一种，彻底掌握排序算法对程序开发是有很大的帮助的

对与排序算法的好坏衡量，主要是从时间复杂度、空间复杂度、稳定性

时间复杂度、空间复杂度前面已经讲过，这里主要看看稳定性的定义

稳定性指的是假定在待排序的记录序列中，存在多个具有相同的关键字的记录，若经过排序，这些记录的相对次序保持不变

即在原序列中，r[i] = r[j]，且 r[i] 在 r[j] 之前，而在排序后的序列中，r[i] 仍在 r[j] 之前，则称这种排序算法是稳定的；否则称为不稳定的

二、有哪些 ​

常见的比较类排序有 5 种。复杂度、稳定性与选型见文末的对比表,每个算法的完整实现与原理各有专篇:

算法一句话思路专篇
冒泡排序反复比较相邻元素,顺序错就交换;每轮把当前最大值「冒」到末尾冒泡排序
选择排序每轮从未排序部分挑出最小(或最大)放到已排序末尾选择排序
插入排序把元素插入到已排好序的子数组中的正确位置插入排序
归并排序分治:先使每个子序列有序,再把两个有序序列合并归并排序
快速排序选 pivot 做分区,小的放左大的放右,再对两部分递归快速排序

共同点:都是比较类排序——靠比较元素大小决定顺序,所以理论下界是 O(n log n)。

非比较类(计数排序、桶排序、基数排序)可以突破这个下界,但前提是值域有特殊结构(比如分数只落在 0~100)。

Q1：常见排序算法的复杂度和适用场景? ​

见下方完整对比表。

记忆锚点:

  • O(n log n) 且稳定 → 归并
  • O(n log n) 平均且原地 → 快排
  • O(n log n) 最坏 + O(1) 空间 → 堆排
  • O(n²) 但几乎有序时快 → 插入排
  • 按 key 排序 → 计数排 / 桶排

JS 的 Array.prototype.sort 用 TimSort:稳定、快速、对部分有序数组接近 O(n)。 所以 sort((a,b) => a.x - b.x) 是稳定的(ES2019 起规范强制)。

Q2：什么是稳定排序?为什么重要? ​

稳定:相等元素排序后保持原有相对顺序。

为什么重要:多关键字排序时可以分步进行—— 先按次要关键字排,再按主要关键字排(稳定),就等价于按多个关键字排序。

ts
// 先按分数排,再稳定地按姓名排 → 结果是「分数升序,同分按姓名升序」
people.sort((a, b) => a.name.localeCompare(b.name))
people.sort((a, b) => a.score - b.score)

工程例子:表格多列排序、任务列表「优先级相同则按创建时间」、依赖注入排序。

注意:JS 的 sort 在 ES2019 之前不保证稳定(V8 旧实现对 >10 个元素用了不稳定排序), 这是老代码里偶发 bug 的来源。

Q3：计数排序和桶排序什么时候用? ​

计数排序:值域已知且很小(如年龄 0-150、分数 0-100)。 用计数数组统计每个值出现次数,再按顺序写回,O(n + k)。

桶排序:值可以均匀分布在一个区间里,分成若干桶,桶内排序后合并,期望 O(n)。

共同点:都是非比较排序,突破 O(n log n) 的比较模型下界。

前提很苛刻:

  • 值域太大就不适用(计数排序要 O(k) 空间)
  • 分布不均匀就不适用(桶排序退化成 O(n²))

典型场景:统计类需求(年龄分布、分数段人数)、成绩排序。

📝 小结 ​

  • 排序选择看三个维度:时间复杂度、是否原地(空间)、是否稳定。
  • 快速记忆:O(n log n) 稳定选归并,原地选快排,最好情况 O(n) 选插入排,值域小选计数排。
  • 稳定性的价值在多关键字排序:分步排序即可实现「主键优先、同键按次键」。
  • JS 的 sort 是 TimSort(稳定),这在 ES2019 后是规范保证。

📊 常见排序算法对比 ​

算法平均时间最坏时间空间稳定特点与适用
冒泡排序O(n²)O(n²)O(1)✅实现最简单;已有序时可提前退出到 O(n)
插入排序O(n²)O(n²)O(1)✅近有序时接近 O(n);常作小数组优化
选择排序O(n²)O(n²)O(1)❌交换次数仅 O(n),适合「比较便宜、交换昂贵」
归并排序O(n log n)O(n log n)O(n)✅最好/最坏都一样;外部排序主力
快速排序O(n log n)O(n²)O(log n)❌原地、缓存友好;需防 pivot 退化
堆排序O(n log n)O(n log n)O(1)❌最坏也有 O(n log n) 且原地;Top K
计数排序O(n + k)O(n + k)O(k)✅非比较排序;值域 k 必须小
桶排序O(n)O(n²)O(n + k)✅非比较排序;要求数据均匀分布

k 为值域大小。JavaScript 的 Array.prototype.sort 用的是 TimSort —— 稳定的混合排序, 对部分有序数组接近 O(n)。

选型速查:

  • 默认 → Array.prototype.sort(稳定、快、对部分有序友好)
  • 要原地 + 内存紧 → 快排(记得三数取中选 pivot)
  • 要稳定 + 数据在磁盘 → 归并
  • 值域小(如分数 0~100)→ 计数排
  • Top K → 大小为 K 的堆,不要全排序
