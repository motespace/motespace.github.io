树

一、是什么

Section titled “一、是什么”

在计算机领域，树形数据结构是一类重要的非线性数据结构，可以表示数据之间一对多的关系。以树与二叉树最为常用，直观看来，树是以分支关系定义的层次结构

二叉树满足以下两个条件：

  • 本身是有序树
  • 树中包含的各个结点的不能超过 2，即只能是 0、1 或者 2

如下图，左侧的为二叉树，而右侧的因为头结点的子结点超过2，因此不属于二叉树：

同时，二叉树可以继续进行分类，分成了满二叉树和完成二叉树：

  • 满二叉树：如果二叉树中除了叶子结点，每个结点的度都为 2

  • 完成二叉树：如果二叉树中除去最后一层节点为满二叉树，且最后一层的结点依次从左到右分布

🎯 面试常考

Section titled “🎯 面试常考”

Q1：树和图的区别?常见的树有哪些?

Section titled “Q1：树和图的区别?常见的树有哪些?”

树是无环的图(有根、无环、每个节点有唯一父节点)。

常见树:

类型 特点 应用
二叉搜索树 BST 左小右大 查找(但会退化)
平衡二叉树(AVL/红黑) 保持 O(log n) Map/Set 的底层
B 树 / B+ 树 多路平衡,减少磁盘 IO 数据库索引
堆 完全二叉树 + 堆序 优先队列、Top K
字典树 Trie 按前缀组织 搜索框自动补全

面试常说的是 B+ 树:数据库索引为什么用 B+ 树而不是红黑树?

  • 扇出大(几百个分支),树高更低(3~4 层),磁盘 IO 次数少
  • 数据全在叶子节点且用链表串起来,范围查询能顺序扫,效率高

Q2：BST 为什么会退化?怎么解决?

Section titled “Q2：BST 为什么会退化?怎么解决?”

退化:按有序顺序插入 1,2,3,4,5,树变成一条链表,查找从 O(log n) 退化成 O(n)。

解决:

  1. 自平衡:AVL(更严格,查询更快)、红黑树(插入删除更频繁时更好)
  2. 随机化:Treap
  3. 工程简化:直接用哈希表(不需要顺序遍历时)

JS 的 Map 就是有序的哈希表——插入顺序保留,但查找是 O(1),不需要树。

Q3：树的遍历有哪几种?

Section titled “Q3：树的遍历有哪几种?”

按访问顺序分:

  • 前序(根左右):用于复制/序列化一棵���(父先于子)
  • 中序(左根右):BST 的中序遍历结果是升序,这是 BST 能排序的原因
  • 后序(左右根):用于释放树(先删子再删父)、求子树高度

按实现方式分:

  • 递归:代码短,深树会爆栈
  • 迭代(显式栈):深树安全,适合生产

📝 小结

Section titled “📝 小结”
  • 树是无环图;B+ 树是数据库索引的首选(扇出大、树高低、叶子链表支持范围查询)。
  • BST 会因有序插入退化成 O(n),解法是自平衡(AVL/红黑)或随机化;不需要顺序时直接用哈希表。
  • 前序=复制树、中序=BST 得到升序、后序=释放树,三种遍历的用途是固定的。
  • 深树用迭代 + 显式栈,递归在 JS 里会爆栈(约 1 万层)。
