Node.js ​

Node.js 是前端工程化的运行时基础，从 npm 包管理到自定义构建脚本都依赖它。

🎯 关键能力 ​

  • 包管理：npm / pnpm / yarn
  • 模块系统：CommonJS / ES Modules
  • 异步编程：Event Loop / Promise / async/await
  • 进程管理：child_process / worker_threads
  • 构建脚本：自定义 CLI 工具

📝 小结 ​

  • 14 章按「运行时基础 → 核心模块 → 机制原理 → 实战方案」组织,既是知识体系也是面试题库。
  • 必会四块:事件循环(与浏览器对比)、Stream 与背压、Buffer 与二进制、模块系统(CJS/ESM)。
  • 实战四题:文件上传(流式 + 分片 + 直传)、JWT 鉴权(算法白名单 + 刷新 + 吊销)、中间件封装、分页设计(游标分页)。
  • 性能与稳定性:事件循环延迟、GC、内存泄漏排查,配合 clinic/0x。
  • 面试讲法:每个模块都用「是什么 → 底层机制 → 真实项目怎么用」三段式回答。
