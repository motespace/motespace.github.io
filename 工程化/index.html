前端工程化

前端工程化 = 用工具、流程、规范把开发效率、代码质量、协作效率提上去。

📚 章节列表

Section titled “📚 章节列表”
  1. Node.js —— Buffer / 事件循环 / Stream / 文件系统 / 中间件 / JWT / 性能调优
  2. Vite —— 8 章节由浅及深：为什么快 / 配置 / 依赖预构建 / 双构建 / HMR / 插件 / 对比 Webpack
  3. Webpack —— 10 章节由浅及深：构建流程 / Loader / Plugin / HMR / DevServer 代理 / 构建提速 / 产物体积

📝 小结

Section titled “📝 小结”
  • 工程化三大块:Node.js 运行时(BFF 的地基)、Vite(现代构建)、Webpack(存量项目与原理)。
  • 学习顺序:先会用 Vite(配置、插件、HMR、依赖预构建)→ 再懂 Vite 为什么快(原生 ESM + esbuild + 依赖预构建)→ 最后用 Webpack 理解 loader/plugin/分包/缓存。
  • 面试常问:Vite 与 Webpack 的本质差异(开发期按需编译 vs 打包)、生产环境 Vite 用 Rollup、monorepo 与微前端的构建协同。
  • 延伸:测试体系见 前端/engineering/testing/,Monorepo 见 前端/engineering/monorepo/。
