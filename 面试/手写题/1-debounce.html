防抖（Debounce） ​

高频面试题。本文按"原理 → 实现 → 生产级 → 实战"组织。

一、什么是防抖 ​

连续触发只执行最后一次。常见用途：搜索输入、表单提交、按钮防重、窗口 resize。

js
// 场景：搜索框
inputEl.oninput = () => {
  fetch('/api/search?q=' + inputEl.value)  // 用户每次按键都发请求
}

// 防抖后
inputEl.oninput = debounce(() => {
  fetch('/api/search?q=' + inputEl.value)
}, 300)
// 用户停止输入 300ms 后才发请求

二、基础版 ​

js
function debounce(fn, wait) {
  let timer = null

  return function (...args) {
    if (timer) clearTimeout(timer)
    timer = setTimeout(() => {
      fn.apply(this, args)
      timer = null
    }, wait)
  }
}

三、立即执行版（leading） ​

js
function debounce(fn, wait, options = {}) {
  const { leading = false, trailing = true } = options
  let timer = null

  return function (...args) {
    const callNow = leading && timer === null

    if (timer) clearTimeout(timer)
    timer = setTimeout(() => {
      timer = null
      if (trailing && !callNow) fn.apply(this, args)
    }, wait)

    if (callNow) fn.apply(this, args)
  }
}

// 用法
const log = debounce(console.log, 1000, { leading: true })

log('a')  // 立即执行
log('b')  // 排队，1s 后不会执行（因为 leading）

四、生产级（lodash 版） ​

js
function debounce(fn, wait, options = {}) {
  const {
    leading = false,
    trailing = true,
    maxWait,
  } = options

  let timer = null
  let lastArgs = null
  let lastThis = null
  let lastCallTime = null
  let lastInvokeTime = 0

  function invokeFunc(time) {
    const args = lastArgs
    const thisArg = lastThis
    lastArgs = lastThis = null
    lastInvokeTime = time
    fn.apply(thisArg, args)
  }

  function remainingWait(time) {
    const timeSinceLastCall = time - lastCallTime
    const timeSinceLastInvoke = time - lastInvokeTime
    return Math.min(
      wait - timeSinceLastCall,
      (maxWait ?? wait) - timeSinceLastInvoke
    )
  }

  function shouldInvoke(time) {
    const timeSinceLastCall = time - lastCallTime
    return (
      lastCallTime === null ||
      timeSinceLastCall >= wait ||
      timeSinceLastCall < 0 ||
      (maxWait !== undefined && time - lastInvokeTime >= maxWait)
    )
  }

  function trailingEdge(time) {
    timer = null
    if (trailing && lastArgs) invokeFunc(time)
    lastArgs = lastThis = null
  }

  function timerExpired() {
    const time = Date.now()
    if (shouldInvoke(time)) return trailingEdge(time)
    timer = setTimeout(timerExpired, remainingWait(time))
  }

  function leadingEdge(time) {
    lastInvokeTime = time
    timer = setTimeout(timerExpired, wait)
    if (leading) invokeFunc(time)
  }

  function debounced(...args) {
    const time = Date.now()
    const isInvoking = shouldInvoke(time)
    lastArgs = args
    lastThis = this
    lastCallTime = time

    if (isInvoking) {
      if (timer === null) return leadingEdge(time)
      if (maxWait !== undefined) {
        timer = setTimeout(timerExpired, wait)
        return invokeFunc(time)
      }
    }

    if (timer === null) timer = setTimeout(timerExpired, wait)
  }

  debounced.cancel = function () {
    if (timer !== null) clearTimeout(timer)
    lastInvokeTime = 0
    lastArgs = lastThis = null
    lastCallTime = null
    timer = null
  }

  debounced.flush = function () {
    return timer === null ? undefined : trailingEdge(Date.now())
  }

  debounced.pending = function () {
    return timer !== null
  }

  return debounced
}

五、React Hook 封装 ​

ts
import { useEffect, useRef } from 'react'

export function useDebouncedCallback<T extends (...args: any[]) => any>(
  fn: T,
  wait: number,
  deps: React.DependencyList = []
) {
  const fnRef = useRef(fn)
  fnRef.current = fn

  const debouncedRef = useRef<ReturnType<typeof debounce>>()

  useEffect(() => {
    debouncedRef.current = debounce(
      (...args: Parameters<T>) => fnRef.current(...args),
      wait
    )
    return () => {
      debouncedRef.current?.cancel()  // ⬅️ 组件卸载时清理
    }
  }, [wait, ...deps])

  return useCallback((...args: Parameters<T>) => {
    debouncedRef.current?.(...args)
  }, [])
}

// 用法
function Search() {
  const [keyword, setKeyword] = useState('')
  const search = useDebouncedCallback((q) => fetch('/api?q=' + q), 300)

  return <input onChange={e => { setKeyword(e.target.value); search(e.target.value) }} />
}

七、面试追问 ​

Q1: 防抖和节流区别？ ​

答：

  • 防抖：连续触发只执行最后一次（等待用户停止）
  • 节流：固定间隔最多一次（节流用户操作频率）

Q2: leading 和 trailing 怎么用？ ​

答：

  • leading=true：第一次立即（防重点击）
  • trailing=true：最后一次延迟（默认，搜索框）
  • 两个一起 = 节流效果

Q3: 为什么需要 maxWait？ ​

答：避免"无限拖尾"。用户持续触发，函数永远不执行，maxWait 强制最迟时间。

Q4: React hook 怎么避免内存泄漏？ ​

答：useEffect cleanup 时调用 fn.cancel()。

Q5: 怎么中断防抖？ ​

答：debounced.cancel() / 组件卸载时 cleanup。

Q6: 防抖和 requestIdleCallback 区别？ ​

答：requestIdleCallback 是浏览器 API，浏览器不忙才执行。防抖是延迟执行。两者不冲突，可以组合。
