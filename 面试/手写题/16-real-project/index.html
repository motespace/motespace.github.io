Q: 你手写过什么库？

Section titled “Q: 你手写过什么库？”

答：

  • 工具函数（防抖、节流、深拷贝）
  • 自定义 Hook（useWS、useDebouncedCallback、useForm）
  • 单例组件（CaptchaManager、ToastManager、ModalManager）
  • 业务组件（CustomTable、RuleEditor）

Q: 怎么从“会用”到“能写”？

Section titled “Q: 怎么从“会用”到“能写”？”

答：

  1. 看源码（lodash / rxjs / mitt / immer）
  2. 在真实项目应用（先基础后复杂）
  3. 加测试 / 边界处理 / 性能优化

Q: 手写代码对你的项目有什么帮助？

Section titled “Q: 手写代码对你的项目有什么帮助？”

答：

  • 调试：知道底层机制，更快找到 root cause
  • 优化：能挑合适的库（不是所有都用 lodash）
  • 写文档：能讲清楚原理

📝 小结

Section titled “📝 小结”
  • 这一页的价值:把手写题接回真实项目,证明不是背题而是真用过。
  • 四个案例:Tooltip 溢出检测(封装工具函数 + ResizeObserver)、操作符驱动的动态表单(WebSocket 即时通讯、验证码单例管理器)。
  • 面试串联话术:先说业务场景 → 说为什么抽成通用函数/类 → 讲实现关键点 → 讲边界与优化。
  • 常见追问:为什么不用现成库(体积、定制、兼容)、怎么测试、如何在多项目中复用。
  • 建议:每个案例准备一句「我自己写过的版本和社区版本的差异」,这是资深候选人的信号。
