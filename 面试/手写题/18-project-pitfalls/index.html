准备 3-5 个坑

Section titled “准备 3-5 个坑”
  1. 高频坑：防抖没 cancel / 节流最后一下丢失 / 深拷贝丢失类型
  2. 真实项目坑：你们项目踩过的（按 STAR 改造）
  3. 避坑原则：“写到最后加 cleanup”

📝 小结

Section titled “📝 小结”
  • 防抖节流类:忘记 cancel 导致组件卸载后仍执行、闭包里的参数是旧的、leading 与 trailing 行为不符预期。
  • 深拷贝类:循环引用栈溢出、丢失 Date 类型、忘了处理 Symbol 键、拷贝了不该拷贝的函数。
  • Promise 类:忘了 return 导致链断、并发用 forEach + await 变串行、all 遇错丢失其他结果。
  • 事件类:监听没解绑、事件名拼错、off 传的函数引用不一致。
  • 生产类:手写版本没考虑边界与浏览器兼容,最后还是引了库,不如直接用库。
  • 面试话术:这些坑要能主动说出来,体现你在生产环境踩过而不是纸上练过。
