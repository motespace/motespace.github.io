一、商户管理 SaaS：可配置表格的 Tooltip 溢出检测 ​

1.1 业务需求 ​

表格单元格超长需要：
- 真实溢出时显示 Tooltip
- 不溢出不显示（避免无意义 Tooltip）
- 内容支持换行

1.2 实现 ​

tsx
// components/CustomTable.tsx
const TooltipCell: React.FC<{ content: ReactNode; showTooltip?: boolean }> = ({
  content,
  showTooltip = true,
}) => {
  const cellRef = useRef<HTMLDivElement>(null)
  const [isOverflowed, setIsOverflowed] = useState(false)

  const checkOverflow = () => {
    const el = cellRef.current
    if (!el) return

    // 真实溢出检测（clientWidth vs scrollWidth）
    setIsOverflowed(el.clientWidth < el.scrollWidth)
  }

  useEffect(() => {
    checkOverflow()
  }, [content])

  useEffect(() => {
    const handleResize = () => checkOverflow()
    window.addEventListener('resize', handleResize)

    // ResizeObserver 监听 DOM 变化
    const observer = new MutationObserver(handleResize)
    if (cellRef.current) {
      observer.observe(cellRef.current, {
        childList: true,
        subtree: true,
        characterData: true,
      })
    }

    return () => {
      window.removeEventListener('resize', handleResize)
      observer.disconnect()
    }
  }, [])

  if (!showTooltip || !isOverflowed) {
    return <div ref={cellRef}>{content}</div>
  }

  return (
    <Tooltip title={content} placement="topLeft">
      <div ref={cellRef} className="ellipsis">
        {content}
      </div>
    </Tooltip>
  )
}

1.3 关联手写题 ​

  • 闭包：checkOverflow 闭包持有 cellRef
  • MutationObserver：DOM 变化监听（性能优化）
  • rAF 节流：可以用 requestAnimationFrame 节流 resize 监听

三、农业数字化：WebSocket 即时通讯 ​

3.1 业务需求 ​

大屏实时数据：
- 100 个传感器 / 秒级数据
- 弱网环境、断线重连
- 多个图表同步更新

3.2 实现 ​

ts
// services/ws-client.ts
class WSClient {
  private ws: WebSocket | null = null
  private url: string
  private listeners = new Set<Function>()
  private reconnectTimer: number | null = null
  private reconnectInterval = 3000
  private destroyed = false

  constructor(url: string) {
    this.url = url
    this.connect()
  }

  connect() {
    this.ws = new WebSocket(this.url)

    this.ws.onopen = () => {
      console.log('WS connected')
    }

    this.ws.onmessage = (e) => {
      try {
        const data = JSON.parse(e.data)
        this.listeners.forEach(fn => fn(data))
      } catch (err) {
        console.error('WS parse error', err)
      }
    }

    this.ws.onclose = () => {
      if (this.destroyed) return
      this.scheduleReconnect()
    }

    this.ws.onerror = (err) => {
      console.error('WS error', err)
    }
  }

  scheduleReconnect() {
    if (this.reconnectTimer) return
    this.reconnectTimer = window.setTimeout(() => {
      this.reconnectTimer = null
      this.connect()
    }, this.reconnectInterval)
  }

  subscribe(fn: Function) {
    this.listeners.add(fn)
    return () => this.listeners.delete(fn)
  }

  destroy() {
    this.destroyed = true
    if (this.reconnectTimer) clearTimeout(this.reconnectTimer)
    this.ws?.close()
    this.listeners.clear()
  }
}

// 用法：Vue / React 都通用
function useWS<T>(url: string) {
  const [data, setData] = useState<T | null>(null)
  const wsRef = useRef<WSClient>()

  useEffect(() => {
    wsRef.current = new WSClient(url)
    const unsubscribe = wsRef.current.subscribe(setData)
    return () => {
      unsubscribe()
      wsRef.current?.destroy()
    }
  }, [url])

  return data
}

3.3 关联手写题 ​

  • EventEmitter：发布订阅模式
  • debounce/throttle：避免短时间多次触发
  • 闭包：reconnectTimer 在 closure 里管理

四、会员服务平台：验证码单例管理器 ​

4.1 业务需求 ​

多接口并发请求时，验证码输入框只弹一次：
- 接口 A、B、C 同时调用
- 三个都返回 401
- 验证码只弹一次，用户输入后三个接口都重试

4.2 实现 ​

ts
// services/auth.ts
class CaptchaManager {
  private currentPromise: Promise<string> | null = null
  private modal: any  // antd Modal.confirm

  async ensureCaptcha(): Promise<string> {
    // 如果已经有验证码请求，复用
    if (this.currentPromise) return this.currentPromise

    // 创建新的验证码请求
    this.currentPromise = new Promise((resolve, reject) => {
      this.modal.confirm({
        title: '请输入验证码',
        content: <CaptchaInput onSubmit={resolve} onCancel={reject} />,
        onCancel: () => {
          this.currentPromise = null
          reject(new Error('Cancelled'))
        },
        onOk: () => {
          // 用户在输入框中提交
        },
      })
    })

    try {
      const result = await this.currentPromise
      return result
    } finally {
      this.currentPromise = null
    }
  }

  reset() {
    this.currentPromise = null
  }
}

// 用法
const captcha = new CaptchaManager()

// HTTP 拦截器
http.interceptors.response.use(
  res => res,
  async err => {
    if (err.response?.status === 401) {
      const code = await captcha.ensureCaptcha()
      // 重试原请求
      err.config.headers['X-Captcha'] = code
      return http(err.config)
    }
    throw err
  }
)

4.3 关联手写题 ​

  • 单例模式：CaptchaManager 全局唯一
  • Promise 复用：所有并发请求共享一个 promise
