Q：组件怎么修改 props？

A：不能直接修改（单向数据流）。要修改必须通过 triggerEvent 通知父组件，让父组件修改后传新值。

Q：组件样式隔离怎么穿透？

A：用 externalClasses 或 styleIsolation: 'apply-shared'。不推荐随意穿透（破坏组件封装性）。

Q：组件库怎么打包？

A：用 npm + 构建工具（Vite / Webpack），最终产物是 miniprogram_dist 或自定义目录，通过 npm 引入。

📝 小结

Section titled “📝 小结”
  • 自定义组件用 Component({ properties, data, methods, lifetimes }) 定义,页面用 Page({ data, onLoad })。
  • 区别:组件有 properties(父传子)与 methods,页面有生命周期(onLoad/onShow);组件的 data 也能被 setData。
  • 通信:父→子用 properties,子→父用 triggerEvent('event', detail);跨组件可用 selectComponent 或 Behavior 混入复用逻辑。
  • 样式隔离:组件样式默认隔离(styleIsolation: 'isolated'),可用 apply-shared/shared 放开;全局类需用 externalClasses。
  • 面试加分:能讲「组件间怎么避免多层 setData 通信」(用 Behavior 或页面级 store,减少跨组件通信层数)。
