Q20: UniApp 的优缺点？

Section titled “Q20: UniApp 的优缺点？”

答案：

优点：

  1. 跨平台：一套代码多端运行
  2. 开发效率：Vue 开发者直接上手
  3. 生态完善：uni-ui、插件市场、uniCloud
  4. 性能好：原生渲染，体验接近原生
  5. 更新方便：无需审核直接推送

缺点：

  1. 包体积：比原生小程序大
  2. 平台差异：需要处理平台兼容
  3. 性能：复杂场景不如原生
  4. 依赖：依赖 DCloud 维护
  5. 审核：App 需要应用市场审核

Q25: UniApp 和 Flutter、React Native 有什么区别？

Section titled “Q25: UniApp 和 Flutter、React Native 有什么区别？”

答案：

方面 UniApp Flutter React Native
语言 JavaScript/Vue Dart JavaScript/React
渲染 原生/WebView Skia 自绘 原生组件
性能 较好 优秀 较好
包体积 中等 较大 较小
跨平台 全端 全端 主要移动端
生态 Vue 生态 Dart/Flutter 生态 React 生态
学习成本 低（Vue） 高（Dart） 中（React）
厂商支持 DCloud Google Meta/Facebook

选择建议：

  • 已有 Vue 经验 → UniApp
  • 追求性能 → Flutter
  • 已有 React 经验 → React Native
  • 需要小程序支持 → UniApp（原生不支持）

📝 小结

Section titled “📝 小结”
  • 综合题的四个高频场景:登录流程、分享、Token 过期处理、下拉刷新与上拉加载。
  • 登录:后端提供统一登录接口 → 前端调 uni.login 拿 code → 换 token → 统一请求拦截器带上;并发 401 用单例 Promise 锁避免重复登录。
  • 分享:按端条件编译(微信 onShareAppMessage、朋友圈按钮、H5 的分享链接),带参分享用 URL query。
  • Token 过期:401 → 触发静默刷新(带 refreshToken)→ 成功后重放挂起请求;刷新失败则清理登录态并跳登录页。
  • 下拉刷新:onPullDownRefresh + uni.stopPullDownRefresh;上拉加载:onReachBottom + 节流,到底了拉取下一页。
  • 面试加分:讲清「刷新 token 时如何让并发请求挂起等待」,这是最能区分层次的追问。
