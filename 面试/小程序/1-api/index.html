小程序怎么封装 wx.request？和 axios 有什么区别？

📚 深度专题推荐：本文是关于「小程序网络请求」的精炼回答。

一、wx.request 基础

Section titled “一、wx.request 基础”

特点

Section titled “特点”
  • 回调地狱（不像 fetch / axios 那样支持 Promise）
  • 默认 url 必须 HTTPS（开发期可勾选“不校验合法域名”绕过）
  • 不支持拦截器（要自己封装）

四、和 axios 的区别

Section titled “四、和 axios 的区别”
维度 axios wx.request
接口风格 Promise 回调（要 Promise 化）
拦截器 内置 自己实现
并发去重 需要 axios-adaptor 自己实现
请求取消 CancelToken / AbortController 不支持（要用 Task.offHeadersReceived）
自动 JSON ✅ ❌（手动 JSON.parse）
错误码处理 手动 手动
适配浏览器 ✅ 只在小程序

五、登录态失效的并发处理（高频追问）

Section titled “五、登录态失效的并发处理（高频追问）”

场景：用户登录态过期，10 个请求同时发出，每个都触发“重新登录”，最终发起 10 次重新登录请求。

解法：单例 + 队列

Section titled “解法：单例 + 队列”

核心：用 refreshing 单例 Promise + 请求队列，确保 10 个并发请求只触发 1 次 token 刷新。

六、面试追问

Section titled “六、面试追问”

Q：小程序支持跨域吗？

A：不存在跨域问题。小程序是客户端运行，不是浏览器，所有请求都是“主动发起”，不存在浏览器同源策略限制。但是服务端必须支持 HTTPS，并且域名要在小程序后台配置。

Q：怎么配置 request 合法域名？

A：登录微信公众平台 → 开发管理 → 服务器域名 → 配置 request 合法域名、uploadFile 合法域名、downloadFile 合法域名。

Q：小程序怎么上传文件？

A：用 wx.uploadFile，不是 wx.request（request 不支持 multipart/form-data）。

Q：怎么设置请求超时？

A：wx.request({ timeout: 5000 })，5 秒后自动 fail。

Q：小程序能发 WebSocket 吗？

A：可以，用 wx.connectSocket + onSocketMessage。详见 uniapp/4-components 相关章节。

📝 小结

Section titled “📝 小结”
  • wx.request 本身是回调式 API,封装目标是 Promise 化 + 统一 baseURL + 拦截器 + 错误处理。
  • 完整封装要点:超时设置、loading 计数(避免并发时重复开关)、错误码映射与统一提示、请求取消、重复请求去重。
  • 与 axios 的区别:wx.request 不支持拦截器/超时之外的取消、FormData 上传格式不同、H5 端不受合法域名限制、跨端要用 uni.request。
  • 高频追问「登录态失效时多个并发请求同时 401 怎么办」:用单例 Promise 锁——第一个 401 触发重新登录,其余请求挂起等待同一个登录 Promise,登录成功后统一重放。
  • 面试加分:能讲清「为什么不能每个请求各自刷新 token」——会触发多次刷新与状态覆盖。
