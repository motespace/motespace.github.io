Section titled “Q18: 重排和重绘的区别？如何避免？”

答案：

重排（Reflow） 元素位置、尺寸变化 Layout 阶段

Q19: 什么是防抖和节流？区别是什么？

Section titled “Q19: 什么是防抖和节流？区别是什么？”

答案：

防抖（Debounce）：事件触发 n 秒后执行，n 秒内再次触发则重置定时器。

节流（Throttle）：n 秒内只执行一次。

区别 防抖 节流
触发时机 停止触发后 n 秒执行 n 秒内最多执行一次
适用场景 表单验证、搜索 滚动、resize

什么是合成层?怎么减少?

Section titled “什么是合成层?怎么减少?”

答案：合成层是浏览器单独交给 GPU 绘制的一块内容。

属性变化 触发阶段 开销
width / height / top Layout → Paint → Composite 高
background-color Paint → Composite 中
transform / opacity 只 Composite 低

但合成层不是越多越好:每层占一块 GPU 显存,层多了会显存溢出、过度绘制。

口诀:能用 transform / opacity 就不用 width / top;will-change 只在动画期间加。

📝 小结

Section titled “📝 小结”
  • Q17 CRP(关键渲染路径):从导航开始到首屏内容渲染完成的路径;优化手段是减少关键资源数量、减少关键资源大小、减少关键请求链深度(preload、内联关键 CSS、减少同步脚本)。
  • Q18 重排 vs 重绘:重排=几何属性变化(宽高位置)需要重新计算布局;重绘=外观变化(颜色背景)只需重新绘制;合成=仅图层合成,最便宜。优化:批量读写、用 transform/opacity 走合成层、避免 offsetWidth 等强制同步布局。
  • Q19 防抖 vs 节流:防抖等「安静下来」再执行,节流固定间隔最多执行一次;分别用于搜索输入与滚动/拖拽。
  • 合成层:过多合成层也耗内存,will-change 要谨慎使用并及时移除。
  • 首屏缩短:预加载关键资源、内联关键 CSS、骨架屏、SSR/预渲染、减少阻塞脚本。
  • 面试加分:能解释「读 offsetWidth 为什么会触发强制同步布局」,这是渲染原理层的硬核问题。
