state 和 props 有什么区别？

一、state

Section titled “一、state”

一个组件的显示形态可以由数据状态和外部参数所决定，而数据状态就是 state，一般在 constructor 中初始化

二、props

Section titled “二、props”

React 的核心思想就是组件化思想，页面会被切分成一些独立的、可复用的组件

组件从概念上看就是一个函数，可以接受一个参数作为输入值，这个参数就是 props，所以可以把 props 理解为从外部传入组件内部的数据

react 具有单向数据流的特性，所以他的主要作用是从父组件向子组件中传递数据

三、区别

Section titled “三、区别”

相同点：

  • 两者都是 JavaScript 对象
  • 两者都是用于保存信息
  • props 和 state 都能触发渲染更新

区别：

  • props 是外部传递给组件的，而 state 是在组件内被组件自己管理的，一般在 constructor 中初始化
  • props 在组件内部是不可修改的，但 state 在组件内部可以进行修改
  • state 是多变的、可以修改

📝 小结

Section titled “📝 小结”
  • props:父组件传入、只读,是自上而下的数据流;state:组件内部管理、可变,触发自身重渲染。
  • 区别维度:来源、能否修改、作用范围、生命周期归属。
  • 组件「重渲染」不等于「重渲染子组件」:父组件重渲染时,子组件因为 props 相同会被 React 跳过(前提是 memo 或同类型同引用)。
  • 状态提升的判断标准:多个组件需要同一份状态 → 提到共同父级;否则保留局部,避免全局污染。
  • 面试追问:为什么 state 更新要 setState 而不是直接改(因为 React 依赖不可变与调度机制)、函数式更新 setX(x => x+1) 的必要性(基于旧值的更新必须用函数式)。
