Section titled “1️⃣ 商户管理 SaaS 平台”
  • 时间：2025.04 - 2026.08
  • 技术栈：Next.js 15 + React 18 + TypeScript + Ant Design + Zustand
  • 项目描述：面向运营与商户的 B 端管理后台，覆盖渠道、会员、运营、支付配置、风控审核与统计分析等核心模块

主要贡献：

  1. 核心业务交付：主力开发渠道运营、会员管理、支付通道、代付审核及商户侧风控等模块，支撑运营人员高效完成配置、审核与风控流转
  2. 契约驱动与协作优化：基于后端接口契约自动生成类型与请求方法，封装统一请求 SDK（处理 Token 注入、错误统一提示、重复请求控制），减少接口变更后的手工维护成本
  3. 多语言与组件沉淀：设计并落地中英双语方案（覆盖菜单、表单校验、业务枚举、富文本）；沉淀高频业务组件 30+（列表查询、表单提交、权限操作、金额录入等），在同系列项目中实现高效复用

2️⃣ 会员服务平台（Web / H5）与前端监控埋点 SDK

Section titled “2️⃣ 会员服务平台（Web / H5）与前端监控埋点 SDK”
  • 时间：2025.04 - 2026.08
  • 技术栈：Next.js 15 + React 18 + TypeScript + Ant Design + antd-mobile + PWA + Zustand
  • 项目描述：C 端会员服务平台，实行 Web 与 H5 分端建设，H5 端支持 App WebView 深度内嵌，覆盖登录注册、营销活动、电子钱包、会员中心等核心场景。

主要贡献：

Section titled “主要贡献：”
  1. 双端架构与跨端通信：负责 Web / H5 双端核心页面与差异化组件开发，统一全局状态与资源拆分策略；封装 H5 与 App 原生 JSBridge 通信能力，实现页面标题、路由跳转、用户信息、语言/主题及缓存清理的双向状态同步。
  2. 安全认证与风控防护：落地图形验证码、三方 OAuth 登录、设备指纹识别与行为校验等认证链路，提升注册登录防刷风控能力；针对敏感接口实施请求参数加密传输，并封装富文本安全渲染组件，有效降低 XSS 与异常内容注入风险。
  3. 自研 RUM 错误监控 SDK：设计并落地轻量级前端监控 SDK（initRUM），统一捕获 JS 运行报错、未捕获 Promise 拒绝（unhandledrejection）及静态资源加载失败；引入滑动窗口限流与构建版本号（NEXT_PUBLIC_BUILD_VERSION）注入，防止上报雪崩并提升问题排查效率。
  4. 自研 React 自动化埋点 SDK：基于 React 节点 Fiber 架构 向上递归遍历查找事件处理器，实现业务代码零侵入的点击行为自动化采集；自动注入设备型号、时区及网络状况（2G-5G/Wi-Fi），支撑精准用户行为分析。
  5. 性能与多端体验优化：落地 PWA 离线缓存策略，结合多语言（i18n）与主题动态切换，提升弱网与极端网络场景下的访问体验与多端适配能力。
