Vue中的过滤器了解吗？过滤器的应用场景有哪些？

一、是什么

Section titled “一、是什么”

过滤器（filter）是输送介质管道上不可缺少的一种装置

大白话，就是把一些不必要的东西过滤掉

过滤器实质不改变原始数据，只是对数据进行加工处理后返回过滤后的数据再进行调用处理，我们也可以理解其为一个纯函数

Vue 允许你自定义过滤器，可被用于一些常见的文本格式化

ps: Vue3中已废弃filter

📝 小结

Section titled “📝 小结”
  • 过滤器是 Vue 2 的格式化能力,本质是一个纯函数:(value, ...args) => 处理后的值,用在模板插值 {{ msg | capitalize }} 里。
  • 注册方式:全局 Vue.filter 或局部 filters 选项;Vue 3 已移除过滤器,官方建议改用方法或计算属性。
  • 典型场景:日期格式化、金额与单位换算、文本截断与脱敏、枚举值转文案。
  • 局限要说清:过滤器只能做「值 → 值」的转换,拿不到组件实例与 this,也不能 v-if 一样控制结构;复杂逻辑写在过滤器里会难以调试。
  • 原理:编译期把 {{ a | f }} 转成 _f("f")(a),运行时从 options.filters 里查函数。
  • 面试加分:讲「Vue 3 移除过滤器后,社区更倾向用 Intl API + 计算属性」,并说明 Intl.DateTimeFormat 才是正解。
