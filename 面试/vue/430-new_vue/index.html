Vue实例挂载的过程

📚 深度专题推荐：本文是关于「Vue 实例化」的精炼回答。如需建立完整的 Vue 知识体系，建议阅读 Vue 2 vs Vue 3 对比深度专题（响应式原理 / 虚拟 DOM / 生命周期 / Composition API / 性能 / 生态 / 迁移 完整剖析）。

一、思考

Section titled “一、思考”

我们都听过知其然知其所以然这句话

那么不知道大家是否思考过new Vue()这个过程中究竟做了些什么？

过程中是如何完成数据的绑定，又是如何将数据渲染到视图的等等

三、结论

Section titled “三、结论”

  • new Vue的时候调用会调用_init方法

    • 定义 $set、 $get 、$delete、$watch 等方法
    • 定义 $on、$off、$emit、$off 等事件
    • 定义 _update、$forceUpdate、$destroy生命周期

  • 调用$mount进行页面的挂载

  • 挂载的时候主要是通过mountComponent方法

  • 定义updateComponent更新函数

  • 执行render生成虚拟DOM

  • _update将虚拟DOM生成真实DOM结构，并且渲染到页面中

📝 小结

Section titled “📝 小结”
  • new Vue() 的完整流程:合并选项(mergeOptions)→ 初始化生命周期 → 初始化事件 → 初始化渲染 → beforeCreate → 初始化 data/props/computed/watch → created → $mount → 挂载前 → 渲染函数生成 VNode → patch → beforeMount → DOM 插入 → mounted。
  • 核心两步是渲染与 patch:渲染函数把数据变成 VNode 树,patch 用 sameVnode 判断能否复用,不同则创建新节点并更新。
  • 更新时走 patch 算法:同层比较 → patchVnode 更新属性与子节点 → 依赖 Dep 通知 Watcher 触发更新。
  • 面试话术:讲清「数据变了 → 触发渲染 watcher → 重新生成 VNode → patch 比对更新 DOM」这条链路,再挂上响应式与 diff 两个关键词。
  • 延伸:Vue 3 把 patch 换成 PatchFlag 标记 + Block 树,只 diff 动态部分。
