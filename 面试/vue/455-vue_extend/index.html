四、面试追问

Section titled “四、面试追问”

Q：Vue.extend 返回的构造函数和 Vue 有什么区别？

A：子类继承自 Vue 父类，选项合并（mergeOptions）会用 Vue.options 作为基础，然后合并 extendOptions。每个 Vue.extend 调用生成独立的子类。

Q：Vue.use 重复调用会怎样？

A：第二次直接 return this，不会重复 install（用 _installedPlugins 数组判断）。

Q：Vue.component 注册的全局组件在哪个文件用都行吗？

A：是的，全局注册的组件在任何子组件中都可以直接 &lt;my-comp /&gt; 使用。局部注册需要 components: { MyComp } 或在 &lt;script setup&gt; 中 import。

Q：自定义指令全局注册用哪个 API？

A：Vue.directive('focus', { inserted: el => el.focus() })。Vue 3 改为 app.directive(...)。

📝 小结

Section titled “📝 小结”
  • Vue.extend(options):用配置对象生成一个 Vue 子类构造器,可以给子类加全局混入或做多实例继承;Vue 3 已移除,改用 defineComponent。
  • Vue.use(plugin):装插件,内部维护一个 installedPlugins 数组保证只装一次,调用插件的 install(Vue, options)。
  • Vue.component(name, definition):全局注册组件,内部存在 Vue.options.components;同名注册会覆盖并给出警告。
  • Vue 3 对应:app.use()、app.component()、app.directive()、app.provide(),挂在 app 实例上而非全局构造函数上(支持多应用)。
  • 面试话术:能说清「app 实例化带来的好处」——多应用隔离、SSR 不污染全局,这是 Vue 3 的架构进步。
