Q：bind 和 inserted 区别？

A：

  • bind：指令绑定到元素时，元素可能还在父节点外（没插入 DOM）
  • inserted：元素已插入父节点，保证 el.parentNode 存在，可以做获取焦点等操作

Q：全局指令和局部指令怎么选？

A：

  • 全局指令（Vue.directive）：整个项目可用，适合通用场景（v-permission / v-copy）
  • 局部指令（组件 directives 选项）：仅本组件用，避免污染全局

Q：Vue 3 中为什么钩子重命名？

A：和组件生命周期钩子命名一致（beforeMount / mounted / updated 等），更直观；bind/inserted 等命名与组件生命周期没有对应关系。

Q：怎么让自定义指令传参？

A：通过 binding.value（值）/ binding.arg（参数）/ binding.modifiers（修饰符）：

对应 binding = { value, arg: 'arg', modifiers: { modifier: true } }。

📝 小结

Section titled “📝 小结”
  • 指令钩子本质是在编译期把 v-xxx 转成 withDirectives + 运行时 vnode 上的 dirs 数组,挂载与更新时由 Vue 遍历调用。
  • Vue 2 钩子:bind、inserted、update、componentUpdated、unbind;Vue 3:created、beforeMount、mounted、updated、beforeUnmount、unmounted,并支持函数简写。
  • 钩子参数:el(元素)、binding(value、oldValue、arg、modifiers、instance)。
  • 指令的钩子在每次更新都会执行(除 mounted 外),所以要自己做性能判断(如 binding.value 没变就直接 return)。
  • 面试追问:自定义指令与 mixin、渲染函数、组件的适用边界;updated 里改 DOM 会不会死循环(会,需要条件判断)。
  • 一句话:指令是「编译期插入的 DOM 钩子」,Vue 3 用 withDirectives 把钩子挂到 vnode 上。
