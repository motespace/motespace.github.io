面试自我介绍模板 ​

使用场景：面试开场 1-5 分钟的自我介绍，决定第一印象和后续问题走向。

核心原则：

  • ✅ 公式：基本信息 + 技术栈 + 代表项目 + 核心能力 + 求职动机
  • ✅ 3 个版本：1 分钟（HR）/ 3 分钟（技术面，最常用）/ 5 分钟（终面）
  • ✅ 讲故事：不要背简历，讲"我做了什么 + 怎么做的 + 带来什么价值"

一、自介绍万能公式 ​

[基本信息]   你好，我叫 XXX，X 年前端经验，主要做 XXX 方向。
    +
[技术栈]     主力技术栈是 React/Vue + TypeScript + Webpack/Vite。
    +
[代表项目]   最近做过的最有挑战的项目是 XXX，我在其中负责 XXX、主导了 XXX。
    +
[核心能力]   我比较擅长 XXX（比如性能优化 / 工程化建设 / 跨端开发）。
    +
[求职动机]   这次看新机会主要是因为 XXX（业务 / 技术成长 / 团队）。

二、3 个版本 ​

🔥 1 分钟版（电梯版 / 破冰用） ​

✅ 推荐版（7 年经验 / 已实战优化） ​

"面试官你好，我叫 XXX，7 年前端经验，做过 B 端 SaaS、SSR、PWA、跨端 App 和大屏这些方向。

技术栈上主力是 React + TypeScript + Next.js，最近 2 年主导了好几个中后台项目；同时熟悉 Vue 生态（Vue 2/3 + Vite），去年刚主导过一个 Vue 2 + Webpack 4 迁移到 Vue 3 + Vite + Pinia 的项目，80 多个组件，启动时间 28 秒降到 0.8 秒；移动端用 uni-app 做过跨端 App + IoT 大屏。

我比较擅长性能优化和工程化建设，能从源码层面讲清楚 Webpack Loader/Plugin 链、Vite 的 esbuild 预构建原理。

这次想找一个业务更聚焦、有技术挑战的方向。"

⏱️ 约 60 秒 ｜ 字数 ~260 字

亮点拆解：

  • ✅ 方向 + 技术栈分层：先说做过哪些方向（业务广度），再分层说技术栈（主力 / 同时熟悉 / 移动端）
  • ✅ 具体项目 + 数据化：80 多个组件、28 秒 → 0.8 秒（不是"做了性能优化"）
  • ✅ 能力标签收尾：性能优化和工程化建设 + 源码层理解
  • ✅ 钩子引导追问："业务更聚焦、有技术挑战" → 面试官可能问业务 / 技术细节

备选版（HR 面 / 笔试破冰） ​

"你好，我叫 XXX，7 年前端经验，主要做 B 端 SaaS 和中后台系统。

主力技术栈是 React + TypeScript + Next.js，最近一个项目是 XX，从 0 到 1 主导完成了整体架构和核心模块。

同时也熟悉 Vue 生态，去年主导过一个 Vue 2 到 Vue 3 + Vite 的迁移项目，启动速度从 28 秒降到 0.8 秒。

平时对前端工程化和性能优化比较感兴趣，这次看新机会主要是因为业务方向比较契合。"

适用：

  • HR 面试
  • 笔试前的破冰
  • 终面一开始的"介绍下自己"

要点：

  • 控制在 200-300 字 / 45-60 秒
  • 一句话说清楚几个关键标签：年限 + 技术栈 + 1 个亮点项目
  • 末句留钩子（"对前端工程化感兴趣"），引导面试官追问

⭐ 3 分钟版（标准版 / 技术面最常用） ​

"你好，我叫 XXX，X 年前端经验，目前在 XX 公司做 B 端运营 SaaS。

技术栈：主力是 React + TypeScript + Next.js，做过 SSR 和 PWA；同时熟悉 Vue 生态（Vue 2 / Vue 3 + Pinia / Vite），有完整迁移经验；移动端用过 uni-app，跨端方案比较熟。

最近的项目是商户管理 SaaS 平台，模块比较多（10+ 业务模块），我作为前端核心开发，主要做了三件事：

第一，沉淀了一套可复用的中后台组件库——可配置表格、搜索表单、弹窗表单、权限按钮、金额输入等。后续新模块的开发效率提升了 40% 左右。

第二，搭建了统一的接口请求层，基于 swagger-typescript-api 自动生成类型和请求方法，集中处理 Token、错误码、多环境切换和重复请求拦截。

第三，配合业务做了金额处理的安全加固，区分法币和虚拟币精度，处理 RSA 加密登录、富文本 XSS 防护等安全细节。

另一个想讲的项目是智能风控引擎平台。这个项目是我从老同事手里接过来的 Vue 2 + Webpack 4 项目，我主导做了整体迁移到 Vue 3 + Vite + Pinia。这个迁移我印象很深，因为涉及到：

  • 80 多个组件的 Composition API 重构（主要是 mixin 拆分）
  • 第三方库的 ESM 兼容处理
  • 用 shallowRef 优化大列表渲染
  • 最终启动时间从 28s 降到 0.8s，但包体没明显变小（因为业务代码量大）

我比较擅长的事情是性能优化和工程化建设，对前端构建工具（Webpack / Vite / Rollup）和监控体系也比较熟悉。

这次看新机会主要是想找一个业务方向更聚焦、技术挑战更大的平台。"

适用：70% 技术面试，各种 level 都通用

要点：

  • 300-500 字 / 2-3 分钟
  • 选 2 个项目展开（不要贪多）
  • 每个项目讲 1-2 个具体亮点（最好有数据）
  • 用技术名词展示深度，但不念列表

🎯 5 分钟版（深度版 / 终面 / 高 level 面试） ​

"你好，我叫 XXX，X 年前端经验，目前在 XX 公司。

我自己的技术成长大致分三个阶段：

第一阶段（0-2 年）：基础建设期。这一段主要在做业务页面、组件库沉淀、熟悉框架原理。我从 Vue 2 学起，后来切到 React，主要靠项目驱动 + 读源码 + 写技术博客沉淀。

第二阶段（2-4 年）：复杂业务 + 工程化。这一段开始做中大型项目。我做过的几个有代表性的：

  • 商户管理 SaaS 平台（React + Next.js，团队 X 人）：这个项目业务复杂度比较高（10+ 模块），我作为前端核心负责两块：

    • 一是接口契约 + 统一请求层，通过 swagger-typescript-api 自动生成 TS 类型和请求方法，配合 Axios 拦截器做 Token 刷新、错误码处理、请求去重（特别是登录失效时的并发请求控制，用了 refresh token 单例队列）
    • 二是复杂业务组件抽象，比如金额输入组件（区分法币和虚拟币的精度）、权限按钮、可配置表格

  • 会员 Web / H5（Vue 2 + SSR + PWA）：这个项目技术栈比较杂，包含 SSR、PWA、三方登录。我做了三块：

    • 用 FingerprintJS 做设备指纹
    • 验证码单例管理器（多请求并发只弹一次）
    • iframe URL 白名单校验（防钓鱼）

第三阶段（4-5 年）：架构能力 + 跨端。这一段开始主导迁移项目和跨端方案。

  • 智能风控平台（Vue 2 → Vue 3 + Vite 迁移）：这个项目是我主导的。80 多个组件，从 mixin 拆分到 setup 组合式，第三方库 ESM 兼容处理，用 esbuild 预构建优化。最后启动时间从 28 秒降到 0.8 秒，HMR 从 2 秒降到 50 毫秒。但包体没明显变小，因为业务代码量大——这个发现也让我理解了 Rollup 和 Webpack 在产物层面的差异。

  • 农业数字化 App + IoT 大屏（uni-app + ECharts）：跨端 + 大屏。ECharts 异步 tooltip、地图和底部轮播联动、WebSocket 在 App 的生命周期管理。

总结一下，我自己的优势：

  1. 业务理解：不只写页面，能从业务视角拆解需求、设计组件
  2. 工程化能力：写过可复用的中间层和组件库，能独立负责一个新项目的脚手架搭建
  3. 跨端经验：Web / H5 / 小程序 / 大屏都做过，能快速上手新技术
  4. 学习能力：Vue 2 到 Vue 3、React 到 Next.js，每次切换都比较快

这次的求职动机：想找一个业务更聚焦、用户量更大、有技术挑战的平台。如果有带人 / 主导项目的机会会更感兴趣。"

适用：

  • 终面 / CTO 面
  • 高级以上岗位
  • 面试官明显想听完整故事

要点：

  • 600-900 字 / 4-5 分钟
  • 分阶段讲成长（比按项目讲更显思考）
  • 突出主导和数据
  • 末段总结能力 + 求职动机

三、4 个项目怎么选 / 怎么讲 ​

选项目的优先级 ​

按"和目标岗位匹配度"选：
  业务复杂度高 + 技术栈匹配 + 有数据 → 必讲
  业务复杂度中等 + 技术栈匹配     → 选讲
  业务简单 或 技术栈不匹配        → 一句话带过

4 个项目的"标签" ​

项目一句话标签适合的场景
商户管理 SaaS复杂业务 + 工程化建设80% 公司都适用，B 端公司必讲
会员 Web / H5SSR + PWA + 三方登录涉及 SSR / 移动端 / 海外业务的公司
智能风控平台Vue 2 → 3 + Vite 迁移Vue 技术栈公司、看重工程化的公司
农业数字化跨端 + 大屏物联网 / 大数据 / ToG 公司

每个项目的"30 秒介绍"模板 ​

商户管理 SaaS 平台 ​

"商户管理 SaaS，React + Next.js + TS，业务复杂度比较高（10+ 模块）。我重点做了接口契约 + 统一请求层（基于 swagger-typescript-api）、可复用组件库、还有金额精度等安全加固。"

会员 Web / H5 ​

"会员服务平台，Vue 2 + SSR + PWA。我负责三件事：FingerprintJS 设备指纹、验证码单例管理器（多请求并发只弹一次）、iframe URL 白名单防钓鱼。"

智能风控平台 ​

"智能风控引擎平台，Vue 2 + Webpack 4 起手，我主导迁移到 Vue 3 + Vite + Pinia。80+ 组件 Composition API 重构，启动时间 28s → 0.8s，HMR 2s → 50ms。"

农业数字化 App + IoT 大屏 ​

"农业数字化，uni-app + ECharts，跨端 App + IoT 大屏。我做了 WebSocket 即时通讯、ECharts 异步 tooltip、地图和底部轮播联动。"

四、为什么看新机会（最容易踩雷的题） ​

万能公式 ​

[对现公司真实不满] + [目标岗位吸引点]

5 个参考话术（根据实际情况选） ​

话术 A：业务方向 ​

"现在公司业务方向有些调整，新项目不太能发挥我的经验。我比较想找一个业务更聚焦、用户量更大的平台。"

话术 B：技术成长 ​

"现在公司技术栈相对稳定了（Vue 2 老项目维护为主），我想找一个技术更新迭代更快、有挑战的环境。"

话术 C：职业发展 ​

"目前团队规模比较小，主导机会有限。希望去一个更大的平台，能带团队、主导更大的项目。"

话术 D：业务/行业 ​

"现公司业务比较窄（主要是 XX），我想拓展行业经验，比如对贵公司的 XX 业务方向（金融/电商/SaaS）很感兴趣。"

话术 E：异地/家庭 ​

"家庭原因计划换城市发展 / 通勤距离想缩短，对贵公司的位置比较满意。"

❌ 不要说的话 ​

  • ❌ "现公司领导不行 / 同事太差 / 加班太多"
  • ❌ "薪资太低"
  • ❌ "被裁员 / 公司倒闭"
  • ❌ "想躺平"
  • ❌ 任何对前雇主的负面评价

五、自我介绍常见误区 ​

误区反例改法
念简历"我叫 XXX，2020 年毕业于 XX 大学，在 XX 公司担任 XXX..."讲故事，跳过基础信息
技术栈罗列"我熟悉 React、Vue、Angular、Webpack、Vite、Rollup..."一句话带过主力技术栈
流水账项目 1 干了 A，项目 2 干了 B...选 1-2 个项目讲亮点
没有数据"我做了性能优化""启动时间从 28s 降到 0.8s"
没有钩子介绍完就停下来末句留钩子引导追问
超时自我介绍讲 5 分钟还没完严格控制时间，3 分钟最佳
过于谦虚"我做得不够好，能力一般..."自信表达，主动展示

六、面试官听完自我介绍后的高频追问 ​

1. "你刚才提到的 XX 项目，能具体讲讲吗？" ​

✅ 准备好每个项目的 STAR：

  • Situation（背景）：项目什么场景，多少用户
  • Task（任务）：你的职责和挑战
  • Action（行动）：你具体做了什么
  • Result（结果）：数据化产出

2. "你刚才说 XX，这个具体怎么做的？" ​

✅ 自我介绍里只说关键词，细节留给追问。

反例：

❌ 我用了 swagger-typescript-api，它是一个 npm 包，可以通过 npx swagger-typescript-api -p xxx 生成 client 文件，然后 import { ... } from './api'...

正例：

✅ 我用 swagger-typescript-api 自动生成 TS 类型和请求方法。

3. "你为什么离职？" ​

→ 参考第四章"为什么看新机会"
