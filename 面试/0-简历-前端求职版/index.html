Section titled “三、个人简介（3 句话）”

一句话一个层次：技术栈 + 亮点 + 求职意向。

模板 A（B 端 SaaS 方向）

Section titled “模板 A（B 端 SaaS 方向）”

7 年前端经验，主力技术栈 React + TypeScript + Next.js，最近 2 年主导多个 B 端运营后台（10+ 模块 / 80+ 组件），擅长接口契约 + 统一请求层 + 组件库沉淀。同时熟悉 Vue 生态，主导过 Vue 2 + Webpack 4 → Vue 3 + Vite + Pinia 的完整迁移（启动 28s → 0.8s）。希望找一个业务聚焦、有技术挑战的中后台方向。

模板 B（全栈 / 独立交付方向）

Section titled “模板 B（全栈 / 独立交付方向）”

7 年前端，最近 2 年在向 Node.js BFF + Next.js 全栈扩展，能独立负责前后端（Next.js App Router + Prisma + PostgreSQL + Server Actions）。擅长工程化建设（Monorepo / 微前端 / 性能优化）。希望找一个全栈方向、能带团队的中高级岗位。

模板 C（AI 方向差异化）

Section titled “模板 C（AI 方向差异化）”

7 年前端 + 半年后转 AI Agent。最近在系统学习 LLM 集成（流式输出 / Function Calling / RAG / MCP），做过前端 + LLM实战项目（ChatGPT 风格聊天 UI + 文档问答 + Function Calling 工具调用）。希望找一个前端为主、为转型 Agent 铺路的岗位。

七、简历注意事项

7.1 必须做的事

Section titled “7.1 必须做的事”
  • 量化指标：启动 28s → 0.8s、80+ 组件、+40% 效率
  • 关键词：技术栈用英文（HR 搜索）
  • STAR 结构：背景/任务/行动/结果
  • PDF 版本：不要 PDF 丢排版
  • GitHub / 博客：必须 LinkedIn 完整可达
  • 简历不超过 1 页 A4（项目描述多则细看项目版本）

7.2 不要做的事

Section titled “7.2 不要做的事”
  • ❌ 不要“主管 / 经理”等 management 词汇（除非真的带人）
  • ❌ 不要写“熟悉 React、Vue、Angular、Webpack、Vite、Rollup…”（技术栈堆叠）
  • ❌ 不要“熟练 Excel / Word”
  • ❌ 不要照片（除非外企 / 国企）
  • ❌ 不要“期望薪资”（HR 面再谈）
  • ❌ 不要“自我评价” |
  • ❌ 不要贴身份证号 / 籍贯 / 婚育

八、不同公司类型的简历变体

Section titled “八、不同公司类型的简历变体”

8.1 大厂（字节 / 阿里 / 腾讯）

Section titled “8.1 大厂（字节 / 阿里 / 腾讯）”

重点：

  • 技术深度 > 业务广度
  • 量化指标 > 业务故事
  • 难点 > 顺带

示例：

  • “主导 Vue 2 → Vite 完整迁移，启动从 28s 降到 0.8s”
  • “设计组件库沉淀 80+ 组件，新模块开发效率 +40%”

8.2 外企（Amazon / Google / Microsoft）

Section titled “8.2 外企（Amazon / Google / Microsoft）”

重点：

  • 业务 impact（user impact / revenue）
  • 全英文（如果有英文版）
  • Leadership / cross-team collaboration

示例：

  • “Reduced business time by 60%, saving 200k USD/year”
  • “Led frontend team of 5 engineers across 2 offices”

8.3 创业公司

Section titled “8.3 创业公司”

重点：

  • 全栈能力（一个人能扛起大半个项目）
  • 交付速度（快糙猛）
  • 业务理解（知道什么是 MVP）

示例：

  • “独立负责 Web + H5 + 小程序三个端，3 个月上线”
  • “Node.js BFF 层覆盖后端，”

8.4 AI 方向（差异化）

Section titled “8.4 AI 方向（差异化）”

重点：

  • 前端 + AI 实战（流式 / Function Calling / RAG）
  • 半年后转型计划
  • 前端能力是基础，AI 能力是差异

示例：

  • “集成 LLM API，实现 ChatGPT 风格聊天 UI + Function Calling 工具调用”
  • “前端 + AI 组合架构（Vercel AI SDK + 流式输出 + RAG 可视化）”

📝 小结

Section titled “📝 小结”
  • 五段式结构:基本信息 → 个人简介 → 技能图谱 → 工作经历 → 项目经验,顺序不能乱,HR 只看前 30 秒。
  • 简介 3 句话:我是谁(年限 + 领域)→ 我最强的一项能力 → 我最近在做什么。
  • 技能图谱按熟练度分级(精通/熟练/了解),只写真正敢被追问的,不要罗列全家桶。
  • 项目经验四个,每个用 STAR + 量化结果:背景、任务、行动、结果(必须有数字)。
  • 简历的真正目的:给面试官一条「深挖链路」——每写一项技术,就该准备好被问三层(是什么 → 原理 → 你的项目怎么用)。
  • 变体:外企强调英文与国际化,大厂强调规模与复杂,创业公司强调一个人能干什么。
