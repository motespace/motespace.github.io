准备阶段（面试前 1 天）

Section titled “准备阶段（面试前 1 天）”

Section titled “着装仪表”
公司类型 推荐

沟通要点

Section titled “沟通要点”
  1. 眼神交流：看眉心或鼻梁，避免一直盯纸 / 地面
  2. 身体语言：坐姿自然、适度前倾（表示在听）
  3. 回答结构：结论先行 + 理由 / 例子支撑
  4. 听不懂的题：直接说“这块我没深入过，但我猜是 XXX 思路”——展示思考 > 假装懂
  5. 被 challenge：先肯定再补，“您说得对，我再补充一下…”

四、远程面试技巧

Section titled “四、远程面试技巧”

设备 / 环境

Section titled “设备 / 环境”
  • 网络稳定（手机热点备用）
  • 摄像头清晰（背景简洁、自然光优先）
  • 麦克风清晰（耳机优先、提前测音）
  • 桌面整洁（避免私人物品出镜）
  • 关闭无关软件（IM 通知、邮件等）

工具

Section titled “工具”
  • 主流平台：腾讯会议 / 飞书 / 钉钉 / Zoom，提前 30 分钟测试客户端
  • 共享屏幕：能熟练切换屏幕（避免展示桌面混乱）
  • 在线编码：牛客 / CodeSandbox，提前熟悉快捷键

流程注意

Section titled “流程注意”
  • 提前 10 分钟进入会议
  • 面试开始前主动说“老师您好，面试开始时麻烦您说一声”
  • 卡顿 / 中断时主动说“我这边网络有点问题，能麻烦您重复一下吗”
  • 共享屏幕前关掉其他标签页、消息通知

五、压力面试应对

Section titled “五、压力面试应对”

⚠️ 高 level 面试官常用：故意质疑你的方案 / 反复追问同一问题 / 表达不友好。

7 种常见套路 + 应对

Section titled “7 种常见套路 + 应对”
套路 举例 应对
故意质疑 “你这个方案不行啊…” “理解您的考虑，我的设计是 XXX（理由），如果场景是 YYY 我会改成 ZZZ”
反复追问 “为什么不是 XXX？” 不急躁，从不同维度再答一遍
打断式 “这个不对，你说重点” 立即收口，“重点是 XXX”，避免长篇大论
沉默压力 答完后等 5 秒不说话 不主动填满沉默，“还有想问的吗？“或等面试官开口
连续否定 “我们不要这种东西” 不争辩，“明白，那您想要的方向是？”
拒绝回答 “你自己想” 沉默 5 秒后给出假设答案
超时打断 答到一半 “下一个题” 不纠结没答完的部分，转下一题

核心原则

Section titled “核心原则”
  • 保持冷静：不急躁、不反驳、不辩解
  • 主动为收：遇到压力测试你立刻认怂或换思路
  • 展示抗压：压力下条理清晰 = 真实能力的体现

六、STAR 法则完整版

Section titled “六、STAR 法则完整版”

描述“最有挑战的事”、“最有成就的事”必用。

STAR 四要素

Section titled “STAR 四要素”
要素 含义 时长占比
Situation 背景：项目场景 / 规模 / 复杂度 10%
Task 任务：你的角色 / 责任 / 目标 10%
Action 行动：技术选型 / 实现 / 关键决策 70%
Result 结果：数据化产出 / 业务价值 / 团队收益 10%

反例 vs 正例

Section titled “反例 vs 正例”

❌ 反例

Section titled “❌ 反例”

“我做过一个性能优化，把启动时间缩短了。”

✅ 正例

Section titled “✅ 正例”

“我们接管了一个 Vue 2 + Webpack 4 的老项目（S：模块 80+，启动 28 秒），我作为前端 owner（T），主导了 Vue 3 + Vite + Pinia 迁移。A：先把 mixin 重构成 Composition API（按 use case 拆分），再做第三方库 ESM 兼容，最后用 shallowRef 优化大列表。R：启动时间从 28s 降到 0.8s，HMR 从 2s 降到 50ms。”

七、反问清单（面试官问“你有什么想问的”）

Section titled “七、反问清单（面试官问“你有什么想问的”）”

⚠️ 必问 2-3 个。空着不答 = 你不重视这份工作。

按面试阶段选

Section titled “按面试阶段选”

一面（技术基础）

Section titled “一面（技术基础）”
  • 团队目前前端基建 / CI / 监控体系是什么水平？
  • 团队有内部技术分享 / 周会机制吗？

二面（项目 / 编码）

Section titled “二面（项目 / 编码）”
  • 我入职后第一个月会负责什么模块？
  • 团队里有没有资深工程师的话，能讲讲他的成长路径吗？

三面（架构 / 终面）

Section titled “三面（架构 / 终面）”
  • 团队明年的技术规划是什么？
  • 公司 / 部门目前最大的技术挑战是什么？
  • 您在团队里最看重工程师的什么品质？

HR 面（谈薪前）

Section titled “HR 面（谈薪前）”
  • 团队规模和构成？
  • 工作时间 / 加班强度？
  • 入职流程大概多久？

❌ 不要问

Section titled “❌ 不要问”
  • ❌ 薪资（HR 面单独议）
  • ❌ 加班强度（终面或入职前问）
  • ❌ “您觉得我能过吗”（不专业）
  • ❌ “贵公司为什么要招这个岗位”（潜台词不好）
  • ❌ 同时面几家公司（暴露不专注）

八、面试结束后的复盘

Section titled “八、面试结束后的复盘”

每次面试结束后立刻（30 分钟内）：

  1. 复盘每道题：
    • 答得好的：为什么答得好？
    • 答得差的：哪一步卡住？怎么改进？
    • 答错 / 不会的：补到复习清单
  2. 记录面试官追问：补充到项目经验
  3. 整理公司问题：后面问 HR / 二面参考
  4. 调整自我介绍：根据面试官反馈微调

九、面试避坑清单

Section titled “九、面试避坑清单”
  • 不要迟到（提前 10 分钟到）
  • 不要背简历（讲故事 > 列经历）
  • 不要争辩（“你说得对，我再补充”）
  • 不要过度谦虚（“我做得不够好”）
  • 不要提别人（同事 / 领导 / 前公司）
  • 不要问薪资（一面不问、二面可议、HR 面谈）
  • 不要“我不会”——“我没深入过，但我的理解是…”
  • 不要长时间沉默——主动问“这块能给我点提示吗”
  • 不要说“我要看公司发展”——“我想要稳定发展”比“公司给我什么”

📝 小结

Section titled “📝 小结”
  • 覆盖线下全流程:提前到场与设备检查 → 进门寒暄 → 自我介绍 → 项目讲解 → 技术问答 → 反问 → 结束收尾。
  • 核心原则是降低对方认知成本:一次只讲一件事,先结论后细节,主动控制节奏。
  • 不同面试官关注点不同:HR 关心稳定性与动机,技术面试官关心深度与真实性,主管关心业务理解与协作。
  • 项目讲解节奏:3 分钟版本 → 看对方反应决定是否展开;不要一口气讲完所有细节。
  • 反问环节准备 3 个:团队规模与技术栈、当前最大挑战、这个岗位半年后的期待——不要问薪资。
  • 收尾:整理面试要点与承诺的补充材料,当天写复盘(被问倒的题要记下来)。
  • 临场兜底:听不懂先复述确认,不会就说推理方向,不要沉默或硬编。
