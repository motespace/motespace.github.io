摘自 场景面试题库

29. 首屏白屏优化

Section titled “29. 首屏白屏优化”

场景：SaaS 后台首次打开白屏 3-5 秒，用户以为系统挂了，怎么优化？

答案要点：

追问：

  • 骨架屏怎么写？→ 手写 HTML 占位 / 用 vue-content-loader / 自动生成（puppeteer 截图 + 高斯模糊）
  • 怎么兼顾 SEO？→ SSR 输出完整 HTML 给爬虫 + 客户端 hydrate
  • 优化到什么程度算“够用”？→ Web Vitals 阈值（LCP < 2.5s、INP < 200ms、CLS < 0.1）

30. 图片优化（懒加载 + 响应式 + CDN）

Section titled “30. 图片优化（懒加载 + 响应式 + CDN）”

场景：商品列表页有 100 张图，每张 500KB，首屏加载 5MB+，怎么优化？

答案要点：

追问：

  • 怎么选 CDN？→ 节点覆盖、回源带宽、价格、是否支持图片处理参数
  • AVIF 兼容性？→ Chrome/Edge/Safari 16+ 支持，老浏览器降级到 WebP（picture 标签自动 fallback）
  • 怎么防止布局抖动（CLS）？→ aspect-ratio 预设宽高比，或提前占位固定尺寸

31. Excel 大数据量导出（10 万行不卡死）

Section titled “31. Excel 大数据量导出（10 万行不卡死）”

场景：商户后台要导出 10 万条订单数据，怎么不卡死浏览器 + 不爆内存？

答案要点：

追问：

  • 流式导出用户体验？→ 加 loading + 进度条（XHR onprogress / fetch 流读取）
  • Excel 太大打不开？→ 推荐 CSV（更轻量）或拆成多个 sheet
  • 怎么防止服务端 OOM？→ DB 游标 + 流式写入 + 不要一次性 find() collect 全部
  • 怎么防止用户重复点击导出？→ 按钮 disabled + 后端去重（同用户 5 分钟内只允许一个任务）

📝 小结

Section titled “📝 小结”
  • 性能场景题要落到指标与手段:首屏(LCP)、交互(INP)、稳定(CLS)、以及业务转化。
  • 典型场景:白屏时间长、首屏包体积大、列表卡顿、动画掉帧、弱网加载慢、频繁请求导致服务端压力。
  • 手段:路由懒加载与代码分割、预加载关键资源、图片格式与尺寸、骨架屏、CDN 与缓存策略、虚拟列表、transform/opacity 动画、节流防抖、服务端聚合与 SSR。
  • 答题必须带测量与结论:用 Lighthouse / DevTools / RUM 定位到具体阶段,再给优化方案和前后数字。
  • 面试加分:讲一次「指标没有变好,复盘发现是第三方脚本拖慢」,体现以数据为准。
