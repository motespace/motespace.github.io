五、安全 / 风控场景题

摘自 场景面试题库

26. CSRF 防护

Section titled “26. CSRF 防护”

场景：用户在商户后台发起转账时，打开了钓鱼页，钓鱼页用用户登录态 cookie 自动发起转账请求，怎么办？

答案要点：

追问：

  • SameSite=Strict 有什么坑？→ 第三方链接点进来跳到站内会丢登录态（电商/银行用 Lax）
  • CSRF Token 怎么防重放？→ 加时间戳 + 一次性 token（用一次失效）
  • 为什么不只校验 Referer？→ Referer 可被禁用（隐私模式）或被 strip，安全不可控

27. 越权访问防护

Section titled “27. 越权访问防护”

场景：商户 A 猜 URL 改成 /order/1001，结果看到的是商户 B 的订单。怎么防？

答案要点：

追问：

  • 为什么不只靠前端隐藏入口？→ 前端可被绕过（DevTools 直接调 API）
  • 每个接口都查权限性能问题？→ 角色-权限缓存 + JWT 内嵌权限点 + DB 索引
  • 数据权限怎么做更优雅？→ ABAC（属性级访问控制），中间件统一注入 user 上下文

28. 敏感数据脱敏展示

Section titled “28. 敏感数据脱敏展示”

场景：后台用户列表展示身份证、手机号、银行卡，怎么做脱敏防止截图泄露？

答案要点：

追问：

  • 怎么实现“点眼睛查看完整身份证”？→ 二次权限校验 + 完整操作日志（谁、何时、为什么看）
  • 脱敏规则怎么统一管理？→ utils 层 + 配 ESLint 禁止散落各页面
  • 日志里打印敏感字段？→ 拦截 console.log + beforeSend 上报过滤

📝 小结

Section titled “📝 小结”
  • 前端安全场景题重点:XSS/CSRF/点击劫持在业务里的真实形态,以及风控与内容安全。
  • 业务形态:富文本编辑器(用户内容渲染 → XSS)、URL 跳转(开放重定向)、文件上传(类型校验、恶意文件)、postMessage 跨域通信、iframe 嵌套、埋点上报携带敏感信息。
  • 防御体系:CSP(script-src + nonce)、输出转义与 DOMPurify、SameSite + CSRF Token、点击劫持用 X-Frame-Options/frame-ancestors、上传走后端校验与病毒扫描。
  • 业务风控:验证码、短信限流、接口签名与防重放、敏感操作二次确认、操作日志与审计。
  • 面试加分:能讲「我们在编辑器里怎么防 XSS」这类具体实现,而不是背概念。
