一、后台系统（SaaS）场景题

摘自 场景面试题库

1. 登录态失效的并发处理

Section titled “1. 登录态失效的并发处理”

场景：用户登录态过期时正在操作页面（如提交表单），突然同时发起 10 个接口请求，全部返回 401，怎么办？

答案要点：

追问：

  • 刷新 token 接口也失败了怎么办？→ 强制跳登录页 + 清状态
  • 多个 401 请求同时来了会怎样？→ 共享同一个 refreshing Promise，避免重复刷新
  • 用户在 A 标签页刷新了 token，B 标签页怎么同步？→ localStorage 事件或 BroadcastChannel

2. 富文本 XSS 防护

Section titled “2. 富文本 XSS 防护”

场景：用户用富文本编辑器发布公告，粘贴一段 &lt;script>alert(1)</script> 进去，怎么防止 XSS？

答案要点：

追问：

  • SVG 里的 &lt;use> 能 XSS 吗？→ 能，用 &lt;svg>&lt;use href="data:image/svg+xml;base64,xxx"> 触发
  • 用户输入 markdown 怎么办？→ markdown-it 解析后再过 DOMPurify
  • 为什么不只靠前端？→ 防绕过（关 JS 也得安全）

3. 列表双击重复提交

Section titled “3. 列表双击重复提交”

场景：用户快速双击“保存”按钮，触发了两次创建接口，导致数据重复。

答案要点：

追问：

  • 两个用户同时点怎么办？→ 后端做幂等（请求 ID + 去重表）
  • 网络慢导致用户多次点击 → 按钮 disabled + loading 状态
  • 提交后想修改 → 乐观锁（version 字段）

4. 三层权限统一管理

Section titled “4. 三层权限统一管理”

场景：菜单 / 按钮 / 接口 三层权限如何统一？新增一个“财务”角色要改 100 处。

答案要点：

追问：

  • 按钮怎么不闪烁？→ 状态就绪前不渲染按钮（用 v-if 而不是 v-show）
  • 后端改了权限怎么办？→ 定期刷新 + WebSocket 推送
  • 多角色用户（既是 admin 又是 editor）？→ 权限取并集

5. 后端改了字段前端要改 200 个地方

Section titled “5. 后端改了字段前端要改 200 个地方”

场景：后端把 userName 改成 username，前端 200 个地方用了，怎么改不漏？

答案要点：

追问：

  • 后端没规范 swagger 怎么办？→ 推动后端写 OpenAPI 规范
  • 字段名相同时类型不更新？→ 在生成脚本加 hash 检查
  • 老字段过渡期？→ 类型用 Pick&lt;User, 'userName' | 'username'> 兼容

6. 1 万行表格滚动卡顿

Section titled “6. 1 万行表格滚动卡顿”

场景：用户列表页 1 万行，滚动时 FPS 掉到 10 以下，怎么优化？

答案要点：

追问：

  • 表格需要按列排序怎么办？→ 后端排序 + 前端虚拟滚动
  • 选中多行怎么操作？→ 维护 selection 状态 + Map<id, item>
  • 1 万行 vs 分页哪个好？→ 100+ 行用分页，1000+ 用虚拟滚动

7. 用户反馈“页面打不开了”

Section titled “7. 用户反馈“页面打不开了””

场景：生产环境用户报“页面打不开了”，怎么排查？

答案要点：

追问：

  • Sentry 配置成本？→ 接入 SDK 1 行，配置 sentry.config.ts
  • 用户隐私？→ 上传前过滤敏感字段（密码、身份证）
  • 怎么减少误报？→ 配置 ignoreErrors + beforeSend 钩子

8. 跨标签页状态同步

Section titled “8. 跨标签页状态同步”

场景：在 A 标签页登出，B 标签页怎么同步跳登录页？

答案要点：

追问：

  • storage 事件能跨域吗？→ 不能（同源策略限制）
  • BroadcastChannel 兼容性？→ Chrome 54+、Firefox 38+、Safari 15.4+，老 Safari 不支持
  • 标签页之间的状态完全同步方案？→ Pinia + storage 持久化 + storage 事件

9. 大文件上传（断点续传）

Section titled “9. 大文件上传（断点续传）”

场景：用户上传 1GB 的视频文件，网络断了怎么办？

答案要点：

追问：

  • 大文件 hash 计算慢？→ 用 Web Worker + 增量 hash
  • 多个分片上传失败？→ retry with exponential backoff
  • 暂停/继续上传？→ 用 tus 协议或自实现分片队列

10. 实时协作（多人同时编辑）

Section titled “10. 实时协作（多人同时编辑）”

场景：多人同时编辑一个文档，怎么实现？

答案要点：

追问：

  • CRDT 和 OT 的区别？→ CRDT 无中心可合并，OT 需要中心协调
  • 离线编辑怎么处理？→ Yjs 内置，操作存本地，重连后合并
  • 性能？→ 10 万字符文档 + 100 用户同时编辑，< 100ms 延迟

📝 小结

Section titled “📝 小结”
  • SaaS 后台的核心复杂度不是页面多,而是多租户 + 高密度表单/表格 + 权限与配置驱动。
  • 高频场景:可配置表格(动态列、列宽记忆、自定义筛选)、复杂表单(联动、校验、动态字段)、批量操作、权限(按钮级 + 数据级)、多租户隔离(域名/租户 ID 贯穿请求与缓存 key)。
  • 答题框架:业务复杂度 → 技术难点 → 方案选型 → 落地细节 → 结果与复用。
  • 通用工程答案:组件抽象(设计系统 + 业务组件)、Schema 驱动表单、配置化表格、统一的请求与权限层、埋点与监控闭环。
  • 面试加分:讲清「一个可配置表格要处理哪些边界」(列宽、排序、分页、列显隐、固定列、导出、空态、加载态),体现真实经验。
