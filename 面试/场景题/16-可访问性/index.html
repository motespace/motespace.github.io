摘自 场景面试题库

54. 国际化（i18n）多语言

Section titled “54. 国际化（i18n）多语言”

场景：SaaS 后台要支持中/英/日三语，UI 文案、日期、数字、货币都要本地化，怎么做？

答案要点：

追问：

  • i18next 和 FormatJS 怎么选？→ react-i18next 上手简单；FormatJS（react-intl）功能更强
  • 翻译文件怎么管理？→ 平台协作（避免开发维护）+ CI/CD 自动化
  • 性能影响？→ 按需加载（不打包）+ 命名空间懒加载
  • RTL 语言支持？→ CSS dir='rtl' + 镜像布局（margin/padding 反向）

55. 暗色模式实现

Section titled “55. 暗色模式实现”

场景：后台支持亮色 / 暗色切换，怎么做到不闪屏、可持久化、跟随系统？

答案要点：

追问：

  • 怎么防闪屏？→ &lt;head&gt; 内联脚本同步设置主题（在 CSS 应用前）
  • 怎么跟随系统？→ prefers-color-scheme + 监听变化
  • 暗色模式对比度问题？→ 避免纯黑+纯白，用灰阶 + WCAG AA 对比度 4.5:1
  • 怎么测试？→ Chrome DevTools → Rendering → Emulate CSS media feature

📝 小结

Section titled “📝 小结”
  • 可访问性(a11y)题在国内外面试中权重上升,重点:语义化、键盘可达、焦点管理、对比度、ARIA 的正确使用、屏幕阅读器。
  • 常见问题:用 div 模拟按钮(无法键盘聚焦、无 role)、弹窗不管理焦点(焦点跑到背景)、图片无 alt、表单 label 缺失、颜色对比度不足、动画未尊重 prefers-reduced-motion。
  • 国际化场景:多语言下的文本膨胀(德语比中文长 30%,按钮要留弹性宽度)、日期/数字/货币的 Intl 格式化、时区处理、RTL 布局、字体回退与 i18n 资源按需加载。
  • 落地:建立 a11y 检查清单、CI 里跑 axe 自动化扫描、键盘操作走查。
  • 面试加分:能讲「我们怎么用 Intl.NumberFormat 解决金额与日期的多地区展示」。
