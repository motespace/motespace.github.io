影刀入门 ​

影刀是国内主流的可视化 RPA 工具,零代码搭流程,适合产品/运营自助。

一、为什么选影刀 ​

工具类型学习曲线适用
影刀可视化 RPA低(拖拽)业务人员 / 产品
UiBot可视化 RPA低业务人员
弘玑企业级 RPA中大型企业流程
Playwright + Python代码 RPA中-高工程师 / 复杂场景

影刀的优势:

  • 国产,中文文档
  • 内置浏览器 / 桌面 / 文件 / Excel 等大量组件
  • 异常处理可视化拖拽
  • 免费版功能足够个人/小团队使用

二、影刀核心概念 ​

流程(Process)
  ├── 步骤(Step) - 单个动作(打开网页、点击、输入)
  ├── 变量(Variable) - 数据存储
  ├── 控制流(if/for/异常处理) - 流程控制
  └── 异常处理 - 失败重试 / 告警

三、典型流程示例 ​

场景:从 Excel 读客户名单 → 自动登录 CRM → 添加客户 ​

[开始]
  ↓
[读取 Excel] customer.xlsx → DataFrame
  ↓
[循环 每行]
  ↓
  [打开网页] crm.example.com
  ↓
  [输入框 输入] 手机号 → DataFrame.手机号
  ↓
  [输入框 输入] 姓名 → DataFrame.姓名
  ↓
  [点击] 提交按钮
  ↓
  [等待] 页面出现"添加成功"文字
  ↓
  [截图保存] 客户ID_姓名.png
  ↓
[结束循环]
  ↓
[结束]

异常处理 ​

[尝试]
  ↓ 主体流程
[捕获异常]
  ↓
[截图] 保存现场
  ↓
[飞书通知] 运维群
  ↓
[写入日志] error_logs.log

四、影刀 vs Python 选型 ​

用影刀的场景:

  • 流程能在 UI 上完整跑通
  • 业务人员要自助维护
  • 不需要复杂逻辑(< 50 个判断分支)

用 Python 的场景:

  • 需要复杂数据处理(pandas)
  • 高并发(> 100 任务并行)
  • 要嵌入到 Web 服务里
  • 反爬要求高(指纹伪装、代理池)
  • 长期维护成本敏感(代码更可控)

五、影刀调用 Python ​

影刀支持执行 Python 脚本组件,处理复杂逻辑:

[影刀流程]
  ↓
[执行 Python 脚本]
    import pandas as pd
    data = pd.read_excel(r'{{Excel路径}}')
    filtered = data[data['金额'] > 1000]
    result = filtered.to_dict('records')
  ↓ 返回 result 给影刀变量

六、影刀高级用法 ​

1. 命令行调用(适合 CI/CD) ​

影刀支持 headless 模式跑流程,通过命令行触发:

bash
yingdao.exe --headless --process "daily_report.dgs" --params "date=2025-01-15"

2. 影刀 + Python 混合架构 ​

Python 服务 (FastAPI)
  ↓ HTTP
影刀客户端(调度、监控)
  ↓ 执行
影刀流程(具体业务)

Python 负责:任务调度、参数下发、结果收集、监控看板

影刀负责:实际页面操作、文件处理、Excel 处理

3. 调度与监控 ​

python
# Python 调度影刀
import requests

def trigger_yingdao(process_name, params):
    return requests.post(
        'http://yingdao-server:8080/api/trigger',
        json={'process': process_name, 'params': params}
    ).json()

trigger_yingdao('daily_report', {'date': '2025-01-15'})

七、踩坑总结 ​

坑解决
元素定位失败优先用 ID/CSS Selector,XPath 慢且脆
流程跑一半卡住加超时 + 异常处理 + 截图
网页改版全流程失效元素定位尽量稳定,定期维护
多账号并发被 ban加随机等待 + 减少频率
影刀收费功能个人版/创业版通常够用
调试困难日志要详细,关键节点截图

八、推荐学习路径 ​

  1. 第 1 周:影刀基础 + 第一个流程(自动登录某个系统)
  2. 第 2 周:循环 + 异常处理 + 飞书告警
  3. 第 3 周:Excel 处理 + 数据筛选 + 报表生成
  4. 第 4 周:实战完整业务场景
  5. 持续:遇到反爬/复杂场景,转 Playwright + Python

💡 影刀是降低 RPA 门槛的好工具,但复杂业务最终还是要靠 Python 代码。两者结合用最稳。
