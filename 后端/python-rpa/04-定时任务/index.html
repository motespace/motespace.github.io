坑 解决
时区错乱(UTC vs 本地) 设 timezone='Asia/Shanghai'
任务阻塞导致后续任务延迟 用 AsyncIOScheduler 或多线程
cron 不执行 先用 crontab -l 看是否生效;systemctl status cron
重启丢失任务 用 SQLAlchemyJobStore 持久化
多个进程同时跑同一任务 加文件锁 fcntl 或 Redis SETNX
任务执行时间过长 设 max_instances=1 + coalescing=True
