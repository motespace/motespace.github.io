浏览器自动化 ​

Playwright / Selenium 模拟浏览器操作,处理 JS 渲染、复杂交互场景。

一、Playwright(推荐) ​

安装 ​

bash
pip install playwright
playwright install chromium  # 下载浏览器

基础用法 ​

python
from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.launch(headless=True)
    page = browser.new_page()

    # 打开网页
    page.goto('https://example.com')

    # 等待元素出现
    page.wait_for_selector('#login-btn')

    # 填写表单
    page.fill('input[name="username"]', 'alice')
    page.fill('input[name="password"]', 'secret')

    # 点击
    page.click('#login-btn')

    # 等待跳转
    page.wait_for_url('**/dashboard**')

    # 截图
    page.screenshot(path='dashboard.png', full_page=True)

    # 提取数据
    title = page.text_content('h1')

    browser.close()

异步版(高并发) ​

python
import asyncio
from playwright.async_api import async_playwright

async def scrape(url):
    async with async_playwright() as p:
        browser = await p.chromium.launch(headless=True)
        page = await browser.new_page()
        await page.goto(url)
        return await page.title()

async def main():
    urls = ['https://example.com/page1', 'https://example.com/page2']
    results = await asyncio.gather(*[scrape(u) for u in urls])
    print(results)

asyncio.run(main())

二、元素定位策略(优先级) ​

python
# 1. ID(最快、最稳)
page.click('#submit')

# 2. CSS Selector
page.click('button.primary')

# 3. data-testid(测试友好属性,推荐)
page.click('[data-testid="login-btn"]')

# 4. text 内容
page.click('text=登录')

# 5. placeholder
page.fill('input[placeholder="请输入手机号"]', '13800138000')

# 6. XPath(慢、脆,尽量避免)
page.click('//button[contains(text(), "登录")]')

实战项目:Always 主动给关键元素加 data-testid 属性:

html
<button data-testid="login-btn">登录</button>

三、等待策略(关键) ​

python
# 1. 等待元素出现(推荐)
page.wait_for_selector('#result', timeout=10000)

# 2. 等待元素可见
page.wait_for_selector('#loading', state='hidden')

# 3. 等待 URL 变化
page.wait_for_url('**/success**')

# 4. 等待固定时间(不推荐,慢且脆)
import time; time.sleep(3)

# 5. 自定义等待
page.wait_for_function(
    'document.querySelector("#status").innerText === "完成"',
    timeout=10000
)

四、处理登录态 ​

python
# 方案 1:Cookie 复用
context.add_cookies([{
    'name': 'session',
    'value': 'xxx',
    'domain': '.example.com',
    'path': '/',
}])

# 方案 2:登录态持久化(storage_state)
context = browser.new_context(storage_state='auth.json')

# 方案 3:Playwright auto login
context = browser.new_context()
page = context.new_page()
page.goto('https://example.com/login')
page.fill('#username', 'alice')
page.fill('#password', 'secret')
page.click('#login-btn')
page.wait_for_url('**/dashboard**')
context.storage_state(path='auth.json')  # 保存

# 下次启动直接用
context = browser.new_context(storage_state='auth.json')

九、踩坑总结 ​

坑解决
headless 模式被检测用 headless=False 或用 undetected-playwright
元素定位失败加 wait_for_selector + 改用 data-testid
页面被反爬识别见 05-RPA反爬实战
Cookie 跨域问题设 sameSite: 'None' + secure: True
截图中文乱码安装中文字体
浏览器自动更新playwright install --with-deps 固定版本
内存泄漏用完 page.close() / context.close()
超长页面卡顿wait_until='domcontentloaded' 替代默认
