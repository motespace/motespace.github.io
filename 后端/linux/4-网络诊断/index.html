⚠️ 容易踩的坑

Section titled “⚠️ 容易踩的坑”
坑 表现 解决
ping 不通但服务能用 ICMP 被防火墙挡 改用 nc 测端口
curl https:// 超时 443 出不去 检查防火墙 / 代理 / 云安全组
curl 能通,浏览器不行 浏览器代理 / DNS / 缓存 排查浏览器设置
容器里 ping 不通 容器默认无 ping apt install iputils-ping 或用 nc
ss 看不到连接 在另一个 net namespace nsenter -t PID -n ss -tunap
端口被监听但外网访问不到 防火墙 / 安全组 / 监听 127.0.0.1 ss -tulnp 看监听地址
0.0.0.0 vs 127.0.0.1 0.0.0.0 接所有,127.0.0.1 只接本地 服务监听 0.0.0.0 才能外网访问
DNS 缓存导致改 hosts 不生效 dig 还是老 IP systemd-resolve --flush-caches
TCP TIME_WAIT 巨多 高并发短连接后 ss -tan state time-wait | wc -l,调 net.ipv4.tcp_tw_reuse=1
