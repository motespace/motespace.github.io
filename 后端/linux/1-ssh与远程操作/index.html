scp vs rsync:

维度 scp rsync
协议 ssh ssh
增量 ❌ 每次全传 ✅ 只传差异
断点续传 ❌ ✅ (--partial)
删除目标端多余文件 ❌ ✅ (--delete)
适合 小文件 / 一次性 大目录 / 定期同步

⚠️ 容易踩的坑

Section titled “⚠️ 容易踩的坑”
坑 表现 解决
私钥权限太大 Permissions 0644 too open chmod 600 ~/.ssh/id_*
改了 authorized_keys 不生效 权限问题 chmod 700 ~/.ssh && chmod 600 ~/.ssh/authorized_keys
ssh-copy-id 不存在 macOS 老版本 手动 cat ~/.ssh/id_*.pub | ssh ...
跳板机转发卡顿 GFW / 网络问题 加 -o "ProxyCommand=nc ..." 或换工具
主机 key 变了报警告 REMOTE HOST IDENTIFICATION HAS CHANGED ssh-keygen -R host 清掉旧 key
rsync 路径结尾斜杠 行为不一样 源 /path/ 拷内容,/path 拷整个目录
服务器改 SSH 端口忘了 连不上 加 -p 2222 或写 config
长时间无操作断开 tmux / screen 配 ServerAliveInterval
