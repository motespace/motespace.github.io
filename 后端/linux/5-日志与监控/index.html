📊 系统监控指标

Section titled “📊 系统监控指标”

关键指标(CNCF / Prometheus 标准)

Section titled “关键指标(CNCF / Prometheus 标准)”
类别 指标
CPU 使用率、load、各核状态
内存 已用 / 可用 / swap / cache
磁盘 空间使用率、IOPS、await
网络 入 / 出带宽、丢包率、错误包
应用 QPS、延迟、错误率
业务 注册数、订单数(自定义)

USE 原则(Brendan Gregg):

  • Utilization:使用率
  • Saturation:饱和度
  • Errors:错误数

⚠️ 容易踩的坑

Section titled “⚠️ 容易踩的坑”
坑 表现 解决
日志塞满磁盘 DB / 应用挂了 logrotate + 监控告警
日志没时间戳 排错找不到时间 应用打日志带 ISO 时间
多个服务时间不同步 日志关联不上 装 chrony / ntpd
单日志文件 GB 级 grep / tail 慢 logrotate 切小
监控指标太多 Prometheus 撑爆 控制 scrape interval / 标签基数
告警太频繁(告警风暴) 没人看 配 for: 5m / 静默规则
告警发邮件没人查 告警等于没有 接电话 / 短信 / 钉钉强提醒
Grafana dashboard 没人维护 监控变成摆设 选社区热门 ID,定期 review
docker / k8s 日志文件化 容器删日志丢 接 stdout 到 Loki / 云日志
