dstat 资源综合(需装)

⚠️ 容易踩的坑

Section titled “⚠️ 容易踩的坑”
坑 表现 解决
free 看 free 不看 available 以为内存够,实际紧张 看 available
kill -9 滥用 数据丢 / 客户端卡死 先 SIGTERM,等 5 秒再 SIGKILL
满盘找不到大文件 删了 inode 没释放 lsof | grep deleted
IO 高 = 应用慢? 可能是磁盘坏 dmesg 看硬件错
load 高但 CPU 不忙 可能是 IO 等待 看 %wa
内存占用越来越高 真泄漏,不是缓存 看 RSS / VSZ 趋势,不是 cache
ps 看 RSS 一直涨 内存泄漏 heapdump / 找大对象
没监控告警,出问题才发现 事后排查 接 Prometheus / 云监控
