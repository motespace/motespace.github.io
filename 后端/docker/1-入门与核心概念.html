Docker 入门与核心概念 ​

Docker 是"应用打包"的标准 —— 把代码 + 运行时 + 依赖打成一个镜像,到处跑。 本文从零开始,讲清镜像 / 容器 / 仓库的关系,跑出第一个容器。

❓ 为什么需要 Docker ​

经典场景:

text
开发:"我这里跑得起来啊"
测试:"我这里跑不起来"
运维:"生产又挂了"

根因:运行环境不一致(系统库版本、Python 版本、glibc、时区、环境变量...)。

Docker 的解法:把应用 + 运行时 + 配置打包成一个镜像,任何地方跑都一样。

text
传统部署:  代码 + 环境(各机器不同)   → 经常挂
Docker:    镜像(代码+环境一体化)    → 到处跑

🧱 核心概念:镜像 / 容器 / 仓库 ​

概念比喻是什么
镜像(Image)类 / 模板只读的"应用快照"(nginx:1.25、myapp:v1.0)
容器(Container)实例 / 对象镜像运行起来的进程(可读可写)
仓库(Registry)GitHub存镜像的地方(Docker Hub / 私有仓库)
Dockerfile配方描述怎么构建镜像
Volume外挂硬盘容器持久化数据
Network虚拟网络容器之间、容器和外部通信

关系:Dockerfile → 构建 → 镜像 → 运行 → 容器,镜像可以推到仓库,别人拉下来跑。

📦 安装 Docker ​

macOS / Windows ​

下载 Docker Desktop:https://www.docker.com/products/docker-desktop/

Linux ​

bash
# Ubuntu / Debian
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER      # 当前用户加入 docker 组(免 sudo)
newgrp docker

# 验证
docker --version
docker run hello-world             # 跑通说明 OK

配置镜像加速(国内) ​

/etc/docker/daemon.json:

json
{
  "registry-mirrors": [
    "https://docker.mirrors.ustc.edu.cn",
    "https://hub-mirror.c.163.com"
  ]
}
bash
sudo systemctl restart docker

🚀 第一个容器 ​

bash
# 跑一个 nginx
docker run -d -p 8080:80 --name my-nginx nginx
# -d:    后台运行
# -p:    端口映射(主机 8080 → 容器 80)
# --name:容器命名

# 浏览器访问 http://localhost:8080

# 看运行中的容器
docker ps

# 看所有容器(包括停止的)
docker ps -a

# 看日志
docker logs my-nginx

# 停止
docker stop my-nginx

# 启动(用之前停止的)
docker start my-nginx

# 删除
docker rm my-nginx

🛠️ 常用 CLI 命令 ​

镜像相关 ​

bash
docker images                          # 本地镜像列表
docker pull nginx:1.25                 # 拉镜像
docker rmi nginx:1.25                  # 删镜像
docker tag myapp:latest myapp:v1.0     # 打 tag
docker image prune                     # 清悬空镜像
docker image prune -a                  # 清所有不用镜像

容器相关 ​

bash
docker run -d nginx                    # 后台跑
docker run -it ubuntu bash             # 交互式
docker ps / docker ps -a               # 列表
docker logs -f my-nginx                # 跟踪日志
docker exec -it my-nginx bash          # 进容器
docker stop / start / restart          # 启停
docker rm -f my-nginx                  # 强删
docker stats                           # 资源占用
docker inspect my-nginx                # 元数据(JSON)

系统相关 ​

bash
docker system df                       # 看磁盘占用
docker system prune                    # 清无用资源
docker system prune -a --volumes       # 全清(慎用)
docker info                            # 引擎信息

📦 镜像操作 ​

bash
# 搜索镜像
docker search mysql

# 拉镜像
docker pull mysql:8.0                  # tag 默认 latest
docker pull ubuntu:22.04

# 看镜像历史(各层)
docker history nginx:1.25

镜像命名规范 ​

[registry/][namespace/]name[:tag]

text
nginx                          # Docker Hub 官方,latest
nginx:1.25                     # tag
myregistry.com/myteam/myapp:v1.0
gcr.io/google-project/image    # Google 镜像

♻️ 容器生命周期 ​

   docker create
       ↓
   Created
       ↓ docker start
   Running ←──── docker restart
       ↓ docker stop
   Stopped
       ↓ docker rm
   (删除)
bash
docker create --name web nginx        # 只创建不启动
docker start web                      # 启动已创建的
docker pause web                      # 暂停进程(内存仍占)
docker unpause web
docker kill web                       # SIGKILL(强杀)

⚠️ 容易踩的坑 ​

坑表现解决
容器跑起来就退出docker ps 看不到用 docker ps -a 看 exit 状态,看日志
端口被占用bind: address already in uselsof -i :8080 找占用 / 换端口
-d 后台跑看不到日志报错也看不到改前台跑 / docker logs -f
改了容器内文件没保存容器重启后丢失用 volume 持久化
用户权限问题permission denied 挂载文件加 :ro 或匹配 UID(--user)
docker pull 慢国内网络问题配置 registry-mirrors
镜像占满磁盘no space left on devicedocker system prune 清无用
docker exec 进容器命令找不到bash 不存在改 sh / ash
时区不对容器时间比主机晚 8 小时-e TZ=Asia/Shanghai 或挂 /etc/localtime
