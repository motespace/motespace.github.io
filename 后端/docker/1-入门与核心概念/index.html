❓ 为什么需要 Docker

Section titled “❓ 为什么需要 Docker”

经典场景:

根因:运行环境不一致(系统库版本、Python 版本、glibc、时区、环境变量…)。

Docker 的解法:把应用 + 运行时 + 配置打包成一个镜像,任何地方跑都一样。

🧱 核心概念:镜像 / 容器 / 仓库

Section titled “🧱 核心概念:镜像 / 容器 / 仓库”

概念 比喻 是什么
镜像(Image) 类 / 模板 只读的“应用快照”(nginx:1.25、myapp:v1.0)
容器(Container) 实例 / 对象 镜像运行起来的进程(可读可写)
仓库(Registry) GitHub 存镜像的地方(Docker Hub / 私有仓库)
Dockerfile 配方 描述怎么构建镜像
Volume 外挂硬盘 容器持久化数据
Network 虚拟网络 容器之间、容器和外部通信

关系:Dockerfile → 构建 → 镜像 → 运行 → 容器,镜像可以推到仓库,别人拉下来跑。

⚠️ 容易踩的坑

Section titled “⚠️ 容易踩的坑”
坑 表现 解决
容器跑起来就退出 docker ps 看不到 用 docker ps -a 看 exit 状态,看日志
端口被占用 bind: address already in use lsof -i :8080 找占用 / 换端口
-d 后台跑看不到日志 报错也看不到 改前台跑 / docker logs -f
改了容器内文件没保存 容器重启后丢失 用 volume 持久化
用户权限问题 permission denied 挂载文件 加 :ro 或匹配 UID(--user)
docker pull 慢 国内网络问题 配置 registry-mirrors
镜像占满磁盘 no space left on device docker system prune 清无用
docker exec 进容器命令找不到 bash 不存在 改 sh / ash
时区不对 容器时间比主机晚 8 小时 -e TZ=Asia/Shanghai 或挂 /etc/localtime
