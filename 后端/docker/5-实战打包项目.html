🟢 实战 1:Node + MySQL ​

myapp/
├── Dockerfile
├── docker-compose.yml
├── .dockerignore
├── package.json
└── src/
    └── server.js

Dockerfile ​

dockerfile
# ---- 阶段 1:依赖 ----
FROM node:20-alpine AS deps
WORKDIR /app
COPY package*.json ./
RUN npm ci --only=production

# ---- 阶段 2:构建(如果有 TS / 打包)----
FROM node:20-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

# ---- 阶段 3:运行 ----
FROM node:20-alpine
WORKDIR /app
ENV NODE_ENV=production

COPY --from=deps   /app/node_modules ./node_modules
COPY --from=builder /app/dist ./dist
COPY package.json ./

USER node
EXPOSE 3000

HEALTHCHECK --interval=30s --timeout=3s \
  CMD wget -qO- http://localhost:3000/health || exit 1

CMD ["node", "dist/server.js"]

docker-compose.yml ​

yaml
services:
  web:
    build: .
    ports:
      - "3000:3000"
    environment:
      - DB_HOST=db
      - DB_PORT=3306
      - DB_USER=root
      - DB_PASSWORD=${DB_PASSWORD}
      - DB_NAME=myapp
    depends_on:
      db:
        condition: service_healthy
    restart: unless-stopped

  db:
    image: mysql:8.0
    environment:
      MYSQL_ROOT_PASSWORD: ${DB_PASSWORD}
      MYSQL_DATABASE: myapp
    volumes:
      - db_data:/var/lib/mysql
      - ./init.sql:/docker-entrypoint-initdb.d/init.sql
    healthcheck:
      test: ["CMD", "mysqladmin", "ping", "-h", "localhost", "-uroot", "-p${DB_PASSWORD}"]
      interval: 5s
      timeout: 3s
      retries: 10

volumes:
  db_data:

🐍 实战 2:Python FastAPI + Redis ​

myapi/
├── Dockerfile
├── docker-compose.yml
├── .dockerignore
├── requirements.txt
└── main.py

requirements.txt ​

fastapi==0.115.0
uvicorn[standard]==0.30.0
redis==5.0.0

main.py ​

python
from fastapi import FastAPI
import redis

app = FastAPI()
r = redis.Redis(host="cache", port=6379)

@app.get("/")
def root():
    return {"status": "ok"}

@app.get("/count")
def count():
    n = r.incr("hits")
    return {"hits": n}

Dockerfile ​

dockerfile
FROM python:3.12-slim AS builder
WORKDIR /app
RUN apt-get update && apt-get install -y --no-install-recommends gcc && rm -rf /var/lib/apt/lists/*
COPY requirements.txt .
RUN pip wheel --no-cache-dir --wheel-dir /wheels -r requirements.txt

FROM python:3.12-slim
WORKDIR /app
COPY --from=builder /wheels /wheels
COPY requirements.txt .
RUN pip install --no-cache-dir --no-index --find-links=/wheels -r requirements.txt && rm -rf /wheels

COPY . .

RUN useradd -m app && chown -R app:app /app
USER app

EXPOSE 8000
HEALTHCHECK --interval=30s CMD curl -f http://localhost:8000/ || exit 1
CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]

docker-compose.yml ​

yaml
services:
  api:
    build: .
    ports:
      - "8000:8000"
    depends_on:
      - cache
    environment:
      - REDIS_HOST=cache

  cache:
    image: redis:7-alpine
    volumes:
      - redis_data:/data

volumes:
  redis_data:
bash
docker compose up -d --build
curl http://localhost:8000/

📤 推送到镜像仓库 ​

Docker Hub(公开) ​

bash
# 登录
docker login

# 打 tag
docker tag myapp:1.0 username/myapp:1.0

# 推送
docker push username/myapp:1.0

私有仓库(国内常见:阿里云 ACR / 腾讯云 TCR) ​

bash
# 阿里云例子
docker login registry.cn-hangzhou.aliyuncs.com
docker tag myapp:1.0 registry.cn-hangzhou.aliyuncs.com/myteam/myapp:1.0
docker push registry.cn-hangzhou.aliyuncs.com/myteam/myapp:1.0

拉取运行 ​

bash
docker pull username/myapp:1.0
docker run -d -p 3000:3000 username/myapp:1.0

🏭 生产部署 tips ​

资源限制 ​

yaml
services:
  web:
    image: myapp:1.0
    deploy:
      resources:
        limits:
          cpus: "1.0"
          memory: 512M
        reservations:
          cpus: "0.5"
          memory: 256M

日志 ​

yaml
services:
  web:
    logging:
      driver: json-file
      options:
        max-size: "10m"
        max-file: "3"

只读文件系统 ​

yaml
services:
  web:
    read_only: true
    tmpfs:
      - /tmp
    volumes:
      - uploads:/app/uploads

用 nginx / traefik 反向代理 ​

生产不直接暴露 Node 端口,前面加 nginx:

yaml
services:
  nginx:
    image: nginx:alpine
    ports:
      - "80:80"
      - "443:443"
    volumes:
      - ./nginx.conf:/etc/nginx/nginx.conf
      - ./certs:/etc/nginx/certs:ro
    depends_on:
      - web

⚠️ 容易踩的坑 ​

坑表现解决
镜像几 GB多阶段没做 / 装了一堆工具多阶段构建,只留运行时
容器跑起来访问不了端口没 -p / 防火墙docker port 验证
改了 docker-compose.yml 没生效没 --builddocker compose up -d --build
MySQL 容器重启密码变了改了 MYSQL_ROOT_PASSWORD初始化后密码不能改
镜像推不上去登录失败 / 网络问题配 registry-mirrors
容器不停 OOMKilled内存不足加资源限制 + JVM 调小堆
多个 web 容器端口冲突bind: address already in usescale 不能带端口映射,改用 LB
生产用 latest tag镜像内容不可控锁版本:myapp:1.0.0
容器以 root 跑容器逃逸 = root 权限加 USER app
