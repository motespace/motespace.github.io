⚠️ 容易踩的坑

Section titled “⚠️ 容易踩的坑”
坑 表现 解决
镜像几 GB 多阶段没做 / 装了一堆工具 多阶段构建,只留运行时
容器跑起来访问不了 端口没 -p / 防火墙 docker port 验证
改了 docker-compose.yml 没生效 没 --build docker compose up -d --build
MySQL 容器重启密码变了 改了 MYSQL_ROOT_PASSWORD 初始化后密码不能改
镜像推不上去 登录失败 / 网络问题 配 registry-mirrors
容器不停 OOMKilled 内存不足 加资源限制 + JVM 调小堆
多个 web 容器端口冲突 bind: address already in use scale 不能带端口映射,改用 LB
生产用 latest tag 镜像内容不可控 锁版本:myapp:1.0.0
容器以 root 跑 容器逃逸 = root 权限 加 USER app
