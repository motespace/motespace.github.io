🔄 compose v1 vs v2

Section titled “🔄 compose v1 vs v2”
版本 命令 安装
v1(旧) docker-compose pip install docker-compose(独立 Python 脚本)
v2(新,推荐) docker compose(空格) Docker Desktop / Docker CLI 自带

本文用 v2 语法(最常见,未来标准)。

字段速查

Section titled “字段速查”
字段 作用
image / build 用现成镜像 / 从 Dockerfile 构建
ports 端口映射 "8080:80"
environment 环境变量
env_file 从文件读环境变量
volumes 挂载卷(路径或命名)
depends_on 启动依赖,不等就绪
restart 重启策略(always / unless-stopped / on-failure)
networks 加入的网络
command 覆盖默认启动命令
healthcheck 健康检查
logging 日志配置
deploy.resources 资源限制(CPU / 内存)

⚠️ 容易踩的坑

Section titled “⚠️ 容易踩的坑”
坑 表现 解决
depends_on 不等就绪 web 起来时 db 还没好,连不上 加 condition: service_healthy
改完代码没生效 跑的还是旧镜像 docker compose up --build
数据丢 down -v 把卷删了 生产别用 -v
.env 提交到 git 密码泄露 .gitignore + .env.example 模板
volumes 路径写错 数据没真持久化 用绝对路径或命名卷
端口冲突 起不来 lsof -i :3000 找占用
服务名当 host 用 连不上 db 是 host(在同一 network)
version 字段过时警告 v2 不需要 直接删掉 version: 字段
compose v1 / v2 命令混用 报错 统一用 docker compose(空格)
