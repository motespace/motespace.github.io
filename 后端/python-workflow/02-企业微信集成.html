企业微信集成 ​

企业微信机器人 / 自建应用,跟飞书类似,但 API 略不同。

一、群机器人(Webhook) ​

python
import requests

WEBHOOK = 'https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=<your-key>'

def send_text(content, mentioned_list=None):
    """@指定人用 mentioned_list"""
    resp = requests.post(WEBHOOK, json={
        'msgtype': 'text',
        'text': {
            'content': content,
            'mentioned_list': mentioned_list or [],
        }
    })
    return resp.json()

def send_markdown(content):
    return requests.post(WEBHOOK, json={
        'msgtype': 'markdown',
        'markdown': {'content': content}
    }).json()

# @某人
send_text('@张三 这个订单异常', mentioned_list=['zhangsan'])
send_markdown('**实时告警**\\n异常订单数:5')

二、自建应用(完整能力) ​

python
import requests
import json
from datetime import datetime

class WecomClient:
    def __init__(self, corp_id, corp_secret, agent_id):
        self.corp_id = corp_id
        self.corp_secret = corp_secret
        self.agent_id = agent_id
        self._token = None
        self._token_expire = 0

    def get_access_token(self):
        if self._token and datetime.now().timestamp() < self._token_expire:
            return self._token
        resp = requests.get(
            'https://qyapi.weixin.qq.com/cgi-bin/gettoken',
            params={'corpid': self.corp_id, 'corpsecret': self.corp_secret}
        ).json()
        if resp.get('errcode') != 0:
            raise RuntimeError('token err: ' + str(resp))
        self._token = resp['access_token']
        self._token_expire = datetime.now().timestamp() + resp['expires_in'] - 60
        return self._token

    def send_app_message(self, user_ids, content):
        """给指定用户发应用消息(成员 userid,逗号分隔)"""
        return requests.post(
            'https://qyapi.weixin.qq.com/cgi-bin/message/send',
            params={'access_token': self.get_access_token()},
            json={
                'touser': ','.join(user_ids) if isinstance(user_ids, list) else user_ids,
                'msgtype': 'text',
                'agentid': self.agent_id,
                'text': {'content': content}
            }
        ).json()

client = WecomClient(
    corp_id=os.environ['WECOM_CORP_ID'],
    corp_secret=os.environ['WECOM_CORP_SECRET'],
    agent_id=1000001,
)
client.send_app_message(['zhangsan'], '订单异常,请尽快处理')

五、踩坑总结 ​

坑解决
回调 URL 必须公网可访问用 ngrok / cloudflared / 反代
msg_signature 校验失败检查 token / EncodingAESKey 配置
应用看不到消息检查应用可见范围,默认仅创建者可见
接收消息需配置 API 接收后台「应用主页」→ API 接收消息
