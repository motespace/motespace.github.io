飞书集成 ​

通过飞书开放平台,把 Python 接入企业 IM:发消息、读写多维表格、自动办公。

一、自定义机器人(Webhook) ​

最简方案,无需注册应用,直接给群发消息:

python
import requests
import json

WEBHOOK = 'https://open.feishu.cn/open-apis/bot/v2/hook/<your-token>'

def send_text(content):
    resp = requests.post(WEBHOOK, json={
        'msg_type': 'text',
        'content': {'text': content}
    })
    return resp.json()

def send_card(title, fields):
    resp = requests.post(WEBHOOK, json={
        'msg_type': 'interactive',
        'card': {
            'header': {
                'title': {'tag': 'plain_text', 'content': title},
                'template': 'blue'
            },
            'elements': [
                {'tag': 'div', 'fields': [
                    {'is_short': True, 'text': {'tag': 'lark_md',
                     'content': '**' + f['label'] + '**\\n' + f['value']}}
                    for f in fields
                ]}
            ]
        }
    })
    return resp.json()

send_text('hello from python')
send_card('今日销售报表', [
    {'label': 'GMV', 'value': '128500'},
    {'label': '订单数', 'value': '342'},
])

注意:Webhook URL 含 token,不能提交到 git。用环境变量:

python
import os
WEBHOOK = os.environ['FEISHU_WEBHOOK']

二、应用 API(完整能力) ​

需要先在飞书开放平台创建应用 → 开通权限 → 发布版本:

python
import requests
from datetime import datetime

class FeishuClient:
    def __init__(self, app_id, app_secret):
        self.app_id = app_id
        self.app_secret = app_secret
        self._token = None
        self._token_expire = 0

    def get_tenant_token(self):
        if self._token and datetime.now().timestamp() < self._token_expire:
            return self._token
        resp = requests.post(
            'https://open.feishu.cn/open-apis/auth/v3/tenant_access_token/internal',
            json={'app_id': self.app_id, 'app_secret': self.app_secret}
        )
        data = resp.json()
        if data['code'] != 0:
            raise RuntimeError('token failed: ' + str(data))
        self._token = data['tenant_access_token']
        self._token_expire = datetime.now().timestamp() + data['expire'] - 60
        return self._token

    def send_message(self, receive_id, msg_type, content):
        return requests.post(
            'https://open.feishu.cn/open-apis/im/v1/messages',
            params={'receive_id_type': 'open_id'},
            headers={'Authorization': 'Bearer ' + self.get_tenant_token()},
            json={
                'receive_id': receive_id,
                'msg_type': msg_type,
                'content': json.dumps(content),
            }
        ).json()

client = FeishuClient(
    app_id=os.environ['FEISHU_APP_ID'],
    app_secret=os.environ['FEISHU_APP_SECRET']
)
client.send_message('ou_xxxxx', 'text', {'text': '你好,这是 Python 发的消息'})

三、多维表格(Bitable)API ​

飞书多维表格 = 在线 Excel + API,可当轻量数据库用:

python
class BitableClient:
    def __init__(self, feishu):
        self.f = feishu

    def list_records(self, app_token, table_id):
        all_records = []
        page_token = None
        while True:
            params = {'page_size': 500}
            if page_token:
                params['page_token'] = page_token
            resp = requests.get(
                'https://open.feishu.cn/open-apis/bitable/v1/apps/' + app_token + '/tables/' + table_id + '/records',
                headers={'Authorization': 'Bearer ' + self.f.get_tenant_token()},
                params=params
            ).json()
            if resp['code'] != 0:
                raise RuntimeError(str(resp))
            all_records.extend(resp['data']['items'])
            if not resp['data']['has_more']:
                break
            page_token = resp['data']['page_token']
        return all_records

    def add_record(self, app_token, table_id, fields):
        return requests.post(
            'https://open.feishu.cn/open-apis/bitable/v1/apps/' + app_token + '/tables/' + table_id + '/records',
            headers={'Authorization': 'Bearer ' + self.f.get_tenant_token()},
            json={'fields': fields}
        ).json()

四、实战:每日数据推送 ​

python
import schedule, time

def job_daily_report():
    from datetime import datetime, timedelta
    yesterday = (datetime.now() - timedelta(days=1)).strftime('%Y-%m-%d')
    gmv = 128500
    orders = 342
    send_card(yesterday + ' 销售日报', [
        {'label': 'GMV', 'value': str(gmv)},
        {'label': '订单数', 'value': str(orders)},
    ])

schedule.every().day.at('09:00').do(job_daily_report)

while True:
    schedule.run_pending()
    time.sleep(60)

五、踩坑总结 ​

坑解决
Webhook 群发限制 100 次/分加限流或换应用 API
应用 API 需要先发布版本后台创建版本再发布
多维表格字段类型是字符串数字字段传 int/float,日期传 timestamp(ms)
token 2 小时过期Client 自动刷新(见上)
IP 白名单限制安全设置加服务器公网 IP
频控 1000 次/分钟加令牌桶限流

六、推荐库 ​

  • 飞书官方 SDK:lark-oapi,自动处理签名/token
  • Webhook 简单场景:直接 requests
  • 多维表格复杂场景:用 SDK 的 bitable 模块
