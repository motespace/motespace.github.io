日期变成数字 parse_dates=['date'] 或 dtype=str
大文件慢 用 pandas + chunksize,或 openpyxl 只读模式 read_only=True
xls 和 xlsx 格式不兼容 openpyxl 只支持 xlsx;xls 用 xlrd
公式不更新 读用 data_only=True,写完调用 wb.calculation.calcMode = 'auto'
