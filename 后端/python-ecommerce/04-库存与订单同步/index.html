八、踩坑总结

Section titled “八、踩坑总结”
坑 解决
API 频控被 ban 加 retry + 限流(令牌桶)
部分 SKU 同步失败 重试 3 次 + 失败的进死信队列
库存不一致(超卖) 中心库存扣减时用事务锁
Webhook 重复触发 用 order_id 幂等去重
多平台订单冲突 每个平台加 source 字段
时区问题 Shopify UTC,入库时统一转本地
库存为 0 时仍可下单 库存预扣减(下单时减 + 支付时减)
