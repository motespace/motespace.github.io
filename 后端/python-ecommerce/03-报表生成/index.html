大表格导出慢 openpyxl 用 wb.save() 多次增量
数字格式不对 显式设 cell.number_format
邮件 HTML 渲染差 用 table 布局,inline CSS
PDF 字体不支持中文 注册中文字体(msyh.ttf)
报表发送失败无感知 异常捕获 + 飞书告警 + 重试
