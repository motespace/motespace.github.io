FastAPI 入门 ​

FastAPI 是类型提示驱动的现代 Python Web 框架,自动生成 OpenAPI 文档。 性能接近 Go / Node,生态活跃,AI / 数据领域的事实标准。

🎯 学到这步能做什么 ​

  • 用 FastAPI 起一个 REST API
  • 用 Pydantic 校验请求体(自动、严格)
  • 写依赖注入(Depends)
  • 跑出 /docs 自动 Swagger UI
  • 用 uvicorn 部署到生产

⚖️ FastAPI vs Flask ​

维度FlaskFastAPI
数据校验手动 / Flask-PydanticPydantic 自动
自动文档无 / Flask-RESTX自带 /docs Swagger
类型提示可选强制(驱动框架)
异步Flask 2.0+ 部分支持原生 async/await
性能中等快(基于 Starlette + uvicorn)
学习曲线平缓略陡(要先懂类型提示)
生态老牌、稳新但增长快,AI/数据领域首选

结论:做 API 优先 FastAPI;做传统服务端渲染/老系统对接选 Flask。

🛣️ 路径参数与查询参数 ​

python
from fastapi import FastAPI
from enum import Enum

app = FastAPI()

class Role(str, Enum):
    admin = "admin"
    user = "user"

# 路径参数
@app.get("/users/{uid}")
def get_user(uid: int):                  # 自动校验类型
    return {"uid": uid}

# 路径参数 + 枚举
@app.get("/roles/{role}")
def get_role(role: Role):                # 非法值返回 422
    return {"role": role}

# 查询参数(不在路径里的参数自动当查询参数)
@app.get("/search")
def search(q: str, page: int = 1, size: int = 20):
    return {"q": q, "page": page, "size": size}

# 可选参数
@app.get("/optional")
def op(x: int | None = None):
    return {"x": x}

关键:函数签名里的类型就是契约,FastAPI 自动校验、生成文档。

📦 请求体 Pydantic ​

python
from pydantic import BaseModel, Field
from typing import Optional

class UserIn(BaseModel):
    name: str = Field(..., min_length=1, max_length=50)
    age: int = Field(ge=0, le=150)
    email: str | None = None
    tags: list[str] = []

@app.post("/users")
def create_user(user: UserIn):
    # user 已经校验过,直接用
    return {"id": 1, **user.model_dump()}

Field(...) 的 ... 表示必填,后面的都是校验约束:

约束含义
min_length / max_length字符串长度
ge / le / gt / lt数值大小(>= / <= / > / <)
regex (v1) / pattern (v2)正则
default默认值
description文档里显示

嵌套模型 ​

python
from pydantic import BaseModel

class Address(BaseModel):
    city: str
    zip: str

class User(BaseModel):
    name: str
    address: Address

u = User(name="张三", address={"city": "杭州", "zip": "310000"})
print(u.address.city)   # 杭州

高级:自定义校验器 ​

python
from pydantic import BaseModel, field_validator

class Account(BaseModel):
    username: str
    password: str

    @field_validator("password")
    @classmethod
    def password_strong(cls, v: str) -> str:
        if len(v) < 8:
            raise ValueError("密码至少 8 位")
        if not any(c.isdigit() for c in v):
            raise ValueError("密码必须含数字")
        return v

📤 响应模型 ​

python
from pydantic import BaseModel

class UserOut(BaseModel):
    id: int
    name: str

@app.get("/users/{uid}", response_model=UserOut)
def get_user(uid: int):
    # 即使函数返回 dict / 多字段,FastAPI 会按 UserOut 过滤/校验
    return {"id": uid, "name": "张三", "password": "secret"}
    # 响应里不会出现 password

response_model_exclude_unset=True 可以只返回显式设了的字段。

💉 依赖注入 Depends ​

python
from fastapi import Depends, Header, HTTPException

def get_db():
    db = SessionLocal()
    try:
        yield db                      # 用 yield 做清理
    finally:
        db.close()

@app.get("/items")
def list_items(db = Depends(get_db)):
    return db.query(Item).all()

# 嵌套依赖:鉴权
def get_current_user(token: str = Header(...)):
    user = verify_token(token)
    if not user:
        raise HTTPException(status_code=401, detail="未授权")
    return user

@app.get("/me")
def me(user = Depends(get_current_user)):
    return user

# 类形式的依赖
class Pagination:
    def __init__(self, page: int = 1, size: int = 20):
        self.page = page
        self.size = size

@app.get("/list")
def list(p: Pagination = Depends()):
    return {"page": p.page, "size": p.size}

核心思想:把"获取资源"抽成函数,框架帮你注入 + 自动管理生命周期(用 yield)。

⚡ 异步支持 ​

python
import httpx

@app.get("/proxy")
async def proxy(url: str):
    async with httpx.AsyncClient() as client:
        r = await client.get(url)
    return r.json()

要点:

  • 用 async def 定义路由,FastAPI 在自己的事件循环里跑
  • 调同步阻塞函数(老的 SQLAlchemy / requests)会阻塞,用同步 def 让 FastAPI 放到线程池跑
  • IO 密集用 async,CPU 密集别用(用 BackgroundTasks 或独立 worker)
python
from fastapi import BackgroundTasks

def slow_task(x: int):
    import time; time.sleep(5)
    print(f"done {x}")

@app.post("/jobs")
def create_job(x: int, bg: BackgroundTasks):
    bg.add_task(slow_task, x)          # 后台跑,不阻塞响应
    return {"status": "queued"}

🛠️ 实战:TODO API ​

python
# main.py
from fastapi import FastAPI, HTTPException, Query
from pydantic import BaseModel, Field
from typing import Optional

app = FastAPI(title="TODO API", version="1.0.0")

class TodoIn(BaseModel):
    title: str = Field(..., min_length=1, max_length=200)
    done: bool = False

class Todo(TodoIn):
    id: int

todos: list[Todo] = []
next_id = 1

@app.get("/todos", response_model=list[Todo], tags=["todos"])
def list_todos(done: Optional[bool] = Query(None)):
    return [t for t in todos if done is None or t.done == done]

@app.post("/todos", response_model=Todo, status_code=201, tags=["todos"])
def create_todo(todo: TodoIn):
    global next_id
    t = Todo(id=next_id, **todo.model_dump())
    next_id += 1
    todos.append(t)
    return t

@app.put("/todos/{tid}", response_model=Todo, tags=["todos"])
def update_todo(tid: int, todo: TodoIn):
    for i, t in enumerate(todos):
        if t.id == tid:
            todos[i] = Todo(id=tid, **todo.model_dump())
            return todos[i]
    raise HTTPException(404, "todo not found")

@app.delete("/todos/{tid}", status_code=204, tags=["todos"])
def delete_todo(tid: int):
    global todos
    todos = [t for t in todos if t.id != tid]
    return None

跑起来直接进 /docs 在线测。

📦 部署 uvicorn ​

bash
# 生产(多 worker)
uvicorn main:app --host 0.0.0.0 --port 8000 --workers 4

# Docker 化(常见做法)
dockerfile
FROM python:3.12-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY . .
CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]

--workers 4 是进程数,经验值 = CPU 核数 × 2 + 1。

nginx
server {

⚠️ 容易踩的坑 ​

坑表现解决
Pydantic v1 写法混用 v2dict() / parse_obj() 不存在v2 用 model_dump() / model_validate()
路径参数顺序冲突/users/me 被 /users/{uid} 抢走把具体路径放动态路径前面
async def 里调同步 SQLAlchemy阻塞 event loop改 def,FastAPI 自动用线程池
Python 3.9 以下写 list[int]TypeError用 List[int](老) 或升级 Python ≥ 3.9
response_model 没设内部字段泄漏(password 等)永远显式声明 response_model
CORS 跨域失败前端 fetch 报 CORS加 CORSMiddleware
Optional[X] vs X | None老写法 Optional,新写法 |Python 3.10+ 推荐 |
字段类型写 dict / listPython 3.8 报错用 typing.Dict / typing.List 或升级 Python
Pydantic v2 Field 没 regex 参数v2 改名为 pattern用 pattern=r"..."

加 CORS:

python
from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:3000"],
    allow_methods=["*"],
    allow_headers=["*"],
    allow_credentials=True,
)
