Python 文件操作

Python 的 open() + with 是最常用 IO,几乎所有脚本都基于这套 API。

🎯 学到这步能做什么

Section titled “🎯 学到这步能做什么”
  • 独立写“读文件 → 处理 → 写文件”的脚本
  • 知道 encoding / newline 这两个参数的意义(踩过的人都知道)
  • 知道 pathlib 比 os.path 更现代
  • 大文件不会一次性 read() 进内存

🔓 open() 的 8 种模式

Section titled “🔓 open() 的 8 种模式”
模式 含义
r 只读(默认)
w 写入,不存在则创建,存在则清空
a 追加,写到末尾
x 排他创建,文件已存在则报错
b 二进制模式(配 r/w/a 用,如 "rb")
t 文本模式(默认)
+ 读 + 写(配 r/w/a 用,如 "r+")

pathlib 主要好处:跨平台(/ 操作符适配 \)、可链式、可读性高。新代码统一用 pathlib。

🌊 大文件流式处理

Section titled “🌊 大文件流式处理”

核心原则:不要 read() 整个文件。

⚠️ 容易踩的坑

Section titled “⚠️ 容易踩的坑”
坑 表现 解决
不写 encoding="utf-8" Windows 默认 GBK → 中文乱码 永远显式指定 encoding
print(open(f).read()) 不关 文件句柄泄露(进程退出才释放) 用 with
csv.writer 不写 newline="" Windows 多余空行 加 newline=""
json.dump 默认 ensure_ascii=True 中文全变 \uXXXX 设 ensure_ascii=False
pathlib 与 os.path 混用 类型混乱 统一选一套,推荐 pathlib
读超大 CSV 用 pd.read_csv pandas 会先全读进内存 改用 csv.reader 逐行处理
