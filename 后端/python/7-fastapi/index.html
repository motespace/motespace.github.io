FastAPI 入门

FastAPI 是类型提示驱动的现代 Python Web 框架,自动生成 OpenAPI 文档。 性能接近 Go / Node,生态活跃,AI / 数据领域的事实标准。

Section titled “🎯 学到这步能做什么”
  • 用 FastAPI 起一个 REST API
  • 用 Pydantic 校验请求体(自动、严格)
  • 写依赖注入(Depends)
  • 跑出 /docs 自动 Swagger UI
  • 用 uvicorn 部署到生产

⚖️ FastAPI vs Flask

Section titled “⚖️ FastAPI vs Flask”
维度 Flask FastAPI
数据校验 手动 / Flask-Pydantic Pydantic 自动
自动文档 无 / Flask-RESTX 自带 /docs Swagger
类型提示 可选 强制(驱动框架)
异步 Flask 2.0+ 部分支持 原生 async/await
性能 中等 快(基于 Starlette + uvicorn)
学习曲线 平缓 略陡(要先懂类型提示)
生态 老牌、稳 新但增长快,AI/数据领域首选

结论:做 API 优先 FastAPI;做传统服务端渲染/老系统对接选 Flask。

📦 请求体 Pydantic

Section titled “📦 请求体 Pydantic”

Field(...) 的 ... 表示必填,后面的都是校验约束:

约束 含义
min_length / max_length 字符串长度
ge / le / gt / lt 数值大小(>= / <= / > / <)
regex (v1) / pattern (v2) 正则
default 默认值
description 文档里显示

⚡ 异步支持

Section titled “⚡ 异步支持”

要点:

  • 用 async def 定义路由,FastAPI 在自己的事件循环里跑
  • 调同步阻塞函数(老的 SQLAlchemy / requests)会阻塞,用同步 def 让 FastAPI 放到线程池跑
  • IO 密集用 async,CPU 密集别用(用 BackgroundTasks 或独立 worker)

和 Flask 版逐点对照

Section titled “和 Flask 版逐点对照”
维度 Flask 版 FastAPI 版
入参解析 request.get_json() + 手动判空 Pydantic 模型自动校验,类型不对直接 422
必填校验 if "title" not in data: abort(400) title: str = Field(..., min_length=1) 声明式
路径参数 def get(tid): 从 request.view_args 取 def get(tid: int) 自动转类型,传错也报 422
查询参数 request.args.get("done") 手动转 bool done: Optional[bool] = Query(None) 自动转换
响应约束 手动 jsonify response_model=list[Todo] 自动过滤多余字段 + 生成文档
状态码 默认 200,创建要手动 201 status_code=201 声明
错误 abort(404, "...") raise HTTPException(404, "...")
交互式文档 ❌ 要自己装 Swagger ✅ 自动生成 /docs
代码量 更多(校验/序列化都手写) 更少(框架替你做)

一句话:Flask 给你最小内核,剩下全自己写;FastAPI 把「校验 + 序列化 + 文档」三件事做进了框架,所以代码更短、错误更早暴露。

跑起来直接进 /docs 在线测。

⚠️ 容易踩的坑

Section titled “⚠️ 容易踩的坑”
坑 表现 解决
Pydantic v1 写法混用 v2 dict() / parse_obj() 不存在 v2 用 model_dump() / model_validate()
路径参数顺序冲突 /users/me 被 /users/{uid} 抢走 把具体路径放动态路径前面
async def 里调同步 SQLAlchemy 阻塞 event loop 改 def,FastAPI 自动用线程池
Python 3.9 以下写 list[int] TypeError 用 List[int](老) 或升级 Python ≥ 3.9
response_model 没设 内部字段泄漏(password 等) 永远显式声明 response_model
CORS 跨域失败 前端 fetch 报 CORS 加 CORSMiddleware
Optional[X] vs X | None 老写法 Optional,新写法 | Python 3.10+ 推荐 |
字段类型写 dict / list Python 3.8 报错 用 typing.Dict / typing.List 或升级 Python
Pydantic v2 Field 没 regex 参数 v2 改名为 pattern 用 pattern=r"..."
