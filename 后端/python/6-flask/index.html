Flask 入门

Flask 是 Python 最经典的轻量 Web 框架,哲学是“微小核心 + 大量扩展”。 学 Flask 能帮你理解 Web 框架的通用概念(路由、请求上下文、中间件),后面学 FastAPI 也轻松。

📥 请求对象 request

Section titled “📥 请求对象 request”

要点:

  • request.args 是 ImmutableMultiDict,用 get 安全读
  • request.form 拿 application/x-www-form-urlencoded / multipart
  • request.json 拿 application/json,缺 Content-Type 时是 None

⚠️ 容易踩的坑

Section titled “⚠️ 容易踩的坑”
坑 表现 解决
request.json 是 None 没设 Content-Type: application/json request.get_json(force=True) 强制解析(不推荐)
修改了代码但页面没变 debug=True 没开 / 缓存了模板 确认 app.run(debug=True)
生产用 app.run() 单进程、性能差、reload 卡住 用 gunicorn / uvicorn
在视图外用 request RuntimeError: Working outside of request context 在视图函数内用,或手动 push context
session 当数据库用 数据存 cookie,只适合小数据 重数据用 Redis / DB
没设 SECRET_KEY 就用 session 报错 app.config["SECRET_KEY"] = "随机字符串"
abort(400, "msg") 后没自定义 handler 错误页是 HTML 写 @app.errorhandler(400) 返回 JSON
静态文件用 Flask 直接 serve 生产性能差 Nginx 直接 serve /static/
CORS 没配前端调不通 浏览器报 CORS 用 flask-cors 扩展
