Python 常用内置库 ​

Python 标准库是最大的"宝藏"——大部分需求不用 pip install。 本文挑 6 个最常用的:re / collections / itertools / functools / dataclasses / typing。

🎯 学到这步能做什么 ​

  • 用 re 写正则(提取日志、解析文本)
  • 用 collections.Counter / defaultdict 替代手写 dict 计数
  • 用 itertools / functools 写出更 Pythonic 的代码
  • 用 dataclass 省掉 __init__ / __repr__
  • 用 typing 给函数加类型提示,IDE 自动补全

📚 章节目录 ​

  • re:正则

🔍 re:正则 ​

python
import re

text = "订单号: ORD-2024-001,金额 99.5 元"

# 1. search:找第一个匹配
m = re.search(r"ORD-(\d+)-(\d+)", text)
if m:
    print(m.group(1))     # 2024
    print(m.group(2))     # 001

# 2. findall:找所有
prices = re.findall(r"\d+\.\d+", text)
# ['99.5']

# 3. sub:替换
clean = re.sub(r"\s+", " ", "hello   world")  # "hello world"

# 4. split:切分
parts = re.split(r"[,;:]", "a,b;c:d")         # ['a', 'b', 'c', 'd']

常用模式速查 ​

模式含义
\d / \D数字 / 非数字
\w / \W字母数字下划线 / 非
\s / \S空白 / 非空白
.任意字符(除换行)
^ / $行首 / 行尾
* / + / ?0+ / 1+ / 0-1
{n,m}n 到 m 次
[abc] / [^abc]字符类 / 排除
(...) / (?:...)捕获组 / 非捕获
(?=...) / (?!...)前瞻 / 负前瞻

预编译(高频正则一定要) ​

python
PHONE_RE = re.compile(r"1[3-9]\d{9}")
PHONE_RE.findall("打我 13800001111 或 13900002222")
# ['13800001111', '13900002222']

EMAIL_RE = re.compile(r"[\w.+-]+@[\w-]+\.[\w.-]+")
EMAIL_RE.findall("联系我:foo.bar@baz.cn")

性能差异:循环 10000 次时,预编译比每次 re.search 快 10 倍以上。

命名分组:可读性 > 索引 ​

python
import re

text = "2024-01-15 用户 张三 下单"
m = re.search(r"(?P<year>\d{4})-(?P<month>\d{2})-(?P<day>\d{2})", text)
m.group("year")     # 2024
m.group("month")    # 01
m["day"]            # 15

📦 collections:容器加强版 ​

python
from collections import Counter, defaultdict, OrderedDict, deque, namedtuple

# Counter:词频统计(神器)
words = ["apple", "banana", "apple", "orange", "banana", "apple"]
c = Counter(words)
print(c.most_common(2))    # [('apple', 3), ('banana', 2)]
print(c["apple"])          # 3
print(c["not_exist"])      # 0(不报错)

# 两个 Counter 相加
c2 = Counter(["apple", "banana"])
c + c2                     # Counter({'apple': 4, 'banana': 3, 'orange': 1})

# defaultdict:缺 key 自动用默认值
groups = defaultdict(list)
for name, team in [("张三", "A"), ("李四", "B"), ("王五", "A")]:
    groups[team].append(name)
print(dict(groups))
# {'A': ['张三', '王五'], 'B': ['李四']}

# deque:双端队列(频繁头尾操作,O(1))
q = deque([1, 2, 3])
q.appendleft(0)             # 头部追加
q.append(4)                 # 尾部追加
q.popleft()                 # 头部弹出

# namedtuple:带名字的 tuple(轻量数据类)
Point = namedtuple("Point", ["x", "y"])
p = Point(1, 2)
print(p.x, p.y)             # 1 2(像访问属性)

🔗 itertools:迭代器工具箱 ​

python
from itertools import chain, groupby, product, combinations, islice, count

# chain:拼接多个迭代器
list(chain([1, 2], [3, 4]))                   # [1, 2, 3, 4]

# product:笛卡尔积
list(product([1, 2], ["a", "b"]))
# [(1, 'a'), (1, 'b'), (2, 'a'), (2, 'b')]

# combinations:组合(无序,不重复)
list(combinations([1, 2, 3], 2))              # [(1,2), (1,3), (2,3)]

# groupby:分组(**必须先 sort!**)
data = [
    {"team": "A", "name": "张三"},
    {"team": "A", "name": "王五"},
    {"team": "B", "name": "李四"},
]
data.sort(key=lambda d: d["team"])
for team, group in groupby(data, key=lambda d: d["team"]):
    print(team, [g["name"] for g in group])
# A ['张三', '王五']
# B ['李四']

# islice:对生成器做切片
gen = (i * i for i in range(100))
list(islice(gen, 5))                          # [0, 1, 4, 9, 16]

# count:无限计数器
from itertools import count
for n in count(10, 2):         # 从 10 开始,步长 2
    if n > 20: break
    print(n)                   # 10, 12, 14, 16, 18, 20

🎁 functools:函数式工具箱 ​

python
from functools import lru_cache, partial, reduce, wraps

# lru_cache:记忆化(递归/重复计算必备)
@lru_cache(maxsize=128)
def fib(n):
    if n < 2: return n
    return fib(n-1) + fib(n-2)

print(fib(100))   # 瞬间出,没有 lru_cache 会卡死

# partial:固定部分参数
def power(base, exp):
    return base ** exp

square = partial(power, exp=2)
print(square(5))  # 25

# reduce:折叠
nums = [1, 2, 3, 4]
reduce(lambda a, b: a + b, nums)         # 10

# wraps:写装饰器时保留原函数元信息
def my_decorator(fn):
    @wraps(fn)
    def wrapper(*args, **kwargs):
        print("before")
        result = fn(*args, **kwargs)
        print("after")
        return result
    return wrapper

🏷️ dataclasses:数据类 ​

@dataclass 自动生成 __init__ / __repr__ / __eq__:

python
from dataclasses import dataclass, field
from typing import List

@dataclass
class User:
    name: str
    age: int = 0
    tags: List[str] = field(default_factory=list)   # 可变默认值用 factory

u = User("张三")
u2 = User("张三", age=20)
print(u == u2)        # False(__eq__ 自动)
print(repr(u))        # User(name='张三', age=0, tags=[])

进阶用法:

python
from dataclasses import dataclass, asdict, replace, fields

@dataclass(frozen=True)            # 不可变实例
class Point:
    x: float
    y: float

p = Point(1, 2)
p.x = 3                            # FrozenInstanceError

# 冻结实例还能当 dict key / 放进 set
points = {Point(1, 2), Point(3, 4)}

# 不可变 dataclass 自动支持 lru_cache
@lru_cache(maxsize=128)
def distance(p: Point) -> float:
    return (p.x ** 2 + p.y ** 2) ** 0.5

# 替换字段(生成新对象,不修改原对象)
p2 = replace(p, x=10)

适用场景:纯数据容器(DTO、配置、返回结构)。不要给行为多的类用 dataclass,正常写 class。

🔤 typing:类型提示 ​

类型提示不影响运行时,但能:

  • IDE 智能补全 + 静态检查
  • 文档作用
  • mypy / pyright 在 CI 里拦截错误
python
from typing import List, Dict, Optional, Tuple, Any, Callable

# 函数签名
def find(items: List[str], keyword: str) -> Optional[str]:
    for it in items:
        if keyword in it:
            return it
    return None

# Python 3.9+:内置 list / dict 可以直接用作类型
def process(data: list[int]) -> dict[str, int]:
    return {"count": len(data)}

# Python 3.10+:可以用 | 表示 Union
def parse(raw: str | bytes) -> dict | None:
    ...

进阶:TypedDict / Protocol / Literal ​

python
from typing import TypedDict

class UserInfo(TypedDict):
    name: str
    age: int

def greet(info: UserInfo) -> str:
    return f"hi, {info['name']}"

greet({"name": "张三", "age": 18})  # IDE 会校验 key 是否齐全
python
from typing import Protocol

class Drawable(Protocol):
    def draw(self) -> None: ...

# 结构化类型:任何实现了 draw() 方法的对象都满足
def render(obj: Drawable) -> None:
    obj.draw()
python
from typing import Literal

# 字面量类型:只能是特定值
def set_mode(mode: Literal["r", "w", "a"]) -> None:
    ...

set_mode("r")     # OK
set_mode("x")     # IDE/mypy 报错

静态检查工具 ​

工具特点
mypy老牌,Python 官方系生态
pyright微软出品,VSCode Pylance 用它,速度快
ruffRust 写的 linter,带 type 检查(实验)

新项目默认加 pyright 或 mypy,能提前发现大量拼写错误。

⚠️ 容易踩的坑 ​

坑表现解决
Counter 返回 0 但 c["x"] += 1 报错计数不存在,先报 KeyError用 defaultdict(int) 或先 c["x"] = 0
groupby 没排序就分组分组错乱(只把连续相同的分一组)groupby 前必须 sort,或用 itertools.groupby 之外的方案
dataclass 默认值是可变对象共享同一个 list/dict,跨实例污染用 field(default_factory=list)
lru_cache 缓存 list 参数TypeError: unhashable包成 tuple,或用 @functools.cache(3.9+)
类型提示写 list[int]Python 3.8 报 TypeError用 List[int](老) 或升级 Python ≥ 3.9
re.search 忘看 NoneNone.group(1) 报错先 if m: 再用
re.findall 带分组返回的是分组列表,不是整段加捕获组: re.findall(r"(?:pattern)", text) 用非捕获组
写 @dataclass 加复杂方法失去数据类的意义行为多的类用普通 class
