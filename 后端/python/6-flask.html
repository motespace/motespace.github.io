Flask 入门 ​

Flask 是 Python 最经典的轻量 Web 框架,哲学是"微小核心 + 大量扩展"。 学 Flask 能帮你理解 Web 框架的通用概念(路由、请求上下文、中间件),后面学 FastAPI 也轻松。

🎯 学到这步能做什么 ​

  • 用 Flask 起一个 REST API
  • 理解路由 / 请求对象 / 响应 / 模板
  • 用 Blueprint 做模块化
  • 用 g / session 做请求级数据
  • 用 gunicorn / waitress 部署到生产

🚀 最小应用 ​

bash
pip install flask
python
# app.py
from flask import Flask

app = Flask(__name__)

@app.route("/")
def index():
    return "hello, flask"

if __name__ == "__main__":
    app.run(debug=True)

启动:python app.py → http://127.0.0.1:5000/

app.run() 启动的是 Werkzeug 内置开发服务器,只用于开发。生产用 gunicorn / waitress。

🛣️ 路由 ​

python
@app.route("/")                          # 根路径
@app.route("/hello")                     # 静态路径

@app.route("/user/<name>")               # 动态路径,默认 string
@app.route("/post/<int:post_id>")        # 限定类型 int
@app.route("/path/<path:sub>")           # 接受带 / 的路径
@app.route("/uuid/<uuid:u>")             # uuid

@app.route("/login", methods=["GET", "POST"])   # 多方法

可用的转换器:

转换器接受示例
string默认,不含 /<name>
int正整数<int:id>
float正浮点数<float:price>
path含 / 的字符串<path:sub>
uuidUUID 字符串<uuid:u>

函数里可以拿路径参数:

python
@app.route("/user/<name>")
def user(name):
    return f"hello, {name}"

@app.route("/post/<int:post_id>")
def post(post_id):
    return {"id": post_id}

📥 请求对象 request ​

python
from flask import request

@app.route("/search")
def search():
    kw = request.args.get("q", "")       # 查询参数 ?q=xxx
    page = request.args.get("page", 1, type=int)

@app.route("/login", methods=["POST"])
def login():
    username = request.form["user"]      # 表单字段
    password = request.form.get("pwd")

    data = request.get_json()            # JSON body(自动解析)
    # 等价于 request.json

    token = request.headers.get("Authorization")
    file  = request.files["avatar"]      # 上传文件

    # 客户端信息
    ip = request.remote_addr
    ua = request.headers.get("User-Agent")

要点:

  • request.args 是 ImmutableMultiDict,用 get 安全读
  • request.form 拿 application/x-www-form-urlencoded / multipart
  • request.json 拿 application/json,缺 Content-Type 时是 None
  • request.get_json(force=True) 强制解析(忽略 Content-Type,不推荐)

📤 响应 ​

python
from flask import jsonify, make_response, Response

# 1. 直接返回字符串 / 字典
@app.route("/text")
def text():
    return "hello"

# 2. 返回 JSON(推荐)
@app.route("/api/user")
def api_user():
    return jsonify({"name": "张三", "age": 18})   # 自动加 Content-Type

# 3. 自定义 status / headers
resp = make_response("created", 201)
resp.headers["X-Custom"] = "value"
return resp

# 4. 返回元组:(body, status, headers)
return {"ok": True}, 200, {"X-Trace": "abc"}

🖼️ 模板 Jinja2 ​

Flask 默认用 Jinja2 模板(类似 Vue 的 {{ }}):

python
from flask import render_template

@app.route("/hello/<name>")
def hello(name):
    return render_template("hello.html", name=name, items=[1, 2, 3])

templates/hello.html:

html
<!DOCTYPE html>
<html>
<body>
  <h1>hello, {{ name }}</h1>
  {% if name == 'admin' %}
    <p>welcome back</p>
  {% endif %}
  <ul>
    {% for item in items %}
      <li>{{ item }}</li>
    {% endfor %}
  </ul>
</body>
</html>

模板继承(避免重复 header / footer):

html
<!-- templates/base.html -->
<html>
  <head><title>{% block title %}{% endblock %}</title></head>
  <body>
    {% block content %}{% endblock %}
  </body>
</html>

<!-- templates/page.html -->
{% extends "base.html" %}
{% block title %}子页面{% endblock %}
{% block content %}
  <h1>子页面内容</h1>
{% endblock %}

🌍 请求上下文 ​

Flask 有一个应用上下文和一个请求上下文,同一线程里直接 import 就能用:

python
from flask import request, session, g, current_app

@app.route("/me")
def me():
    user_id = session.get("user_id")      # session:基于 cookie 的会话
    g.locale = "zh-CN"                    # g:本次请求的临时存储
    return current_app.name               # current_app:当前应用对象

要点:

  • request / session / g 都依赖请求上下文,只在请求处理时能用
  • 在后台线程 / 启动代码里访问会报 RuntimeError: Working outside of request context
  • 需要的话手动 push:app.app_context().push()
  • g 是请求级"全局变量",生命周期 = 一次请求结束,别用来跨请求存数据

📑 Blueprint 蓝图 ​

Blueprint 是 Flask 的"模块化路由组":

python
# user.py
from flask import Blueprint
bp = Blueprint("user", __name__, url_prefix="/api/user")

@bp.route("/<int:uid>")
def get(uid):
    return {"id": uid, "name": "张三"}

@bp.route("/me")
def me():
    return {"name": "current user"}
python
# app.py
from user import bp as user_bp
app.register_blueprint(user_bp)

访问 /api/user/1 和 /api/user/me。

大型项目结构 ​

app/
├── __init__.py            # create_app 工厂
├── models/                # 数据模型
│   └── user.py
├── views/                 # 蓝图
│   ├── __init__.py
│   ├── user.py
│   └── todo.py
└── templates/             # Jinja2 模板

__init__.py 用工厂模式:

python
from flask import Flask

def create_app():
    app = Flask(__name__)
    app.config["SECRET_KEY"] = "dev-secret"   # 实际从环境变量读

    from .views.user import bp as user_bp
    from .views.todo import bp as todo_bp
    app.register_blueprint(user_bp)
    app.register_blueprint(todo_bp)

    return app

❌ 错误处理 ​

python
from flask import jsonify, abort

@app.errorhandler(404)
def not_found(e):
    return jsonify({"error": "not found"}), 404

@app.errorhandler(Exception)
def all_err(e):
    app.logger.exception(e)             # 记日志
    return jsonify({"error": "server error"}), 500

# 主动抛错
@app.route("/admin")
def admin():
    if not session.get("is_admin"):
        abort(403)

🛠️ 实战:TODO API ​

python
# app.py
from flask import Flask, request, jsonify, abort

app = Flask(__name__)

todos = []
next_id = 1

@app.route("/todos", methods=["GET"])
def list_todos():
    return jsonify(todos)

@app.route("/todos", methods=["POST"])
def create_todo():
    global next_id
    data = request.get_json() or {}
    if "title" not in data:
        abort(400, "title is required")
    todo = {"id": next_id, "title": data["title"], "done": False}
    next_id += 1
    todos.append(todo)
    return jsonify(todo), 201

@app.route("/todos/<int:tid>", methods=["PUT"])
def update_todo(tid):
    todo = next((t for t in todos if t["id"] == tid), None)
    if not todo:
        abort(404)
    todo.update(request.get_json() or {})
    return jsonify(todo)

@app.route("/todos/<int:tid>", methods=["DELETE"])
def delete_todo(tid):
    global todos
    todos = [t for t in todos if t["id"] != tid]
    return "", 204

if __name__ == "__main__":
    app.run(debug=True)

📦 部署 ​

Flask 自带 app.run() 只用于开发,生产用 WSGI 服务器:

Linux / macOS:gunicorn ​

bash
pip install gunicorn
gunicorn -w 4 -b 0.0.0.0:8000 app:app
# -w 4: 4 个 worker 进程
# -b:   绑定地址

Windows:waitress ​

bash
pip install waitress
waitress-serve --port=8000 app:app

反向代理(Nginx) ​

nginx
server {
    listen 80;
    server_name api.example.com;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}

⚠️ 容易踩的坑 ​

坑表现解决
request.json 是 None没设 Content-Type: application/jsonrequest.get_json(force=True) 强制解析(不推荐)
修改了代码但页面没变debug=True 没开 / 缓存了模板确认 app.run(debug=True)
生产用 app.run()单进程、性能差、reload 卡住用 gunicorn / uvicorn
在视图外用 requestRuntimeError: Working outside of request context在视图函数内用,或手动 push context
session 当数据库用数据存 cookie,只适合小数据重数据用 Redis / DB
没设 SECRET_KEY 就用 session报错app.config["SECRET_KEY"] = "随机字符串"
abort(400, "msg") 后没自定义 handler错误页是 HTML写 @app.errorhandler(400) 返回 JSON
静态文件用 Flask 直接 serve生产性能差Nginx 直接 serve /static/
CORS 没配前端调不通浏览器报 CORS用 flask-cors 扩展
