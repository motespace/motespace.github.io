Python 与 Node.js 对比 ​

作为同时会 JS 和 Python 的前端,经常被问"我到底该用哪个"。 这章给出实战视角的对比,不是教科书。

  • 知道两个生态各自最擅长什么

📝 语法对比 ​

python
# Python:列表推导式、关键字参数、装饰器
squares = [x * x for x in range(10)]

def greet(name: str, *, excited: bool = False) -> str:
    suffix = "!" if excited else ""
    return f"hello, {name}{suffix}"

print(greet("world", excited=True))     # hello, world!
javascript
// Node.js:箭头函数、解构、模板字符串
const squares = Array.from({length: 10}, (_, i) => i * i);

function greet(name, opts = {}) {
  const suffix = opts.excited ? "!" : "";
  return `hello, ${name}${suffix}`;
}

console.log(greet("world", { excited: true }));

差异点:

特性PythonNode.js
异步async/await (asyncio)async/await (Promise)
解构无原生,靠 *args / **kwargs对象/数组解构原生
包管理pip / poetry / uvnpm / pnpm / yarn
字符串模板f-string f"{x}"模板字符串 `${x}`
类型系统typing(运行时无影响)TypeScript(编译时类型)
多线程GIL,CPU 密集用 multiprocessingworker_threads(部分场景)
模块系统importimport (ESM) / require (CJS)
类继承支持多继承单继承 + mixin

⚡ 异步模型对比 ​

python
# Python asyncio
import asyncio

async def fetch(url):
    await asyncio.sleep(1)        # 模拟 IO
    return url

async def main():
    results = await asyncio.gather(
        fetch("a"), fetch("b"), fetch("c"),
    )
    print(results)

asyncio.run(main())
javascript
// Node.js Promise.all
async function fetch(url) {
  await new Promise(r => setTimeout(r, 1000));
  return url;
}

async function main() {
  const results = await Promise.all([fetch("a"), fetch("b"), fetch("c")]);
  console.log(results);
}

main();

体验上几乎一致,但底层不同:

  • Node.js event loop 是单线程 + 回调队列,所有 IO 默认异步(库默认就是异步 IO)
  • Python 的同步 IO(文件、requests)默认是阻塞,要异步必须显式用 aiohttp 等库 + asyncio
  • Node.js 写并发几乎没心智负担;Python 要刻意选 async 库 + 加 await

🚀 性能与类型 ​

性能(粗略):

  • CPU 密集:Node.js V8 通常略胜 Python CPython,但差距不大;PyPy / uv(Anaconda 发行版的 Python)能接近 V8
  • IO 密集:两者都很快(都靠异步),差距无感

类型系统:

  • Python:运行时动态,typing + mypy 做静态检查(社区在向"渐进式类型"走)
  • Node.js:TypeScript 已经是事实标准,编译期类型,IDE 体验一流

你的项目主要是?

│   └─ Node.js

│   └─ 想类型严谨 + 自动文档 → FastAPI
├─ 数据分析 / 爬虫 / 运维脚本

├─ AI / LLM / RAG
│   └─ Python(几乎没别的选择)
└─ 不确定
    └─ 看团队主力语言 → 用主力语言,别混

真实案例参考 ​

  • Instagram:Python(Django) —— 大量图片处理 + ML 推荐
  • Netflix:Node.js + Python 混用 —— Node 做 API 网关,Python 做推荐算法
  • Uber:Node.js + Python + Go —— 按业务模块拆
  • Dropbox:主力 Python —— 文件同步 + 桌面客户端
  • PayPal:从 Java 迁到 Node.js —— BFF 性能大幅提升
