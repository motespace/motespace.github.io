⚠️ 容易踩的坑

Section titled “⚠️ 容易踩的坑”
坑 表现 解决
requests.get 不设 timeout 网络挂了永远卡住 永远显式 timeout
pandas 读 CSV 中文乱码 Excel 导出的 CSV 是 GBK pd.read_csv(path, encoding="gbk")
pandas 写 CSV Excel 打开乱码 utf-8 普通 Excel 不认 BOM encoding="utf-8-sig"
DataFrame 改了不生效 大多数方法返回新对象 用 df = df.assign(...) 或加 inplace=True
OpenAI SDK 写 openai.ChatCompletion.create v1.x 老接口没了 用新接口 client.chat.completions.create
prompt 里塞整个 DataFrame token 爆炸 / 超限 只传 head() + describe() 摘要
API key 硬编码提交到 Git 严重安全事故(几小时就能被扫到) 用 .env + python-dotenv + .gitignore
流式响应忘了 flush=True 输出延迟,看不到实时效果 print(..., flush=True)
to_csv 默认带 index 多一列 unnamed index=False
describe() 只看数值列 看不到字符串列统计 df.describe(include="all")
