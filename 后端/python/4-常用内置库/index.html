Python 常用内置库

Python 标准库是最大的“宝藏”——大部分需求不用 pip install。 本文挑 6 个最常用的:re / collections / itertools / functools / dataclasses / typing。

🎯 学到这步能做什么

Section titled “🎯 学到这步能做什么”
  • 用 re 写正则(提取日志、解析文本)
  • 用 collections.Counter / defaultdict 替代手写 dict 计数
  • 用 itertools / functools 写出更 Pythonic 的代码
  • 用 dataclass 省掉 __init__ / __repr__
  • 用 typing 给函数加类型提示,IDE 自动补全

⚠️ 容易踩的坑

Section titled “⚠️ 容易踩的坑”
坑 表现 解决
Counter 返回 0 但 c["x"] += 1 报错 计数不存在,先报 KeyError 用 defaultdict(int) 或先 c["x"] = 0
groupby 没排序就分组 分组错乱(只把连续相同的分一组) groupby 前必须 sort,或用 itertools.groupby 之外的方案
dataclass 默认值是可变对象 共享同一个 list/dict,跨实例污染 用 field(default_factory=list)
lru_cache 缓存 list 参数 TypeError: unhashable 包成 tuple,或用 @functools.cache(3.9+)
类型提示写 list[int] Python 3.8 报 TypeError 用 List[int](老) 或升级 Python ≥ 3.9
re.search 忘看 None None.group(1) 报错 先 if m: 再用
re.findall 带分组 返回的是分组列表,不是整段 加捕获组: re.findall(r"(?:pattern)", text) 用非捕获组
写 @dataclass 加复杂方法 失去数据类的意义 行为多的类用普通 class
