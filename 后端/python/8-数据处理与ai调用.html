🌐 requests HTTP 调用 ​

bash
pip install requests
python
import requests

# 1. GET
r = requests.get(
    "https://api.github.com/repos/python/cpython",
    timeout=10,
)
print(r.status_code)         # 200
print(r.json()["stargazers_count"])

# 2. GET with query params
r = requests.get(
    "https://httpbin.org/get",
    params={"q": "python", "page": 2},
    headers={"User-Agent": "my-app/1.0"},
    timeout=5,
)

# 3. POST JSON
r = requests.post(
    "https://api.example.com/users",
    json={"name": "张三", "age": 18},     # 自动设 Content-Type + 序列化
    headers={"Authorization": "Bearer xxx"},
    timeout=5,
)
r.raise_for_status()         # 4xx/5xx 抛异常
data = r.json()

Session:复用连接 / 统一 header ​

python
session = requests.Session()
session.headers["Authorization"] = "Bearer xxx"
session.timeout = 10          # 注意:这不是参数,是属性

# 后面所有请求自动带 header
r1 = session.get("https://api/.../a")
r2 = session.get("https://api/.../b")

# Session 上下文:确保关闭
with requests.Session() as s:
    s.get("https://api/")

异常处理(必须) ​

python
from requests.exceptions import RequestException, Timeout

try:
    r = requests.get(url, timeout=5)
    r.raise_for_status()
    data = r.json()
except Timeout:
    print("请求超时")
except RequestException as e:
    print(f"请求失败: {e}")
except ValueError:           # JSON 解析失败
    print("返回不是合法 JSON")

🤖 OpenAI SDK 基础 ​

bash
pip install openai
python
from openai import OpenAI

client = OpenAI(
    api_key="sk-...",
    base_url="https://api.openai.com/v1",       # 兼容协议的国产模型也能用
)

resp = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[
        {"role": "system", "content": "你是一个助手,回答简洁。"},
        {"role": "user", "content": "用一句话解释 async/await"},
    ],
    temperature=0.7,
    max_tokens=500,
)

print(resp.choices[0].message.content)
print(resp.usage.total_tokens)   # 本次消耗的 token 数

要点:

  • base_url 改一下就能用 Azure / DeepSeek / 通义千问 / 智谱 等兼容协议的服务
  • api_key 别硬编码,用环境变量:os.environ["OPENAI_API_KEY"]
  • temperature 越高越发散(0 = 稳定,1 = 发散;默认 1)

📡 流式输出 ​

流式 = GPT 边生成边吐,前端能"打字机效果"。

python
stream = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "写一首五言绝句"}],
    stream=True,
)

for chunk in stream:
    delta = chunk.choices[0].delta.content
    if delta:
        print(delta, end="", flush=True)

FastAPI 暴露流式端点:

python
from fastapi import FastAPI
from fastapi.responses import StreamingResponse

app = FastAPI()

@app.get("/chat")
def chat(q: str):
    def gen():
        stream = client.chat.completions.create(
            model="gpt-4o-mini",
            messages=[{"role": "user", "content": q}],
            stream=True,
        )
        for chunk in stream:
            delta = chunk.choices[0].delta.content
            if delta:
                yield delta
    return StreamingResponse(gen(), media_type="text/plain")

🛠️ 实战:GPT 分析 CSV ​

把数据处理 + AI 调用拼起来 —— 读 CSV → 拼成 prompt → 让 GPT 总结:

python
# analyze_csv.py
import pandas as pd
from openai import OpenAI
import os

client = OpenAI(api_key=os.environ["OPENAI_API_KEY"])

def summarize_csv(path: str) -> str:
    df = pd.read_csv(path)
    head = df.head(5).to_markdown()                  # 转 markdown 喂给 GPT
    summary = df.describe(include="all").to_markdown()

    prompt = f"""以下是 CSV 文件前 5 行和统计摘要,请用中文给出 3 条关键洞察:

## 前 5 行
{head}

## 统计摘要
{summary}

只输出洞察,不要列数据。
"""

    resp = client.chat.completions.create(
        model="gpt-4o-mini",
        messages=[{"role": "user", "content": prompt}],
        temperature=0.3,
    )
    return resp.choices[0].message.content

if __name__ == "__main__":
    print(summarize_csv("sales.csv"))

跑(以 bash 为例):

bash
export OPENAI_API_KEY=sk-...

⚠️ 容易踩的坑 ​

坑表现解决
requests.get 不设 timeout网络挂了永远卡住永远显式 timeout
pandas 读 CSV 中文乱码Excel 导出的 CSV 是 GBKpd.read_csv(path, encoding="gbk")
pandas 写 CSV Excel 打开乱码utf-8 普通 Excel 不认 BOMencoding="utf-8-sig"
DataFrame 改了不生效大多数方法返回新对象用 df = df.assign(...) 或加 inplace=True
OpenAI SDK 写 openai.ChatCompletion.createv1.x 老接口没了用新接口 client.chat.completions.create
prompt 里塞整个 DataFrametoken 爆炸 / 超限只传 head() + describe() 摘要
API key 硬编码提交到 Git严重安全事故(几小时就能被扫到)用 .env + python-dotenv + .gitignore
流式响应忘了 flush=True输出延迟,看不到实时效果print(..., flush=True)
to_csv 默认带 index多一列 unnamedindex=False
describe() 只看数值列看不到字符串列统计df.describe(include="all")
