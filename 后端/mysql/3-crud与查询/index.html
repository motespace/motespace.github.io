⚠️ 容易踩的坑

Section titled “⚠️ 容易踩的坑”
坑 表现 解决
SELECT * 浪费 IO,字段变更炸代码 明确列名:SELECT id, name
WHERE 没用索引字段 全表扫描 走 索引章节
LIMIT N, M 深分页 巨慢 改游标分页 / WHERE id > last_id
WHERE age+1 = 20 索引失效 改 WHERE age = 19
LIKE '%xxx%' 索引失效 全文索引 / ES
IN (SELECT ...) 返回大结果集 慢 改 JOIN
没 LIMIT 的 UPDATE / DELETE 全表更新 / 删库 永远加 WHERE 和 LIMIT
GROUP BY 字段忘了聚合 严格模式报错 非聚合列全加 GROUP BY
COUNT(*) 慢 全表扫 副表存计数 / 用近似值
