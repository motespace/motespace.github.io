MySQL 入门与安装 ​

MySQL 是最流行的开源关系数据库,Web 后端的事实标准之一。 本文从安装到第一次连接,跑通"能看到表、能查数据"为止。

🎯 学到这步能做什么 ​

  • 在本地 / 服务器装 MySQL
  • 用 CLI 客户端连上数据库,跑第一条 SQL
  • 知道数据库 / 表 / 行的关系
  • 区分 MySQL / MariaDB / PostgreSQL 何时选哪个

📚 章节目录 ​

  • MySQL vs MariaDB vs PostgreSQL
  • 本地安装 MySQL
  • 第一次连接

⚖️ MySQL vs MariaDB vs PostgreSQL ​

维度MySQLMariaDBPostgreSQL
出身Oracle 维护MySQL 原作者 fork学院派,功能强
许可GPL(开源版)+ 商业纯 GPL(全开源)BSD-like(更宽松)
性能读强,写中略快于 MySQL复杂查询 / 写强
JSON支持支持支持最丰富
地理信息基础基础PostGIS 业界最强
严格模式默认不严默认不严默认严格
生态 / 文档最多兼容 MySQL增长快
适用场景Web 通用 / 中小型项目MySQL 替代复杂查询 / GIS / 严格事务

简单选型:

  • 普通 Web 项目 + ORM → MySQL / MariaDB 都行
  • 需要严格事务 / 复杂查询 / GIS → PostgreSQL
  • 历史包袱 / 兼容性 → MySQL

本文以 MySQL 8.x 为例,大部分语法 MariaDB 通用。

📦 本地安装 MySQL ​

macOS(Homebrew) ​

bash
brew install mysql
brew services start mysql        # 开机自启
mysql_secure_installation         # 初始化(root 密码等)
mysql -u root -p

Ubuntu / Debian ​

bash
sudo apt update
sudo apt install mysql-server
sudo systemctl start mysql
sudo mysql_secure_installation

Docker(最快,推荐) ​

bash
docker run -d \
  --name mysql \
  -p 3306:3306 \
  -e MYSQL_ROOT_PASSWORD=yourpassword \
  -e MYSQL_DATABASE=myapp \
  -v mysql_data:/var/lib/mysql \
  mysql:8.0

数据存在 Docker volume mysql_data,删容器不丢数据。

Windows ​

官方安装包:https://dev.mysql.com/downloads/installer/

或者用 Docker Desktop(推荐,跟 Linux 命令一致)。

🔌 第一次连接 ​

bash
# 本地连接(密码交互输入)
mysql -u root -p

# 指定 host / port
mysql -h 127.0.0.1 -P 3306 -u root -p

# 直接传密码(不推荐,会留在 shell 历史)
mysql -u root -pyourpassword

# 连完看版本
mysql> SELECT VERSION();
+-----------+
| VERSION() |
+-----------+
| 8.0.36    |
+-----------+

用配置文件存密码(~/.my.cnf) ​

ini
[client]
user=root
password=yourpassword
host=127.0.0.1

chmod 600:chmod 600 ~/.my.cnf。连接时就不用输了。

🗄️ SQL 基础:库 / 表 / 行 ​

sql
-- 看所有库
SHOW DATABASES;

-- 创建库
CREATE DATABASE myapp
  CHARACTER SET utf8mb4
  COLLATE utf8mb4_unicode_ci;
-- utf8mb4:真 Unicode(支持 emoji),别用 utf8(MySQL 老 utf8 是 3 字节,装不下 emoji)

-- 切换库
USE myapp;

-- 创建表
CREATE TABLE users (
    id         INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    name       VARCHAR(50) NOT NULL,
    email      VARCHAR(100) NOT NULL UNIQUE,
    age        TINYINT UNSIGNED,                          -- 0-255
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 看表结构
DESCRIBE users;
-- 或 SHOW CREATE TABLE users;

-- 增
INSERT INTO users (name, email, age) VALUES
  ('张三', 'zhang@example.com', 25),
  ('李四', 'li@example.com', 30);

-- 查
SELECT id, name, email FROM users;
SELECT * FROM users WHERE age >= 18 LIMIT 10;

-- 改
UPDATE users SET age = 26 WHERE name = '张三';

-- 删
DELETE FROM users WHERE name = '李四';

-- 删表 / 删库(慎用!)
DROP TABLE users;
DROP DATABASE myapp;

常用命令速查 ​

命令作用
SHOW DATABASES;所有库
SHOW TABLES;当前库所有表
DESCRIBE table_name;表结构
SHOW CREATE TABLE table_name;建表 SQL
SHOW PROCESSLIST;当前连接
SHOW VARIABLES LIKE '%timeout%';系统变量
\c取消当前命令
\q退出

⚠️ 容易踩的坑 ​

坑表现解决
用 utf8 字符集emoji / 某些中文存不进去统一用 utf8mb4
root 密码忘了登录不进去用 --skip-grant-tables 启动重置
连不上 localhostCan't connect to MySQL server检查服务是否启动 / 端口是否对
端口 3306 被占用启动失败lsof -i :3306 看占用进程
Docker 容器重启数据丢用 -v 挂载 volume-v mysql_data:/var/lib/mysql
Linux 大小写敏感表名 User ≠ user建库时统一 lower_case_table_names
WHERE 字符串忘了引号SQL 报错或误匹配引号必加:WHERE name = '张三'
mysql -uroot 报错后退出上一条命令有 ; 但 mysql 还在等输入输入 ; 结束上一条,或 \c 取消
