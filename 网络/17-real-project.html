真实项目:完整 HTTP 网络流程复盘 ​

来自简历项目"01 商户管理 SaaS"的真实代码,展示一个 Web 应用完整的 HTTP 网络流程。

一、登录流程全景 ​

1. 用户在浏览器输入邮箱、密码
   ↓
2. 前端 RSA 公钥加密密码(避免明文传输)
   ↓
3. POST /api/login
   - Content-Type: application/json
   - timezone: Asia/Shanghai
   - X-Request-Id: 唯一 ID(防重放、链路追踪)
   ↓
4. 服务器验证账号密码
   - 查数据库
   - bcrypt 比对密码哈希
   ↓
5. 签发 token(JWT / Session)
   - 短期 token(15~30 分钟)
   - 长期 refresh token(7~30 天)
   ↓
6. 返回 200 OK
   - body: { code: 0, data: { token: 'xxx' } }
   - Set-Cookie: Authorization=xxx; HttpOnly; Secure; SameSite=Lax
   ↓
7. 前端存储 token(内存 + Cookie)
   ↓
8. 后续请求自动带 Authorization 头 / Cookie

二、HttpClient 设计 ​

2.1 真实代码(merchant 项目) ​

ts
// merchant/src/utils/http-client.ts

import axios, { AxiosInstance, AxiosRequestConfig } from 'axios'

export class HttpClient {
  private instance: AxiosInstance
  private doRequest: boolean = false  // 防止并发刷新

  constructor(baseURL: string) {
    this.instance = axios.create({
      baseURL,
      timeout: 30000,  // 30 秒超时
      withCredentials: true,  // 带 Cookie
    })

    // 请求拦截器
    this.instance.interceptors.request.use((config) => {
      // 1. 加通用 Header
      config.headers['I18n'] = CookieService.get('I18n') || 'en'
      config.headers['Authorization'] = CookieService.get('Authorization') || ''
      config.headers['timezone'] = getTimezoneForRequest()

      // 2. 请求 ID(链路追踪)
      config.headers['X-Request-Id'] = generateUUID()

      return config
    })

    // 响应拦截器
    this.instance.interceptors.response.use(
      (response) => response.data,
      async (error) => {
        const { response, config } = error

        // 网络错误
        if (!response) {
          if (error.code === 'ECONNABORTED') {
            message.error('请求超时,请稍后再试')
          } else {
            message.error('网络异常')
          }
          return Promise.reject(error)
        }

        // HTTP 状态码处理
        if (response.status === 401) {
          // 登录失效,自动刷新 token
          if (!this.doRequest) {
            this.doRequest = true
            try {
              await this.refreshToken()
              this.doRequest = false
              return this.instance.request(config)  // 重试原请求
            } catch (e) {
              this.doRequest = false
              this.clearAuth()
              location.replace('/gate.html')
              return Promise.reject(e)
            }
          }
        }

        // 业务码处理
        if (response.status === 200 && response.data) {
          if (response.data.code === 'INVALIDATION') {
            clearTimezoneOnLogout()
            location.replace('/gate.html')
            return Promise.reject(error)
          }
          if (response.data.code === 'SYS_BUSY') {
            message.error(i18n.t('common.serverError.sysBusy'))
            return Promise.reject(error)
          }
        }

        // 其他错误
        if (response.status >= 500) {
          message.error('系统繁忙')
          // 上报到 Sentry
          reportError(error)
        } else {
          message.error(response.data?.message || `请求失败 ${response.status}`)
        }

        return Promise.reject(error)
      }
    )
  }

  // 业务方法
  get(url: string, params?: any) {
    return this.instance.get(url, { params })
  }

  post(url: string, data?: any) {
    return this.instance.post(url, data)
  }
}

2.2 关键设计 ​

请求拦截器:

  • 通用 Header 注入(I18n、Authorization、timezone)
  • 链路追踪 ID(X-Request-Id)
  • 防止 CSRF:从 Cookie 读 token 写入 Header(双 Cookie 模式)

响应拦截器:

  • 网络错误 / HTTP 错误 / 业务码分别处理
  • 401 自动刷新 token + 重试
  • 防止多个请求并发刷新(单飞模式)

三、Token 刷新机制 ​

3.1 真实代码 ​

ts
async refreshToken() {
  const refreshToken = CookieService.get('Refresh-Token')
  if (!refreshToken) {
    throw new Error('No refresh token')
  }

  const res = await axios.post('/api/auth/refresh', {}, {
    headers: { 'X-Refresh-Token': refreshToken },
    withCredentials: true,
  })

  if (res.data.code === 'SUCCESS') {
    CookieService.set('Authorization', res.data.data.token, {
      httpOnly: false,  // JS 可读(因为 Header 要用)
      maxAge: 15 * 60,
    })
    CookieService.set('Refresh-Token', res.data.data.refreshToken, {
      httpOnly: true,  // HttpOnly(防 XSS 偷)
      maxAge: 7 * 24 * 60 * 60,
    })
  }
}

3.2 防并发刷新 ​

ts
private doRequest = false

async handle401(error) {
  if (this.doRequest) {
    // 已经在刷新了,等待
    return new Promise((resolve) => {
      const interval = setInterval(() => {
        if (!this.doRequest) {
          clearInterval(interval)
          resolve(this.instance.request(error.config))
        }
      }, 100)
    })
  }

  this.doRequest = true
  try {
    await this.refreshToken()
    this.doRequest = false
    return this.instance.request(error.config)
  } catch (e) {
    this.doRequest = false
    throw e
  }
}

四、登录接口完整设计 ​

4.1 前端 ​

ts
async login(credentials: LoginDTO) {
  // 1. RSA 加密密码
  const publicKey = await this.getPublicKey()
  const encryptedPassword = encryptRSA(credentials.password, publicKey)

  // 2. 发起请求
  const res = await this.post('/api/login', {
    username: credentials.username,
    password: encryptedPassword,
    timezone: getTimezoneForRequest(),
    device: 'web',
  })

  // 3. 处理响应
  if (res.code === 'SUCCESS') {
    CookieService.set('Authorization', res.data.token, {
      httpOnly: false,
      maxAge: 24 * 60 * 60,
      secure: true,
      sameSite: 'lax',
    })
    return res.data
  }

  throw new Error(res.message || '登录失败')
}

4.2 服务端(伪代码) ​

ts
app.post('/api/login', async (req, res) => {
  // 1. RSA 解密密码
  const password = decryptRSA(req.body.password, serverPrivateKey)

  // 2. 验证
  const user = await db.user.findUnique({ where: { username: req.body.username } })
  if (!user || !await bcrypt.compare(password, user.passwordHash)) {
    return res.json({ code: 'INVALID_CREDENTIALS', message: '账号或密码错误' })
  }

  // 3. 检查登录失败次数(防暴力破解)
  if (user.lockedUntil && user.lockedUntil > Date.now()) {
    return res.json({ code: 'ACCOUNT_LOCKED', message: '账户已锁定' })
  }

  // 4. 签发 token
  const token = jwt.sign(
    { sub: user.id, role: user.role },
    SECRET,
    { expiresIn: '15m' }
  )
  const refreshToken = jwt.sign(
    { sub: user.id, type: 'refresh' },
    REFRESH_SECRET,
    { expiresIn: '7d' }
  )

  // 5. 设置 Cookie
  res.cookie('Authorization', token, {
    httpOnly: false,
    secure: true,
    sameSite: 'lax',
    maxAge: 15 * 60 * 1000,
  })
  res.cookie('Refresh-Token', refreshToken, {
    httpOnly: true,
    secure: true,
    sameSite: 'lax',
    maxAge: 7 * 24 * 60 * 60 * 1000,
  })

  // 6. 记录登录日志
  await auditLog({
    userId: user.id,
    action: 'login_success',
    ip: req.ip,
    userAgent: req.headers['user-agent'],
  })

  res.json({
    code: 'SUCCESS',
    data: { user: sanitize(user), token },
  })
})

五、上传 / 下载 ​

5.1 大文件上传 ​

ts
// 分片上传
async function uploadFile(file: File) {
  const chunkSize = 5 * 1024 * 1024  // 5MB 每片
  const chunks = Math.ceil(file.size / chunkSize)
  
  // 1. 初始化上传任务
  const initRes = await this.post('/api/upload/init', {
    filename: file.name,
    size: file.size,
    chunks,
    hash: await sha256(file),  // 文件 hash,秒传校验
  })

  // 2. 已存在的分片(秒传)
  if (initRes.data.existed) {
    return initRes.data.url
  }

  // 3. 上传每个分片(并发限速)
  const uploadedChunks: number[] = []
  for (let i = 0; i < chunks; i++) {
    if (initRes.data.uploaded.includes(i)) continue  // 已上传,跳过

    const blob = file.slice(i * chunkSize, (i + 1) * chunkSize)
    await this.post(`/api/upload/chunk/${initRes.data.uploadId}/${i}`, blob, {
      headers: { 'Content-Type': 'application/octet-stream' },
      onUploadProgress: (e) => {
        const totalUploaded = uploadedChunks.reduce((s, n) => s + chunkSize, 0) + e.loaded
        onProgress(totalUploaded / file.size)
      },
    })
    uploadedChunks.push(i)
  }

  // 4. 合并
  const finalRes = await this.post(`/api/upload/complete/${initRes.data.uploadId}`)
  return finalRes.data.url
}

5.2 流式下载 ​

ts
// 服务端支持 Range(断点续传)
app.get('/api/download/:fileId', (req, res) => {
  const file = getFile(req.params.fileId)
  const range = req.headers.range  // bytes=0-1023
  
  if (range) {
    const [start, end] = parseRange(range)
    res.status(206)
    res.setHeader('Content-Range', `bytes ${start}-${end}/${file.size}`)
    res.setHeader('Content-Length', end - start + 1)
    fs.createReadStream(file.path, { start, end }).pipe(res)
  } else {
    res.setHeader('Content-Length', file.size)
    fs.createReadStream(file.path).pipe(res)
  }
})

六、网络层优化 ​

6.1 BFF 层(Backend for Frontend) ​

浏览器 → BFF(聚合 + 缓存) → 微服务

优势:

  • 减少请求数(浏览器一次请求,BFF 调多个微服务)
  • 简化前端逻辑
  • 统一鉴权、限速、缓存
ts
// BFF 端:合并多个 API
app.get('/api/dashboard', async (req, res) => {
  const [user, orders, metrics] = await Promise.all([
    userService.getUser(req.user.id),
    orderService.getRecentOrders(req.user.id),
    metricsService.getMetrics(req.user.id),
  ])

  res.json({ user, orders, metrics })
})

nginx
server {
  listen 443 ssl http2;

  # HTTP/2 配置
  ssl_protocols TLSv1.2 TLSv1.3;
  ssl_ciphers HIGH:!aNULL:!MD5;

  # HTTP/3 也开
  add_header Alt-Svc 'h3=":443"; ma=86400' always;

  # 启用 Brotli 压缩
  brotli on;
  brotli_comp_level 6;
  brotli_types text/plain text/css application/javascript application/json image/svg+xml;

  # 启用 gzip 压缩(Brotli 不支持的客户端)
  gzip on;
  gzip_types text/plain text/css application/javascript;
  gzip_min_length 1024;

  location / {
    proxy_pass http://backend;
  }
}
