网络推荐深入阅读

经典书籍

Section titled “经典书籍”

  • 《HTTP 权威指南》(HTTP: The Definitive Guide) —— David Gourley / Brian Totty。HTTP 协议的“圣经”,从协议演进到详细字段,从缓存到代理。强烈建议至少读前 12 章。

  • 《计算机网络:自顶向下方法》(Computer Networking: A Top-Down Approach) —— James Kurose / Keith Ross。从应用层开始讲,逐步深入。教材级质量,适合系统化学习。

  • 《TCP/IP 详解 卷一:协议》(TCP/IP Illustrated, Volume 1: The Protocols) —— W. Richard Stevens。TCP/IP 协议栈深度讲解,网络工程师必读。

  • 《Web 性能权威指南》(High Performance Browser Networking) —— Ilya Grigorik。Google 性能团队出品,网络、HTTPS、HTTP/2、缓存都涵盖。

  • 《HTTP/2 详解》(http2-explained) —— Daniel Stenberg(cURL 作者)。免费电子书,中文版质量也很好。HTTP/2 入门首选。

  • 《HTTPS 权威指南》(Bulletproof SSL and TLS) —— Ivan Ristic(SSL Labs 创始人)。HTTPS 配置、证书、攻击防御全面覆盖。

备注

Section titled “备注”
  • RFC 是终极权威——但篇幅大,建议先读导论/教程,再回头查 RFC
  • 生产配置参考 Nginx / Cloudflare 文档,不要照搬博客(博客版本老)
  • 安全最关键的:HTTPS 配置 + Cookie 安全 + CSP + 输入验证,任何一环缺失都可能出问题

📝 小结

Section titled “📝 小结”
  • 必读规范:RFC 7230-7235(HTTP/1.1)、RFC 9114(HTTP/3)、RFC 8446(TLS 1.3),面试引用规范比引用博客有说服力。
  • 官方资源优先级:MDN(查 API)、web.dev(原理 + 性能)、Chrome 团队博客(新特性)、HTTP Working Group 邮件列表(争议点)。
  • 调试工具要熟:Chrome DevTools Network 面板、curl -v、Charles/Whistle 抓包、Wireshark 看 TCP 层。
  • 进阶方向:读 QUIC 论文、HTTP/2 HPACK 与流优先级、CDN 与边缘网络。
  • 学习路径:先 MDN + 《图解 HTTP》→ 再 RFC 关键章节 → 最后看 HTTP/3 与 QUIC 实战。
  • 关键问题清单要能默写:队头阻塞、缓存决策、TLS 握手、CORS 预检、HTTP/2 多路复用。
