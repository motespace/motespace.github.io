前端安全 ​

7 年前端面试必问。本文按攻击 → 防御 → 实战三段式组织，配真实代码（来自简历项目）。

📚 章节列表 ​

  1. 安全检查清单
  2. Clickjacking（点击劫持）
  3. CSP（Content Security Policy）
  4. 点击劫持防御：CSRF Token + SameSite

  6. 第三方依赖安全
  7. iframe 安全

📝 小结 ​

  • 安全按「威胁模型 → 单点攻击 → 防御 → 监控 → 实战」组织,XSS / CSRF / CSP / Clickjacking 是必答四件套。
  • XSS 三类(存储型/反射型/DOM 型)与防御手段(转义 + CSP + 避免 innerHTML)的对应关系要能画出来。
  • CSRF 防御三件套:Token、SameSite Cookie、校验 Origin/Referer;要讲清为什么「自定义请求头」也能防。
  • 前端安全的边界:前端只能减少攻击面,真正的防线在服务端(校验、鉴权、参数化查询)。
  • 面试高分点:讲「我们项目里做的具体事」——CSP 落地、依赖漏洞扫描、token 存储位置选择(为什么不用 localStorage)。
  • 加分:结合最近一次安全漏洞或事故讲「发现 → 修复 → 复盘」的完整闭环。
