🎯 面试常考

Section titled “🎯 面试常考”

Q1：XSS 有哪几种?

存储型(内容入库后对所有人生效)、反射型(参数直接回显,危害最大)、DOM 型(前端 JS 直接把数据写进 DOM)。

Q2：怎么防?

根本原则:不要把不可信数据当 HTML 解析。React/Vue 默认转义,要用 dangerouslySetInnerHTML / v-html 时必须先消毒(DOMPurify);富文本用白名单标签过滤。

Q3：还有哪些容易忽略的注入点?

javascript: 伪协议、事件属性 onerror/onclick、SVG 里的 script、srcdoc 属性、以及通过 URL 参数污染前端路由再渲染。

📝 小结

Section titled “📝 小结”
  • 三种形态:存储型(入库后对所有人生效)、反射型(参数回显)、DOM 型(前端 JS 直接写进 DOM)。
  • 根本原则:不要把不可信数据当 HTML 解析 —— 用框架的转义,必须用 dangerouslySetInnerHTML 时先过 DOMPurify。
  • 容易漏的注入点:javascript: 伪协议、事件属性、SVG 里的 script、srcdoc、URL 参数污染前端路由。
  • 加 CSP(script-src 不含 unsafe-inline)是第二道防线。
