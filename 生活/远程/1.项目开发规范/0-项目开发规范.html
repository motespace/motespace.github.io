🚀 项目开发规范文档 ​

技术栈：React + TypeScript + Next.js + TailwindCSS + Ant Design

📁 1-项目结构推荐 ​

less
src/
├── components/     // 可复用组件
│   └── Button.tsx
├── features/       // 按功能模块划分
│   └── user/
│       ├── api.ts
│       ├── hooks.ts
│       ├── UserPage.tsx
├── pages/          // Next.js 页面
│   ├── index.tsx
│   └── about.tsx
├── styles/         // 全局样式
│   └── globals.css
├── utils/          // 工具函数
├── constants/      // 常量配置
├── hooks/          // 通用 hooks
├── types/          // 类型定义
├── contexts/       // 全局状态
└── lib/            // 第三方封装

💡 2-命名规范 ​

  • 文件夹 & 文件：使用小写+中划线或小写驼峰，如：user-profile、userProfile.tsx
  • 组件名：使用大驼峰（PascalCase），如：UserCard
  • hook：useXxx 格式，如：useUserInfo
  • 类型定义：加 Type 后缀，如：UserType
  • 接口定义：加 I 前缀或 Dto 后缀，如：IUser 或 UserDto

⚛️ 3. React & TS 规范 ​

  • 所有组件必须使用函数式组件（Function Component）。
  • 必须使用 TypeScript，明确 props 和状态类型。
ts
type UserCardProps = {   
	name: string;  
	age: number; 
};  
const UserCard: React.FC<UserCardProps> = ({ name, age }) => {   
	return <div>{name} - {age} </div>; 
};
  • 避免使用 any，优先使用 unknown 并配合类型收缩。
  • 默认导出（export default）用于页面组件；可复用组件使用具名导出（export）。

🎨 4. TailwindCSS 使用规范 ​

  • 类名顺序统一：布局 > 大小 > 边距 > 字体 > 颜色等。
  • 抽象样式推荐使用类组件封装或组合类：
ts
<div className="flex items-center justify-between px-4 py-2 text-sm text-gray-700">
  • 可复用样式建议封装成组件或使用 clsx 管理动态类：
ts
import clsx from "clsx";  

<div className={clsx("text-sm", isActive && "text-blue-500")} />

🧩 5. Ant Design 使用规范 ​

  • 表单统一使用 Form.useForm() 管理表单状态。
  • 表格、分页统一封装复用逻辑。
  • 自定义主题在 tailwind.config.js 与 Ant Design 的 ConfigProvider 中同步风格。

🧼 6. 代码风格 & Lint 规范 ​

  • 使用 ESLint 配合 Prettier 进行代码格式化。
  • 使用 Husky + lint-staged 提交前检查代码风格。
  • 建议启用规则示例（ESLint + Prettier）：
bash
npm install eslint prettier eslint-config-prettier eslint-plugin-react eslint-plugin-react-hooks eslint-plugin-tailwindcss --save-dev

.eslintrc.js 示例配置：

js
module.exports = {
  extends: [
    'next/core-web-vitals',
    'plugin:react/recommended',
    'plugin:@typescript-eslint/recommended',
    'plugin:tailwindcss/recommended',
    'prettier'
  ],
  plugins: ['react', '@typescript-eslint', 'tailwindcss'],
  rules: {
    'react/react-in-jsx-scope': 'off',
    '@typescript-eslint/no-explicit-any': 'warn',
  },
};

🧪 7. 其他规范建议 ​

  • 网络请求统一封装 axios，配合 hooks 使用（如 SWR、React Query）。
  • 权限控制通过高阶组件或 layout 中统一处理。
  • 多语言使用 next-i18next。
  • SSR/ISR/CSR 使用场景明确，保持页面响应速度。
