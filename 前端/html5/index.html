HTML5 专题

JD 第一行就写 HTML5。这个专题把“浏览器新能力”这块补齐：语义化结构、文件与二进制、Canvas 图形、离线与实时通信。

📚 章节列表

Section titled “📚 章节列表”
  1. 语义化与文档结构 — 语义标签、SEO 可访问性、表单增强、DOM 解析
  2. 文件与二进制 — File / Blob / FileReader / 拖拽 / 下载 / 图片处理
  3. Canvas 与图形 — 2D 绘制、离屏、性能、WebGL / SVG 对比
  4. 离线与实时通信 — IndexedDB / Service Worker / WebSocket / SSE / Web Worker

速查表：HTML5 到底带来什么

Section titled “速查表：HTML5 到底带来什么”
能力 关键 API 典型场景
语义结构 &lt;header&gt; &lt;nav&gt; &lt;main&gt; &lt;article&gt; &lt;aside&gt; &lt;footer&gt; SEO、无障碍、SEO 爬虫理解页面
表单增强 type=email/datetime/color/range、datalist、FormData 移动端原生键盘、免 JS 校验
多媒体 <video> <audio> + Media Source Extensions 音视频播放
图形 &lt;canvas&gt;、&lt;svg&gt;、WebGL 图表、大屏、游戏、图像处理
本地存储 localStorage / sessionStorage / IndexedDB 登录态、离线草稿、大数据缓存
离线 Service Worker + Cache API + Manifest PWA、弱网可用
通信 WebSocket / SSE / fetch / Beacon 实时推送、埋点上报
设备能力 Geolocation、Notification、Clipboard、File API 定位、推送、剪贴板、附件
多线程 Web Worker 大文件解析、加密、图片处理
媒体采集 MediaRecorder、getUserMedia 录音、摄像头
渲染调度 requestAnimationFrame、IntersectionObserver 动画、懒加载

Section titled “面试提醒”

📝 小结

Section titled “📝 小结”
  • HTML5 带来的是浏览器原生能力:语义结构、二进制与文件、Canvas 图形、离线与实时通信、多媒体、存储。
  • 语义化的真实收益是 SEO 与无障碍(读屏软件依赖语义标签),面试时别只说「更规范」。
  • 二进制三件套:Blob / File / FileReader,配合 URL.createObjectURL 做本地预览,再用 canvas 做图片压缩再上传。
  • 实时通信三选一:轮询、SSE、WebSocket;SSE 走 HTTP/2 自带重连,最适合单向推送。
  • 离线能力靠 Service Worker + Cache API + Manifest,配 IndexedDB 存业务数据。
  • 面试可讲「用 Web Worker 做 Excel 解析/大文件加密,避免主线程卡顿」这类真实优化。
