关键问题清单(面试常考)

Section titled “关键问题清单(面试常考)”

读完上述资料,这些问题都能答上来。

简答速记(对清单的补充)

Section titled “简答速记(对清单的补充)”
  • JSX 是什么? React.createElement 的语法糖;babel/swc 编译时转函数调用
  • Virtual DOM 原理? JS 对象描述 DOM;render → diff → patch;React 16+ 用 Fiber 实现
  • Diff 为什么 O(n)? 三条假设(类型不同重建 / key 标识 / 同级比较),放弃完美最小更新
  • Hooks 为什么不能条件调? 链表按调用顺序索引;条件调用破坏顺序 → state 错位
  • useEffect 时机? Commit 之后异步(paint 后);useLayoutEffect 同步(DOM 更新后、paint 前)
  • React 性能优化手段? memo / useMemo / useCallback / 拆分组件 / 虚拟列表 / 不可变数据
  • Concurrent Mode 关键能力? 自动批处理 + useTransition + useDeferredValue + Suspense + 时间切片
  • 受控 vs 非受控? 受控 = value + onChange(状态可见);非受控 = ref(性能好、简单)
  • 状态提升 vs Context? 3 层以下提升;3 层以上 Context;全局复杂用 Zustand/Redux
  • React vs Vue 核心区别? React 运行时 diff(JSX);Vue 编译时 patch flag;心智不同(函数式 vs 响应式)

备注

Section titled “备注”
  • React 官方文档永远是第一优先级
  • 源码阅读时,跟着 commit message 看 PR 描述,理解设计动机
  • 实战项目优先于理论阅读(写 1 个比读 10 个有用)

📝 小结

Section titled “📝 小结”
  • 读源码的顺序:先看调度器 scheduler → react-reconciler 的 beginWork/completeWork → hooks 的 mountState/updateState,不要一上来啃 Fiber 双缓冲。
  • Fiber 的关键结构:current 与 workInProgress 双树、alternate 互相指、child/sibling/return 组成链表、flags 记录副作用。
  • 优先级靠 Lane 建模(React 18 起):同步 SyncLane、默认 DefaultLane、过渡 TransitionLane,可组合成 lane 集合。
  • 官方文档之外,Dan Abramov 的博客(useEffect 完整指南、useMemo 何时用)是最值得反复读的二手材料。
  • 学习路径:先做 todo → 再做并发渲染 demo → 最后读源码,别反过来。
