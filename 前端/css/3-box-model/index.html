Section titled “七、面试常考”

Q1:盒模型两种模式的区别?

Section titled “Q1:盒模型两种模式的区别?”

答:

  • content-box:width 仅 content,border + padding 额外加
  • border-box:width 包含 content + padding + border
  • 现代项目推荐 border-box

Q2:margin 合并的条件?

Section titled “Q2:margin 合并的条件?”

答:

  • 仅垂直 margin
  • 仅块级元素
  • 仅普通流(position: absolute 不算)
  • 仅相邻兄弟 / 父子
  • 解决方法:父元素创建 BFC、加 padding/border

Q3:position 各值的行为?

Section titled “Q3:position 各值的行为?”

答:

  • static:正常流
  • relative:相对自身原位置,仍占位
  • absolute:脱离文档流,相对最近 positioned 祖先
  • fixed:脱离文档流,相对视口
  • sticky:粘性,滚动容器内吸顶

面试追问(深化原 Q1-Q3)

Section titled “面试追问(深化原 Q1-Q3)”
  • box-sizing: inherit 怎么用? 全局设 * { box-sizing: border-box } 或在 :root 设后所有元素 inherit
  • margin 负值的效果? 元素向相反方向偏移;margin-left: -100% 实现全屏布局
  • sticky 和 fixed 区别? sticky 在父容器内吸顶(滚出父容器就失效);fixed 永远相对视口
  • 包含块(containing block) 怎么确定? static/relative 父元素;absolute 找最近 positioned;fixed 视口;sticky 最近滚动祖先

📝 小结

Section titled “📝 小结”
  • 两种盒模型:content-box(width 只算内容)vs border-box(含 padding 和 border),现代项目统一 * { box-sizing: border-box }。
  • margin 会垂直合并(相邻兄弟、父子之间),解决办法是父元素创建 BFC 或加 padding/border。
  • 定位五种值的关键差异:relative 占位、absolute 脱离文档流、fixed 相对视口、sticky 在滚动容器内吸顶。
  • 层叠上下文由 transform/opacity/filter/z-index 等属性创建,z-index 只在同一个上下文内比较。
