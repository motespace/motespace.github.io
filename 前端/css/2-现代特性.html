CSS 现代特性 ​

现代 CSS 已经强大到能替代很多 JS 工作。本文整理 2020+ 主流特性，重点是能立刻在生产用的部分。

1. CSS 变量（Custom Properties） ​

1.1 基础用法 ​

css
:root {
  --primary: #1890ff;
  --primary-hover: #40a9ff;
  --radius: 4px;
  --shadow: 0 2px 8px rgba(0,0,0,0.15);
  --spacing-sm: 8px;
  --spacing-md: 16px;
  --spacing-lg: 24px;
}

.button {
  background: var(--primary);
  border-radius: var(--radius);
  box-shadow: var(--shadow);
  padding: var(--spacing-sm) var(--spacing-md);
}

.button:hover {
  background: var(--primary-hover);
}

1.2 动态切换主题 ​

css
/* 暗色主题 */
[data-theme='dark'] {
  --bg: #1a1a1a;
  --text: #ffffff;
  --primary: #177ddc;
}

/* 浅色主题 */
[data-theme='light'] {
  --bg: #ffffff;
  --text: #333333;
  --primary: #1890ff;
}

body {
  background: var(--bg);
  color: var(--text);
}
js
// JS 切换
document.documentElement.setAttribute('data-theme', 'dark')

1.3 变量的计算 ​

css
:root {
  --base: 8px;
}

.box {
  padding: calc(var(--base) * 2);   /* 16px */
  margin: calc(var(--base) * 0.5);  /* 4px */
}

1.4 真实项目：会员端主题切换 ​

css
/* member-h5 真实代码 */
:root {
  --text-p1: #1a1a1a;
  --text-p2: #666;
  --bg-p1: #fff;
}

[data-theme='dark'] {
  --text-p1: #fff;
  --text-p2: #aaa;
  --bg-p1: #1a1a1a;
}

.platform_btn {
  color: var(--text-p2);
  background: var(--bg-p1);
}

2. Flexbox Gap（终于解决了间距问题） ​

css
/* 老办法：margin + 否定伪类 */
.list > * + * { margin-left: 16px; }

/* 新办法：gap 一行搞定 */
.list {
  display: flex;
  gap: 16px;            /* 行列统一间距 */
  row-gap: 8px;          /* 行间距 */
  column-gap: 16px;      /* 列间距 */
}

所有 display: flex / grid / inline-flex / inline-grid 都支持 gap。

3. CSS Grid 完整能力 ​

3.1 命名网格区域 ​

css
.dashboard {
  display: grid;
  grid-template-areas:
    "header header header"
    "sidebar main aside"
    "footer footer footer";
  grid-template-rows: 60px 1fr 40px;
  grid-template-columns: 200px 1fr 200px;
  gap: 16px;
  height: 100vh;
}

.header { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main { grid-area: main; }
.aside { grid-area: aside; }
.footer { grid-area: footer; }

3.2 响应式 Grid ​

css
.grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
  gap: 16px;
}
/* 自动适应：宽屏 4 列、窄屏 2 列、手机 1 列，无需媒体查询 */

3.3 子网格（Subgrid，2023+） ​

css
.parent {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
}

.child {
  display: grid;
  grid-template-columns: subgrid;  /* 继承父级列 */
  gap: 8px;
}

4. 容器查询（Container Queries，2023+ 主流） ​

媒体查询只能根据视口宽度响应，容器查询根据父容器大小响应——更适合组件化开发。

4.1 基础用法 ​

css
.card-container {
  container-type: inline-size;
  container-name: card;
}

@container card (min-width: 400px) {
  .card {
    display: flex;
    flex-direction: row;
  }
  .card__image { width: 200px; }
}

@container card (max-width: 399px) {
  .card {
    display: block;
  }
  .card__image { width: 100%; }
}

4.2 单元查询 ​

css
@container (min-width: 400px) {
  .card { ... }
}

5. :has() 父选择器（2023+ 主流） ​

has() 让父元素能根据子元素状态改变样式——曾经只能靠 JS 实现的逻辑。

css
/* ❌ 老办法：JS 给父元素加 class */
document.querySelector('.form').classList.toggle('has-error', hasError)

/* ✅ 新办法：纯 CSS */
.form:has(input:invalid) {
  border-color: red;
}

.form:has(input:focus) .help-text {
  color: blue;
}

/* 卡片包含图片时显示特定布局 */
.card:has(.card__image) {
  display: grid;
  grid-template-columns: 200px 1fr;
}

/* 表格行被选中 */
.table tr:has(input:checked) {
  background: var(--selected-bg);
}

6. aspect-ratio（替代 padding hack） ​

css
/* 老办法：保持 16:9 比例（不灵活）*/
.box {
  position: relative;
  width: 100%;
  padding-top: 56.25%; /* 9 / 16 = 56.25% */
}
.box__content {
  position: absolute;
  inset: 0;
}

/* ✅ 新办法：直接声明 */
.box {
  width: 100%;
  aspect-ratio: 16 / 9;
}

7. clamp() 响应式尺寸 ​

css
/* clamp(最小值, 首选值, 最大值) */
.title {
  /* 视口宽度变化时字号自动缩放，下限 24px，上限 48px */
  font-size: clamp(24px, 4vw, 48px);
}

.container {
  width: clamp(320px, 90%, 1200px);
}

.grid {
  gap: clamp(8px, 2vw, 24px);
}

8. :is() / :where() 简化选择器 ​

css
/* ❌ 重复写 */
.nav a:hover,
.nav button:hover,
.nav span:hover {
  color: red;
}

/* ✅ 用 :is() */
.nav :is(a, button, span):hover {
  color: red;
}

/* :where() 和 :is() 类似，但优先级为 0（不影响特异性）*/
/* 适合：重置样式 / 主题样式 */
:where(h1, h2, h3) {
  margin: 0;  /* 比直接写 h1, h2, h3 优先级低 */
}

css

13.3 动画性能：transform / opacity ​

css
/* ✅ 合成层动画，性能好 */

  transition: transform 0.3s, opacity 0.3s;

  transform: translateY(-4px);
  opacity: 0.9;

/* ❌ 触发 layout / paint，性能差 */
.box {
  transition: width 0.3s, margin 0.3s, top 0.3s;

面试常考 ​

Q1:CSS 现代特性包含哪些? ​

答:

  • 容器查询:@container、container-type、cqi/cqw 单位
  • 子网格:subgrid 继承父网格轨道
  • :has() 选择器:父选择器(等 15 年)
  • :focus-visible:键盘聚焦才有 outline
  • :where() 优先级为 0:可作为默认样式
  • color-mix() / lch() / oklch() 颜色:色彩空间转换
  • text-wrap: balance/pretty:标题自动平衡换行

Q2::has() 选择器解决了什么? ​

答:

  • 父选择器(基于子元素状态选父)
  • 例:form:has(input:invalid) { border: 2px solid red }(子 input 校验失败时给父 form 加红框)
  • 例:.card:has(img) { display: grid; grid-template-columns: 200px 1fr }
  • 浏览器支持:Chrome 105+ / Safari 15.4+ / Firefox 121+(2023 末全支持)

Q3:容器查询 vs 媒体查询? ​

答:

  • 媒体查询:看视口(viewport)宽度 → 全局响应式
  • 容器查询:看父容器宽度 → 真正组件级响应式
  • 例:卡片组件在不同父容器中自适应布局
  • 写法:@container (min-width: 400px) { .card { display: flex; } }

Q4:text-wrap: balance 有什么用? ​

答:

  • 标题自动平衡换行(避免最后一行只有一个词)
  • text-wrap: pretty 针对段落末行优化
  • Chrome 114+ / Safari 17.5+ / Firefox 121+ 支持
  • 提升排版美感,无需手动 <br>

Q5:@property 是什么? ​

答:

  • 用 CSS 注册自定义属性,带类型、初始值、是否继承
  • 例:@property --color { syntax: '<color>'; inherits: false; initial-value: red; }
  • 优势:变量可参与动画(CSS 普通变量不可)
  • 支持:Chrome 85+ / Safari 16.4+ / Firefox 128+
