Flexbox 布局深度

一、Flex 基础

Section titled “一、Flex 基础”

1.1 是什么

Section titled “1.1 是什么”

Flexbox = 一维布局模型,擅长行或列的元素排列。

适用场景:

  • ✅ 居中(垂直/水平)
  • ✅ 导航栏、工具栏
  • ✅ 等分布局
  • ✅ 卡片列表
  • ❌ 二维布局 → 用 Grid

五、Flex 的适用边界

Section titled “五、Flex 的适用边界”

一句话判据:需要同时控制「行」和「列」吗?需要 → Grid,不需要 → Flex。

场景 用 Flex
一维布局(只排一行或一列) ✅ Flex 的主场
居中(单个元素) ✅ 三行代码搞定,Grid 反而绕
导航栏 / 工具条 ✅ 子项宽度按内容自适应
标签页、按钮组 ✅ 内容长短不一时 Flex 不会溢出
等宽卡片网格 ❌ Grid 更简洁
整体页面布局 ❌ Grid 的行列控制更直观
需要重叠元素 ❌ Grid 的 grid-area 天然支持

为什么 Flex 更适合一维:

  • 主轴/交叉轴只需理解一条方向,不用建立行列坐标系
  • flex-basis + flex-grow 让子项按内容自然伸缩,不用算宽度
  • 换行由 flex-wrap 自动处理,不需要显式定义行轨道

为什么 Grid 更适合二维:

  • 行与列都是显式定义的(grid-template-columns/rows),子项用 grid-area 精确定位
  • 跨行跨列、命名区域、整体对齐,都是 Grid 的原生能力

完整的两维对比表(场景 × Grid/Flex/原因)→ CSS Grid 的「Grid vs Flex 选型」

六、面试常考

Section titled “六、面试常考”

Q1:flex: 1 是什么意思?

Section titled “Q1:flex: 1 是什么意思?”

答:flex: 1 是 flex: 1 1 0% 的简写。

  • grow: 1(放大占满剩余空间)
  • shrink: 1(可缩小)
  • basis: 0%(基础大小 0)

效果:多元素均分容器,这是最常用的等宽布局写法。

Q2:justify-content 和 align-items 区别?

Section titled “Q2:justify-content 和 align-items 区别?”

答:

  • justify-content:主轴方向(flex-direction 决定)
  • align-items:交叉轴方向(永远垂直主轴)

主轴默认水平 → justify-content 横向,align-items 纵向。

Q3:Flex 项目最小尺寸问题?

Section titled “Q3:Flex 项目最小尺寸问题?”

答:

实战:flex 容器里文字不省略,加 min-width: 0。

面试追问(深化原 Q1-Q3)

Section titled “面试追问(深化原 Q1-Q3)”
  • flex-basis: 0 vs auto? 0 忽略内容尺寸;auto 保留内容尺寸。flex: 1 用 0 实现“严格均分”
  • align-self 何时用? 单个 flex 项目覆盖父的 align-items
  • order 能改 DOM 顺序吗? 视觉上能,但 DOM 顺序不变 → 屏幕阅读器/键盘 Tab 仍按 DOM 顺序
  • flex-wrap: wrap 换行后 align-content? 控制多行的交叉轴对齐;默认 stretch
  • flex 性能问题? 大列表 flex 布局重计算成本高;可用 contain: layout 隔离

📝 小结

Section titled “📝 小结”
  • Flex 的核心是主轴/交叉轴:flex-direction 决定主轴方向,其余属性都相对这两个轴解释。
  • 换行的三个维度:主轴 flex-wrap、交叉轴 align-content、单行内 align-items。
  • justify-content 管主轴、align-items 管交叉轴,gap 比 margin 更好用(不会在容器边缘多出间距)。
  • 选型:一行或一列 → Flex;需要行列对齐的二维网格 → Grid。
