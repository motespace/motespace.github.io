现代 CSS 视觉效果

backdrop-filter、clip-path、mask、filter:毛玻璃和形状裁切,以前要靠图片或 canvas,现在一行 CSS。

一、backdrop-filter:毛玻璃

Section titled “一、backdrop-filter:毛玻璃”

四个要点:

属性 作用
blur() 模糊背后的内容
saturate() 提高饱和度,避免模糊后显得灰扑扑
brightness() 调整亮度
contrast() 增强对比

必须同时设置半透明背景色,否则模糊的是背后但你的卡片本身不透明,看不到效果。

性能警告

Section titled “性能警告”

backdrop-filter 很贵。它要读取、模糊、再合成背后的像素:

  • 只在小面积元素上用(卡片、导航栏),不要大面积铺满
  • 背后的内容在动时,每一帧都要重新模糊 → 移动端容易掉帧

兼容性

Section titled “兼容性”

Chrome / Edge 76+、Safari 9+(需 -webkit- 前缀)、Firefox 103+。移动端 Safari 支持良好,但低端机性能差。

二、clip-path:任意形状裁切

Section titled “二、clip-path:任意形状裁切”

常用形状速查:

优点:不需要额外的 DOM 元素(不像 border-radius 只能做圆角),形状任意。

注意:clip-path 会裁掉框外的部分,包括 box-shadow 和 border。要描边得用两层嵌套 + filter: drop-shadow()。

三、mask:遮罩

Section titled “三、mask:遮罩”

和 clip-path 类似,但遮罩可以是渐变,而不只是路径。

和 clip-path 的区别:

clip-path mask
形状 只能用路径(多边形/圆角) 路径 + 渐变 + 图片
透明度 只能裁掉,不能半透明 可以渐变到透明
作用 几何裁切 像素级遮罩

六、@property:让 CSS 变量可动画

Section titled “六、@property:让 CSS 变量可动画”

没有 @property 之前,CSS 变量是离散的,无法平滑过渡(只能整步跳变)。@property 让它变成有类型的、可插值的。

用途:渐变动画、角度过渡、自定义属性的补间动画。

🎯 面试常考

Section titled “🎯 面试常考”

Q1: backdrop-filter 和 filter 的区别? filter 处理元素自己(整个元素被模糊/调色);backdrop-filter 处理元素背后的内容(背后模糊,元素本身保持清晰)。毛玻璃效果用后者。

Q2: backdrop-filter 为什么卡? 它要读取背后像素、做模糊、再与自身合成,每帧都要重算。大面积使用或背后内容在动时开销极大。优化:限制使用面积、给静态背景、给不支持的浏览器做降级。

Q3: clip-path 和 border-radius 怎么选? 需要圆角用 border-radius(更简单,支持阴影);需要任意多边形、斜切、丝带等形状用 clip-path。注意 clip-path 会裁掉阴影和边框。

Q4: mask 和 clip-path 的区别? clip-path 只能用几何路径,只能「裁掉」不能半透明;mask 支持渐变和图片,能做出渐隐效果。

Q5: @property 解决什么问题? 让自定义属性有类型和初始值,从而可以被平滑插值。CSS 变量默认是离散值,动画时只能跳变;声明成 &lt;angle&gt; 后就能做连续过渡。

📝 小结

Section titled “📝 小结”
  • backdrop-filter 做毛玻璃很贵,小面积用 + 半透明背景 + @supports 降级。
  • filter 管自己,backdrop-filter 管背后;mask 支持渐变,clip-path 只支持几何路径。
  • background-clip: text 做渐变文字,记得加 -webkit- 前缀。
  • @property 让自定义属性可动画,是渐变动画的关键。
