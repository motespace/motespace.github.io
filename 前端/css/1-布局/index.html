11. 常见面试题

Section titled “11. 常见面试题”
题目 答案要点
盒模型两种 content-box（标准）vs border-box（IE）
Flexbox 主轴和交叉轴 flex-direction 决定主轴
flex: 1 是什么意思 flex: 1 1 0，三个值分别 grow / shrink / basis
space-between 和 space-around 区别 between 两端贴边；around 两端有间距
Grid 和 Flexbox 区别 Flexbox 一维 / Grid 二维
position: sticky 生效条件 父元素不能有 overflow: hidden
BFC 解决什么问题 清除浮动 / 阻止 margin 合并 / 防止浮动覆盖
Margin 塌陷怎么解决 BFC / padding-top / display: flex

| position: sticky 失效的常见原因? | 父元素有 overflow: hidden / 父元素高度不够 / 元素本身不是块级 | | Flex 1 vs Flex auto 区别? | flex: 1 = 1 1 0%(平均分配);flex: auto = 1 1 auto(按内容比例) | | 移动端 1px 边框为什么变粗? | DPR>1 时 1 物理像素 = 多 CSS 像素;用 transform scale 缩放或 border-image |

面试追问

Section titled “面试追问”
  • BFC 触发方式? overflow: hidden、display: flow-root、position: absolute、float 等
  • margin 塌陷什么时候发生? 仅垂直方向、块级、普通流的相邻兄弟 / 父子元素
  • space-between vs space-evenly? between 两端贴边;evenly 所有间距相等(包括两端)
  • Grid 什么时候优于 Flexbox? 二维布局(行+列同时控制);Flexbox 只一维

12. 项目踩过的坑

Section titled “12. 项目踩过的坑”
  1. position: sticky 不生效：父元素有 overflow: hidden 会破坏 sticky 上下文。
  2. flex 子项被压缩：flex-shrink: 1 是默认，文字内容过长会撑爆容器，要设置 flex-shrink: 0 或 min-width: 0。
  3. Margin 塌陷在 flex/grid 里不存在：所以中后台布局推荐用 flex 容器，能避免很多塌陷问题。
  4. 100vh 在移动端有 bug：底部地址栏会遮挡 100vh 内容，用 100dvh（dynamic viewport height）替代。
  5. Grid 的 fr 单位：在子项内容超出时会撑爆列宽，需要 minmax(0, 1fr) 限制。

📝 小结

Section titled “📝 小结”
  • 布局选型:一维用 Flex、二维用 Grid、常规流用块级、需要脱离文档流用定位。
  • Flex 的核心是「主轴 + 交叉轴」,所有属性都围绕这两个轴定义,理解了这点就不会记混。
  • Grid 是真正的二维布局,grid-template-areas 能用可视化的名字排版,适合复杂表单和页面骨架。
  • 绝对定位的参照物是最近的 positioned 祖先(没有则视口),fixed 参照视口 —— 这是 z-index 失效的根源之一。
