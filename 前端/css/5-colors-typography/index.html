Q3:linear-gradient 角度方向?

Section titled “Q3:linear-gradient 角度方向?”

答:0deg 从下到上,90deg 从左到右,180deg 从上到下(默认)。 与数学坐标系不同(数学 0° 是右,顺时针)。

面试追问(深化原 Q1-Q3)

Section titled “面试追问(深化原 Q1-Q3)”
  • -webkit-line-clamp 兼容性? Chrome/Safari/Edge 支持;Firefox 68+ 支持
  • 多行省略 fallback? JS 计算行数 + 截断(准确但麻烦);或 line-clamp + IE hack
  • font-display: swap 风险? 文字先 fallback 后切真字体 → 布局抖动(FOUT);optional 跳过加载失败
  • WOFF2 vs WOFF? WOFF2 Brotli 压缩,体积比 WOFF 小 30%;现代项目首选 WOFF2
  • unicode-range 用法? 字体子集化,只加载用到的字符;@font-face { unicode-range: U+0025-00FF; }

📝 小结

Section titled “📝 小结”
  • 颜色体系建议用 CSS 变量 + 语义命名(--color-primary),而不是在组件里写死具体色值。
  • color-mix() 可以在 CSS 里混色,做主题和状态色(hover/disabled)不用再引入预处理器。
  • 字体栈要有兜底顺序:系统字体 → 中文字体 → 通用 sans-serif,避免不同设备回退到难看的结果。
  • font-display: swap 避免字体加载时的空白(FOIT),配合 size-adjust 可以减少字体替换造成的抖动。
