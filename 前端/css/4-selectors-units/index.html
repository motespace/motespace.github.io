Q1:CSS 选择器优先级?

Section titled “Q1:CSS 选择器优先级?”

答:!important > 行内 > ID > class > 元素。 具体数值:!important 10000,行内 1000,ID 100,class/属性/伪类 10,元素/伪元素 1。 相等优先级,后写的胜出。

Q2:rem 和 em 区别?

Section titled “Q2:rem 和 em 区别?”

答:

  • em:相对父元素 font-size(嵌套会累积)
  • rem:相对根元素 font-size(html)
  • 推荐用 rem 做整体布局,em 做组件内相对

Q3:CSS 变量有什么优势?

Section titled “Q3:CSS 变量有什么优势?”

答:

  • 运行时可改(动态主题)
  • 跨组件共享
  • 比 SCSS 变量灵活(SCSS 编译时定死)

面试追问(深化原 Q1-Q3)

Section titled “面试追问(深化原 Q1-Q3)”
  • :nth-child vs :nth-of-type? child 算所有兄弟;of-type 只算同类型
  • 属性选择器性能? [class^="icon-"] 走属性扫描,比 ID 慢 10x;大列表慎用
  • CSS 变量继承? 默认继承;@property 注册后可指定类型和初始值
  • rem 移动端适配? html { font-size: calc(100vw / 7.5) }(设计稿 750px);或 postcss-pxtorem

📝 小结

Section titled “📝 小结”
  • 优先级用三元组记:ID(100) > 类/属性/伪类(10) > 标签/伪元素(1),相同则后者覆盖前者。
  • !important 会打断这个规则,只在「第三方样式覆盖不掉、且确实无法改源码」时用。
  • 常用单位:px(绝对)、rem(相对根字号)、em(相对父字号)、vw/vh(相对视口)、%(相对父容器)。
  • :is()/:where() 可以收敛选择器,:where() 的优先级是 0,适合做「可被覆盖」的默认样式。
