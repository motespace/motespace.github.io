二、滚动驱动动画

Section titled “二、滚动驱动动画”

过去要用 JS 监听 scroll 算进度再改样式。现在可以用纯 CSS:

animation-timeline: scroll() 是关键 —— 动画的进度由滚动位置驱动,而不是由时间驱动。

三种时间线

Section titled “三种时间线”
时间线 驱动什么 用法
scroll() 整个文档的滚动进度 animation-timeline: scroll()
scroll(root block) 指定滚动容器的进度 animation-timeline: scroll(nearest)
view() 元素进出视口的进度 animation-timeline: view()

view() 做滚动入场动画

Section titled “view() 做滚动入场动画”

animation-range 定义动画在时间线的哪一段生效:

  • entry 0% → 元素刚开始进入视口
  • cover 30% → 元素覆盖视口 30%
  • exit → 元素开始离开
  • contain → 元素完全在视口内

支持情况

Section titled “支持情况”
  • View Transition:Chrome / Edge 111+、Safari 18+、Firefox 144+。必须做降级(用 if (!document.startViewTransition))
  • 滚动驱动动画:Chrome / Edge 115+、Firefox 144+。Safari 尚不支持,必须用 @supports 检测

三、两个能力的共同点

Section titled “三、两个能力的共同点”
View Transition 滚动驱动动画
驱动方式 DOM 状态变化 滚动位置
声明式 是(CSS 定义动画) 是
性能 浏览器自动做合成层优化 同样走合成器
降级要求 必须 必须

两者都把「以前要用 JS 手写的动画」变成 CSS 声明,好处是:

  • 不占用主线程(走合成器)
  • 代码更少
  • 自动适配用户的 prefers-reduced-motion 设置

四、什么时候用

Section titled “四、什么时候用”
场景 用什么
列表增删的平滑过渡 View Transition + view-transition-name
图片点击放大 View Transition
Tab 内容切换 View Transition
阅读进度条 滚动驱动动画 scroll()
元素滚动入场 滚动驱动动画 view()
横向滚动叙事 scroll-timeline

不要滥用 View Transition:过渡期间页面是「冻结」的,动画超过 300ms 会让人觉得卡。而且它只适合「一次性状态切换」,不适合连续交互。

🎯 面试常考

Section titled “🎯 面试常考”

Q1: View Transition 的执行流程? document.startViewTransition(callback) → 浏览器截取旧状态快照 → 执行 callback 修改 DOM → 截取新状态 → 播放过渡动画 → finished promise resolve。回调里的 DOM 修改必须同步。

Q2: view-transition-name 有什么作用? 给元素起一个名字,新旧状态中同名的元素会被自动匹配,做位置和尺寸的平滑过渡(morph),而不是简单的淡出淡入。

Q3: 滚动驱动动画和传统 scroll 事件监听有什么区别? 传统做法要用 JS 监听 scroll、计算进度、改样式,占主线程且容易掉帧。滚动驱动动画用 animation-timeline: scroll() 把进度直接交给合成器,零 JS 且不占主线程。

Q4: animation-range 是干什么的? 定义动画在时间线上的哪一段生效。比如 entry 0% cover 30% 表示从元素刚进入视口到覆盖视口 30% 这段区间内动画从 0 走到 100%。

Q5: 浏览器支持情况? View Transition:Chrome/Edge 111+、Safari 18+、Firefox 144+。滚动驱动动画:Chrome/Edge 115+、Firefox 144+,Safari 尚不支持。两者都必须做降级,View Transition 用 document.startViewTransition 存在性检测,滚动动画用 @supports (animation-timeline: scroll())。

📝 小结

Section titled “📝 小结”
  • View Transition 让「状态切换」变成可动画的过程,靠 view-transition-name 配对元素做 morph。
  • 滚动驱动动画用 scroll() / view() 把滚动位置变成动画时间线,零 JS。
  • 两者都走合成器、不占主线程,但都必须做降级(View Transition 检测 API,滚动动画用 @supports)。
  • 过渡动画别超过 300ms,并且要尊重 prefers-reduced-motion。
