Web Storage:Cookie / localStorage / IndexedDB ​

一、Cookie ​

1.1 是什么 ​

Cookie = 服务端通过 Set-Cookie 让浏览器存储,后续自动带上。

http
Set-Cookie: session=xxx; HttpOnly; Secure; SameSite=Lax
Cookie: session=xxx

1.2 特点 ​

特性值
大小~4KB / 单个
数量~50 / 域名
生命周期默认会话期,可设 Max-Age
自动发送✅ 每次请求
访问性JS 可读(非 HttpOnly)

1.3 JS 访问 Cookie ​

js
// 读取(非 HttpOnly)
document.cookie  // 'name=John; theme=dark'

// 写入
document.cookie = 'name=Tom; expires=...; path=/'

// 删除(设过期)
document.cookie = 'name=; expires=Thu, 01 Jan 1970 00:00:00 GMT; path=/'

二、Web Storage API ​

2.1 localStorage ​

特点:

  • 永久存储(除非手动删除)
  • ~5~10MB
  • 同源策略
  • 同步 API
  • 不自动发送(JS 访问)
js
// 存储
localStorage.setItem('key', 'value')
localStorage.key = 'value'      // 简写
localStorage['key'] = 'value'   // 简写

// 读取
localStorage.getItem('key')      // 'value' 或 null
localStorage.key                 // 'value'
localStorage['key']              // 'value'

// 删除
localStorage.removeItem('key')
localStorage.clear()  // 清空所有

// 数量
localStorage.length  // 当前存储数量

// 索引(0,1,2...)
localStorage.key(0)  // 第一个 key 名

2.2 sessionStorage ​

和 localStorage 一样,但生命周期是会话(关闭标签页就清空)。

js
// API 完全一样
sessionStorage.setItem('key', 'value')
sessionStorage.getItem('key')
// 区别:关闭标签页(不是刷新)就清空

2.3 实战:封装 ​

js
// 通用存储函数
const storage = {
  get<T = unknown>(key: string, defaultValue?: T): T | undefined {
    try {
      const item = localStorage.getItem(key)
      return item ? JSON.parse(item) : defaultValue
    } catch {
      return defaultValue
    }
  },
  set(key: string, value: unknown): void {
    try {
      localStorage.setItem(key, JSON.stringify(value))
    } catch (e) {
      console.error('Storage quota exceeded', e)
    }
  },
  remove(key: string): void {
    localStorage.removeItem(key)
  },
}

// 使用
storage.set('user', { name: 'tom', age: 20 })
const user = storage.get('user', {})  // 带默认值

2.4 storage 事件(跨标签页) ​

js
// 监听其他标签页的 storage 变化
window.addEventListener('storage', (e) => {
  if (e.key === 'user') {
    console.log('其他标签页改了 user:', e.newValue)
  }
})

实战:多标签页同步登录态、登出。

三、IndexedDB(大数据本地存储) ​

3.1 是什么 ​

IndexedDB = 浏览器内嵌的事务型对象数据库。

  • 大小:可达几 GB(浏览器决定)
  • 支持索引、事务
  • 异步 API
  • 同源

3.2 基本用法 ​

ts
// 打开数据库
const request = indexedDB.open('MyDB', 1)

request.onsuccess = (e) => {
  const db = e.target.result
  // 拿到 db
}

request.onerror = (e) => {
  console.error('Open failed', e)
}

request.onupgradeneeded = (e) => {
  const db = e.target.result
  // 创建对象仓库
  if (!db.objectStoreNames.contains('users')) {
    const store = db.createObjectStore('users', { keyPath: 'id' })
    store.createIndex('name', 'name', { unique: false })
  }
}

3.3 增删改查 ​

ts
// 添加 / 更新
function addUser(user) {
  const tx = db.transaction(['users'], 'readwrite')
  const store = tx.objectStore('users')
  store.put(user)
  return tx.complete  // Promise
}

// 读取(通过 key)
function getUser(id) {
  return new Promise((resolve, reject) => {
    const tx = db.transaction(['users'], 'readonly')
    const store = tx.objectStore('users')
    const req = store.get(id)
    req.onsuccess = () => resolve(req.result)
    req.onerror = () => reject(req.error)
  })
}

// 通过索引查询
function getUserByName(name) {
  return new Promise((resolve, reject) => {
    const tx = db.transaction(['users'], 'readonly')
    const index = tx.objectStore('users').index('name')
    const req = index.get(name)
    req.onsuccess = () => resolve(req.result)
    req.onerror = () => reject(req.error)
  })
}

// 删除
function deleteUser(id) {
  const tx = db.transaction(['users'], 'readwrite')
  tx.objectStore('users').delete(id)
  return tx.complete
}

// 全部读取
function getAllUsers() {
  return new Promise((resolve, reject) => {
    const tx = db.transaction(['users'], 'readonly')
    const req = tx.objectStore('users').getAll()
    req.onsuccess = () => resolve(req.result)
    req.onerror = () => reject(req.error)
  })
}

3.4 封装(Dexie.js) ​

裸 IndexedDB 太繁琐,用 Dexie.js 简化:

bash
npm install dexie
ts
import Dexie from 'dexie'

const db = new Dexie('MyDB')
db.version(1).stores({
  users: '++id, name, age',  // ++ = auto-increment
  posts: '++id, userId, createdAt',
})

// 增删改查
await db.users.add({ name: 'tom', age: 20 })
await db.users.where('name').equals('tom').toArray()
await db.users.update(1, { age: 21 })
await db.users.delete(1)

五、实战经验 ​

5.1 选型 ​

Token / 会话:
  → Cookie(HttpOnly + Secure + SameSite)

用户偏好(主题、语言):
  → localStorage

表单草稿(防止误关):
  → sessionStorage

大量数据(笔记、商品缓存):
  → IndexedDB

5.2 安全注意 ​

js
// ❌ 敏感数据(密码、token)放 localStorage
localStorage.setItem('token', jwtToken)
// XSS 可以偷走

// ✅ 敏感数据用 HttpOnly Cookie
// 服务端 Set-Cookie: token=xxx; HttpOnly

5.3 容量管理 ​

js
// 检查容量(估算)
function getStorageSize() {
  let total = 0
  for (const key of Object.keys(localStorage)) {
    total += localStorage[key].length + key.length
  }
  return total  // 字节
}

// 写入前检查
function safeSetItem(key, value) {
  try {
    localStorage.setItem(key, value)
  } catch (e) {
    if (e.name === 'QuotaExceededError') {
      // 清理过期数据
      clearExpiredData()
      localStorage.setItem(key, value)
    }
  }
}

5.4 序列化 ​

js
// 复杂对象必须 JSON 序列化
localStorage.setItem('user', JSON.stringify({ name: 'tom' }))
const user = JSON.parse(localStorage.getItem('user'))

// ❌ 错误:直接存对象
localStorage.setItem('user', { name: 'tom' })  // '[object Object]'

// ❌ 错误:反序列化失败处理
const data = JSON.parse(localStorage.getItem('user') || 'null')
// JSON.parse('undefined') 报错

六、Crypto Storage(高级) ​

现代 API,可以加密存储:

js
// ❌ 敏感数据明文存
localStorage.setItem('secret', 'value')

// ✅ 加密
const encoder = new TextEncoder()
const data = encoder.encode('value')
const key = await crypto.subtle.generateKey(
  { name: 'AES-GCM', length: 256 },
  true,
  ['encrypt', 'decrypt']
)
const iv = crypto.getRandomValues(new Uint8Array(12))
const encrypted = await crypto.subtle.encrypt(
  { name: 'AES-GCM', iv },
  key,
  data
)
localStorage.setItem('secret', JSON.stringify({ iv, encrypted }))

七、面试常考 ​

Q1:Cookie 和 localStorage 区别? ​

答:

  • Cookie:自动发送到服务端,~4KB,适合 token
  • localStorage:不自动发送,~5MB,适合配置、UI 状态
  • 敏感数据:用 Cookie(HttpOnly 防 XSS)

Q2:什么时候用 IndexedDB? ​

答:

  • 数据量大(几 MB+)
  • 需要结构化查询(索引)
  • 离线应用
  • localStorage 容量不够

Q3:storage 事件能监听同标签页吗? ​

答:不能。storage 事件只在其他标签页修改时触发,自己改自己不触发。
