2. 箭头函数

Section titled “2. 箭头函数”

箭头函数没有自己的 this，继承外层作用域的 this。这是它和普通函数最大的区别。

箭头函数不能用的场景：

  • 不能作为构造函数（new 会报错）。
  • 没有 arguments 对象。
  • 不能作为 Generator 函数。
  • Vue 2 的 methods 里不能写箭头函数（this 拿不到 Vue 实例）。

面试追问

Section titled “面试追问”
  • var 循环闭包问题? for (var i=0; i<3; i++) setTimeout 全部输出 3;改 let 或 IIFE
  • 解构重命名? const { name: userName } = obj;深层解构 const { a: { b } } = obj
  • 扩展运算符应用场景? 数组浅拷贝 / 数组合并 / 函数参数 Math.max(...arr) / 剩余参数 (...rest)
  • Proxy 13 种 trap? get/set/has/deleteProperty/defineProperty/getOwnPropertyDescriptor 等

真实项目里踩过的坑

Section titled “真实项目里踩过的坑”
  1. forEach 里 await 不生效：必须用 for...of 或 Promise.all(arr.map(...))。
  2. ?? 替代 ||：处理数字 0、空字符串、false 这些合法值时，必须用 ??。
  3. 箭头函数不能用 Vue 2 methods：会拿不到 Vue 实例的 this。
  4. Proxy 不能监听非对象：原始类型要用 ref() 包装。

📝 小结

Section titled “📝 小结”
  • let/const 是块级作用域且存在暂时性死区;const 约束的是绑定不可重新赋值,不是值不可变。
  • 箭头函数没有自己的 this/arguments,this 取自词法作用域——这正是它在 Vue 回调里更安全的原因。
  • 解构赋值支持默认值与重命名,注意对象解构会丢失 this 绑定的场景。
  • 展开运算符是浅拷贝,{...obj} 只复制一层;深拷贝用 structuredClone 或专门的库。
  • Map/Set 保留插入顺序、可迭代、键可为任意类型;WeakMap/WeakSet 键必须是对象且弱引用,适合做 DOM 节点缓存。
  • Proxy/Reflect 是 Vue 3 响应式的地基:Proxy 拦截读写,Reflect 保证 set 里 receiver 语义正确。
  • 可选链 ?. 与空值合并 ?? 是只针对 nullish 的安全操作,注意 || 会把 0 和 '' 也吃掉。
