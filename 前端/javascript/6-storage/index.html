七、面试常考

Section titled “七、面试常考”

Q1:Cookie 和 localStorage 区别?

Section titled “Q1:Cookie 和 localStorage 区别?”

答:

  • Cookie:自动发送到服务端,~4KB,适合 token
  • localStorage:不自动发送,~5MB,适合配置、UI 状态
  • 敏感数据:用 Cookie(HttpOnly 防 XSS)

Q2:什么时候用 IndexedDB?

Section titled “Q2:什么时候用 IndexedDB?”

答:

  • 数据量大(几 MB+)
  • 需要结构化查询(索引)
  • 离线应用
  • localStorage 容量不够

Q3:storage 事件能监听同标签页吗?

Section titled “Q3:storage 事件能监听同标签页吗?”

答:不能。storage 事件只在其他标签页修改时触发,自己改自己不触发。

面试追问(深化原 Q1-Q3)

Section titled “面试追问(深化原 Q1-Q3)”
  • Cookie 安全属性? HttpOnly(防 XSS)、Secure(只 HTTPS)、SameSite=Strict(防 CSRF)
  • localStorage 同步阻塞? 同步 API,大数据读写卡主线程;考虑 IndexedDB
  • IndexedDB 事务? 所有操作必须在事务内;跨标签页同源共享存储
  • Storage Quota 怎么查? navigator.storage.estimate();Chrome 默认 60% 磁盘

📝 小结

Section titled “📝 小结”
  • Cookie 有 4KB 限制、会自动携带、可设 HttpOnly/Secure/SameSite;localStorage 同步、持久、5~10MB、JS 可读。
  • 存储 Token 优先 HttpOnly Cookie(防 XSS 读),但 Cookie 自动带上 → CSRF 要另防。
  • IndexedDB 是异步的、支持索引和事务,适合离线缓存和大结构化数据。
  • 所有 Web Storage 都是同步 API,读写阻塞主线程,大数据别放。
