Vue 插件系统 ​

一、什么是插件 ​

插件 是为 Vue 添加全局功能的代码。

常见用途:

  • 添加全局方法/属性(如 $axios、$message)
  • 添加全局资源(指令、过滤器、组件)
  • 通过 app.use() 全局配置
ts
import { createApp } from 'vue'
import App from './App.vue'
import router from './router'
import pinia from './store'

const app = createApp(App)

// Vue 官方插件
app.use(router)
app.use(pinia)

// 第三方插件(Element Plus、i18n、axios)
app.use(ElementPlus)
app.use(i18n)

// 自定义插件
app.use(myPlugin, { /* 选项 */ })

二、编写插件 ​

2.1 插件结构 ​

ts
// plugins/my-plugin.ts
import type { App, Plugin } from 'vue'

interface Options {
  prefix?: string
  // ...
}

const myPlugin: Plugin = {
  install(app: App, options: Options = {}) {
    // 1. 全局方法/属性
    app.config.globalProperties.$myMethod = () => {
      // ...
    }

    // 2. 全局指令
    app.directive('my-directive', {
      mounted(el, binding) {
        // ...
      },
    })

    // 3. 全局组件
    app.component('MyComponent', MyComponent)

    // 4. provide/inject
    app.provide('myKey', { /* ... */ })

    // 5. 全局 mixin(慎用)
    // app.mixin({ ... })

    // 6. 路由、状态(扩展)
    // app.use(router)
    // app.use(pinia)
  },
}

export default myPlugin

2.2 函数式插件 ​

ts
// 简单插件可以是函数
const myPlugin = (app: App, options: Options) => {
  app.config.globalProperties.$hello = () => 'Hello'
}

三、Vue 2 vs Vue 3 插件对比 ​

3.1 安装方式 ​

js
// Vue 2 - 全局 Vue
import Vue from 'vue'
import VueRouter from 'vue-router'

Vue.use(VueRouter)  // 直接 Vue.use

// Vue 3 - app 实例
import { createApp } from 'vue'
import { createRouter } from 'vue-router'

const app = createApp(App)
app.use(createRouter({ /* ... */ }))  // app.use

关键变化:

  • 不再有全局 Vue 变量
  • 插件安装到具体 app 实例(支持多实例)

3.2 全局属性 ​

js
// Vue 2 - prototype
Vue.prototype.$http = axios

// Vue 3 - globalProperties
app.config.globalProperties.$http = axios

// 访问方式
// Vue 2: this.$http
// Vue 3: this.$http(组件内)或 getCurrentInstance().appContext.config.globalProperties.$http

3.3 插件能力对比 ​

能力Vue 2Vue 3
全局方法Vue.prototypeapp.config.globalProperties
全局组件Vue.componentapp.component
全局指令Vue.directiveapp.directive
全局 mixinVue.mixinapp.mixin
provide/injectVue.provideapp.provide
生命周期钩子全局钩子(beforeCreate 等)移除

3.4 全局生命周期钩子(已移除) ​

js
// Vue 2 - 移除全局钩子
Vue.mixin({
  created() {
    console.log('所有组件 created')
  },
})

// Vue 3 - 用 provide + 组合式
// 父级
import { provide } from 'vue'
provide('onCreated', (callback) => callback())

// 子级
import { inject, onMounted } from 'vue'
const onCreated = inject('onCreated', () => {})
onCreated(() => console.log('created'))

四、实战插件 ​

4.1 axios 插件 ​

ts
// plugins/axios.ts
import axios, { type AxiosInstance } from 'axios'
import type { App } from 'vue'

const setupAxios = (app: App) => {
  const instance = axios.create({
    baseURL: import.meta.env.VITE_API_BASE_URL,
    timeout: 10000,
  })

  // 请求拦截器
  instance.interceptors.request.use((config) => {
    const token = localStorage.getItem('token')
    if (token) {
      config.headers.Authorization = `Bearer ${token}`
    }
    return config
  })

  // 响应拦截器
  instance.interceptors.response.use(
    (response) => response.data,
    (error) => {
      if (error.response?.status === 401) {
        // 跳登录
      }
      return Promise.reject(error)
    }
  )

  app.config.globalProperties.$axios = instance
  app.provide('axios', instance)
}

export default setupAxios
ts
// main.ts
import setupAxios from './plugins/axios'
app.use(setupAxios)

// 组件使用
const { $axios } = getCurrentInstance()!.appContext.config.globalProperties
const data = await $axios.get('/users')

4.3 Element Plus 自动注册 ​

ts
// plugins/element-plus.ts
import ElementPlus from 'element-plus'
import 'element-plus/dist/index.css'
import * as ElementPlusIconsVue from '@element-plus/icons-vue'

export default {
  install(app: App) {
    app.use(ElementPlus)
    
    // 注册所有图标
    for (const [key, component] of Object.entries(ElementPlusIconsVue)) {
      app.component(key, component)
    }
  },
}

4.4 全局错误处理 ​

ts
// plugins/error-handler.ts
import type { App } from 'vue'

export default {
  install(app: App) {
    app.config.errorHandler = (err, instance, info) => {
      console.error('Vue 错误:', err, info)
      // 上报到 Sentry
      Sentry.captureException(err)
    }

    window.addEventListener('unhandledrejection', (e) => {
      console.error('未捕获 Promise 错误:', e.reason)
    })
  },
}

八、面试常考 ​

Q1:Vue 3 插件和 Vue 2 区别? ​

答:

  • 安装方式:Vue 2 Vue.use(),Vue 3 app.use()
  • 多实例:Vue 3 支持(每个 app 独立)
  • 全局属性:Vue 2 prototype,Vue 3 globalProperties
  • 生命周期钩子:Vue 2 全局 mixin,Vue 3 移除(用 provide)

Q2:什么时候写插件? ​

答:

  • 多个项目共享的工具(axios、sdk)
  • 跨组件全局可用的方法/属性
  • 第三方库的 Vue 包装(Element Plus、Pinia)
  • 全局错误处理、埋点

Q3:全局属性 vs provide/inject? ​

答:

  • 全局属性(globalProperties):简单直接,但 TS 支持弱
  • provide/inject:更现代、TS 友好、跨层级
  • 推荐:能 provide 就 provide,简单全局用 globalProperties

面试追问(深化原 Q1-Q3) ​

  • app.use 注册顺序? 插件按注册顺序执行 install;先注册的 plugin 内的 component / directive 优先级低
  • provide / inject 跨插件通信? 插件 install 中 app.provide('key', value);组件用 inject('key')
  • 第三方 UI 库(Vant/Element)怎么集成? app.use(Vant);按需引入用 unplugin-vue-components
  • 插件和全局 mixin 区别? 插件更标准化、可配置;mixin Vue 3 已弱化
  • 如何编写 TS 友好的插件? 导出 Plugin 类型;Plugin<Options[]> 让用户有类型提示
