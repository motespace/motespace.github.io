十二、面试常考

Section titled “十二、面试常考”

Q1:Vue 3 Composition API 解决了什么问题?

Section titled “Q1:Vue 3 Composition API 解决了什么问题?”

答:

  • Vue 2 Options API 复用靠 mixin(命名冲突、来源不清)
  • 大组件 Options 块多,逻辑分散
  • TS 支持弱
  • Composition 按逻辑组织、composable 复用、TS 友好

Q2:Vue 3 vs Vue 2 响应式原理?

Section titled “Q2:Vue 3 vs Vue 2 响应式原理?”

答:

  • Vue 2:Object.defineProperty 给每个属性加 getter/setter
  • Vue 3:Proxy 代理整个对象,惰性追踪、效率更高、支持数组/Map/Set

Q3:Teleport 解决了什么?

Section titled “Q3:Teleport 解决了什么?”

答:

  • 组件 DOM 受父组件 CSS 影响(z-index、overflow、transform)
  • Teleport 把组件移到 body,不受父组件影响
  • 模态框、Toast 等必备

面试追问(深化原 Q1-Q3)

Section titled “面试追问(深化原 Q1-Q3)”
  • defineModel 解决了什么? 替代手写 props + emit;编译时展开,父组件用 v-model 更直观
  • defineProps 泛型怎么写? defineProps<{ name: string; age?: number }>();运行时用 withDefaults
  • toRefs 和 toRef 区别? toRefs(obj) 批量转,toRef(obj, 'key') 单个;解构 reactive 必备
  • defineExpose 何时用? <script setup> 默认组件封闭;父组件要 ref 拿子组件时,子用 defineExpose 暴露
  • Vue 3.4 模板解析器改进? 性能提升 2 倍;修复 rethrow 优化;新编译策略

📝 小结

Section titled “📝 小结”
  • script setup 是最大变化:编译时把 setup 变成 setup 闭包,性能和 TS 推断都更好。
  • defineModel(3.4+)内置双向绑定,defineExpose 限制组件暴露给父级的成员,useTemplateRef(3.5+)替代字符串 ref。
  • Fragment 支持多根节点,Teleport 把内容渲染到别处(弹窗挂 body),Suspense 处理异步依赖。
  • defineAsyncComponent 做组件懒加载,配合路由级分割。
