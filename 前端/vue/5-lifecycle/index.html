Vue 生命周期详解

一、为什么需要了解生命周期

Section titled “一、为什么需要了解生命周期”

Vue 组件从创建到销毁经历多个阶段,每个阶段触发不同的“钩子”——在这些钩子里可以:

  • created:初始化数据、发请求
  • mounted:操作 DOM、初始化第三方库
  • beforeUnmount:清理定时器、解绑事件

4.2 两种写法的生命周期对照

Section titled “4.2 两种写法的生命周期对照”
Options API Composition API
创建 created() setup() 里直接执行
挂载 mounted() onMounted()
更新前 beforeUpdate() onBeforeUpdate()
更新后 updated() onUpdated()
卸载前 beforeUnmount() onBeforeUnmount()
卸载后 unmounted() onUnmounted()

关键差别:Options API 的 created 在 setup 之后(setup 先跑),但 mounted 仍然在 DOM 挂载之后。

两种 API 风格的全维度对比(代码组织 / 逻辑复用 / TS / this)→ Vue 3 新特性 的「Composition API vs Options API」

5.3 异步组件

Section titled “5.3 异步组件”

异步组件在加载完成后才触发 created / mounted,之前组件处于未挂载状态。

生命周期要点:请求数据放在 setup 或 onMounted 里都可以,但要注意组件可能因为 v-if 反复挂载卸载,定时器与监听要成对清理。

异步组件的完整用法、加载状态、错误处理 → Vue 3 新特性

5.4 Suspense

Section titled “5.4 Suspense”

&lt;Suspense&gt; 让异步组件在数据就绪前显示 fallback,期间组件尚未挂载,所以父组件的 mounted 会等 Suspense 内的内容就绪后才触发。

生命周期要点:用 Suspense 时,onMounted 的触发时机与普通异步组件不同,别把「等数据」和「等挂载」混为一谈。

Suspense 的原理、嵌套用法、实验状态 → Vue 3 新特性

Section titled “八、与 React 生命周期的对比”

十、Vue 2 ↔ Vue 3 生命周期钩子对照表

Section titled “十、Vue 2 ↔ Vue 3 生命周期钩子对照表”

Vue 3 对钩子做了大幅调整:

  • ❌ 删除:beforeCreate / created —— 因为 setup() 已经覆盖了它们的功能
  • 🔄 重命名:beforeDestroy / destroyed → beforeUnmount / unmounted(语义更准确)
  • 🆕 新增:onRenderTracked / onRenderTriggered —— 调试响应式依赖用

9.2 为什么重命名 destroyed → unmounted?

Section titled “9.2 为什么重命名 destroyed → unmounted?”

Vue 3 把 beforeDestroy / destroyed 改为 beforeUnmount / unmounted,语义更准确:

术语 含义
destroy 听起来像“销毁实例对象”,但实际上实例对象还在
unmount ✅ 准确表达“从 DOM 树卸载”,this 仍然可用,只是 $el 没了

十一、面试常考

Section titled “十一、面试常考”

Q1:父子组件生命周期顺序?

Section titled “Q1:父子组件生命周期顺序?”

答:

  • 创建/挂载:父先,但子先完成(created → mounted)
  • 更新:父先,但子先完成(beforeUpdate → updated)
  • 卸载:父先,但子先完成(beforeUnmount → unmounted)

Q2:created 和 mounted 区别?

Section titled “Q2:created 和 mounted 区别?”

答:

  • created:data/methods/computed 已初始化,但 DOM 还没生成,不能访问 $refs
  • mounted:DOM 已挂载,可以操作 DOM,常用于第三方库初始化
  • 服务端渲染:mounted 不执行

Q3:setup 和 created 哪个先?

Section titled “Q3:setup 和 created 哪个先?”

答:

  • setup() 在 created 之前执行(实际等价)
  • 组合式 API 的 setup 替代了 created/beforeCreate
  • 组合式 API 里不用 beforeCreate/created,改用 setup 本身

面试追问(深化原 Q1-Q3)

Section titled “面试追问(深化原 Q1-Q3)”
  • onMounted 在 SSR 中执行吗? 不执行;SSR 阶段只有 setup / onServerPrefetch
  • 父子组件 mounted 顺序为什么反? Vue 先挂载父 → 父 mounted hook → 再递归挂载子;子全部完成才回到父 mounted
  • onUpdated 慎用? 容易死循环(改数据 → 触发 update);需要条件判断或 watch
  • keep-alive 多了哪两个生命周期? onActivated(激活)、onDeactivated(失活)

📝 小结

Section titled “📝 小结”
  • 生命周期按组件实例划分:创建(setup/beforeCreate/created)→ 挂载(mounted)→ 更新(updated)→ 卸载(unmounted)。
  • created 里拿不到 DOM,mounted 才拿得到;setup 等价于 created。
  • Composition API 里用 onMounted/onUnmounted 等组合式函数代替选项式钩子。
  • 组件被 &lt;KeepAlive&gt; 缓存时,mounted/unmounted 不再触发,要用 activated/deactivated。
