Vue 模板语法与指令 ​

一、模板编译原理 ​

Vue 模板不是 HTML,Vue 编译器把它编译成渲染函数:

html
<!-- 模板 -->
<div>{{ message }}</div>

<!-- 编译后 -->
function render() {
  return h('div', null, this.message)
}

编译时优化(Vue 3):

  • 静态提升:静态节点提升到渲染函数外
  • PatchFlag:动态节点标记
  • Block Tree:减少 diff 范围

二、文本插值 ​

2.1 Mustache 语法 ​

vue
<template>
  <p>{{ message }}</p>
  <p>{{ count + 1 }}</p>
  <p>{{ ok ? 'YES' : 'NO' }}</p>
  <p>{{ message.split('').reverse().join('') }}</p>
</template>

2.2 v-once(只渲染一次) ​

vue
<p v-once>{{ staticContent }}</p>

编译后静态内容,不再响应数据变化。

2.3 v-pre(跳过编译) ​

vue
<p v-pre>{{ 这里的内容不会被编译 }}</p>

用途:展示 Vue 语法本身、加快大段静态内容编译。

2.4 v-html(原始 HTML) ​

vue
<p v-html="rawHtml"></p>

⚠️ 安全警告:

ts
// ❌ 危险:XSS 风险
const rawHtml = ref('<img src=x onerror=alert(1)>')

// ✅ 安全:用 DOMPurify 净化
import DOMPurify from 'dompurify'
const safeHtml = computed(() => DOMPurify.sanitize(rawHtml.value))

实战:

  • 富文本(评论、商品描述)必须经过 DOMPurify
  • 内部信任的内容(配置项)可直接用

三、指令详解 ​

3.1 v-bind(😃— 绑定属性 ​

vue
<!-- 绑定 attribute -->
<img :src="imageUrl" :alt="imageAlt" />

<!-- 绑定 class(对象) -->
<div :class="{ active: isActive, disabled: !enabled }"></div>

<!-- 绑定 class(数组) -->
<div :class="[activeClass, errorClass]"></div>

<!-- 绑定 style(对象) -->
<div :style="{ color: textColor, fontSize: fontSize + 'px' }"></div>

<!-- 绑定 style(数组) -->
<div :style="[baseStyles, overridingStyles]"></div>

<!-- 绑定 prop -->
<Child :title="pageTitle" />

<!-- 动态属性名 -->
<button :[key]="value">  <!-- v-bind 动态参数 -->

3.2 v-on(@)— 监听事件 ​

vue
<!-- 基本 -->
<button @click="handleClick">点击</button>

<!-- 内联 -->
<button @click="count++">+1</button>

<!-- 传参 -->
<button @click="handleClick($event, item)">点击</button>

<!-- 多个事件 -->
<input @input="onInput" @blur="onBlur" @focus="onFocus" />

<!-- 修饰符 -->
<form @submit.prevent="onSubmit">      <!-- 阻止默认 -->
<input @keyup.enter="onEnter">          <!-- 特定键 -->
<div @click.stop="onClick">              <!-- 阻止冒泡 -->
<div @click.self="onClick">              <!-- 仅自己触发 -->
<div @click.once="onClick">              <!-- 仅触发一次 -->
<div @click.passive="onScroll">          <!-- 不阻止默认 -->

修饰符链:

vue
<button @click.stop.prevent="onClick">点击</button>

3.3 v-if / v-else-if / v-else(条件渲染) ​

vue
<template>
  <div v-if="type === 'A'">A</div>
  <div v-else-if="type === 'B'">B</div>
  <div v-else-if="type === 'C'">C</div>
  <div v-else>默认</div>
</template>

原理:if 是真销毁/真创建(v-if=false 节点不存在)。

3.4 v-show(切换显示) ​

vue
<p v-show="isVisible">显示/隐藏</p>

原理:display: none/block 切换,节点始终存在。

3.5 v-show vs v-if ​

v-ifv-show
DOM销毁/创建切换 display
开销初次渲染快,切换慢初次渲染慢,切换快
适用条件不常变频繁切换

3.6 v-for(列表渲染) ​

vue
<template>
  <!-- 数组 -->
  <ul>
    <li v-for="item in items" :key="item.id">{{ item.name }}</li>
  </ul>

  <!-- 带索引 -->
  <li v-for="(item, index) in items" :key="item.id">
    {{ index }} - {{ item.name }}
  </li>

  <!-- 对象 -->
  <li v-for="(value, key) in obj" :key="key">{{ key }}: {{ value }}</li>

  <!-- 数字(1~n) -->
  <span v-for="n in 10" :key="n">{{ n }}</span>

  <!-- 字符串 -->
  <span v-for="char in 'hello'" :key="char">{{ char }}</span>
</template>

key 的作用:Vue 用 key 匹配新旧节点,识别移动/插入/删除。

vue
<!-- ❌ 用 index 作 key -->
<li v-for="(item, index) in items" :key="index">

<!-- ✅ 用稳定 id -->
<li v-for="item in items" :key="item.id">

为什么不用 index? 重排时 index 不变,Vue 会错配,导致不必要的 DOM 操作。

3.7 v-model(双向绑定) ​

基本原理 ​

vue
<input v-model="text" />
<!-- 等价于 -->
<input :value="text" @input="text = $event.target.value" />

表单元素 ​

vue
<!-- text / textarea -->
<input v-model="text" />
<textarea v-model="content"></textarea>

<!-- checkbox(单选) -->
<input type="checkbox" v-model="checked" />

<!-- checkbox(多选,绑数组) -->
<input type="checkbox" value="Apple" v-model="fruits" />
<input type="checkbox" value="Banana" v-model="fruits" />

<!-- radio -->
<input type="radio" value="A" v-model="picked" />

<!-- select -->
<select v-model="selected">
  <option value="A">A</option>
</select>

修饰符 ​

vue
<!-- .lazy:change 时才更新(不是 input) -->
<input v-model.lazy="text" />

<!-- .number:自动转数字 -->
<input v-model.number="age" type="number" />

<!-- .trim:去除首尾空格 -->
<input v-model.trim="text" />

自定义组件 v-model ​

vue
<!-- CustomInput.vue -->
<script setup>
defineProps(['modelValue'])
const emit = defineEmits(['update:modelValue'])
</script>

<template>
  <input
    :value="modelValue"
    @input="emit('update:modelValue', $event.target.value)"
  />
</template>

<!-- 使用 -->
<CustomInput v-model="text" />

详见 2-component-basics.md。

3.8 v-once(性能优化) ​

vue
<p v-once>{{ staticValue }}</p>

编译成静态节点,不参与响应式更新。

3.9 v-memo(Vue 3.2+) ​

vue
<div v-memo="[depA, depB]">
  <!-- 只在 depA 或 depB 变化时重新渲染 -->
  <ExpensiveComponent />
</div>

用途:大列表中跳过不必要的子组件更新。

3.10 v-pre / v-cloak(技巧) ​

vue
<!-- v-pre:跳过编译 -->
<pre v-pre>{{ Vue 模板语法 }}</pre>

<!-- v-cloak:防止未编译闪烁 -->
<style>
[v-cloak] { display: none; }
</style>
<div v-cloak>{{ message }}</div>

四、模板编译优化 ​

4.1 静态提升 ​

vue
<!-- 模板 -->
<div>
  <p>静态文本</p>
  <p>{{ dynamic }}</p>
</div>

<!-- 编译后(简化) -->
const hoisted = { type: 'p', children: '静态文本' }
function render() {
  return h('div', null, [
    hoisted,                    // 静态节点,提到外部
    h('p', null, this.dynamic), // 动态节点
  ])
}

效果:静态节点不参与 diff,提升性能。

4.2 PatchFlag ​

vue
<p class="static" :class="dynamic">{{ text }}</p>

编译时标记动态部分:

{
  type: 'p',
  props: { class: 'static dynamic' },  // PatchFlag: CLASS
  children: text,                       // PatchFlag: TEXT
}

效果:diff 时只比较标记的动态部分,跳过静态。

4.3 Block Tree ​

Vue 3 把模板拆成多个 Block,每个 Block 内部独立更新:

<div>
  <header>静态</header>
  <div v-if="show">
    <p>{{ text }}</p>
  </div>
</div>

v-if 节点可能是动态 Block,独立收集依赖,其他 Block 不需要更新它。

五、模板编写最佳实践 ​

5.1 避免过深的嵌套 ​

vue
<!-- ❌ 嵌套 -->
<div v-if="user">
  <div v-if="user.profile">
    <div v-if="user.profile.address">
      ...
    </div>
  </div>
</div>

<!-- ✅ 用 computed 简化 -->
<template v-if="fullAddress">
  <div>{{ fullAddress }}</div>
</template>

5.2 key 用稳定 ID ​

vue
<!-- ❌ -->
<li v-for="(item, i) in items" :key="i">

<!-- ✅ -->
<li v-for="item in items" :key="item.id">

5.3 v-if vs v-show ​

vue
<!-- 偶尔切换 → v-if -->
<div v-if="showModal">Modal</div>

<!-- 频繁切换 → v-show -->
<div v-show="loading">加载中</div>

5.4 避免复杂表达式 ​

vue
<!-- ❌ 模板里复杂逻辑 -->
<p>{{ items.filter(i => i.active).map(i => i.name).join(', ') }}</p>

<!-- ✅ computed -->
<p>{{ activeNames }}</p>
ts
const activeNames = computed(() =>
  items.value.filter(i => i.active).map(i => i.name).join(', ')
)

5.5 避免直接修改 props ​

vue
<!-- ❌ -->
<Child :count="count" @click="count++" />

<!-- ✅ 用 emit 让父组件改 -->
<Child :count="count" @change="$emit('change', count + 1)" />

详见 7-custom-directives.md。

七、SSR 与模板 ​

Vue SSR 在服务端编译模板,不能依赖浏览器 API:

vue
<template>
  <!-- ❌ 在服务端渲染会报错 -->
  <div :style="{ background: localStorage.getItem('color') }"></div>

  <!-- ✅ 在 onMounted 里访问 -->
  <div :style="{ background: color }"></div>
</template>

八、面试常考 ​

Q1:v-if 和 v-show 区别? ​

答:

  • v-if:真销毁/创建,切换开销大,适合条件不常变
  • v-show:切换 display,节点常驻,适合频繁切换

Q2:为什么列表要加 key? ​

答:

  • key 是节点的唯一标识
  • 没 key:Vue 按 index 匹配,重排时错位,可能导致 bug
  • 有 key(稳定 ID):Vue 正确识别 DOM 的增删改,提升 diff 效率

Q3:v-model 原理? ​

答:

  • 是 :value + @input 的语法糖
  • 表单元素:监听 input/change 事件更新数据
  • 自定义组件:约定 modelValue prop + update:modelValue 事件

Q4:模板编译优化有哪些? ​

答:

  • 静态提升:静态节点提到 render 外
  • PatchFlag:标记动态部分,跳过静态 diff
  • Block Tree:模板拆块,独立收集依赖
  • 缓存事件处理函数

面试追问(深化原 Q1-Q4) ​

  • v-if 和 v-for 不能一起用? Vue 2 中 v-for 优先(v-if 被忽略);Vue 3 中 v-if 优先。永远不要一起用,用 template 包裹
  • key 选 index 有什么坑? 重排 / 过滤时 index 和 item 错位 → DOM 错乱、状态残留
  • v-model 自定义修饰符怎么实现? props.modelModifiers + 组件内处理;如 v-model.capitalize
  • PatchFlag 怎么工作的? 编译时给动态节点打标记(1=文本、2=class、4=style 等);diff 只比对这些位

九、Vue 2 vs Vue 3 对比 ​

9.1 文本插值(基本不变) ​

html
<!-- Vue 2 / Vue 3 都一样 -->
<p>{{ message }}</p>

9.2 v-bind(语法不变) ​

html
<!-- Vue 2 -->
<img :src="imageUrl" v-bind:alt="imageAlt">

<!-- Vue 3 -->
<img :src="imageUrl" :alt="imageAlt">
<!-- 完全一样,只是建议在动态属性名场景用 v-bind:[key] -->

9.3 v-on(语法不变) ​

html
<!-- Vue 2 / Vue 3 一致 -->
<button @click="handler">点击</button>
<button @click.stop.prevent="handler">带修饰符</button>

Vue 3 增强:

  • 新增 exact、passive、once 等修饰符
  • 事件必须以 onXxx 形式(不再支持 v-on:click.native)

9.4 v-model(最大变化 ⭐) ​

html
<!-- Vue 2:仅 value + input -->
<input v-model="text">

<!-- Vue 3:多个 v-model,自定义 prop 名 -->
<UserForm v-model:username="name" v-model:age="age" />

<!-- 自定义组件(同 props / update 约定) -->
<CustomInput v-model="searchText" />
<!-- 等价于 -->
<CustomInput
  :modelValue="searchText"
  @update:modelValue="searchText = $event"
/>

Vue 3 新增:

  • .lazy、.number、.trim 一致
  • 多个 v-model
  • 自定义组件 prop 名(v-model:xxx)

9.5 v-if / v-show(不变) ​

html
<!-- Vue 2 / Vue 3 一致 -->
<div v-if="loading">加载中</div>
<div v-show="visible">显示</div>

9.6 v-for(用法变化 ⚠️) ​

html
<!-- Vue 2:必须有 key,可以用 index -->
<li v-for="(item, index) in items" :key="index">
  {{ item.name }}
</li>

<!-- Vue 3:key 仍然必须,但有了 v-for 优先级 -->
<!-- Vue 3.x 之前:v-if 优先级高于 v-for(不推荐组合) -->
<!-- Vue 3.x 起:同时使用时,不再有歧义(vue 3.2+ 修复) -->
<template v-for="item in items" :key="item.id">
  <div v-if="item.show">{{ item.name }}</div>
</template>

Vue 3 推荐:

  • 用 <template v-for> 包裹复杂逻辑
  • 仍必须 加 key

9.7 新指令(Vue 3 新增) ​

html
<!-- Vue 3 独有 -->
<p v-once>静态内容</p>
<p v-memo="[dep]">仅依赖变化时更新</p>
<div v-cloak>防闪烁</div>

<!-- Vue 3.4 新增 defineModel 宏 -->
<script setup>
const model = defineModel()  // 自动注册 v-model
</script>

9.8 编译器优化 ​

Vue 3 编译时做了大量优化:

Vue 2 编译产物:
  - 每次 render 都要全量重新生成
  - 没有 PatchFlag
  
Vue 3 编译产物:
  - 静态节点提升(hoistStatic)
  - PatchFlag 标记动态部分
  - Block Tree 收集依赖
  - 事件监听器缓存

效果:同样组件,Vue 3 编译产物更小、运行时更快。

9.9 关键变化对比表 ​

指令Vue 2Vue 3
v-model单个多个(v-model:name)
v-for 优先级高于 v-if同时使用不再冲突
新指令无v-memo、defineModel 宏
编译优化无静态提升 + PatchFlag
v-on.native支持移除(改用 emits)
