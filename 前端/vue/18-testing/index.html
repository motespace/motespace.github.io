Q1:Vue 组件怎么测试?

Section titled “Q1:Vue 组件怎么测试?”

答:

  • 用 @vue/test-utils 的 mount 渲染组件
  • 测试 props、emit、slot、事件
  • 用 await flushPromises() 等异步
  • Mock 外部依赖(fetch、子组件)

Q2:Vue 2 和 Vue 3 测试区别?

Section titled “Q2:Vue 2 和 Vue 3 测试区别?”

答:

  • @vue/test-utils 升级到 2.x,API 小变(propsData → props)
  • 推荐用 Vitest 替代 Jest(更快)
  • 组合式 API 测试更直接(ref/computed 直接测试)
  • flushPromises 简化异步测试

Q3:覆盖率多少合适?

Section titled “Q3:覆盖率多少合适?”

答:

  • 工具 / composable:90%+
  • 业务核心:70~80%
  • 展示组件:不强制
  • 追求 100% 是反模式

面试追问(深化原 Q1-Q3)

Section titled “面试追问(深化原 Q1-Q3)”
  • Vue Test Utils vs Vitest 关系? VTU 是 Vue 组件测试工具;Vitest 是测试运行器;两者配合(类似 React Testing Library + Jest)
  • 组件测试的 3A 原则? Arrange(准备 props/状态)、Act(渲染 + 交互)、Assert(断言 DOM/store)
  • mock 全局属性怎么做? vi.stubGlobal('$router', mockRouter) 或 global: { mocks: { $t: ... } }
  • shallowMount vs mount? shallow 浅渲染(子组件 stub);mount 全渲染。单元测试用 shallow 隔离
  • 覆盖率目标? 业务 60-70% / 工具函数 90%+;不要为覆盖率写无意义断言

13.7 对比总结

Section titled “13.7 对比总结”
特性 Vue 2 + Jest Vue 3 + Vitest
配置复杂度 复杂(babel + jest) 简单(零配置 TS)
启动速度 慢(几秒) 快(< 1s)
watch 模式 慢 快
ESM 支持 需配置 原生
API 风格 propsData / localVue props / global
异步测试 done 回调 async/await + flushPromises
TypeScript 需 babel 原生

📝 小结

Section titled “📝 小结”
  • Vue 3 推荐 Vitest(与 Vite 同源,配置复用)+ Vue Test Utils。
  • @vue/test-utils 的 mount 挂载组件,shallowMount 只渲染一层(避免子组件依赖)。
  • 测试异步组件用 flushPromises,测试 props 更新用 await nextTick()。
  • 测试的重点是行为(用户看到什么)而不是实现(内部状态),组件重构时才不会大面积改测试。
