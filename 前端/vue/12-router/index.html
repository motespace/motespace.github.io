Q1:history 模式和 hash 模式?

Section titled “Q1:history 模式和 hash 模式?”

答:

  • history:/about,URL 干净,需要服务端配置 fallback
  • hash:/#/about,无需配置,SEO 略差
  • 新项目推荐 history + SSR 或 SPA + fallback

Q2:路由守卫有哪些?

Section titled “Q2:路由守卫有哪些?”

答:

  • beforeEach:全局前置(鉴权)
  • beforeEnter:路由独享
  • afterEach:全局后置(日志)
  • onBeforeRouteLeave:组件内离开守卫
  • onBeforeRouteUpdate:组件内更新守卫

面试追问(深化原 Q1-Q3)

Section titled “面试追问(深化原 Q1-Q3)”
  • history 模式服务端 fallback 怎么配? Nginx try_files $uri /index.html;或框架自带(Vite/Next.js)
  • 路由懒加载写法? component: () => import('./User.vue');Vue Router 自动分包
  • beforeEach 防重入? next('/login') 之前判 if (to.path === '/login') return next();否则死循环
  • keep-alive 怎么缓存路由? &lt;keep-alive&gt;&lt;router-view /&gt;</keep-alive>;配合 meta.cache 控制
  • 路由参数变化 vs 路由切换? 同组件不同参数:用 beforeRouteUpdate 或 watch(route)

十五、Vue Router 3 vs 4 对比

Section titled “十五、Vue Router 3 vs 4 对比”

15.1 创建路由

Section titled “15.1 创建路由”

关键变化:

  • 不再 Vue.use(VueRouter)
  • new VueRouter() → createRouter()
  • mode: 'history' → history: createWebHistory()
  • 组件推荐懒加载(无需特殊处理)

15.2 路由跳转 API

Section titled “15.2 路由跳转 API”

变化:

  • this.$router → useRouter()
  • this.$route → useRoute()
  • 不依赖组件实例,可在 composable 里用

15.3 路由守卫(语法变化)

Section titled “15.3 路由守卫(语法变化)”

变化:

  • 不再需要 next()
  • 通过返回值控制:undefined 放行 / 路由对象跳转 / false 取消
  • 异步守卫更自然

15.4 组件内守卫(API 改名)

Section titled “15.4 组件内守卫(API 改名)”

变化:

  • 选项式钩子 → 组合式函数
  • 不再有 beforeRouteEnter(可以用 onMounted + watch 替代)

Section titled “15.9 对比总结”

📝 小结

Section titled “📝 小结”
  • 两种模式:hash(默认,不需要服务端配合)和 history(需要 fallback 配置)。
  • history 模式必须配 try_files $uri $uri/ /index.html,而且 CDN 也要配回源,否则 404。
  • 路由守卫分三类:全局(beforeEach)、路由级、组件内;next(false) 可中断导航。
  • 动态路由(addRoute)要配合 removeRoute 清理,否则用户切换角色后残留权限。
