Vue 自定义指令

一、什么是自定义指令

Section titled “一、什么是自定义指令”

自定义指令是对原生 DOM 元素做底层操作的封装,以 v- 开头。

适用场景:

  • 自动聚焦(v-focus)
  • 权限控制(v-permission)
  • 防抖节流(v-debounce-click)
  • 拖拽、复制、长按等

八、自定义指令 vs 组件

Section titled “八、自定义指令 vs 组件”

何时用哪个:

  • 只改 DOM → 指令
  • 需要 template/slot → 组件
  • 通用 → 指令(可复用)
  • 业务 → 组件

Section titled “九、面试常考”

Q1:Vue 3 钩子为什么改名?

Section titled “Q1:Vue 3 钩子为什么改名?”

答:

  • Vue 3 钩子语义更清晰(与生命周期钩子风格一致)
  • bind → created(统一语义)
  • inserted → mounted(更准确,挂载后才触发)
  • unbind → unmounted(组件卸载后触发)

Q2:指令和组件的区别?

Section titled “Q2:指令和组件的区别?”

答:

  • 指令:包装 DOM 操作,无 template
  • 组件:完整 UI,可有 template、slot
  • 复用行为用指令,封装 UI 用组件

Q3:权限控制用指令还是组件?

Section titled “Q3:权限控制用指令还是组件?”

答:

  • 指令(v-permission):无 UI 展示,直接隐藏
  • 组件(&lt;Permission&gt;):有 fallback UI,显示“无权限”
  • 看场景:简单隐藏用指令,需要提示用组件

面试追问(深化原 Q1-Q3)

Section titled “面试追问(深化原 Q1-Q3)”
  • 钩子参数怎么用? el(DOM 节点)、binding(指令信息)、vnode(虚拟节点)、prevVnode(上一个 VNode)
  • 自定义指令全局注册? app.directive('focus', { mounted: el => el.focus() })
  • 指令 v-permission 实现要点? mounted(el, binding) { if (!hasPermission(binding.value)) el.parentNode?.removeChild(el) }
  • 指令 vs Render 函数? 指令修改现有 DOM;Render 函数生成 VNode;指令更轻、Render 更灵活

📝 小结

Section titled “📝 小结”
  • 自定义指令是对 DOM 的复用封装,适合 v-model 之外无法用组件表达的场景(自动聚焦、权限控制、埋点)。
  • 指令钩子:mounted/updated/unmounted/beforeUnmount,以及函数式简写成 created/beforeMount。
  • 指令不关心数据流,只拿到 DOM —— 想做数据绑定应该用组件。
  • 在 &lt;script setup&gt; 里用 vMyDir 命名,模板里写 v-my-dir。
