UniApp 样式方案 ​

一、UniApp 样式特点 ​

UniApp 跨多个端,样式处理比纯 Vue 复杂:

端样式系统
小程序rpx(自家单位) + 部分 CSS
H5完整 CSS + 媒体查询
Appnvue 用原生 CSS / vue 页面用 webview CSS
快应用类似小程序

核心问题:一套代码,多端样式可能不一致。

二、rpx 单位(推荐) ​

2.1 是什么 ​

rpx 是 UniApp 引入的相对单位:

  • iPhone 6 屏幕(750rpx × 1334rpx)为基准
  • 1rpx = 屏幕宽度 / 750
  • 自动适配不同屏幕
iPhone 6 (375px 宽):
  750rpx = 375px
  1rpx = 0.5px

iPad (768px 宽):
  750rpx = 768px
  1rpx ≈ 1.024px

2.2 使用 ​

css
/* 占屏幕一半 */
.box { width: 750rpx; }  /* 不推荐 */

/* 推荐:固定大小用 rpx,容器用 750rpx */
.box { width: 200rpx; height: 200rpx; }  /* 16x16 个方块 */

/* 占满宽度 */
.full-width { width: 100%; }  /* 或 750rpx */

2.3 单位对比 ​

单位含义适用
rpx自适应宽度(750rpx = 屏宽)宽度、高度、padding
px物理像素边框、阴影
rem相对根字体文字大小
vh/vw视口大小H5 适配
%父元素百分比弹性布局

2.4 设计稿对应 ​

设计师一般给 750 × 1334 的设计稿:

css
/* 设计稿 100px → 直接写 100rpx */
/* 设计稿 200px → 写 200rpx */
/* 设计稿 50px → 写 50rpx */

不需要 复杂换算,1px = 1rpx(以 750 设计稿为基准)。

三、跨端样式差异 ​

3.1 微信小程序 ​

  • 不支持通用 CSS 选择器(*)
  • 不支持 IE hack
  • rpx 是核心
  • 字体需要 font-family 显式声明
css
/* ❌ 不支持 */
* { box-sizing: border-box; }

/* ✅ 显式 */
view, text, button, image {
  box-sizing: border-box;
}

3.2 H5 ​

  • 完整 CSS 支持
  • 可以用 PostCSS、Sass
  • 需要兼容老浏览器(项目要求)
css
/* H5 用 vw/vh 适配 */
.title { font-size: 4.8vw; }  /* 16px @ 320 屏宽 */

3.3 App(nvue) ​

  • 用原生 CSS(类似 React Native)
  • 部分 CSS 不支持(如 position: sticky)
  • 不能用 SCSS 等预处理器
css
/* nvue 不支持 */
.sticky { position: sticky; top: 0; }

/* nvue 支持的 */
.box { display: flex; flex-direction: row; }

四、sass / scss 支持 ​

4.1 安装 ​

bash
npm install sass --save-dev

Vue 文件直接用:

vue
<style lang="scss">
.box {
  $size: 200rpx;
  width: $size;
  height: $size;
  
  &:hover {
    background: #f5f5f5;
  }
}
</style>

4.2 共享变量 ​

@/styles/variables.scss:

scss
$primary: #007AFF;
$danger: #ff4d4f;
$warning: #faad14;

Vue 文件:

vue
<style lang="scss">
@import '@/styles/variables.scss';

.button {
  background: $primary;
}
</style>

4.3 uni.scss ​

UniApp 自动注入 uni.scss:

scss
/* uni.scss - 全局样式变量 */

$uni-bg-color: #fff;

$uni-border-color: #c8c7cc;
$uni-font-size-sm: 24rpx;
$uni-font-size-base: 28rpx;
$uni-font-size-lg: 32rpx;

五、Flex 布局(主要布局方式) ​

UniApp 跨端推荐 Flex 布局:

css
.container {
  display: flex;
  flex-direction: column;  /* row | column */
  justify-content: center; /* flex-start | flex-end | center | space-between | space-around */
  align-items: center;     /* flex-start | flex-end | center | stretch */
}

.item { flex: 1; }  /* 弹性 */
.item-fixed { width: 200rpx; }

常用场景:

css
/* 顶部栏 */
.tab-bar {
  display: flex;
  justify-content: space-around;
}

/* 列表 */
.list-item {
  display: flex;
  align-items: center;
  padding: 20rpx;
}

/* 居中 */
.center {
  display: flex;
  justify-content: center;
  align-items: center;
}

七、常见问题 ​

7.1 样式不生效 ​

问题:写了样式不生效。

排查:

vue
<style scoped>
/* Vue 3 + UniApp:scoped 会加 data-v-xxx 属性,样式只作用于本组件 */
.box { color: red; }
</style>

解决:确认 class 名匹配、scoped 没影响。

7.2 单位不匹配 ​

css
/* ❌ 小程序里 100px 可能太小 */
.box { width: 100px; }

/* ✅ 用 rpx */
.box { width: 100rpx; }

7.3 z-index 不生效 ​

小程序有自己的层级机制,某些情况下 z-index 无效:

css
/* 用 fixed + 较高级别 */
.modal {
  position: fixed;
  z-index: 999;
}

7.4 iOS 安全区域 ​

css
/* 顶部刘海、底部 Home Indicator */
.page {
  padding-top: env(safe-area-inset-top);
  padding-bottom: env(safe-area-inset-bottom);
}

7.5 1px 边框问题 ​

css
/* 用 transform 缩放 */
.border-1px {
  position: relative;
}
.border-1px::after {
  content: '';
  position: absolute;
  bottom: 0;
  left: 0;
  width: 100%;
  height: 1px;
  background: #ccc;
  transform: scaleY(0.5);
}

八、性能优化 ​

8.1 减少样式嵌套 ​

scss
/* ❌ 嵌套过深,影响渲染 */
.box {
  .child {
    .inner {
      .text {
        color: red;
      }
    }
  }
}

/* ✅ 直接扁平 */
.text { color: red; }

8.2 避免昂贵选择器 ​

css
/* ❌ 通用选择器 */
* { box-sizing: border-box; }

/* ✅ 标签选择器 */
view, text, image, button {
  box-sizing: border-box;
}

8.3 全局样式精简 ​

App.vue 里的全局样式每个页面都加载,别写太多。

🎯 面试常考 ​

Q1:UniApp 单位体系? ​

答:

  • rpx:750rpx = 屏幕宽度;自动适配(微信小程序规范)
  • upx:同 rpx,H5 端别名
  • px:固定像素
  • em / rem:相对父/根元素
  • 推荐:rpx 写尺寸,px 写边框
  • 设计稿:750px → 1px = 1rpx;375px → 1px = 2rpx

Q2:跨端样式差异? ​

答:

  • H5 支持所有 CSS;小程序部分 CSS 不支持(动画、伪元素)
  • 条件编译:/* #ifdef H5 */ / /* #endif */
  • 全局样式:App.vue 的 <style>(全局生效)
  • 局部样式:scoped(Vue 单文件组件)
