一、UniApp 的响应式系统

Section titled “一、UniApp 的响应式系统”

UniApp 的核心是 Vue(主要是 Vue 3 Composition API + 部分 Vue 2 Options API 兼容)。

数据响应式 = 数据变 → 视图自动更新。

原理(Vue 3):

  • ref / reactive 创建响应式数据
  • Proxy 代理对象的 get/set
  • 读取时追踪依赖,修改时触发更新

📝 小结

Section titled “📝 小结”
  • uni-app 基于 Vue 的响应式:ref(基本类型)/ reactive(对象),模板里自动解包,reactive 解构会丢响应式(要用 toRefs)。
  • 模板里 {{ }} 插值是响应式的,但函数调用不会自动更新——computed 才能缓存并追踪依赖。
  • watch 默认懒执行(变更后执行一次),watchEffect 立即执行且自动收集依赖,后者适合「副作用依赖多」的场景。
  • props 单向向下,emit 向上;v-model 在组件上等于 :value + @input,uni-app 的 uni-model 同理。
  • 小程序端 setData 是跨线程数据拷贝,大对象频繁更新会卡,解决办法:只 setData 必要字段、分页渲染、避免 watch 深度监听大对象。
  • 面试常问「computed 和 watch 区别」:computed 用于派生展示值并缓存,watch 用于副作用(请求、埋点、持久化)。

面试常考

Section titled “面试常考”

Q1:UniApp 数据绑定和 Vue 区别?

Section titled “Q1:UniApp 数据绑定和 Vue 区别?”

答:

  • 几乎一样:Vue 3 ref / reactive + 模板
  • 区别:不能用 HTML 元素(用 &lt;view&gt;、&lt;text&gt;)
  • 一些 Web 事件不支持(@click 替代 @tap)
  • 性能:大列表用 v-for + 稳定 key(同 Vue)

Q2:UniApp 跨端数据通信 3 种?

Section titled “Q2:UniApp 跨端数据通信 3 种?”

答:

  • uni.$emit / uni.$on:全局事件(跨页面 / 跨组件)
  • Pinia:状态管理(推荐)
  • globalData:App 级全局变量(老方案)
