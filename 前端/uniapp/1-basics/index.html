1.1 什么是 UniApp

Section titled “1.1 什么是 UniApp”

UniApp 是 DCloud 推出的跨平台应用开发框架，使用 Vue.js 作为开发语言，一套代码可编译到：

  • App 端：iOS、Android、鸿蒙

面试常考

Section titled “面试常考”

Q1:UniApp 核心特点?

Section titled “Q1:UniApp 核心特点?”

答:

  • 一码多端:一套代码编译到 微信/支付宝/抖音/H5/Android/iOS
  • 基于 Vue 3 + Vite 生态(新版);Vue 2 老项目也支持
  • 编译时:条件编译 + 平台 API 适配
  • 运行时:统一组件/JS API(抹平平台差异)

Q2:UniApp vs Taro 区别?

Section titled “Q2:UniApp vs Taro 区别?”

答:

  • UniApp 生态最大(DCloud 维护);Taro 京东维护
  • 语法:UniApp 偏 Vue;Taro 偏 React(3.x 支持 Vue 3)
  • 性能:Taro 3.x React 风格更接近 RN;UniApp 偏 webview 渲染
  • 选:Vue 团队 → UniApp;React 团队 → Taro

Q3:pages.json 核心作用?

Section titled “Q3:pages.json 核心作用?”

答:

  • 全局路由配置(类似微信小程序 app.json)
  • tabBar 配置(底部导航)
  • 页面样式(下拉刷新、导航栏)
  • easycom 配置(组件自动导入)
  • 启动模式(subPackages 分包)

📝 小结

Section titled “📝 小结”
  • UniApp 的核心是一套代码编译到多端:Vue 层写业务,编译器把它翻译成小程序原生语法(App 端则直接用 Vue 运行时)。
  • 项目结构:pages.json(路由与窗口配置)、manifest.json(应用配置)、App.vue(全局生命周期与全局样式)、static/(不参与编译的资源)。
  • pages.json 的 pages 数组第一项是启动页,tabBar 里的图标必须是本地静态图片(不能是网络图)。
  • 条件编译用 // #ifdef / <!-- #endif --> 在编译期裁掉不同端代码,运行时判断做不到的优化就用它。
  • 调试要用 HBuilderX 或 cli 的真机预览,小程序开发者工具只覆盖部分能力。
  • 面试要能说清「uni-app 的编译原理」:语法层 + 平台 API 层 + 组件层三套运行时适配。
