面试常考

Section titled “面试常考”

Q1:navigateTo vs redirectTo vs reLaunch?

Section titled “Q1:navigateTo vs redirectTo vs reLaunch?”

答:

  • navigateTo:保留当前页,压栈;可返回(navigateBack)
  • redirectTo:替换当前页,不入栈;不能返回
  • reLaunch:关闭所有页,打开新页;相当于重置
  • switchTab:切到 tabBar 页(必须在 tabBar 列表)

Q2:页面栈上限?

Section titled “Q2:页面栈上限?”

答:

  • 小程序:10 层(微信、支付宝);超出需 redirectTo
  • H5:无限制
  • 实测:超 10 层 navigateTo 失败,需用 redirectTo 替换

📝 小结

Section titled “📝 小结”
  • 跳转 API 分两类:navigateTo(压栈,页面栈上限 10)、redirectTo(替换当前)、switchTab(切 tabBar)、reLaunch(清栈重启)、navigateBack(返回)。
  • 参数用 URL query 传:uni.navigateTo({ url: '/pages/detail?id=1' }),接收端在 onLoad(options) 里取。
  • 路由拦截靠 uni.addInterceptor('navigateTo', { invoke, success, fail }),适合做登录校验与埋点。
  • 声明式导航是 &lt;navigator url="..."&gt; 组件,常用于列表页跳转。
  • 深度链接在小程序端需要配置 pages 里的 navigateToMiniProgramAppIdList 等能力,App 端用 scheme/universal link。
  • 面试常问「为什么页面栈限制 10 层」:小程序运行内存与层级渲染成本限制,深链场景改用 reLaunch 或合并页面。
