UniApp 面试题详解 ​

一、基础概念 ​

Q1: UniApp 是什么？和原生小程序有什么区别？ ​

答案：

UniApp 是 DCloud 推出的跨平台应用开发框架，使用 Vue.js 语法，一套代码可编译到：

  • App（iOS、Android）
  • 小程序（微信、支付宝、百度、抖音、QQ）
  • H5

与原生小程序的区别：

方面UniApp原生小程序
开发语法Vue.js自定义 WXML/WXSS/JS
跨平台多端统一仅限微信
生态Vue 生态 + uni 插件市场微信生态
性能接近原生优秀
包体积稍大小（主包 2MB）
学习成本Vue 开发者低需要学习新语法

Q2: UniApp 的跨平台原理是什么？ ​

答案：

UniApp 通过以下方式实现跨平台：

1. 统一 DSL：

  • 使用 Vue 语法（模板、样式、脚本）
  • 统一组件和 API

2. 条件编译：

javascript
// #ifdef APP-PLUS
// App 平台代码
// #endif

// #ifdef MP-WEIXIN
// 微信小程序代码
// #endif

3. 编译器转换：

  • Vue 模板 → 各平台模板（WXML、ttml 等）
  • Vue 代码 → 各平台 JS
  • CSS → 各平台样式

4. 渲染层差异：

  • App-nvue：原生渲染
  • 小程序：平台原生渲染
  • H5：WebView 渲染

Q3: 叙述 UniApp 的项目结构？ ​

答案：

├── pages/                  # 页面
│   ├── index/
│   │   └── index.vue
│   └── list/
│       └── list.vue
├── static/                 # 静态资源
├── components/            # 组件
├── pages.json              # 页面路由配置
├── manifest.json           # App 配置
├── App.vue                # 应用入口
├── main.js                # Vue 实例
└── uni.scss               # 全局样式变量

重要文件说明：

文件作用
pages.json路由、tabBar、全局样式配置
manifest.jsonApp 名称、图标、平台配置
App.vue应用生命周期、全局样式
main.jsVue 实例创建

二、生命周期 ​

Q4: UniApp 有哪些生命周期？执行顺序是什么？ ​

答案：

三类生命周期：

  1. 应用生命周期（App.vue）

    • onLaunch - 应用启动
    • onShow - 应用显示
    • onHide - 应用隐藏
    • onError - 脚本错误

  2. 页面生命周期（页面）

    • onLoad - 页面加载
    • onShow - 页面显示
    • onReady - 初次渲染完成
    • onHide - 页面隐藏
    • onUnload - 页面卸载

  3. 组件生命周期（Vue 组件）

    • beforeCreate - 实例创建前
    • created - 实例创建后
    • beforeMount - 挂载前
    • mounted - 挂载后
    • beforeUnmount - 卸载前
    • unmounted - 卸载后

执行顺序：

首次打开：
onLaunch → onShow → onLoad → onShow → onReady

切换到后台：
onHide

从后台切回：
onShow

关闭页面：
onUnload

Q5: onShow 和 onLoad 的区别？ ​

答案：

方面onLoadonShow
触发次数只触发一次每次显示都触发
获取参数✅ 可以获取❌ 不能获取
适用场景初始化请求数据刷新
javascript
// onLoad - 适合初始化
onLoad((options) => {
  console.log('页面参数:', options.id)
  fetchData(options.id)
})

// onShow - 适合刷新
onShow(() => {
  // 每次显示都执行
  checkUpdate()
})

三、路由与页面 ​

Q6: UniApp 路由方式有哪些？区别是什么？ ​

答案：

API说明页面栈特点
navigateTo跳转非 tabBar压栈保留当前页，可返回
redirectTo关闭当前页跳转替换栈顶关闭当前页
reLaunch关闭所有页面跳转清空栈关闭所有页
switchTab跳转 tabBar清空非 tabBar只能跳 tabBar
navigateBack返回弹出可指定层数
javascript
// navigateTo - 保留当前页
uni.navigateTo({ url: '/pages/detail/detail?id=1' })

// redirectTo - 关闭当前页
uni.redirectTo({ url: '/pages/detail/detail?id=1' })

// switchTab - 跳转 tabBar（需在 tabBar 列表中）
uni.switchTab({ url: '/pages/index/index' })

// reLaunch - 关闭所有页
uni.reLaunch({ url: '/pages/index/index' })

// navigateBack - 返回
uni.navigateBack({ delta: 1 })

Q7: 如何实现页面间数据传递？ ​

答案：

方式一：URL 参数

javascript
// A 页面
uni.navigateTo({
  url: '/pages/detail/detail?id=1&name=test'
})

// B 页面 onLoad
onLoad((options) => {
  console.log(options.id)   // 1
  console.log(options.name) // test
})

方式二：EventChannel

javascript
// A 页面
uni.navigateTo({
  url: '/pages/detail/detail',
  events: {
    refresh: (data) => console.log('收到数据:', data)
  }
})

// B 页面
onLoad(() => {
  const eventChannel = getOpenerEventChannel()
  eventChannel.emit('refresh', { name: '更新' })
})

方式三：Storage

javascript
// A 页面
uni.setStorageSync('detail', JSON.stringify(data))
uni.navigateTo({ url: '/pages/detail/detail' })

// B 页面
onLoad(() => {
  const data = JSON.parse(uni.getStorageSync('detail'))
})

Q8: 如何实现路由拦截？ ​

答案：

javascript
// main.js
App.mpType = 'app'

// 注册拦截器
uni.addInterceptor('navigateTo', {
  invoke(e) {
    // 检查登录
    const token = uni.getStorageSync('token')
    if (!token && !e.url.includes('/pages/login/')) {
      uni.navigateTo({ url: '/pages/login/login?redirect=' + encodeURIComponent(e.url) })
      return false
    }
    return true
  },
  success(e) {
    console.log('success')
  },
  fail(e) {
    console.log('fail')
  }
})

// 其他路由也需要拦截
uni.addInterceptor('redirectTo', { /* 同上 */ })
uni.addInterceptor('reLaunch', { /* 同上 */ })
uni.addInterceptor('switchTab', {
  invoke(e) {
    // tabBar 页面也需要检查
    return true
  }
})

五、条件编译 ​

Q11: 什么是条件编译？如何使用？ ​

答案：

条件编译是用特殊的注释标记，在编译时根据平台生成不同代码。

平台标识：

平台标识
AppAPP-PLUS
H5H5
微信小程序MP-WEIXIN
支付宝小程序MP-ALIPAY
百度小程序MP-BAIDU

JS 条件编译：

javascript
// #ifdef APP-PLUS
uni.requireNativePlugin('native-module')
// #endif

// #ifdef MP-WEIXIN
uni.login({ provider: 'weixin' })
// #endif

模板条件编译：

vue
<template>
  <!-- #ifdef H5 -->
  <div>H5 专属</div>
  <!-- #endif -->

  <!-- #ifdef APP-PLUS -->
  <button>App 专属</button>
  <!-- #endif -->
</template>

CSS 条件编译：

css
view {
  /* #ifdef APP-PLUS */
  color: red;
  /* #endif */

  /* #ifdef MP-WEIXIN */
  color: blue;
  /* #endif */
}

Q14: 小程序包体积超限怎么办？ ​

答案：

限制解决方案
主包 2MB分包加载
总包 8MB压缩图片、删除无用代码
单个文件 2MB压缩图片、使用 CDN

优化方法：

  1. 分包加载：将次要页面拆分到分包
  2. 图片压缩：使用 tinypng、WebP 格式
  3. Tree Shaking：删除未使用的代码
  4. 删除无用资源：定期清理 static 目录
  5. 使用 CDN：大图放到 CDN

九、状态管理 ​

Q19: UniApp 如何实现状态管理？ ​

答案：

方式一：Pinia（推荐）

javascript
// stores/user.js
import { defineStore } from 'pinia'

export const useUserStore = defineStore('user', {
  state: () => ({
    token: '',
    userInfo: null
  }),
  getters: {
    isLoggedIn: state => !!state.token
  },
  actions: {
    login(token) {
      this.token = token
      uni.setStorageSync('token', token)
    },
    logout() {
      this.token = ''
      uni.removeStorageSync('token')
    }
  }
})

方式二：Vuex

javascript
// store/index.js
import { createStore } from 'vuex'

export default createStore({
  state: {
    token: ''
  },
  mutations: {
    SET_TOKEN(state, token) {
      state.token = token
    }
  },
  actions: {
    async login({ commit }, credentials) {
      const res = await uni.request({
        url: '/api/login',
        method: 'POST',
        data: credentials
      })
      commit('SET_TOKEN', res.data.token)
    }
  }
})

十、综合问题 ​

Q20: UniApp 的优缺点？ ​

答案：

优点：

  1. 跨平台：一套代码多端运行
  2. 开发效率：Vue 开发者直接上手
  3. 生态完善：uni-ui、插件市场、uniCloud
  4. 性能好：原生渲染，体验接近原生
  5. 更新方便：无需审核直接推送

缺点：

  1. 包体积：比原生小程序大
  2. 平台差异：需要处理平台兼容
  3. 性能：复杂场景不如原生
  4. 依赖：依赖 DCloud 维护
  5. 审核：App 需要应用市场审核

Q21: 如何实现登录流程？ ​

答案：

javascript
// 1. 发起登录
const [error, res] = await uni.login({ provider: 'weixin' })

// 2. 获取用户信息（需要用户授权）
const profile = await new Promise((resolve, reject) => {
  uni.getUserProfile({
    desc: '用于完善用户资料',
    success: (res) => resolve(res),
    fail: reject
  })
})

// 3. 发送登录信息到服务器
const loginResult = await uni.request({
  url: '/api/login',
  method: 'POST',
  data: {
    code: res.code,
    encryptedData: profile.encryptedData,
    iv: profile.iv
  }
})

// 4. 保存 token
if (loginResult.data.token) {
  uni.setStorageSync('token', loginResult.data.token)
  uni.setStorageSync('userInfo', loginResult.data.userInfo)
}

uni.navigateBack()

Q23: 如何处理登录超时/Token 过期？ ​

javascript
// 请求封装中处理
const request = (options) => {
  return new Promise((resolve, reject) => {
    uni.request({
      ...options,
      success: (res) => {
        if (res.statusCode === 401) {
          // Token 过期或无效
          uni.removeStorageSync('token')
          uni.removeStorageSync('userInfo')

          // 跳转登录页
          uni.reLaunch({ url: '/pages/login/login' })
          reject(new Error('未授权'))
        } else {
          resolve(res.data)
        }
      },
      fail: reject
    })
  })
}

// 使用
async function fetchData() {
  try {
    const data = await request({ url: '/api/user' })
    return data
  } catch (err) {
    console.error(err)
  }
}

Q24: 如何实现下拉刷新和上拉加载？ ​

答案：

vue
<template>
  <scroll-view
    scroll-y
    :refresher-enabled="true"
    :refresher-triggered="isRefresh"
    @refresherrefresh="onRefresh"
    @scrolltolower="onLoadMore"
  >
    <view v-for="item in list" :key="item.id">
      {{ item.title }}
    </view>

    <view v-if="hasMore" class="loading">加载中...</view>
    <view v-else class="no-more">没有更多了</view>
  </scroll-view>
</template>

<script setup>
import { ref } from 'vue'

const list = ref([])
const page = 1
const pageSize = 20
const hasMore = ref(true)
const isRefresh = ref(false)

const fetchData = async () => {
  const [error, res] = await uni.request({
    url: '/api/list',
    data: { page, pageSize }
  })

  if (!error) {
    if (page === 1) {
      list.value = res.data
    } else {
      list.value = [...list.value, ...res.data]
    }
    hasMore.value = res.data.length === pageSize
  }
}

const onRefresh = async () => {
  isRefresh.value = true
  page = 1
  await fetchData()
  isRefresh.value = false
  uni.showToast({ title: '刷新成功', icon: 'success' })
}

const onLoadMore = async () => {
  if (!hasMore.value) return
  page++
  await fetchData()
}

// 初始加载
onLoad(() => {
  fetchData()
})
</script>
