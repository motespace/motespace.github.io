UniApp 生命周期详解 ​

一、生命周期分类 ​

UniApp 的生命周期分为三类：

分类说明触发时机
应用生命周期整个应用小程序启动/显示/隐藏
页面生命周期单个页面页面加载/显示/隐藏/卸载
组件生命周期Vue 组件创建/挂载/销毁

二、应用生命周期 ​

2.1 完整生命周期 ​

生命周期说明支持平台
onLaunch应用启动全平台
onShow应用显示全平台
onHide应用隐藏全平台
onError脚本错误全平台
onPageNotFound页面不存在全平台
onUnhandledRejectionPromise 拒绝2.8.9+
onThemeChange主题变化App 3.2+
onUniNViewMessageNView 消息App
onLastPageBackPress最后页面返回App

2.2 App.vue 中使用 ​

vue
<script setup>
import { onLaunch, onShow, onHide, onError, onPageNotFound } from '@dcloudio/uni-app'

// 应用启动
onLaunch((options) => {
  console.log('App Launch', options)
  // 应用启动参数（从微信等环境启动时）
  // options.query = { path: 'pages/index/index', ... }
})

// 应用显示
onShow((options) => {
  console.log('App Show', options)
  // 从后台切回前台时触发
})

// 应用隐藏
onHide(() => {
  console.log('App Hide')
  // 进入后台或切换应用时触发
})

// 脚本错误
onError((err) => {
  console.error('App Error', err)
  // 上报错误信息
  reportError(err)
})

// 页面不存在
onPageNotFound((res) => {
  console.log('Page Not Found', res)
  // 跳转 404 页面
  uni.redirectTo({
    url: 'pages/404/404'
  })
})

// Promise 拒绝未处理
onUnhandledRejection((res) => {
  console.error('Unhandled Rejection', res.reason)
})

// 主题变化（深色模式）
onThemeChange((res) => {
  console.log('Theme Change', res.theme)
})
</script>

2.3 执行时机图解 ​

用户首次打开小程序
──────────────────────────────────────
onLaunch → onShow → 页面 onLoad → onShow → onReady

用户切换到后台
──────────────────────────────────────
App onHide → 页面 onHide

用户从后台切回
──────────────────────────────────────
App onShow → 页面 onShow

用户关闭小程序
──────────────────────────────────────
App onHide → (小程序被销毁)

三、页面生命周期 ​

3.1 完整生命周期 ​

生命周期说明触发时机
onLoad页面加载页面创建时（只触发一次）
onShow页面显示页面显示/从后台切回
onReady初次渲染完成页面渲染完成（只触发一次）
onHide页面隐藏页面不可见/切入后台
onUnload页面卸载页面关闭/redirectTo/switchTab
onPullDownRefresh下拉刷新用户下拉操作
onReachBottom上拉触底页面上拉触底
onShareAppMessage分享用户点击分享
onShareTimeline分享到朋友圈用户点击分享
onAddToFavorites收藏用户点击收藏
onPageScroll页面滚动页面滚动时
onResize窗口尺寸变化窗口大小改变
onTabItemTapTab 点击Tab 点击时
onNavigationBarButtonTap导航栏按钮点击原生导航栏按钮点击
onNavigationBarSearchInputChanged搜索框输入导航栏搜索框输入
onNavigationBarSearchInputConfirmed搜索确认导航栏搜索框确认
onNavigationBarSearchInputCleared搜索清除导航栏搜索框清除

3.2 页面中使用 ​

vue
<script setup>
import { ref, onMounted } from 'vue'
import {
  onLoad,
  onShow,
  onReady,
  onHide,
  onUnload,
  onPullDownRefresh,
  onReachBottom,
  onPageScroll,
  onShareAppMessage,
  onAddToFavorites
} from '@dcloudio/uni-app'

// 页面加载（只触发一次）
onLoad((options) => {
  console.log('onLoad', options)
  // options = { id: '1', name: 'test' } 从 URL 获取的参数
  // 获取页面间通信数据
  const eventChannel = getOpenerEventChannel()
  eventChannel.on('dataFromDetail', (data) => {
    console.log('收到详情页数据', data)
  })
})

// 页面显示
onShow(() => {
  console.log('onShow')
  // 每次显示都触发，适合刷新数据
  fetchData()
})

// 页面初次渲染完成
onReady(() => {
  console.log('onReady')
  // 可以获取页面元素
  const query = uni.createSelectorQuery()
  query.select('.content').boundingClientRect()
})

// 页面隐藏
onHide(() => {
  console.log('onHide')
  // 暂停音乐、定时器等
  audio.pause()
  clearInterval(timer)
})

// 页面卸载
onUnload(() => {
  console.log('onUnload')
  // 清理资源
  clearAll()
})

// 下拉刷新
onPullDownRefresh(() => {
  console.log('onPullDownRefresh')
  fetchData().finally(() => {
    uni.stopPullDownRefresh()
  })
})

// 上拉触底
onReachBottom(() => {
  console.log('onReachBottom')
  loadMore()
})

// 页面滚动
onPageScroll((e) => {
  console.log('onPageScroll', e.scrollTop)
})

// 分享给朋友
onShareAppMessage((res) => {
  console.log('onShareAppMessage', res)
  return {
    title: '分享标题',
    path: '/pages/index/index?id=123',
    imageUrl: '/static/share.png'
  }
})

// 分享到朋友圈
onShareTimeline(() => {
  return {
    title: '分享标题',
    query: 'id=123',
    imageUrl: '/static/share.png'
  }
})

// 收藏
onAddToFavorites((res) => {
  return {
    title: '收藏标题',
    imageUrl: '/static/favorite.png',
    query: 'id=123'
  }
})
</script>

3.3 生命周期执行顺序 ​

A 页面 → navigateTo → B 页面
────────────────────────────────────────────
A onHide
B onLoad → B onShow → B onReady

B → navigateBack → A
────────────────────────────────────────────
B onUnload
A onShow

A → switchTab → B（tabBar 页面）
────────────────────────────────────────────
A onHide (不触发 onUnload)
B onLoad → B onShow → B onReady

B → switchTab → A
────────────────────────────────────────────
B onHide (不触发 onUnload)
A onShow

四、组件生命周期 ​

4.1 Vue 3 组合式 API ​

vue
<script setup>
import { ref, onMounted, onBeforeMount, onUnmounted, onBeforeUnmount } from 'vue'

const count = ref(0)

// 实例创建前
beforeCreate(() => {
  console.log('beforeCreate')
})

// 实例创建后
created(() => {
  console.log('created')
  // 可访问 this
  // 不能访问 DOM
})

// 挂载前
onBeforeMount(() => {
  console.log('onBeforeMount')
})

// 挂载后
onMounted(() => {
  console.log('onMounted')
  // 可以访问 DOM
  document.querySelector('.el')
})

// 卸载前
onBeforeUnmount(() => {
  console.log('onBeforeUnmount')
  // 清理定时器、事件监听
})

// 卸载后
onUnmounted(() => {
  console.log('onUnmounted')
})
</script>

4.2 组件页面生命周期（pageLifetimes） ​

javascript
export default {
  // 组件所在页面生命周期
  pageLifetimes: {
    show() {
      // 页面显示
    },
    hide() {
      // 页面隐藏
    },
    resize(size) {
      // 页面尺寸变化
    }
  }
}

4.3 小程序特有生命周期 ​

javascript
export default {
  // 小程序特有
  lifetimes: {
    created() {
      console.log('组件创建')
    },
    attached() {
      console.log('组件进入页面节点树')
    },
    ready() {
      console.log('组件布局完成')
    },
    moved() {
      console.log('组件被移动')
    },
    detached() {
      console.log('组件离开页面节点树')
    },
    error(err) {
      console.error('组件错误', err)
    }
  }
}

五、组件与页面通信 ​

5.1 父子组件通信 ​

vue
<!-- 父组件 -->
<template>
  <ChildComponent
    :title="title"
    :list="list"
    @update="handleUpdate"
    @delete="handleDelete"
  />
</template>

<script setup>
const title = ref('标题')
const list = ref([1, 2, 3])

const handleUpdate = (data) => {
  console.log('更新:', data)
}

const handleDelete = (id) => {
  console.log('删除:', id)
}
</script>
vue
<!-- 子组件 -->
<template>
  <view>
    <text>{{ title }}</text>
    <button @click="emit('update', newData)">更新</button>
  </view>
</template>

<script setup>
import { defineProps, defineEmits } from 'vue'

const props = defineProps({
  title: String,
  list: Array
})

const emit = defineEmits(['update', 'delete'])
</script>

5.2 跨页面通信 ​

javascript
// A 页面 - 发送数据
const eventChannel = getOpenerEventChannel()

// 方式1：通过 URL 参数
uni.navigateTo({
  url: '/pages/detail/detail?id=1&name=test'
})

// 方式2：通过事件通道
uni.navigateTo({
  url: '/pages/detail/detail',
  events: {
    refresh: (data) => {
      console.log('收到详情页数据', data)
    }
  }
})

// B 页面 - 发送数据回上一页
onLoad((options) => {
  const eventChannel = getOpenerEventChannel()
  eventChannel.emit('refresh', { name: '更新数据' })
  eventChannel.emit('refresh', { name: '再次更新' })
})

六、页面间数据传递 ​

javascript
// 发送
uni.navigateTo({

javascript
// A 页面
uni.setStorageSync('detail', JSON.stringify(data))
uni.navigateTo({ url: '/pages/detail/detail' })

// B 页面
onLoad(() => {
  const data = JSON.parse(uni.getStorageSync('detail'))
})

七、生命周期与性能 ​

7.1 onShow vs onLoad ​

生命周期触发次数适用场景
onLoad只触发一次初始化请求、获取参数
onShow每次显示触发刷新数据、检查登录

7.2 避免重复请求 ​

javascript
// 方案1：使用标志位
dataReady = false

onShow(() => {
  if (!dataReady) {
    fetchData()
  }
})

onHide(() => {
  dataReady = true
})

// 方案2：使用缓存
onShow(() => {
  const cache = uni.getStorageSync('cache_key')
  if (cache) {
    this.data = cache
  } else {
    fetchData()
  }
})

7.3 清理定时器 ​

javascript
let timer = null

onLoad(() => {
  timer = setInterval(() => {
    this.update()
  }, 1000)
})

onUnload(() => {
  if (timer) {
    clearInterval(timer)
    timer = null
  }
})

onHide(() => {
  // 如果 tabBar 页面切换也需要清理
  if (timer) {
    clearInterval(timer)
  }
})
