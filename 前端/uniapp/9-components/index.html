面试常考

Section titled “面试常考”

Q1:UniApp 组件 3 类?

Section titled “Q1:UniApp 组件 3 类?”

答:

  • 内置组件:<view>、<text>、<image>、<scroll-view>(跨端)
  • easycom 组件:components/comp/comp.vue 自动导入(无需 import)
  • uni-ui:DCloud 官方组件库(<uni-card> 等)
  • 性能:内置组件最轻;uni-ui 功能丰富;easycom 自定义组件

Q2:easycom 自动导入原理?

Section titled “Q2:easycom 自动导入原理?”

答:

  • 配置 pages.json 的 easycom 规则
  • 规则:{"autoscan": true, "custom": {"^uni-(.*)": "@/components/uni-$1/uni-$1.vue"}}
  • 模板里直接用 <uni-card />,无需 import
  • 原理:编译时扫描 components/ 目录,自动生成 import

📝 小结

Section titled “📝 小结”
  • easycom 规则:组件放在 components/组件名/组件名.vue 即自动注册,无需 import。
  • 组件通信:props 向下、emit 向上、事件总线 uni.$emit、以及 uni.$on 需要在 onUnload 里 uni.$off 解绑。
  • 自定义组件的 model 选项用于支持 v-model 的默认属性与事件名。
  • 跨端组件要注意:不能用 window/document,样式用 rpx,平台特有能力用条件编译。
  • 组件性能:减少 props 深度嵌套(小程序端属性传递成本高)、用 virtual list 组件处理长列表、避免在组件内创建过多监听。
  • 面试可讲「组件封装的设计原则」:单一职责、props 契约清晰、样式隔离(小程序天然隔离,H5 需注意)。
