一、基础概念 ​

详细文档：UniApp 基础

1.1 什么是 UniApp ​

跨平台应用开发框架，基于 Vue.js，一套代码编译到多个平台：

  • App 端：iOS、Android、鸿蒙
  • 小程序：微信、支付宝、百度、抖音、QQ 等
  • Web：H5

1.2 特点 ​

特点说明
跨平台一套代码，多端发布
性能好渲染层原生，体验接近原生
生态完善插件市场、云打包、uniCloud
上手快Vue 开发者直接上手

1.3 开发方式 ​

方式说明适用场景
HBuilderX官方 IDE，内置增强推荐
CLI命令行创建习惯 VS Code 的开发者
Vue CLI通过 uni-app CLI已有 Vue 项目

四、路由与导航 ​

详细文档：路由与导航

4.1 编程式导航 ​

javascript
// 跳转到新页面
uni.navigateTo({
  url: '/pages/detail/detail?id=1&name=test'
})

// 关闭当前页面，跳转到新页面
uni.redirectTo({
  url: '/pages/detail/detail?id=1'
})

// 跳转到 tabBar 页面
uni.switchTab({
  url: '/pages/index/index'
})

// 关闭所有页面，打开新页面
uni.reLaunch({
  url: '/pages/detail/detail'
})

// 关闭当前页面，返回上一页
uni.navigateBack({
  delta: 1
})

4.2 声明式导航 ​

vue
<navigator url="/pages/detail/detail?id=1" open-type="navigate">

</navigator>

<!-- open-type 取值：navigate/redirect/switchTab/reLaunch/navigateBack -->

javascript

4.4 路由守卫 ​

javascript
// main.js
uni.addInterceptor('navigateTo', {
  invoke(e) {
    // 拦截前处理
    const token = uni.getStorageSync('token')
    if (!token && !e.url.includes('/pages/login/login')) {
      uni.navigateTo({ url: '/pages/login/login' })
      return false
    }
    return true
  },
  success(e) {
    // 成功后处理
  },
  fail(e) {
    // 失败处理
  }
})

七、API ​

详细文档：API 详解

7.1 网络请求 ​

javascript
// 基本用法
uni.request({
  url: 'https://api.example.com',
  method: 'GET',
  data: { id: 1 },
  header: { 'Authorization': token },
  success: res => {
    console.log(res.data)
  }
})

// Promise 封装
const request = (options) => {
  return new Promise((resolve, reject) => {
    uni.request({
      ...options,
      success: res => resolve(res),
      fail: err => reject(err)
    })
  })
}

十、状态管理 ​

10.1 Pinia（推荐） ​

bash
npm install pinia
javascript
// stores/user.js
import { defineStore } from 'pinia'

export const useUserStore = defineStore('user', {
  state: () => ({
    name: '张三',
    token: ''
  }),
  getters: {
    isLoggedIn: state => !!state.token
  },
  actions: {
    login(token) {
      this.token = token
      uni.setStorageSync('token', token)
    },
    logout() {
      this.token = ''
      uni.removeStorageSync('token')
    }
  }
})
javascript
// main.js
import { createPinia } from 'pinia'

const pinia = createPinia()
app.use(pinia)

// App.vue
import { useUserStore } from '@/stores/user'

const userStore = useUserStore()
userStore.login('token123')

10.2 Vuex ​

javascript
// store/index.js
import { createStore } from 'vuex'

export default createStore({
  state: {
    token: ''
  },
  mutations: {
    SET_TOKEN(state, token) {
      state.token = token
    }
  },
  actions: {
    async login({ commit }, credentials) {
      const res = await uni.request({
        url: '/api/login',
        method: 'POST',
        data: credentials
      })
      commit('SET_TOKEN', res.data.token)
    }
  }
})

十二、面试题 ​

详细文档：面试题

Q1: UniApp 和小程序的区别？ ​

方面UniApp原生小程序
开发语言VueVue/React（自定义）
跨平台多端仅微信
生态依托 Vue 生态独立生态
性能接近原生优秀
包体积稍大较小

Q2: 如何实现跨平台？ ​

UniApp 通过条件编译 + 统一 DSL 实现跨平台：

  • 编译时根据平台标识生成不同代码
  • 统一组件和 API 的调用方式
  • 各平台原生渲染层差异由框架处理

Q3: UniApp 的优缺点？ ​

优点：

  • 一套代码多端运行
  • 开发成本低
  • 生态丰富（uni-ui、插件市场）
  • 支持 uniCloud

缺点：

  • 性能不如原生
  • 包体积相对较大
  • 平台差异需要额外处理
