2.2 text（文本） ​

vue
<template>
  <view>
    <!-- 基本文本 -->
    <text>普通文本</text>

    <!--  selectable 控制选择 -->
    <text selectable="true">可选中文本</text>

    <!--  space 显示空格 -->
    <text space="ensp">空格处理 enspspace</text>
    <text space="nbsp">空格处理 nbsp</text>

    <!--  decode 解码 -->
    <text decode="true">&lt; &gt; &amp;</text>
  </view>
</template>

space 取值：

值说明
nbsp根据字体设置空格
ensp中文字符空格一半大小
emsp中文字符空格大小

2.3 rich-text（富文本） ​

vue
<template>
  <view>
    <!-- HTML 字符串 -->
    <rich-text :nodes="htmlString"></rich-text>

    <!-- 对象数组 -->
    <rich-text :nodes="nodesArray"></rich-text>
  </view>
</template>

<script setup>
const htmlString = `
  <h1>标题</h1>
  <p>段落内容</p>
  <img src="https://example.com/image.jpg" />
`

const nodesArray = [
  {
    name: 'div',
    attrs: { class: 'container' },
    children: [
      { type: 'node', name: 'span', attrs: { style: 'color: red' }, children: ['文本'] }
    ]
  }
]
</script>

3.1 button（按钮） ​

vue
<template>
  <view>
    <!-- 基本按钮 -->
    <button size="default">默认按钮</button>

    <!-- 类型 -->
    <button type="primary">primary</button>
    <button type="default">default</button>
    <button type="warn">warn</button>

    <!-- 尺寸 -->
    <button size="mini">mini</button>

    <!-- 开放能力 -->
    <button open-type="share">分享</button>
    <button open-type="getPhoneNumber" @getphonenumber="onGetPhone">获取手机号</button>
    <button open-type="contact">客服</button>

    <!-- 禁用 -->
    <button disabled>禁用按钮</button>

    <!-- 加载中 -->
    <button loading="true">加载中</button>
  </view>
</template>

open-type 取值：

值说明平台

mode 取值说明：

mode说明
scaleToFill缩放，不保持比例
aspectFit缩放，保持比例，最大完整显示
aspectFill缩放，保持比例，最大填充
widthFix宽度不变，高度自动变化
heightFix高度不变，宽度自动变化
top不缩放，只显示顶部
bottom不缩放，只显示底部
center不缩放，只显示中间
left不缩放，只显示左边
right不缩放，只显示右边

面试常考 ​

Q1:UniApp 组件 3 类? ​

答:

  • 内置组件:<view>、<text>、<image>、<scroll-view>(跨端)
  • easycom 组件:components/comp/comp.vue 自动导入(无需 import)
  • uni-ui:DCloud 官方组件库(<uni-card> 等)
  • 性能:内置组件最轻;uni-ui 功能丰富;easycom 自定义组件

Q2:easycom 自动导入原理? ​

答:

  • 配置 pages.json 的 easycom 规则
  • 规则:{"autoscan": true, "custom": {"^uni-(.*)": "@/components/uni-$1/uni-$1.vue"}}
  • 模板里直接用 <uni-card />,无需 import
  • 原理:编译时扫描 components/ 目录,自动生成 import
