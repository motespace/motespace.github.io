UniApp 样式方案

一、UniApp 样式特点

Section titled “一、UniApp 样式特点”

UniApp 跨多个端,样式处理比纯 Vue 复杂:

端 样式系统
小程序 rpx(自家单位) + 部分 CSS
H5 完整 CSS + 媒体查询
App nvue 用原生 CSS / vue 页面用 webview CSS
快应用 类似小程序

核心问题:一套代码,多端样式可能不一致。

二、rpx 单位(推荐)

Section titled “二、rpx 单位(推荐)”

2.1 是什么

Section titled “2.1 是什么”

rpx 是 UniApp 引入的相对单位:

  • iPhone 6 屏幕(750rpx × 1334rpx)为基准
  • 1rpx = 屏幕宽度 / 750
  • 自动适配不同屏幕

2.3 单位对比

Section titled “2.3 单位对比”
单位 含义 适用
rpx 自适应宽度(750rpx = 屏宽) 宽度、高度、padding
px 物理像素 边框、阴影
rem 相对根字体 文字大小
vh/vw 视口大小 H5 适配
% 父元素百分比 弹性布局

Section titled “3.1 微信小程序”

Section titled “3.3 App(nvue)”

十、最佳实践

10.2 避坑清单

Section titled “10.2 避坑清单”
  • 不用 * 通配符
  • 边框用 1px / 2px(rpx 在小程序太粗)
  • iOS 安全区适配
  • 不同端样式差异用条件编译
  • 全局样式放 App.vue,不放 main.js
  • 字体用 system 字体或网络字体

📝 小结

Section titled “📝 小结”
  • rpx 是 uni-app 的响应式单位:750rpx = 屏幕宽度,按比例缩放,是跨端一致的基础(等价于 rem/vw 的思路)。
  • 跨端样式差异:小程序不支持 * 通配、标签选择器支持有限、部分伪类不支持,推荐用 class 选择器。
  • 布局以 Flex 为主,小程序端对 Grid 支持逐步完善但仍有限制,复杂布局用 flex + 嵌套。
  • 单位混用要注意:px 在小程序端不会随屏幕缩放,统一用 rpx;H5 端可用 vw/vh 与 safe-area-inset-bottom 处理刘海屏。
  • SCSS 需要在 pages.json 的 style 或 vite 插件里开启,变量文件放 uni.scss 全局注入。
  • 面试加分:能说清「rpx 换算的本质就是以 750 为基准的等比缩放」,并解释为什么它比 media query 更适合小程序。

🎯 面试常考

Section titled “🎯 面试常考”

Q1:UniApp 单位体系?

Section titled “Q1:UniApp 单位体系?”

答:

  • rpx:750rpx = 屏幕宽度;自动适配(微信小程序规范)
  • upx:同 rpx,H5 端别名
  • px:固定像素
  • em / rem:相对父/根元素
  • 推荐:rpx 写尺寸,px 写边框
  • 设计稿:750px → 1px = 1rpx;375px → 1px = 2rpx

Q2:跨端样式差异?

Section titled “Q2:跨端样式差异?”

答:

  • H5 支持所有 CSS;小程序部分 CSS 不支持(动画、伪元素)
  • 条件编译:/* #ifdef H5 */ / /* #endif */
  • 全局样式:App.vue 的 &lt;style&gt;(全局生效)
  • 局部样式:scoped(Vue 单文件组件)
