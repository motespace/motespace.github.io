面试常考

Section titled “面试常考”

Q1:UniApp 三层生命周期?

Section titled “Q1:UniApp 三层生命周期?”

答:

  • 应用级:App.vue 的 onLaunch / onShow / onHide(整个 app 启动/进入前台/进入后台)
  • 页面级:onLoad / onShow / onReady / onUnload(页面加载/显示/渲染完成/卸载)
  • 组件级:标准 Vue 生命周期 + mounted / unmounted
  • 注意:页面 onShow 每次进入都触发;onLoad 只触发一次

Q2:onLoad vs onShow 区别?

Section titled “Q2:onLoad vs onShow 区别?”

答:

  • onLoad:页面创建时触发 1 次,接收路由参数
  • onShow:页面显示时触发(每次进入都触发,包括返回)
  • 用途:初始数据用 onLoad;每次显示都更新用 onShow
  • 性能:onShow 避免重操作(可能频繁触发)

📝 小结

Section titled “📝 小结”
  • 三类生命周期:应用级(App.vue 的 onLaunch/onShow/onHide)、页面级(onLoad/onShow/onReady/onHide/onUnload)、组件级(Vue 标准 created/mounted…)。
  • onLoad 只触发一次且带参数,onShow 每次页面显示都触发——「需要在每次进入时刷新」用 onShow,「只初始化一次」用 onLoad。
  • onReady 表示首屏渲染完成,适合做首屏后依赖布局的操作(如 createSelectorQuery 量尺寸)。
  • 页面卸载 onUnload 要清理定时器、事件监听、订阅,否则小程序端会内存泄漏。
  • 组件通信用 uni.$emit/$on/$off 的事件总线模式时要成对解绑,或直接用 props/emit + provide/inject。
  • 面试常问「页面栈与生命周期关系」:进栈触发 onLoad/onShow,退栈触发 onHide,销毁才 onUnload。
