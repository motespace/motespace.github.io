面试常考

Section titled “面试常考”

Q1:本地存储 4 种方式?

Section titled “Q1:本地存储 4 种方式?”

答:

  • uni.setStorage / uni.getStorage / uni.removeStorage / uni.clearStorage:同步 API
  • uni.setStorageSync / getStorageSync:同步版本(阻塞)
  • 实战:大文件用文件系统(uni.saveFile);KV 用 storage
  • 限制:小 10MB(各平台不同)

Q2:跳转 4 种 API 区别?

Section titled “Q2:跳转 4 种 API 区别?”

答:

  • navigateTo:压栈(可返回)
  • redirectTo:替换(不返回)
  • reLaunch:重置
  • switchTab:切 tabBar 页
  • 实战:登录后跳转用 reLaunch(清掉登录页)

📝 小结

Section titled “📝 小结”
  • 速查表按「场景 → API」组织,比按 API 名组织更好用:上传、下载、登录、定位、分享、剪贴板各一行。
  • 最常问的三个:uni.request(网络)、uni.setStorageSync(本地存储)、uni.showModal(交互反馈)。
  • 同步存储 API(setStorageSync)在主线程执行,数据量大时用异步版本避免卡顿。
  • 文件类:小程序用 chooseFile/chooseMessageFile,App/H5 用 chooseFile,差异要条件编译。
  • 面试用法:被问「你熟悉 uni-app 吗」时,直接说几个高频 API 的跨端差异,比背 API 列表有说服力。
