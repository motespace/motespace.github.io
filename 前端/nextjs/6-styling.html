二、CSS Modules ​

2.1 基础用法 ​

css
/* components/Button.module.css */
.button {
  padding: 8px 16px;
  border-radius: 4px;
  cursor: pointer;
  transition: all 0.2s;
}

.primary {
  background-color: #0070f3;
  color: white;
}

.secondary {
  background-color: #f3f3f3;
  color: #333;
}

.button:hover {
  opacity: 0.9;
}
tsx
/* components/Button.tsx */
import styles from './Button.module.css'

export default function Button({
  children,
  variant = 'primary'
}: {
  children: React.ReactNode
  variant?: 'primary' | 'secondary'
}) {
  return (
    <button className={`${styles.button} ${styles[variant]}`}>
      {children}
    </button>
  )
}

}

6.2 条件类名 ​

tsx
import clsx from 'clsx'

export default function Button({
  children,
  variant = 'primary',
  size = 'medium',
  disabled = false
}) {
  return (
    <button
      className={clsx(
        'rounded font-medium transition',
        {
          'bg-blue-500 text-white hover:bg-blue-600': variant === 'primary',
          'bg-gray-200 text-gray-800 hover:bg-gray-300': variant === 'secondary',
          'px-2 py-1 text-sm': size === 'small',
          'px-4 py-2 text-base': size === 'medium',
          'px-6 py-3 text-lg': size === 'large',
          'opacity-50 cursor-not-allowed': disabled
        }
      )}
      disabled={disabled}
    >
      {children}
    </button>
  )
}

🎯 面试常考 ​

Q1:Next.js 推荐样式方案? ​

答:

  • CSS Modules:局部作用域,推荐
  • Tailwind CSS:原子化,Next.js 13+ 一等支持
  • CSS-in-JS:styled-components / emotion;Next.js 14+ 服务端组件限制
  • 全局 CSS:app/globals.css;只在 root layout 导入

Q2:为什么 App Router 默认推荐 Tailwind? ​

答:

  • 零运行时(对 RSC 友好)
  • 自动 tree-shaking(按需)
  • 与 SSR / SSG 无缝
  • 设计 token 集中管理
  • 新项目首选(Next.js 官方文档默认示例都用)

Q3:styled-components 在 App Router 怎么配? ​

答:

  • 安装 next-with-styled-components 或手写 registry
  • App Router 14+ 必须用 ServerStyleSheet 处理 SSR
  • 性能:每个 styled-component 有运行时开销,大项目慎用
  • 新项目建议:Server Component + Tailwind + CSS Modules 组合

Q4:CSS Modules 写法? ​

答:

tsx
// button.module.css
.btn { color: red }

// button.tsx
import styles from './button.module.css'
<button className={styles.btn}>Click</button>
  • 局部作用域(编译时 hash)
  • 支持 :global() 突破局部
  • 配 typescript-plugin-css-modules 有类型补全
