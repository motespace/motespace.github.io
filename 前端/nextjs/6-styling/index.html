Section titled “8.2 样式组织建议”
类型 推荐方案 原因

🎯 面试常考

Section titled “🎯 面试常考”

Q1:Next.js 推荐样式方案?

Section titled “Q1:Next.js 推荐样式方案?”

答:

  • CSS Modules:局部作用域,推荐
  • Tailwind CSS:原子化,Next.js 13+ 一等支持
  • CSS-in-JS:styled-components / emotion;Next.js 14+ 服务端组件限制
  • 全局 CSS:app/globals.css;只在 root layout 导入

Q2:为什么 App Router 默认推荐 Tailwind?

Section titled “Q2:为什么 App Router 默认推荐 Tailwind?”

答:

  • 零运行时(对 RSC 友好)
  • 自动 tree-shaking(按需)
  • 与 SSR / SSG 无缝
  • 设计 token 集中管理
  • 新项目首选(Next.js 官方文档默认示例都用)

Q3:styled-components 在 App Router 怎么配?

Section titled “Q3:styled-components 在 App Router 怎么配?”

答:

  • 安装 next-with-styled-components 或手写 registry
  • App Router 14+ 必须用 ServerStyleSheet 处理 SSR
  • 性能:每个 styled-component 有运行时开销,大项目慎用
  • 新项目建议:Server Component + Tailwind + CSS Modules 组合

Q4:CSS Modules 写法?

Section titled “Q4:CSS Modules 写法?”

答:

  • 局部作用域(编译时 hash)
  • 支持 :global() 突破局部
  • 配 typescript-plugin-css-modules 有类型补全

📝 小结

Section titled “📝 小结”
  • Next.js 推荐 CSS Modules(局部作用域、零运行时)+ Tailwind(原子类、约束设计系统),两者不冲突。
  • 只能把全局 CSS 放在根 layout(import './globals.css'),组件内 import 全局 CSS 会报错。
  • CSS Modules 的类名可以写成 styles['btn-primary'],配合 cva/clsx 做变体管理。
  • Tailwind v4 用 @import "tailwindcss" + @theme 定义 design token,和组件库 token 打通要靠 CSS 变量。
  • 避免「样式冲突」的根因是作用域隔离,不是加优先级;Tailwind 的 group/peer/任意变体 [&>*] 是解决复合样式的正解。
  • 面试追问:Tailwind 的优点是约束 + 可删除(用不到就删干净),适合组件库和设计系统,不适合需要大量主题定制的老项目。
