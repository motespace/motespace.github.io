面试常考

Section titled “面试常考”

Q1:App Router API Routes 怎么写?

Section titled “Q1:App Router API Routes 怎么写?”

答:

  • app/api/posts/route.ts 导出 GET / POST 等 HTTP 方法
  • 每个方法是 Request → Response 的异步函数
  • 例:export async function GET() { return Response.json({ data: [] }) }
  • 动态参数:app/api/posts/[id]/route.ts;{ params }: { params: { id: string } }

Q2:Route Handlers vs Server Actions 选哪个?

Section titled “Q2:Route Handlers vs Server Actions 选哪个?”

答:

  • Route Handlers:对外 RESTful API、Webhook、第三方消费
  • Server Actions:内部表单提交、按钮触发
  • 实战:能 Actions 就不写 API(代码少、类型安全)

Q3:API Route 中间件怎么用?

Section titled “Q3:API Route 中间件怎么用?”

答:

  • App Router 中间件作用于所有 route(包括 API)
  • 鉴权:if (!token) return new Response('Unauthorized', { status: 401 })
  • 日志 / 限流 / 跨域统一处理

Q4:错误处理?

Section titled “Q4:错误处理?”

答:

  • try-catch 包业务逻辑
  • 返回 Response.json({ error }, { status: 500 })
  • 区分 4xx(客户端错误)vs 5xx(服务端)
  • 用 zod / yup 校验入参

📝 小结

Section titled “📝 小结”
  • App Router 里叫 Route Handlers(app/api/xxx/route.ts),导出 GET/POST/PUT/DELETE,请求是标准 Request、返回 Response。
  • 不用 res.json() 而是直接 return Response.json(data);流式用 ReadableStream。
  • runtime、dynamic、revalidate 等段配置决定该路由是静态还是动态,和页面级的配置语义一致。
  • Route Handler 适合对外 API / BFF 聚合 / Webhook;内部写操作优先 Server Actions。
  • 跨域要显式处理 CORS 头与 OPTIONS 预检;鉴权用中间件 + 路由内二次校验。
  • 面试常问「Route Handler 和 API Route 区别」:前者基于 Web 标准 Request/Response 且支持 Edge,后者是 Node 传统封装。
