Next.js API Routes 详解 ​

一、API Routes 简介 ​

API Routes 允许在 Next.js 应用中创建 API 端点。

App Router vs Pages Router ​

RouterAPI 位置文件命名
App Routerapp/api/route.ts
Pages Routerpages/api/*.ts

二、App Router API Routes ​

2.1 基础结构 ​

app/
├── api/
│   ├── user/
│   │   └── route.ts      # GET /api/user, POST /api/user
│   ├── user/[id]/
│   │   └── route.ts      # GET /api/user/:id, PUT /api/user/:id, DELETE /api/user/:id
│   └── posts/
│       └── route.ts      # GET /api/posts, POST /api/posts

2.2 基础 GET 请求 ​

tsx
// app/api/user/route.ts
import { NextResponse } from 'next/server'

export async function GET() {
  const users = await db.user.findMany()

  return NextResponse.json(users)
}

2.3 基础 POST 请求 ​

tsx
// app/api/user/route.ts
import { NextResponse } from 'next/server'
import { z } from 'zod'

const schema = z.object({
  name: z.string().min(1),
  email: z.string().email()
})

export async function POST(request: Request) {
  try {
    const body = await request.json()
    const validated = schema.parse(body)

    const user = await db.user.create({
      data: validated
    })

    return NextResponse.json(user, { status: 201 })
  } catch (error) {
    return NextResponse.json(
      { error: '创建用户失败' },
      { status: 400 }
    )
  }
}

2.4 获取动态参数 ​

tsx
// app/api/user/[id]/route.ts
import { NextResponse } from 'next/server'

export async function GET(
  request: Request,
  { params }: { params: { id: string } }
) {
  const user = await db.user.findUnique({
    where: { id: params.id }
  })

  if (!user) {
    return NextResponse.json({ error: '用户不存在' }, { status: 404 })
  }

  return NextResponse.json(user)
}

export async function PUT(
  request: Request,
  { params }: { params: { id: string } }
) {
  const body = await request.json()

  const user = await db.user.update({
    where: { id: params.id },
    data: body
  })

  return NextResponse.json(user)
}

export async function DELETE(
  request: Request,
  { params }: { params: { id: string } }
) {
  await db.user.delete({
    where: { id: params.id }
  })

  return NextResponse.json({ success: true })
}

三、Pages Router API Routes ​

3.1 基础结构 ​

pages/
└── api/
    ├── hello.ts          # /api/hello
    └── posts/
        └── [id].ts       # /api/posts/:id

3.2 基础示例 ​

tsx
// pages/api/hello.ts
import type { NextApiRequest, NextApiResponse } from 'next'

export default function handler(
  req: NextApiRequest,
  res: NextApiResponse
) {
  if (req.method === 'GET') {
    res.status(200).json({ message: 'Hello!' })
  } else {
    res.status(405).json({ error: 'Method not allowed' })
  }
}

3.3 动态路由 ​

tsx
// pages/api/posts/[id].ts
import type { NextApiRequest, NextApiResponse } from 'next'

export default async function handler(
  req: NextApiRequest,
  res: NextApiResponse
) {
  const { id } = req.query

  if (req.method === 'GET') {
    const post = await db.post.findUnique({ where: { id: id as string } })
    res.status(200).json(post)
  }

  if (req.method === 'PUT') {
    const post = await db.post.update({
      where: { id: id as string },
      data: req.body
    })
    res.status(200).json(post)
  }

  if (req.method === 'DELETE') {
    await db.post.delete({ where: { id: id as string } })
    res.status(204).end()
  }
}

四、请求处理 ​

4.1 获取查询参数 ​

tsx
// App Router
export async function GET(request: Request) {
  const { searchParams } = new URL(request.url)
  const page = searchParams.get('page') ?? '1'
  const limit = searchParams.get('limit') ?? '10'
}

// Pages Router
export default function handler(req: NextApiRequest, res: NextApiResponse) {
  const { page, limit } = req.query
}

4.2 获取 Headers ​

tsx
export async function GET(request: Request) {
  const token = request.headers.get('authorization')
  const userAgent = request.headers.get('user-agent')

  if (!token) {
    return NextResponse.json({ error: '未授权' }, { status: 401 })
  }

  return NextResponse.json({ token, userAgent })
}

4.3 设置 Cookie ​

tsx
export async function POST(request: Request) {
  const response = NextResponse.json({ success: true })

  // 设置 Cookie
  response.cookies.set('token', 'abc123', {
    httpOnly: true,
    secure: process.env.NODE_ENV === 'production',
    sameSite: 'strict',
    maxAge: 60 * 60 * 24, // 1 天
    path: '/'
  })

  return response
}

4.4 读取 Cookie ​

tsx
import { cookies } from 'next/headers'

export async function GET() {
  const cookieStore = cookies()
  const token = cookieStore.get('token')

  if (!token) {
    return NextResponse.json({ error: '未登录' }, { status: 401 })
  }

  return NextResponse.json({ token: token.value })
}

五、响应处理 ​

5.1 标准响应 ​

tsx
// 成功响应
return NextResponse.json({ success: true })

// 带状态码

// 纯文本
return new Response('Hello', { status: 200 })

// HTML
return new Response('<h1>Hello</h1>', {
  headers: { 'Content-Type': 'text/html' }
})

5.2 缓存控制 ​

tsx
export async function GET() {
  return NextResponse.json(
    { data: 'cached' },
    {
      headers: {
        'Cache-Control': 'public, max-age=3600, s-maxage=86400'
      }
    }
  )
}

5.3 CORS 设置 ​

tsx
import { NextResponse } from 'next/server'

export async function GET() {
  return NextResponse.json({ data: 'data' }, {
    headers: {
      'Access-Control-Allow-Origin': '*',
      'Access-Control-Allow-Methods': 'GET, POST, PUT, DELETE',
      'Access-Control-Allow-Headers': 'Content-Type, Authorization'
    }
  })
}

// OPTIONS 处理（CORS 预检请求）
export async function OPTIONS() {
  return new Response(null, {
    headers: {
      'Access-Control-Allow-Origin': '*',
      'Access-Control-Allow-Methods': 'GET, POST, PUT, DELETE',

六、中间件 ​

6.1 中间件基础 ​

tsx
// middleware.ts（项目根目录）
import { NextResponse } from 'next/server'
import type { NextRequest } from 'next/server'

export function middleware(request: NextRequest) {
  // 获取请求路径
  const path = request.nextUrl.pathname

  // 公开路径（不需要登录）
  const publicPaths = ['/', '/login', '/register']
  const isPublic = publicPaths.some(p => path === p || path.startsWith('/api/'))

  // 获取 token
  const token = request.cookies.get('token')

  // 需要登录的路径
  const protectedPaths = ['/dashboard', '/profile', '/settings']
  const isProtected = protectedPaths.some(p => path.startsWith(p))

  // 如果访问受保护路径但没有 token，重定向到登录页
  if (isProtected && !token) {
    return NextResponse.redirect(new URL('/login', request.url))
  }

  // 如果已登录且访问登录页，重定向到首页
  if (token && path === '/login') {
    return NextResponse.redirect(new URL('/dashboard', request.url))
  }

  return NextResponse.next()
}

// 配置匹配路径
export const config = {
  matcher: ['/((?!_next/static|_next/image|favicon.ico).*)']
}

6.2 中间件实现 JWT 验证 ​

tsx
// middleware.ts
import { NextResponse } from 'next/server'
import type { NextRequest } from 'next/server'
import { verifyToken } from './lib/jwt'

export async function middleware(request: NextRequest) {
  const token = request.cookies.get('auth-token')?.value

  const protectedRoutes = ['/dashboard', '/profile', '/settings']
  const isProtectedRoute = protectedRoutes.some(route =>
    request.nextUrl.pathname.startsWith(route)
  )

  if (isProtectedRoute) {
    if (!token) {
      return NextResponse.redirect(new URL('/login', request.url))
    }

    try {
      await verifyToken(token)
    } catch {
      return NextResponse.redirect(new URL('/login', request.url))
    }
  }

  return NextResponse.next()
}

export const config = {
  matcher: ['/dashboard/:path*', '/profile/:path*', '/settings/:path*']
}

6.3 中间件中的 API 请求重写 ​

tsx
// middleware.ts
import { NextResponse } from 'next/server'
import type { NextRequest } from 'next/server'

export function middleware(request: NextRequest) {
  const url = request.nextUrl.clone()

  // 将 /api/proxy/* 重写到外部 API
  if (url.pathname.startsWith('/api/proxy')) {
    url.pathname = url.pathname.replace('/api/proxy', '')
    url.hostname = 'external-api.com'
    url.protocol = 'https:'

    return NextResponse.rewrite(url)
  }

  return NextResponse.next()
}

// app/api/posts/route.ts
export async function GET(request: Request) {
  const { searchParams } = new URL(request.url)
  const page = parseInt(searchParams.get('page') ?? '1')
  const limit = parseInt(searchParams.get('limit') ?? '10')
  const skip = (page - 1) * limit

  const [posts, total] = await Promise.all([
    db.post.findMany({
      skip,
      take: limit,
      orderBy: { createdAt: 'desc' }
    }),
    db.post.count()
  ])

    posts,
    pagination: {
      page,
      limit,
      total,
      totalPages: Math.ceil(total / limit)
    }
  })
}

9.3 速率限制示例 ​

tsx
import { NextResponse } from 'next/server'

const rateLimit = new Map<string, { count: number; lastReset: number }>()

export async function POST(request: Request) {
  const ip = request.headers.get('x-forwarded-for') ?? 'unknown'
  const now = Date.now()
  const limit = 100 // 100 requests
  const windowMs = 60 * 1000 // 1 minute

  let record = rateLimit.get(ip)

  if (!record || now - record.lastReset > windowMs) {
    record = { count: 0, lastReset: now }
  }

  record.count++

  if (record.count > limit) {
    return NextResponse.json(
      { error: '请求过于频繁' },
      { status: 429 }
    )
  }

  rateLimit.set(ip, record)

  // 处理请求...
  return NextResponse.json({ success: true })
}

面试常考 ​

Q1:App Router API Routes 怎么写? ​

答:

  • app/api/posts/route.ts 导出 GET / POST 等 HTTP 方法
  • 每个方法是 Request → Response 的异步函数
  • 例:export async function GET() { return Response.json({ data: [] }) }
  • 动态参数:app/api/posts/[id]/route.ts;{ params }: { params: { id: string } }

Q2:Route Handlers vs Server Actions 选哪个? ​

答:

  • Route Handlers:对外 RESTful API、Webhook、第三方消费
  • Server Actions:内部表单提交、按钮触发
  • 实战:能 Actions 就不写 API(代码少、类型安全)

Q3:API Route 中间件怎么用? ​

答:

  • App Router 中间件作用于所有 route(包括 API)
  • 鉴权:if (!token) return new Response('Unauthorized', { status: 401 })
  • 日志 / 限流 / 跨域统一处理

Q4:错误处理? ​

答:

  • try-catch 包业务逻辑
  • 返回 Response.json({ error }, { status: 500 })
  • 区分 4xx(客户端错误)vs 5xx(服务端)
  • 用 zod / yup 校验入参
