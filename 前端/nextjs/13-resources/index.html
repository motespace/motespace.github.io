简答速记(对清单的补充)

Section titled “简答速记(对清单的补充)”
  • App Router vs Pages Router? App Router(13+)基于 React Server Components、文件路由、支持流式;Pages Router(13-)传统 SPA/SSR
  • SSR vs SSG vs ISR vs CSR? SSR 每次请求渲染;SSG 构建时静态;ISR 增量静态;CSR 客户端渲染
  • Server Components vs Client Components? Server 组件服务端运行(无 state/effect);Client 加 'use client' 可交互
  • getStaticProps vs getServerSideProps? SSG vs SSR;前者构建时,后者请求时
  • Streaming 原理? Suspense 边界 + RSC 协议;服务端分块流式返回 HTML
  • Server Actions? 'use server' 指令的函数,客户端直接调用服务端逻辑
  • 缓存机制? Data Cache(fetch)/Full Route Cache(整页)/Router Cache(客户端导航)
  • Middleware? Edge Runtime 运行;鉴权 / 重定向 / header 修改

📝 小结

Section titled “📝 小结”
  • 学习顺序建议:官方 App Router 教程 → 官方数据获取与缓存章节 → 部署文档 → 再看 examples/ 官方仓库里的真实项目。
  • 必读:Next.js 官方文档的 Data Fetching / Caching / Rendering 三章,是面试里 SSR/ISR/缓存问题的主战场。
  • 生态必装:zod(校验)、@tanstack/react-query(客户端数据)、next-auth/auth.js(鉴权)、prisma(数据层)。
  • 源码方向:看 packages/next/src/server/app-render 理解渲染流程,比读博客有效。
  • 关键问题清单要能默写:SSR/SSG/ISR 区别、缓存四层、RSC 限制、Server Actions 安全、middleware 与 edge 限制。
