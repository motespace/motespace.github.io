Playwright E2E 测试 ​

现代化 E2E 框架：跨浏览器 + 速度快 + 自动录屏 + Page Object。 本文按"配置 → 测试 → 实战"组织。

一、为什么选 Playwright ​

维度PlaywrightSeleniumCypress
浏览器Chromium/Firefox/WebKit全部Chromium/Firefox/Edge
速度快慢中
API 设计现代化 async/await老式简单
自动等待✅❌✅
录屏✅❌✅
CI 集成✅✅✅

二、安装 ​

bash
pnpm add -D @playwright/test
pnpm exec playwright install

三、配置 ​

3.1 playwright.config.ts ​

ts
import { defineConfig, devices } from '@playwright/test'

export default defineConfig({
  testDir: './e2e',
  fullyParallel: true,
  forbidOnly: !!process.env.CI,
  retries: process.env.CI ? 2 : 0,
  workers: process.env.CI ? 1 : undefined,
  reporter: 'html',

  use: {
    baseURL: 'http://localhost:3000',
    trace: 'on-first-retry',
    screenshot: 'only-on-failure',
    video: 'retain-on-failure',
  },

  projects: [
    { name: 'chromium', use: { ...devices['Desktop Chrome'] } },
    { name: 'firefox', use: { ...devices['Desktop Firefox'] } },
    { name: 'webkit', use: { ...devices['Desktop Safari'] } },
  ],

  webServer: {
    command: 'pnpm dev',
    url: 'http://localhost:3000',
    reuseExistingServer: !process.env.CI,
    timeout: 120_000,
  },
})

ts
// e2e/auth.spec.ts
import { test, expect } from '@playwright/test'

test('user can login successfully', async ({ page }) => {
  await page.goto('/login')

  await page.fill('input[name="email"]', 'tom@example.com')
  await page.fill('input[name="password"]', '123456')

  await page.fill('input[name="password"]', 'wrong')
  await page.click('button[type="submit"]')

})

五、Page Object Model ​

5.1 创建 Page Object ​

ts
// e2e/pages/LoginPage.ts
import { type Page, expect } from '@playwright/test'

export class LoginPage {
  constructor(public page: Page) {}

  async goto() {
    await this.page.goto('/login')
  }

  async login(email: string, password: string) {
    await this.page.fill('input[name="email"]', email)
    await this.page.fill('input[name="password"]', password)
    await this.page.click('button[type="submit"]')
  }

  async expectError(message: string) {
    await expect(this.page.locator('.error-message')).toContainText(message)
  }

  async expectSuccess() {
    await expect(this.page).toHaveURL('/dashboard')
  }
}

5.2 使用 Page Object ​

ts
// e2e/auth.spec.ts
import { test } from '@playwright/test'
import { LoginPage } from './pages/LoginPage'

test('user can login', async ({ page }) => {
  const loginPage = new LoginPage(page)
  await loginPage.goto()
  await loginPage.login('tom@example.com', '123456')
  await loginPage.expectSuccess()
})

ts
// CSS 选择器
await page.locator('.button').click()

6.2 等待 ​

ts
// 自动等待（默认）
await page.click('button')  // 自动等可见、可点击

// 显式等待
await page.waitForSelector('.toast')
await page.waitForURL(/dashboard/)
await page.waitForLoadState('networkidle')

// 自定义等待
await expect(page.locator('.count')).toHaveText('10')

6.3 输入 ​

ts
// fill：清空 + 输入

// type：逐字符输入（更真实）
await page.type('input', 'hello')

// press：按键
await page.press('input', 'Enter')

ts

七、Fixtures（依赖注入） ​

7.1 自定义 fixture ​

ts
// e2e/fixtures.ts
import { test as base } from '@playwright/test'
import { LoginPage } from './pages/LoginPage'

export const test = base.extend<{
  loginPage: LoginPage
  authenticatedPage: Page
}>({
  loginPage: async ({ page }, use) => {
    await use(new LoginPage(page))
  },

  authenticatedPage: async ({ page }, use) => {
    // 自动登录
    await page.goto('/login')
    await page.fill('input[name="email"]', 'test@example.com')
    await page.fill('input[name="password"]', '123456')
    await page.click('button[type="submit"]')
    await page.waitForURL('/dashboard')

    await use(page)
  },
})

export { expect } from '@playwright/test'

ts
// e2e/dashboard.spec.ts

})

十二、面试高频追问 ​

Q1: Playwright 和 Cypress 区别？ ​

答：

  • Playwright：支持 Chromium / Firefox / WebKit，跨浏览器
  • Cypress：支持 Chromium / Firefox / Edge，不支持 Safari
  • 选型：需要 Safari 测试 -> Playwright；只要 Chromium -> Cypress 也行

Q2: 怎么减少 E2E 不稳定性？ ​

答：

  1. 用 expect 自动等待，不要 waitForTimeout
  2. 用 data-testid 而不是 CSS
  3. 重试机制
  4. 避免依赖时间（用 fixed date mock）

Q3: E2E 测试覆盖多少？ ​

答：只测关键路径（登录、注册、支付、核心流程）。10-20 个测试覆盖 80% 信心。

Q4: 怎么和单元测试配合？ ​

答：

  • 单元测试：测函数、Hook、组件逻辑（70%）
  • E2E：测用户视角的关键路径（10%）
  • 两者互补，不重叠

Q5: Playwright 怎么录屏？ ​

答：

ts
use: {
  video: 'retain-on-failure',
}

// 失败时自动保存录屏到 test-results/

面试追问(深化原 Q1-Q5) ​

  • Playwright 优势? 跨浏览器(Chromium/Firefox/WebKit)、并行快、自动等待
  • Playwright vs Cypress? Playwright 多浏览器;Cypress 调试体验好但只 Chromium 系
  • E2E 慢怎么办? 并行(workers)、按需跑(受影响路径)、mock 外部依赖
  • 视觉回归? Playwright toHaveScreenshot() 自动比对;小项目实用
  • E2E 调试? --debug 模式;trace viewer;CI 视频录制
