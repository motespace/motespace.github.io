1. 硬链接 + 内容寻址存储

Section titled “1. 硬链接 + 内容寻址存储”

package: react (1MB)

  • npm/yarn：每个项目复制一份
  • pnpm：全局一份 + 硬链接（节省 50%+ 磁盘）

2. 非平铺 node_modules（防幽灵依赖）

Section titled “2. 非平铺 node_modules（防幽灵依赖）”

npm/yarn 平铺结构：A 包没声明 pkg-c 但 require pkg-c 能跑（幽灵依赖） pnpm 非平铺：强制嵌套，幽灵依赖直接报错

七、Monorepo 常见坑

Section titled “七、Monorepo 常见坑”

7.1 幽灵依赖

Section titled “7.1 幽灵依赖”

解决：在每个子包明确声明依赖。

7.2 版本不一致

Section titled “7.2 版本不一致”

ui 包: react ^18.0.0 utils 包: react ^17.0.0 web 包: react ^18.0.0

解决：用 pnpm.overrides 统一版本。

7.3 循环依赖

Section titled “7.3 循环依赖”

ui -> utils utils -> ui // 死循环

解决：抽 base 包，让 ui 和 utils 都依赖 base。

7.4 CI 慢

Section titled “7.4 CI 慢”

所有 CI 都跑所有包的 build -> 慢

解决：用 Turborepo + 远程缓存（见 §2）。

八、面试高频追问

Section titled “八、面试高频追问”

Q1: 为什么要 Monorepo？和 Multirepo 区别？

Section titled “Q1: 为什么要 Monorepo？和 Multirepo 区别？”

答：

  • Multirepo：每个项目独立仓库，独立 CI/CD
  • Monorepo：所有项目一个仓库，统一管理
  • 选型：业务相关 -> Monorepo（统一升级、跨包重构）/ 业务独立 -> Multirepo（团队独立）

Q2: pnpm 比 npm/yarn 强在哪？

Section titled “Q2: pnpm 比 npm/yarn 强在哪？”

答：

  • 磁盘：硬链接节省 50%+
  • 速度：快 2-3x
  • 防幽灵依赖：嵌套结构强制声明
  • monorepo 原生：workspace 协议

Q3: workspace 协议和 file 协议区别？

Section titled “Q3: workspace 协议和 file 协议区别？”

答：

  • workspace:*：软链接到 workspace 里的包，源码实时同步
  • file:../packages/ui：硬链接/复制，适合发布后的版本

Q4: Monorepo 下怎么做版本管理？

Section titled “Q4: Monorepo 下怎么做版本管理？”

答：

  • 统一版本：所有包同版本（适合工具库）
  • 独立版本：每个包独立（用 Changesets 管理变更日志）

Section titled “面试追问(深化原 Q1-Q5)”
  • pnpm workspace 配置? 根 pnpm-workspace.yaml 列 packages;pnpm install 一次装所有
  • pnpm 优势 vs npm/yarn? 硬链接(节省空间)、monorepo 友好、更严格的依赖隔离

📝 小结

Section titled “📝 小结”
  • Monorepo 方案对比:Nx(强规则+任务编排)、Turborepo(轻量+缓存)、Lerna(发版为主)、pnpm workspace(只做依赖管理,需配 Turborepo)。
  • 选 pnpm 的核心原因:硬链接 + 符号链接的 node_modules 结构,同版本依赖只存一份,省磁盘也避免幽灵依赖。
  • workspace 必须用 pnpm-workspace.yaml 声明 packages,包之间互相依赖用 workspace:*。
  • --filter 是 monorepo 的命脉:--filter @pkg 只跑某个包,--filter ...@pkg 跑它和所有依赖方,^... 只跑依赖它的。
  • 常见坑:node_modules 必须装在仓库根(用 pnpm install 在根执行)、包之间不要循环依赖、构建产物用 dist 且加 .gitignore。
  • 面试能说清「为什么 npm/yarn 的扁平 node_modules 会造成幽灵依赖、pnpm 怎么解决」,就是加分项。
