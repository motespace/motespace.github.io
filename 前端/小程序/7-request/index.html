小程序网络请求与封装

小程序的 wx.request 和浏览器的 fetch 很像,但多了三个限制: 域名必须备案并配置、并发上限 10、不能跨域但没有 CORS 那套。

1. 三个硬限制

Section titled “1. 三个硬限制”

1.1 域名白名单

Section titled “1.1 域名白名单”

小程序只能请求在 mp.weixin.qq.com 后台配置过的域名, 且必须是 HTTPS(开发阶段可以在「开发设置」里勾选「不校验合法域名」临时绕过)。

注意:端口要一致,域名不能带路径(路径写在请求里)。

1.2 并发上限 10

Section titled “1.2 并发上限 10”

同时最多 10 个 wx.request。超出的会进队列等待。

1.3 超时与重试

Section titled “1.3 超时与重试”

移动网络波动大,超时设 10s 左右,失败给重试入口。

2. 统一封装

Section titled “2. 统一封装”

要点:

  • 统一 baseURL、token 注入、超时、错误格式
  • 401 统一跳登录并清 token
  • 网络类错误才重试,业务错误不重试

3. 与 axios 的对比

Section titled “3. 与 axios 的对比”
axios wx.request
拦截器 有 没有,要自己包一层
超时 默认 0(不超时) 默认 60s
取消请求 AbortController task.abort()
数组序列化 默认 对象会被转成 a=1&b=2,数组要自己处理
响应结构 res.data res.data(整体在 data 里)

5. 缓存与离线

Section titled “5. 缓存与离线”

推荐做法:

  • 进入页面先渲染缓存,再发请求更新(类似 stale-while-revalidate)
  • 请求失败时保留旧数据 + 提示「当前为缓存内容」

6. 面试常考

Section titled “6. 面试常考”

Q1:wx.request 有哪些限制?

Section titled “Q1:wx.request 有哪些限制?”

答:三个:① 域名必须在后台配置白名单且是 HTTPS;② 并发上限 10,超了排队; ③ 单次请求超时默认 60s(要自己设短)。另外 cookie 不会自动带, 需要自己从 header 里读 Set-Cookie 或用 token。

Q2:怎么封装请求?和 axios 比缺什么?

Section titled “Q2:怎么封装请求?和 axios 比缺什么?”

答:封装要处理:baseURL、token 注入、超时、统一错误格式、401 跳登录、 网络类错误重试。和 axios 比缺拦截器(要自己实现一套)和取消请求 (要用 wx.request 返回的 task 的 abort())。

Q3:上传文件要注意什么?

Section titled “Q3:上传文件要注意什么?”

答:用 wx.uploadFile,参数是 filePath + name(文件字段名) + formData(普通参数); 返回值 res.data 是字符串要自己 JSON.parse;不支持 data 对象; 大文件要自己分片再合并。

Q4:怎么让页面在弱网下也有内容?

Section titled “Q4:怎么让页面在弱网下也有内容?”

答:请求前先读本地缓存渲染一版(标记 fromCache),请求成功后覆盖并更新缓存; 失败时保留缓存内容 + 提示「当前为缓存数据」。列表页尤其要做, 否则弱网下是白屏。
