小程序生命周期

小程序有 App 级和Page 级两套生命周期,还有 Component 级。 最常被问的差异是:onLoad / onReady / onShow 到底谁先谁后。

1. App 生命周期(整个小程序只有一份)

Section titled “1. App 生命周期(整个小程序只有一份)”

onLaunch 里不要做重活:此时还没有页面,wx.getSystemInfo 之类的同步调用可以, 但网络请求会拖慢首屏。常见做法是 onLaunch 里只存全局状态,首屏请求放页面的 onLoad。

2. Page 生命周期(每个页面一份)

Section titled “2. Page 生命周期(每个页面一份)”
生命周期 触发时机 适合做什么
onLoad 页面创建时,只一次 拿参数(options)、发首屏请求
onShow 页面显示时,每次 刷新数据、恢复轮询
onReady 页面首次渲染完成后,只一次 测布局(createSelectorQuery)、操作 Canvas
onHide 页面隐藏 停定时器、取消请求
onUnload 页面销毁 清理全局注册、取消订阅

2.1 onLoad vs onShow

Section titled “2.1 onLoad vs onShow”

规则:首屏必需的数据放 onLoad,「每次回来都要更新」的数据放 onShow。 在 onShow 里无条件请求会导致返回页面时又闪一次 loading。

2.2 onReady 与 createSelectorQuery

Section titled “2.2 onReady 与 createSelectorQuery”

必须在 onReady 之后——之前视图层还没渲染,查不到节点。

2.3 路由切换时的生命周期顺序

Section titled “2.3 路由切换时的生命周期顺序”

注意:A 的 onHide 先于 B 的 onLoad。 所以在 A 里保存状态、在 B 里读,时序是对的。

3. Component 生命周期

Section titled “3. Component 生命周期”

自定义组件也有生命周期,但名字不同:

Page Component 说明
onLoad attached 组件进入页面
onReady ready 渲染完成
onUnload detached 卸载

created 里不能 setData(还没有视图),要设初始值直接写 data: {...}。

4. 页面间数据传递

Section titled “4. 页面间数据传递”

4.1 URL 参数

Section titled “4.1 URL 参数”

注意:query 传的是字符串,数字要自己转;长度有限制,别传大对象。

4.2 全局状态

Section titled “4.2 全局状态”

全局状态慎用:所有页面共享,改一处影响全局,且不会自动触发视图更新。 正经的做法是状态库(store),或者用 MobX-miniprogram 这类。

5. 面试常考

Section titled “5. 面试常考”

Q1:小程序有哪些生命周期?onLoad 和 onShow 有什么区别?

Section titled “Q1:小程序有哪些生命周期?onLoad 和 onShow 有什么区别?”

答:App 级有 onLaunch / onShow / onHide / onError; Page 级有 onLoad(创建时一次)/ onShow(每次显示)/ onReady(首次渲染完)/ onHide / onUnload。 区别:onLoad 只在页面创建时触发一次,用来拿参数和发首屏请求; onShow 每次页面显示都触发,适合「从别处返回时要刷新」的场景。 无条件在 onShow 请求会导致返回时重复加载。

Q2:onReady 什么时候用?和 onLoad 有什么区别?

Section titled “Q2:onReady 什么时候用?和 onLoad 有什么区别?”

答:onLoad 是页面创建时(视图还没渲染),onReady 是首次渲染完成后。 需要读取节点尺寸、测量布局、操作 Canvas 的逻辑必须放 onReady, 因为之前 createSelectorQuery 查不到节点。

Q3:页面跳转时两个页面的生命周期顺序?

Section titled “Q3:页面跳转时两个页面的生命周期顺序?”

答:跳转时,旧页面先 onHide,新页面再 onLoad → onShow → onReady; 返回时,被返回的页面 onShow,被离开的页面 onUnload。 所以在旧页面 onHide 里存数据、新页面 onLoad 里读,时序是对的。

Q4:组件的生命周期和页面有什么不一样?

Section titled “Q4:组件的生命周期和页面有什么不一样?”

答:组件用 created / attached / ready / moved / detached。 created 里不能 setData(还没有视图),初始值直接写在 data 里; attached 之后才能 setData;detached 对应页面的 onUnload。
