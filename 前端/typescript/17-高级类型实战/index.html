Section titled “八、面试高频追问”

Q1: as const 和 satisfies 的区别？

Section titled “Q1: as const 和 satisfies 的区别？”

答：

  • as const：把所有字面量标记为最具体的字面量类型，但没有类型校验
  • satisfies：校验类型符合约束，但保留字面量推断
  • 配合用：satisfies ... as const 可以校验 + 字面量 + readonly

Q2: 协变和逆变在什么时候用？

Section titled “Q2: 协变和逆变在什么时候用？”

答：

  • 协变：返回值、子类型赋值给父类型（Cat 是 Animal）
  • 逆变：函数参数，能处理子类型一定能处理父类型
  • 不变：可变结构（数组、Map）

Q3: infer 和 extends 有什么区别？

Section titled “Q3: infer 和 extends 有什么区别？”

答：

  • extends 是类型约束（必须是 X 的子类型）
  • infer 是在条件类型中声明类型变量并捕获

Q4: 怎么写一个 lodash.get 的类型安全版本？

Section titled “Q4: 怎么写一个 lodash.get 的类型安全版本？”

答：用模板字面量类型 + 递归 + keyof，详见 §5.2。

Q6: satisfies 在生产项目怎么用？

Section titled “Q6: satisfies 在生产项目怎么用？”

答：

  • 配置对象（路由、菜单、i18n 文案）
  • 表单 schema
  • 任何需要“字面量类型 + 校验”的场景

面试追问(深化原 Q1-Q6)

Section titled “面试追问(深化原 Q1-Q6)”
  • 分布式条件类型怎么避免爆栈? 递归类型加边界检查 T extends any[] ? ... : never;TS 4.5+ 改进了尾递归
  • as const satisfies 优先级? 先 satisfies 校验,再 as const 锁定字面量;缺一不可
  • infer 实战场景? Promise unwrap、数组元素、函数返回值;Awaited&lt;T&gt; 就是 T extends Promise&lt;infer U&gt; ? U : T
  • 协变逆变在 React 组件 props? ReactNode 协变;事件 handler 逆变;useState 不变
  • 模板字面量 + 递归? 路径类型 / 事件名 / CSS 工具类自动生成;最强大但编译慢

📝 小结

Section titled “📝 小结”
  • 高级类型的价值是「把运行时的约束搬到编译期」,比如让表单字段和校验规则绑定。
  • 常用组合:映射类型做字段变换、条件类型 + infer 做提取、infer + as 做校验。
  • 可辨识联合(discriminated union)能做出穷尽检查,加一个新类型忘了处理会编译报错。
  • 泛型 + 条件类型可以实现「表单类型自动从 schema 推导」这类高级需求。
