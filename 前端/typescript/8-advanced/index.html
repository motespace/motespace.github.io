说说你对 TypeScript 中高级类型的理解？有哪些？

一、是什么

Section titled “一、是什么”

除了string、number、boolean 这种基础类型外，在 typescript 类型声明中还存在一些高级的类型应用

这些高级类型，是typescript为了保证语言的灵活性，所使用的一些语言特性。这些特性有助于我们应对复杂多变的开发场景

二、有哪些

Section titled “二、有哪些”

常见的高级类型有如下：

  • 交叉类型
  • 联合类型
  • 类型别名
  • 类型索引
  • 类型约束
  • 映射类型
  • 条件类型

类型索引

Section titled “类型索引”

keyof 类似于 Object.keys ，用于获取一个接口中 Key 的联合类型。

类型约束

Section titled “类型约束”

通过关键字 extend 进行约束，不同于在 class 后使用 extends 的继承作用，泛型内使用的主要作用是对泛型加以约束

类型约束通常和类型索引一起使用，例如我们有一个方法专门用来获取对象的值，但是这个对象并不确定，我们就可以使用 extends 和 keyof 进行约束。

条件类型的语法规则和三元表达式一致，经常用于一些类型不确定的情况。

上面的意思就是，如果 T 是 U 的子集，就是类型 X，否则为类型 Y

三、总结

Section titled “三、总结”

可以看到，如果只是掌握了 typeScript 的一些基础类型，可能很难游刃有余的去使用 typeScript，需要了解一些typescript的高阶用法

面试常考

Section titled “面试常考”

Q1:infer 关键字 3 个实战场景?

Section titled “Q1:infer 关键字 3 个实战场景?”

答:

  1. 解 Promise:type Unwrap&lt;T&gt; = T extends Promise&lt;infer U&gt; ? U : T
  2. 提取函数返回:type Return&lt;T&gt; = T extends (...args: any[]) => infer R ? R : never
  3. 数组首项:type First&lt;T extends any[]&gt; = T extends [infer F, ...any[]] ? F : never 配合 Parameters&lt;T&gt; / Awaited&lt;T&gt; 内置工具类型可覆盖大部分场景。

Q2:模板字面量类型怎么用?

Section titled “Q2:模板字面量类型怎么用?”

答:

  • type Event = `on${Capitalize&lt;string&gt;}` 自动生成事件名
  • CSS 工具类自动生成:type Bg = bg-${Color}
  • 配合递归:路径类型 type Path&lt;T&gt; = keyof T | ...
  • 性能:复杂模板字面量类型编译慢

Q3:satisfies vs as 区别?

Section titled “Q3:satisfies vs as 区别?”

答:

  • as:强制断言;绕过类型检查(可能不安全)
  • satisfies:类型校验;保留字面量推断
  • 实战:satisfies Record<string, string> 校验 config 是 string 字典,又保留具体字面量

Q4:TS 5.x 新特性?

Section titled “Q4:TS 5.x 新特性?”

答:

  • const 类型参数:&lt;const T&gt; 强制窄类型
  • 装饰器稳定(Stage 3):@logged 标准化
  • 资源管理(using):using file = new FileHandle() 自动释放
  • 类型谓词缩小 in:if ('a' in obj) obj.a
  • 性能:增量编译优化,大型项目重编译时间 -50%

📝 小结

Section titled “📝 小结”
  • 高级类型的三大支柱:映射类型({[K in keyof T]: ...})、条件类型(T extends U ? X : Y)、模板字面量类型。
  • 映射类型 + as 子句可以重命名键、过滤键,是 Pick/Omit/Record 的底层。
  • 条件类型配合 infer 可以从复杂类型里提取子类型。
  • as const 让表达式保留字面量类型,是做字面量联合推导的关键。
