说说你对 TypeScript 中类的理解？应用场景？

一、是什么

Section titled “一、是什么”

类（Class）是面向对象程序设计（OOP，Object-Oriented Programming）实现信息封装的基础

类是一种用户定义的引用数据类型，也称类类型

传统的面向对象语言基本都是基于类的，JavaScript 基于原型的方式让开发者多了很多理解成本

在 ES6 之后，JavaScript 拥有了 class 关键字，虽然本质依然是构造函数，但是使用起来已经方便了许多

但是 JavaScript 的class依然有一些特性还没有加入，比如修饰符和抽象类

TypeScript 的 class 支持面向对象的所有特性，比如 类、接口等

二、使用方式

Section titled “二、使用方式”

定义类的关键字为 class，后面紧跟类名，类可以包含以下几个模块（类的数据成员）：

  • 字段 ： 字段是类里面声明的变量。字段表示对象的有关数据。
  • 构造函数： 类实例化时调用，可以为类的对象分配内存。
  • 方法： 方法为对象要执行的操作

面试常考

Section titled “面试常考”

Q1:class 修饰符 4 种?

Section titled “Q1:class 修饰符 4 种?”

答:

  • public:默认,外部可访问
  • private:# 私有字段(ES2022 真正私有);private 仅 TS 编译时(运行时仍可访问)
  • protected:子类可访问
  • readonly:只读(声明时或构造函数内赋值)

Q2:abstract class vs interface 区别?

Section titled “Q2:abstract class vs interface 区别?”

答:

  • abstract class:可包含实现 + 抽象方法;单继承;运行时存在
  • interface:纯类型;多实现;编译时擦除
  • 用 abstract:需要共享代码;用 interface:仅约束形状

Q3:getter / setter 有什么用?

Section titled “Q3:getter / setter 有什么用?”

答:

  • 访问器,像属性一样访问但实际是函数
  • 用法:get fullName() { return this.first + this.last }
  • 用途:计算属性、校验、副作用
  • TS 中可声明 get name(): string

Q4:静态成员 vs 实例成员?

Section titled “Q4:静态成员 vs 实例成员?”

答:

  • static 静态成员:类本身持有,实例共享;class Foo { static count = 0 }
  • 实例成员:每个实例独立
  • 单例模式:用 static + private constructor
  • static abstract (TS 4.4+):父类声明静态抽象方法

📝 小结

Section titled “📝 小结”
  • TS 的 class = JS 的 class + 属性/方法/构造器的类型标注。
  • 参数属性(constructor(private x: number))一行完成声明和赋值。
  • private/protected/public 只是编译期约束,运行时都是普通属性 —— 「private 字段」不等于「真的私有」,要真私有用 # 或 WeakMap。
  • implements 让类必须满足接口;abstract 声明抽象成员,子类必须实现。
