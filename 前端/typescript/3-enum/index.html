面试常考

Section titled “面试常考”

Q1:数字 enum vs 字符串 enum 区别?

Section titled “Q1:数字 enum vs 字符串 enum 区别?”

答:

  • 数字 enum:默认从 0 自增;可双向映射(Color[0] === 'Red')
  • 字符串 enum:必须显式赋值,无反向映射;更安全
  • 异构 enum(数字+字符串):不推荐(TS 官方警告)
  • 编译产物:数字 enum 编译为对象;字符串 enum 仅对象字面量

Q2:为什么很多人不推荐 enum?

Section titled “Q2:为什么很多人不推荐 enum?”

答:

  • 编译产物大(双向映射对象)
  • tree-shaking 难(对象引用)
  • 替代方案:as const 对象 + 联合类型
  • 例:const Status = { Active: 'active', Inactive: 'inactive' } as const; type Status = typeof Status[keyof typeof Status]

Q3:const enum 是什么?

Section titled “Q3:const enum 是什么?”

答:

  • 编译时内联,无运行时对象
  • 体积小,但破坏 tree-shaking
  • isolatedModules 模式下不支持(Vite/esbuild 报错)
  • 现代项目推荐 as const 而非 const enum

Q4:enum 反向映射怎么用?

Section titled “Q4:enum 反向映射怎么用?”

答:

  • 仅数字 enum 有:enum Color { Red = 1 } → Color[1] === 'Red'
  • 用途:从值反查名字(枚举化日志、协议类型)
  • 字符串 enum 无反向映射(Color['Red'] = ‘Red’,反之 undefined)

📝 小结

Section titled “📝 小结”
  • enum 是「一组相关常量的集合」,比裸常量多了类型约束和互操作性。
  • 数字枚举有反向映射(值→名),字符串枚举没有;字符串枚举在序列化场景更安全。
  • 计算成员不能有反向映射,混合枚举会失去部分类型推断能力。
  • const enum 编译期内联,减少运行时体积,但不能与 isolatedModules 一起用。
