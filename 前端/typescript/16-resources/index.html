TypeScript 学习资源

一、官方文档(必读)

Section titled “一、官方文档(必读)”
  • TypeScript 官方文档(英文)——最权威,新特性最先在这里发
  • TypeScript 中文文档——社区翻译,基本同步

官方文档从入门到高级类型全覆盖,每个章节都有可运行的 playground 例子——遇到不确定的类型行为直接打开 TypeScript Playground 试一下。

二、推荐书

Section titled “二、推荐书”
  • 《TypeScript 编程》(Programming TypeScript)——O’Reilly 出品,入门 + 进阶,内容扎实
  • 《Effective TypeScript》——62 个具体实践,适合已经会 TS 想“用好”的人

三、练习平台

Section titled “三、练习平台”

3.1 type-challenges(强烈推荐)

Section titled “3.1 type-challenges(强烈推荐)”

github.com/type-challenges/type-challenges

从简单到地狱级别的类型体操题集。面试遇到 “Pick 实现”、“DeepReadonly” 时这就是复习利器。前端面试 TS 高频题基本都来自这里。

推荐刷到中等难度(medium)就足够应付面试。

3.2 TypeScript Exercises

Section titled “3.2 TypeScript Exercises”

typescript-exercises.github.io

偏基础,把 JS 重写成 TS 的练习。

四、优质博客/视频

Section titled “四、优质博客/视频”
  • TypeScript Deep Dive(中文:jkchao.gitbook.io/typescript-book)——开源免费电子书,中文版质量很好
  • Matt Pocock(Twitter/@mattpocockUk)——TS 团队外最大的 KOL,博客和视频质量极高
  • Titian Cernicova-Dragomir(TS 团队核心成员)——博客 关于类型设计的文章

五、Playground 与工具

Section titled “五、Playground 与工具”
  • TypeScript Playground——浏览器内运行 TS,支持多版本切换
  • ts-repl——Replit 的在线 TS REPL
  • VS Code 内置 TS Server,不需要任何插件就能获得最好的 TS 体验

六、社区

Section titled “六、社区”
  • TypeScript GitHub: github.com/microsoft/TypeScript——发 issue、提 PR、读 RFC
  • Stack Overflow typescript tag——90% 的常见问题这里都有答案

面试常考

Section titled “面试常考”

Q1:TS 学习路径推荐?

Section titled “Q1:TS 学习路径推荐?”

答:

  1. 基础类型 / 接口 / 联合类型
  2. 泛型 / 工具类型
  3. 条件类型 / infer / 模板字面量
  4. 实战:React / Vue 组件类型
  5. 类型编程:zod / io-ts / type-challenges
  • 周期:2-3 个月系统学习(边做项目边查类型)

Q2:type-challenges 怎么刷?

Section titled “Q2:type-challenges 怎么刷?”

答:

  • GitHub 仓库:几万道类型挑战题
  • 分难度:Easy / Medium / Hard / Extreme
  • 实战:Hard 级别 50% 都能独立解决 = 高级 TS 工程师
  • 重点关注:Pick / Omit / DeepReadonly / Promise.all 推断

Q3:TS 工程师级别划分?

Section titled “Q3:TS 工程师级别划分?”

答:

  • 初级:基础类型 / interface / 泛型使用
  • 中级:Partial / Pick / Omit / 联合类型
  • 高级:条件类型 / infer / 模板字面量 / 类型守卫
  • 资深:类型编程(zod / type-challenges 难题);库作者级别
  • 区分:看是否理解类型即函数

Q4:推荐学习资源?

Section titled “Q4:推荐学习资源?”

答:

  • 官方手册:typescriptlang.org 必读 Handbook
  • Type Challenges:github.com/type-challenges/type-challenges
  • type-level-typescript:type-level-typescript.org(交互式)
  • Matt Pocock:totaltypescript.com(实战向,付费)
  • 书籍:Programming TypeScript(O’Reilly)

📝 小结

Section titled “📝 小结”
  • 官方文档(handbook)是权威,尤其「类型体操」章节。
  • TypeScript Deep Dive 是进阶的最优选择。
  • type-challenges 是练手题库,按难度分级,建议从 easy 开始刷。
  • 社区:TypeScript 官方 Wiki、@types 包索引。
