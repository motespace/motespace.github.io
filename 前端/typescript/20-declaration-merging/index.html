🎯 面试常考

Section titled “🎯 面试常考”

Q1: 什么是声明合并? TS 允许多处在同一作用域声明同名类型,编译器把它们合并成一个。四种场景:接口合并、命名空间合并、函数+命名空间、类+接口。类型别名不能合并。

Q2: 声明合并最常见的用途? 给第三方库的类型打补丁 —— 用 declare module 'xxx' 往已有模块追加接口成员,不用重新声明整个模块。典型场景是给 Express 的 Request 加 user 字段。

Q3: declare module 和 declare global 的区别? declare module 'x' 是模块增强,替换并合并指定模块的类型;declare global 往全局作用域添加声明,用于扩展内置类型(Array、Window)。declare global 所在文件必须是模块(有顶层 import/export)。

Q4: 怎么从联合类型提取公共部分? 用 infer 在条件类型里提取,再用 | 组合;或者用 UnionToIntersection 把联合转成交叉。

Q5: 路径别名只在 tsconfig 里配够吗? 不够。paths 只影响编译期的类型检查,运行时打包器也要认识,需要同时配 Vite 的 resolve.alias 或用 vite-tsconfig-paths 插件。

📝 小结

Section titled “📝 小结”
  • 四种合并场景:接口、命名空间、函数+命名空间、类+接口;类型别名不能合并。
  • 模块增强是给第三方库打补丁的标准手段,注意是「替换+合并」而非纯追加。
  • declare global 要写在模块文件里(加 export {})。
  • 路径别名要同时配 tsconfig 的 paths 和 Vite 的 alias。
