Q1: Vue 3 推荐什么写法？

Section titled “Q1: Vue 3 推荐什么写法？”

答：&lt;script setup&gt; + defineProps&lt;T&gt;() + defineEmits&lt;T&gt;() + defineModel（Vue 3.4+）+ useTemplateRef（Vue 3.5+）。不用 vue-property-decorator（那是 Vue 2 class 写法）。

Q2: defineModel 是什么？

Section titled “Q2: defineModel 是什么？”

答：Vue 3.4+ 简化 v-model 写法。defineModel&lt;T&gt;() 自动处理 props.modelValue + emit('update:modelValue')。

Q3: ref vs reactive 怎么选？

Section titled “Q3: ref vs reactive 怎么选？”

答：优先 ref（一致 + TS 推导好）。reactive 用于复杂 state（多字段强关联）。

Q4: Vue 3.5 新特性？

Section titled “Q4: Vue 3.5 新特性？”

答：

  • useTemplateRef：模板 ref 类型安全
  • defineProps 支持解构
  • 响应式系统重构（更快）
  • 自定义元素改进

Q6: defineEmits 怎么写？

Section titled “Q6: defineEmits 怎么写？”

答：类型签名写法 defineEmits<{ name: [args] }>()，或新写法 defineEmits<{ submit: [formData: FormData] }>()。

Q7: Vue 3 服务端组件？

Section titled “Q7: Vue 3 服务端组件？”

答：Nuxt 3 默认 Server Component。&lt;script setup&gt; 加 async + await useFetch，SSR 自动处理。

面试追问(深化原 Q1-Q7)

Section titled “面试追问(深化原 Q1-Q7)”
  • useTemplateRef vs 普通 ref? useTemplateRef('myEl') 给模板 ref 加类型;ref&lt;HTMLElement | null&gt;(null)
  • defineProps 解构 (3.5)? const { name = ''default'' } = defineProps&lt;Props&gt;();解构后保持响应性
  • 响应式系统重构影响? 3.5 性能提升 2x;内存占用减少;API 不变(用户无感)
  • 自定义元素改进? 更好地和 web components 集成;CSS scope 改进
  • Vue 3.5+ 服务端组件类型? defineAsyncComponent + Promise 类型推导

📝 小结

Section titled “📝 小结”
  • Vue 3 + TS 推荐 &lt;script setup lang="ts"&gt;,配合 defineProps/defineEmits 宏。
  • defineProps 的类型可以用类型声明(defineProps&lt;Props&gt;())或运行时声明(withDefaults),前者更简洁但不能有默认值。
  • ref 适合基本类型和要整体替换的对象,reactive 适合复杂对象的字段级修改,解构 reactive 会丢失响应式。
  • defineModel(3.4+)让组件支持双向绑定,useTemplateRef(3.5+)替代 ref="xxx" 的字符串写法。
