TypeScript Utility Types(工具类型)

一、是什么

Section titled “一、是什么”

工具类型是 TS 内置的、基于已有类型构造新类型的类型操作符。它们本质上是泛型 + 映射类型 + 条件类型的封装——理解了前面的章节,工具类型就是“语法糖”。

业务代码里几乎所有重复的类型定义都可以用工具类型组合出来,避免到处 Pick / Omit 手抄。

📝 小结

Section titled “📝 小结”
  • 工具类型是内置的泛型类型,覆盖 90% 的类型操作场景。
  • 读多写少用 Partial/Readonly/Pick/Omit,状态管理用 Required/Record/NonNullable。
  • ReturnType/Parameters/Awaited 能从已有函数反推类型,配合 typeof fn 写类型安全的包装器。
  • satisfies 用来「校验但不拓宽」,是 TS 4.9 之后最值得学的新特性。

面试常考

Section titled “面试常考”

Q1:常用工具类型分组?

Section titled “Q1:常用工具类型分组?”

答:

  • 对象结构:Partial<T> / Required<T> / Readonly<T> / Pick<T, K> / Omit<T, K>
  • 联合操作:Exclude<T, U> / Extract<T, U> / NonNullable<T>
  • 函数:Parameters<T> / ReturnType<T> / Awaited<T>
  • 字符串:Uppercase<T> / Lowercase<T> / Capitalize<T> / Uncapitalize<T>
  • 实战中 80% 用 Partial / Omit / Pick / ReturnType

Q2:Omit<T, K> vs Pick<T, K> 反着用?

Section titled “Q2:Omit<T, K> vs Pick<T, K> 反着用?”

答:

  • Pick<T, K>:挑出 K 字段;Pick<User, 'id' | 'name'> = {id, name}
  • Omit<T, K>:排除 K 字段;Omit<User, 'password'> = User 去掉 password
  • 等价:Omit<T, K> = Pick<T, Exclude<keyof T, K>>
  • 实战:Omit 选所有字段 - 敏感字段(密码、token)

Q3:自定义工具类型例子?

Section titled “Q3:自定义工具类型例子?”

答:

  • 深 Partial:type DeepPartial<T> = { [K in keyof T]?: T[K] extends object ? DeepPartial<T[K]> : T[K] }
  • 函数参数提取:type FirstArg<T> = T extends (arg: infer A, ...rest: any[]) => any ? A : never
  • API 响应包装:type ApiResponse<T> = { code: number; data: T; message: string }
  • 用模板字面量生成事件名:type EventName<T> = on${Capitalize<T>}Change``

Q4:工具类型和泛型关系?

Section titled “Q4:工具类型和泛型关系?”

答:

  • 工具类型本质就是泛型
  • 泛型是机制,工具类型是常用模式
  • 实战:别为 1 次使用造工具类型;复用 ≥ 2 次再抽
