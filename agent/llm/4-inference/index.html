推理参数调优

同一个 prompt,不同参数 = 完全不同效果。理解 temperature / top_p / max_tokens, 才能精准控制 LLM 输出。

一、核心参数速查

Section titled “一、核心参数速查”
参数 控制什么 典型值
temperature 随机性(创造性) 0.0 - 1.0
top_p 多样性(累积概率) 0.0 - 1.0
max_tokens 最大输出长度 1 - 模型上限
stop 停止生成符 ["\n\n", "###"]
presence_penalty 话题多样性 -2.0 - 2.0
frequency_penalty 词汇重复惩罚 -2.0 - 2.0
n 生成几个候选 1 - 5
seed 随机种子(可重现) 任意整数

场景推荐

Section titled “场景推荐”

翻译 0.0 - 0.3
摘要 0.0 - 0.3
创意写作 0.7 - 1.2

🎯 面试常考

Section titled “🎯 面试常考”

Q1：temperature 是什么?

控制输出随机性。0 最确定(几乎每次一样,适合抽取、代码),0.7 左右平衡,1 以上更发散(适合创意)。

Q2：top_p 和 temperature 有什么区别?

top_p 是「核采样」,只看累计概率前 P 的候选;temperature 是缩放 logits 的整体分布。建议只调一个,不要同时调。

Q3：max_tokens 设多少合适?

按任务预估输出长度并留余量;设太小会被截断,设太大会增加成本(输出按实际生成计费,但预算是上限)。

📝 小结

Section titled “📝 小结”
  • temperature 控制随机性:低=稳定可复现(抽取、分类、代码);高=多样有创意(文案、头脑风暴);0 基本确定性。
  • top_p 是核采样:只从累计概率前 p 的 token 里选;p 与 temperature 不要同时调,一般固定一个。
  • max_tokens 限制输出长度(同时是成本闸门);stop 提前终止;seed 配合 temperature=0 可提升可复现性。
  • presence_penalty / frequency_penalty 分别抑制「重复出现」与「高频词重复」,做文案去重有用。
  • 流式(streaming)只影响首字延迟与感知,不影响总 token 与总成本。
  • 面试话术:能讲清「temperature 影响的是分布采样而不是模型能力」,以及「为什么一般只调 temperature 或 top_p 其中一个」。
