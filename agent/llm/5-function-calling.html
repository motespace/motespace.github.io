Function Calling / Tool Use ​

Agent 的基石。让 LLM 不只聊天,还能调用工具(查天气、下订单、查数据库)。 本章系统讲解 Function Calling 协议 + 实战代码。

一、Function Calling 是什么? ​

普通 LLM:只能生成文本
       ↓
Function Calling:LLM 可以决定"调用哪个函数 + 传什么参数"
       ↓
  你的代码执行函数,把结果返回给 LLM
       ↓
LLM 基于结果生成最终回复

类比:LLM 像一个聪明的助手,Function Calling 让他能"打电话给外部专家"(函数)。

二、Function Calling 基本流程 ​

┌────────────────────────────────────────────────────┐
│ 1. 定义工具列表(tool description)                  │
│    "get_weather(location): 查询天气"                │
└────────────────────────────────────────────────────┘
                    ↓
┌────────────────────────────────────────────────────┐
│ 2. 把工具列表 + 用户消息传给 LLM                    │
│    LLM 决定:"需要调用 get_weather('北京')"           │
└────────────────────────────────────────────────────┘
                    ↓
┌────────────────────────────────────────────────────┐
│ 3. 你的代码执行函数,得到结果 {"temp": 25, ...}       │
└────────────────────────────────────────────────────┘
                    ↓
┌────────────────────────────────────────────────────┐
│ 4. 把结果再传回 LLM,LLM 生成自然语言回复            │
│    "北京今天 25 度,晴天,适合出门"                    │
└────────────────────────────────────────────────────┘

3. 执行工具 ​

import json

# 实际的工具实现
def get_weather(location: str, unit: str = "celsius") -> dict:
    """模拟天气 API"""
    return {"temp": 25, "condition": "晴", "location": location, "unit": unit}

def search_web(query: str) -> dict:
    """模拟搜索 API"""
    return {"results": [f"{query} 的搜索结果 1", f"{query} 的搜索结果 2"]}

# 执行所有工具调用
for tool_call in response_message.tool_calls:
    function_name = tool_call.function.name
    function_args = json.loads(tool_call.function.arguments)

    # 调用对应函数
    if function_name == "get_weather":
        function_response = get_weather(**function_args)
    elif function_name == "search_web":
        function_response = search_web(**function_args)

    # 把工具结果加入消息历史
    messages.append({
        "role": "tool",
        "tool_call_id": tool_call.id,
        "name": function_name,
        "content": json.dumps(function_response, ensure_ascii=False),
    })

四、完整代码模板 ​

python
import json
from openai import OpenAI

client = OpenAI()

# ===== 1. 定义工具 =====
TOOLS = [
    {
        "type": "function",
        "function": {
            "name": "search_docs",
            "description": "在技术文档库中搜索相关内容",
            "parameters": {
                "type": "object",
                "properties": {
                    "query": {"type": "string", "description": "搜索关键词"},
                    "max_results": {"type": "integer", "default": 3},
                },
                "required": ["query"],
            },
        },
    },
]

# ===== 2. 实现工具函数 =====
def search_docs(query: str, max_results: int = 3) -> list[dict]:
    """实际的搜索实现"""
    # ... 调用搜索 API / 数据库 / 向量检索 ...
    return [{"title": f"Doc about {query}", "content": "..."}]

# ===== 3. Agent 循环 =====
def run_agent(user_message: str, max_iterations: int = 5) -> str:
    """运行 Agent(支持多轮工具调用)"""
    messages = [{"role": "user", "content": user_message}]

    for _ in range(max_iterations):
        response = client.chat.completions.create(
            model="gpt-4",
            messages=messages,
            tools=TOOLS,
        )

        message = response.choices[0].message
        messages.append(message)

        # 如果 LLM 不再调用工具,结束
        if not message.tool_calls:
            return message.content

        # 执行工具调用
        for tool_call in message.tool_calls:
            function_name = tool_call.function.name
            function_args = json.loads(tool_call.function.arguments)

            try:
                function_response = search_docs(**function_args)
            except Exception as e:
                function_response = {"error": str(e)}

            messages.append({
                "role": "tool",
                "tool_call_id": tool_call.id,
                "name": function_name,
                "content": json.dumps(function_response, ensure_ascii=False),
            })

    return "Agent 达到最大迭代次数"

# ===== 4. 使用 =====
result = run_agent("怎么用 LangChain 实现 RAG?")
print(result)

五、并行工具调用 ​

LLM 可以一次调用多个工具(并行):

python
# 用户:"北京和上海今天天气怎么样?"
# LLM 可能输出:
# tool_calls=[
#   {name: get_weather, args: {location: "北京"}},
#   {name: get_weather, args: {location: "上海"}},
# ]

# 你需要并行执行
import asyncio

async def get_weather_async(location: str) -> dict:
    # 异步调用 API
    await asyncio.sleep(0.1)
    return {"temp": 25, "location": location}

async def execute_tools_parallel(tool_calls):
    tasks = []
    for tc in tool_calls:
        func_name = tc.function.name
        func_args = json.loads(tc.function.arguments)
        if func_name == "get_weather":
            tasks.append(get_weather_async(**func_args))

    return await asyncio.gather(*tasks)

七、LangChain 统一抽象 ​

python
from langchain_openai import ChatOpenAI
from langchain_core.tools import tool
from langchain.agents import create_tool_calling_agent, AgentExecutor

# 1. 用装饰器定义工具(自动从函数签名生成 schema)
@tool
def search_docs(query: str, max_results: int = 3) -> str:
    """在技术文档库中搜索相关内容"""
    # 实际搜索逻辑
    return f"找到 {max_results} 条关于 '{query}' 的结果"

@tool
def calculate(expression: str) -> str:
    """计算数学表达式"""
    return str(eval(expression))

# 2. 创建 Agent
llm = ChatOpenAI(model="gpt-4")
tools = [search_docs, calculate]

# LangChain 提供的预制 Agent(ReAct 风格)
from langchain import hub
prompt = hub.pull("hwchase17/openai-functions-agent")
agent = create_tool_calling_agent(llm, tools, prompt)
agent_executor = AgentExecutor(agent=agent, tools=tools, verbose=True)

# 3. 使用
result = agent_executor.invoke({"input": "LangChain 怎么用?"})
print(result["output"])

九、复杂场景:结构化输出 + 工具调用 ​

python
from pydantic import BaseModel
from openai import OpenAI

class ToolCallDecision(BaseModel):
    """LLM 决策的结构化输出"""
    reasoning: str
    next_action: str  # "call_tool" 或 "respond_to_user"
    tool_name: str | None = None
    tool_args: dict | None = None

client = OpenAI()

# 让 LLM 必须返回这种结构
response = client.beta.chat.completions.parse(
    model="gpt-4o",
    messages=[
        {"role": "system", "content": "你是 Agent,先决定下一步行动"},
        {"role": "user", "content": "查 LangChain 教程"},
    ],
    response_format=ToolCallDecision,
)

decision = response.choices[0].message.parsed
print(f"推理: {decision.reasoning}")
print(f"行动: {decision.next_action}")
if decision.tool_name:
    print(f"工具: {decision.tool_name}({decision.tool_args})")

🎯 面试常考 ​

Q1：Function Calling 是什么?

模型不直接返回文本,而是返回「我要调用哪个函数、传什么参数」的结构化意图,由你的代码真正执行,再把结果回传给模型继续。

Q2：模型调用工具的完整流程?

① 开发者把工具 schema 连同问题一起发给模型;② 模型返回 tool_calls;③ 你本地执行函数;④ 把结果作为 tool 消息回传;⑤ 模型基于结果生成最终回答。

Q3：怎么提高工具调用的准确率?

工具描述写清楚「什么时候该用、参数含义」;schema 参数少而明确(枚举优于自由文本);提供 few-shot 示例;必要时做参数校验和重试纠正。
