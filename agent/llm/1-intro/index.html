LLM 是什么 + Transformer 极简原理

30 分钟理解大语言模型。不用公式,一张图搞懂核心。

一、LLM 是什么?

Section titled “一、LLM 是什么?”

LLM(Large Language Model)大语言模型 = 用海量文本训练出来的、能理解和生成自然语言的 AI。

二、能力边界

Section titled “二、能力边界”
能做 不能做
文本理解、生成、翻译、总结 实时信息(训练数据截止后的)
代码编写、调试、解释 数学推理(容易算错)
多轮对话、上下文理解 精确事实(可能“幻觉”)
角色扮演、风格模仿 真正“理解”(只是统计模式)

三、Transformer 极简原理(一张图)

Section titled “三、Transformer 极简原理(一张图)”

核心创新:

  • Self-Attention:让模型看到“我”时,能同时关注“爱”和“学习”,理解上下文
  • 并行计算:不像 RNN 那样必须按顺序处理,训练快 10 倍以上
  • 可堆叠:堆 N 层就能理解更复杂的模式

四、从 GPT 到 ChatGPT

Section titled “四、从 GPT 到 ChatGPT”

GPT-1/2/3/4 演进

Section titled “GPT-1/2/3/4 演进”

InstructGPT / ChatGPT:从“续写”到“对话”

Section titled “InstructGPT / ChatGPT:从“续写”到“对话””

RLHF(Reinforcement Learning from Human Feedback):

  1. 人工标注员写好答案(监督学习)
  2. 人工对模型多个回答排序(奖励模型)
  3. 用奖励模型训练 LLM(强化学习)

五、训练 vs 推理

Section titled “五、训练 vs 推理”
阶段 做什么 算力需求
预训练 用海量文本(数千亿 token)训练基础能力 数千张 A100,数月,数百万美元
微调(Fine-tuning) 用特定领域数据优化 几十张 A100,数小时
RLHF 对齐人类意图 类似微调
推理(Inference) 用户使用时生成回答 单次请求,毫秒到秒级

六、Token:LLM 的“原子单位”

Section titled “六、Token:LLM 的“原子单位””

LLM 不直接处理字符,而是处理 token(词片段)。

为什么重要:

  • API 按 token 计费
  • 上下文窗口限制(8K / 32K / 128K / 200K)
  • 一次请求 = prompt tokens + completion tokens

七、Context Window(上下文窗口)

Section titled “七、Context Window(上下文窗口)”

主流模型的 context window:

模型 窗口
GPT-3.5-turbo 16K
GPT-4 8K / 32K
GPT-4 Turbo 128K
Claude 3.5 Sonnet 200K
Gemini 1.5 Pro 1M(实验)

八、参数(Parameter)与涌现能力

Section titled “八、参数(Parameter)与涌现能力”

涌现能力(Emergent Ability):

  • 模型小时完全没有,大了突然出现的“突变”能力
  • 例如:小模型不会做数学题,大模型突然会了
  • 但这也有争议(可能是评测指标设计问题)

🎯 面试常考

Section titled “🎯 面试常考”

Q1：Transformer 的核心是什么?

Self-Attention:让每个 token 能直接关注序列里其他所有 token,通过 Q/K/V 计算相关性权重,再加权求和。这是并行化和长距离依赖的基础。

Q2：训练和推理有什么区别?

训练是学习参数(前向 + 反向传播),推理是固定参数下生成输出。推理阶段只做前向,靠 KV Cache 复用已算过的注意力结果。

Q3：闭源和开源模型怎么选?

闭源 API 效果强、免运维、按量付费;开源可本地部署、数据不出域、可微调,但显存成本高、效果通常略逊。

📝 小结

Section titled “📝 小结”
  • LLM 是在大规模语料上训练出来的、预测下一个 token 的概率模型,不是检索系统也不是知识库。
  • 能力边界要诚实:擅长语言相关的生成、改写、总结、分类、翻译、代码生成;不擅长精确计数、事实检索、空间推理、需要最新数据的问题。
  • Transformer 极简原理:注意力机制让每个 token 能看到上下文里的其他 token(解决 RNN 的长程依赖),再叠加多头注意力、前馈层、残差连接与 LayerNorm;decoder-only 架构决定了它是「续写模型」。
  • 原始 GPT 是纯续写;InstructGPT / ChatGPT 用 RLHF 做对齐,才变成「听懂指令并按格式回答」的助手。
  • 训练(预训练 + 后训练/对齐)与推理是两回事:权重不变,只改变输入与采样参数。
  • Token 是模型看到的最小单位,同一个词在不同 tokenizer 下 token 数不同,所以计费与上下文都按 token 算。
  • 面试话术:一句话「LLM 是条件概率模型,输出是采样出来的,不是查出来的」——这句话能挡住大部分幻觉误解。
