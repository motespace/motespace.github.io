📝 小结

Section titled “📝 小结”
  • 练习设计成「写得出 + 说得清」:算 token、算成本、设计限流策略、对比模型选型,都是能落地的工程题。
  • 做完后一定口述一遍原理,能讲清才算过——这是这套练习与普通 tutorial 的区别。
  • 踩坑指南部分比题目更重要:token 估算偏差、上下文超限、限流未退避、参数超 temperature 与 top_p 同时乱调。
  • 建议把成本计算题的结果记成一个表格,面试时直接引用「我算过单会话成本」。
  • 与 前端/ai-integration/ 对照:前端视角的流式、工具调用、RAG 在那边有完整实现。
