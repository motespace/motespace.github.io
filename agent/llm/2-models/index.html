🎯 面试常考

Section titled “🎯 面试常考”

Q1：怎么选模型?

按场景四维权衡:能力(推理/代码)、成本(输入输出单价 × token 量)、上下文长度、速度(TTFT 与 TPS)。先用便宜的跑通,再按需要升级。

Q2：不同模型的价格差在哪?

主要差在输入/输出单价和上下文长度上限。输出通常比输入贵 3-4 倍,所以要控制输出长度。

Q3：小模型什么时候够用?

分类、抽取、改写、简单问答这类任务,小模型 + 精调 Prompt 完全够用,而且成本能低一个量级。

📝 小结

Section titled “📝 小结”
  • 选型先看三件事:能力档位(推理/代码/长上下文)、成本(输入输出 token 单价)、部署形态(API vs 本地)。
  • 闭源旗舰:GPT / Claude / Gemini,能力最强、按量计费、数据出网(合规风险)。
  • 开源模型:Llama / Qwen / DeepSeek / Mistral,权重可下载,可私有化部署、可微调、数据不出网,代价是显存与推理运维成本。
  • 本地部署工具链:Ollama(最快上手)、vLLM(高并发生产)、llama.cpp(量化轻量)、HuggingFace Transformers(最灵活)。
  • 决策原则:能用小模型就不用大模型(成本与延迟差一个量级),先用 API 验证需求再考虑私有化。
  • 面试加分:能讲清「私有化部署的真实成本不只是显卡」——还要算运维、推理服务、监控与升级成本。
