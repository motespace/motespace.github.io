🎯 面试常考

Section titled “🎯 面试常考”

Q1：完整的 Agent 图怎么搭?

至少三节点:agent(调模型)→ tools(执行工具)→ 条件边(有 tool_calls 回到 agent,否则 END),再加 checkpointer 支持恢复。

Q2：怎么防止 Agent 死循环?

限制最大轮数;工具调用连续 N 次无进展就终止;给每个节点设置超时;在提示词里明确终止条件。

Q3：怎么调试 Agent?

用 app.stream(state, stream_mode="values") 把每一步的 State 打出来,能看到模型到底把状态改成了什么;配合 LangSmith 看完整 trace。

📝 小结

Section titled “📝 小结”
  • ReAct 图的标准四节点:agent(决定调不调工具)→ tools(执行工具)→ 条件边路由 → 回到 agent 或 END。
  • 关键实现:用 llm.bind_tools(tools) 让模型输出 tool_calls;tools 节点用 ToolNode 执行并返回 ToolMessage。
  • 终止条件:模型不再返回 tool_calls 就走 END;再加 recursion_limit 与状态里的步数计数做双保险。
  • 多 Agent 图同理:每个 Agent 是一个节点,用一个「路由节点」决定下一个 Agent;State 里用 add_messages 累积对话。
  • 实战清单:定义 State(带 messages)→ 绑工具的 LLM → ToolNode → 条件边 → 编译 → 加 checkpoint 支持多轮。
  • 面试加分:讲清「ToolNode 是 LangGraph 内置的,自己写就容易漏掉把 ToolMessage 正确回填这一步」。
