🎯 面试常考

Section titled “🎯 面试常考”

Q1：节点怎么写?

一个普通函数,签名 (state) -> dict,返回要更新的字段。不需要返回完整 State。

Q2：怎么写条件边?

add_conditional_edges(node, routing_fn, mapping):routing_fn 读 State 返回一个 key,mapping 把 key 映射到目标节点或 END。

Q3：怎么让图停下来问人?

编译时传 interrupt_before=[‘节点名’],图会在这之前挂起,把 State 存进 checkpointer;人工处理后再用 Command(resume=...) 恢复。

📝 小结

Section titled “📝 小结”
  • Node 是普通函数(可同步/异步),签名 (state, config) -> 部分 State;config 里能拿到 thread_id、回调、运行时配置。
  • Edge 三种:普通边(固定流转)、条件边(函数返回下一个节点名)、入口/出口边(set_entry_point / add_edge(END))。
  • 条件边是实现「if-else 决策」的方式,通常配合一个路由函数把状态映射到节点名。
  • 循环控制:靠条件边指回之前的节点形成环,必须加最大迭代次数(用状态里的 count),否则死循环烧 token。
  • 错误处理:节点内 try/except 决定是「抛出去」还是「写入 error 字段走降级分支」;并行节点用 add_edge([a,b], c) 做 fan-out/fan-in。
  • 面试加分:能画出「决策节点 → 工具节点 → 回环到决策节点」的 ReAct 图,并说明如何终止循环。
