🎯 面试常考

Section titled “🎯 面试常考”

Q1：LCEL 怎么组合多个步骤?

用 | 管道:prompt | model | parser。链本身也是 Runnable,所以可以嵌套:把一条子链当成另一个链的一环。

Q2：并行执行怎么做?

chain_a | chain_b 是串行;并行要用 RunnableParallel(prompt=..., model=...) 或者让多个分支各自输出再合并,适合互不依赖的调用。

Q3：链里怎么加重试?

用 with_retry(stop_after_attempt=3, wait_exponential_jitter=True) 包住任一 Runnable,或用 with_fallbacks([备用链]) 做降级。

📝 小结

Section titled “📝 小结”
  • LCEL 三件套:prompt | llm | parser,每个组件都是 Runnable,| 定义数据流向。
  • 统一接口:invoke(同步)、ainvoke(异步)、stream(流式)、batch(批量)、pipe(把 Runnable 当函数用)。
  • 并行:prompt1 | (prompt2 | llm2) | parser 这类分支 + 汇合写法,多个任务并行执行再合并,能显著降低总延迟。
  • 传参:RunnablePassthrough 透传输入,RunnableLambda 插入自定义处理函数,RunnableParallel 同时传多个 key。
  • 高级:批处理(batch)、流式(stream + parser 逐块解析)、重试与降级(with_retry / with_fallbacks)。
  • 面试加分:能画出「串行 → 并行 → 降级」三种链路的取舍,说明你在意延迟与可用性。
