🎯 面试常考

Section titled “🎯 面试常考”

Q1：10 行代码能写出 Agent 吗?

能。核心只有两步:把工具 schema 给模型、把模型返回的 tool_calls 执行掉再回传。真实 Agent 就是这个循环,只是加了判断何时停止。

Q2：从 LLM 到 Agent 差了什么?

差一个「工具循环」:模型不只输出文本,还能输出「我要调用哪个函数、传什么参数」,由你的代码执行并把结果回传。

📝 小结

Section titled “📝 小结”
  • 三级递进:裸调 LLM(10 行)→ 加 Prompt 模板(prompt | llm | output_parser)→ 加工具变成 Agent。
  • 裸调只验证「模型能通」;加模板才体现结构化与可复用;加工具才是 Agent 的最小形态。
  • LCEL 的 | 是把 Runnable 串成链,每一步输入输出类型对齐,链本身也是一个 Runnable。
  • 输出解析器(StrOutputParser、JsonOutputParser、PydanticOutputParser)让链的结果直接是程序可用的数据,这是工程化的关键一步。
  • 上手路径:先跑通裸调用 → 再加模板 → 再加工具,每步都能单独验证,不要一次写完。
  • 面试加分:能说清「LangChain 的价值是把「调模型」变成「编排组件」,核心抽象是 Runnable 与 LCEL」。
