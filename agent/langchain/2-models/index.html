🎯 面试常考

Section titled “🎯 面试常考”

Q1：LLM 和 ChatModel 有什么区别?

ChatModel 接口是 messages 数组(有 role),LLM 接口是纯字符串。实际用 ChatModel,底层多数模型都是 chat 接口。

Q2：怎么在多个模型之间路由?

最简单是按任务写死逻辑;进阶用 RunnableBranch 按输入特征分支;再进阶可以接一个分类器先判断问题类型再选模型。

Q3：统一接口带来什么问题?

各厂商参数名和能力不一致(有的支持 tools、有的不支持),要用 bind_tools 做能力对齐,不能假设所有模型能力相同。

📝 小结

Section titled “📝 小结”
  • LLM vs ChatModel:LLM 收字符串出字符串(老接口);ChatModel 收消息列表出消息(推荐,支持多轮、Function Calling、结构化输出)。
  • 统一接口:invoke / stream / batch / ainvoke / astream,换模型不用改业务代码。
  • 集成覆盖:OpenAI、Anthropic、Ollama、本地 vLLM、开源模型(HuggingFace),以及统一消息格式(LangChain 的 HumanMessage/AIMessage/SystemMessage/ToolMessage)。
  • 结构化输出用 with_structured_output(PydanticModel),让模型按 schema 返回,可直接做类型安全的下游处理。
  • 实战要点:统一封装一个 get_model() 工厂(按任务路由不同模型与温度)、统一超时与重试、记录 token usage。
  • 面试加分:能讲「模型路由」——简单任务走小模型、复杂任务走大模型,是直接省钱的架构决策。
