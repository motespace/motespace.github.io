🎯 面试常考

Section titled “🎯 面试常考”

Q1：LangChain 的核心抽象是什么?

Runnable:任何实现了 invoke(input) → output 的东西都能被组合,Prompt、Model、Parser、Retriever 都是 Runnable,于是可以用 | 串起来。

Q2：LCEL 相比 Chain 类的优势?

① 每个环节可独立测试;② 支持并行(| 变 .pipe()、.parallel());③ 支持流式和异步;④ 错误处理可以局部重试。

📝 小结

Section titled “📝 小结”
  • LangChain 是LLM 应用编排框架:模型集成、Prompt 模板、输出解析、链、Agent、检索(RAG)、记忆的一站式方案。
  • 核心抽象是 Runnable:invoke / ainvoke / stream / batch / pipe 五个接口统一了所有组件,链式组合靠 |。
  • 生态:LangChain(通用)、LangGraph(有状态工作流)、LangSmith(调试与追踪)、LangServe(服务化部署)。
  • 现在推荐 LCEL(表达式语言) 而不是老的 Chain 类:可组合、可并行、可流式、易调试。
  • 安装要按需拆包(langchain-core / langchain-openai / langchain-community),避免把全部依赖拖进来。
  • 面试加分:讲清「我为什么用 LCEL 而不是老的 Chain/Agent 类」——统一接口 + 可组合 + 少一层魔法。
