🎯 面试常考

Section titled “🎯 面试常考”

Q1：LangChain 的 Agent 是怎么工作的?

核心是「模型 + 工具 + 循环」:把工具绑给模型,模型返回 tool_calls 就执行工具、把结果回传,直到模型给出最终答案或达到最大轮数。

Q2：怎么控制 Agent 不乱调工具?

工具描述写清适用场景;限制 max_iterations;必要时在工具内部做权限校验;对高风险工具加人工确认。

Q3：Agent 和固定链怎么选?

流程确定就用固定链(更可控、更省 token);流程依赖模型判断(要查什么、调用哪个工具)才用 Agent。

📝 小结

Section titled “📝 小结”
  • Agent = 让模型自己决定调用哪些工具、按什么顺序调用,而不是写死流程。
  • Tool 三种定义:@tool 装饰器(自动从签名生成 schema)、StructuredTool(精细控制 schema 与错误处理)、从 OpenAI function schema 创建。
  • Tool 的 description 决定模型选不选它——写清「什么时候该用它、什么时候不该用」比写清功能更重要。
  • 创建 Agent 三种方式:create_react_agent(推荐)、initialize_agent(旧 API)、直接用 bind_tools 让模型自己决策。
  • 执行循环:模型输出 tool_calls → 执行工具 → 回填 ToolMessage → 模型继续,直到不再要工具。
  • 关键工程项:工具白名单与权限校验、参数二次校验、最大迭代次数、危险操作要人工确认、每步的 token 与耗时埋点。
  • 面试加分:讲清「Agent 的不可控点就是工具选择与参数,所以要在工具层做约束而不是在 Prompt 层求模型听话」。
