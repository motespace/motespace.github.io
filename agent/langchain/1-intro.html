LangChain 入门 ​

LangChain 是 LLM 应用开发的事实标准框架。本章从整体架构开始,带你 30 分钟上手。

一、LangChain 是什么? ​

LangChain = 构建 LLM 应用的开源框架。

问题:LLM API 直接调用太底层
  - 没有 Prompt 模板
  - 没有链式调用
  - 没有 Agent 框架
  - 没有 RAG 支持
  - 没有 Memory

解决方案:LangChain 提供一站式抽象
  - Models(OpenAI / Claude / 本地模型)
  - Prompts(模板管理)
  - Chains(LCEL 链式调用)
  - Agents(自主选择工具)
  - Memory(对话记忆)
  - RAG(文档检索增强)

二、整体架构 ​

┌──────────────────────────────────────────────────────────┐
│                       Applications                          │
│         (Agent / RAG / Chatbot / Workflow)                  │
├──────────────────────────────────────────────────────────┤
│                  LangChain Components                       │
│  ┌─────────┐ ┌─────────┐ ┌─────────┐ ┌─────────┐         │
│  │ Models  │ │ Prompts │ │ Chains  │ │ Agents  │         │
│  └─────────┘ └─────────┘ └─────────┘ └─────────┘         │
│  ┌─────────┐ ┌─────────┐ ┌─────────┐ ┌─────────┐         │

│  └─────────┘ └─────────┘ └─────────┘ └─────────┘         │
├──────────────────────────────────────────────────────────┤
│                       LangChain Core                        │
│  (LCEL / Runnable / BaseLanguageModel / Output Parser)    │
├──────────────────────────────────────────────────────────┤
│                    Integrations                             │
│   langchain-openai  langchain-anthropic  langchain-ollama │
│   langchain-community(各种集成)                            │
└──────────────────────────────────────────────────────────┘

四、第一个 LangChain 调用 ​

python
from langchain_openai import ChatOpenAI
from langchain_core.messages import HumanMessage

# 1. 初始化 LLM
llm = ChatOpenAI(model="gpt-4o", temperature=0.7)

# 2. 调用(同步)
response = llm.invoke([HumanMessage(content="用一句话介绍 LangChain")])
print(response.content)

# 3. 异步调用
import asyncio

async def main():
    response = await llm.ainvoke([HumanMessage(content="异步调用")])
    print(response.content)

asyncio.run(main())

# 4. 批量调用
responses = llm.batch([
    [HumanMessage(content="1+1=?")],
    [HumanMessage(content="2+2=?")],
    [HumanMessage(content="3+3=?")],
])
for r in responses:
    print(r.content)

# 5. 流式输出
for chunk in llm.stream([HumanMessage(content="讲个笑话")]):
    print(chunk.content, end="", flush=True)
print()

五、PromptTemplate(模板管理) ​

python
from langchain_core.prompts import PromptTemplate, ChatPromptTemplate

# 1. 简单模板
template = PromptTemplate.from_template("""
你是 {role}。

任务:{task}

输入:{input}
输出:
""")

prompt = template.format(role="Python 教师", task="解释概念", input="什么是装饰器?")
print(prompt)

# 2. 聊天模板(多角色)
chat_template = ChatPromptTemplate.from_messages([
    ("system", "你是{role},回答用中文。"),
    ("human", "{input}"),
])

messages = chat_template.format_messages(role="Python 教师", input="什么是装饰器?")
response = llm.invoke(messages)

# 3. 复杂模板(带 Few-shot)
from langchain_core.prompts import FewShotChatMessagePromptTemplate

examples = [
    {"input": "什么是 Python?", "output": "编程语言"},
    {"input": "什么是 JavaScript?", "output": "Web 脚本语言"},
    {"input": "什么是 Rust?", "output": "系统编程语言"},
]

example_prompt = ChatPromptTemplate.from_messages([
    ("human", "{input}"),
    ("ai", "{output}"),
])

few_shot_prompt = FewShotChatMessagePromptTemplate(
    example_prompt=example_prompt,
    examples=examples,
)

final_prompt = ChatPromptTemplate.from_messages([
    ("system", "你是技术词典。"),
    few_shot_prompt,
    ("human", "{input}"),
])

# 4. 从文件加载(模板可管理)
# prompts/translate.yml
template = PromptTemplate.from_file("prompts/translate.yml")

六、OutputParser(结构化输出) ​

python
from langchain_core.output_parsers import StrOutputParser, JsonOutputParser
from pydantic import BaseModel, Field

# 1. 字符串输出
parser = StrOutputParser()
chain = llm | parser  # 简单的 chain
result = chain.invoke([HumanMessage(content="讲个笑话")])

# 2. JSON 输出
class MovieInfo(BaseModel):
    title: str = Field(..., description="电影名")
    year: int = Field(..., description="上映年份")
    director: str = Field(..., description="导演")

parser = JsonOutputParser(pydantic_object=MovieInfo)
prompt = ChatPromptTemplate.from_messages([
    ("system", "提取电影信息。\n{format_instructions}"),
    ("human", "{input}"),
])

chain = prompt.partial(
    format_instructions=parser.get_format_instructions()
) | llm | parser

result = chain.invoke({"input": "《肖申克的救赎》1994 年上映,导演弗兰克·达拉邦特"})
print(result.title, result.year, result.director)
# 肖申克的救赎 1994 弗兰克·达拉邦特

七、Chain(链式调用) ​

python
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-4o")

# LCEL(LangChain Expression Language)链式语法
prompt = ChatPromptTemplate.from_messages([
    ("system", "你是翻译,翻成英文。"),
    ("human", "{text}"),
])

# 用 | 串联(类似 Unix pipe)
chain = prompt | llm | StrOutputParser()

# 调用
result = chain.invoke({"text": "你好世界"})
print(result)  # Hello World

# 流式
for chunk in chain.stream({"text": "今天天气真好"}):
    print(chunk, end="", flush=True)

八、核心抽象:Runnable ​

python
# LangChain v0.1+ 所有组件都实现 Runnable 接口
# 统一 API:invoke / ainvoke / batch / abatch / stream / astream

# 查看 Runnable 类型
from langchain_core.runnables import Runnable

# 自定义 Runnable
from langchain_core.runnables import RunnableLambda

uppercase = RunnableLambda(lambda x: x.upper())
chain = uppercase | (lambda x: f"Result: {x}")

result = chain.invoke("hello")
# Result: HELLO

# RunnablePassthrough(传递原值)
from langchain_core.runnables import RunnablePassthrough

chain = RunnablePassthrough() | (lambda x: x * 2)
print(chain.invoke(5))  # 10

九、Callbacks(监控) ​

python
from langchain_core.callbacks import BaseCallbackHandler
from langchain_core.outputs import LLMResult

class MyCallback(BaseCallbackHandler):
    """自定义回调:打印每次 LLM 调用的详情"""

    def on_llm_start(self, serialized, prompts, **kwargs):
        print(f"[LLM Start] prompts: {prompts[:1]}...")

    def on_llm_end(self, response: LLMResult, **kwargs):
        usage = response.llm_output.get("token_usage", {})
        print(f"[LLM End] tokens: {usage}")

    def on_llm_error(self, error, **kwargs):
        print(f"[LLM Error] {error}")

# 用
llm = ChatOpenAI(model="gpt-4o", callbacks=[MyCallback()])

# 或用 LangSmith(推荐)
import os
os.environ["LANGCHAIN_TRACING_V2"] = "true"
os.environ["LANGCHAIN_API_KEY"] = "lsv2_xxx"
# 现在所有 LLM 调用都会自动记录到 LangSmith

# 1. 用 Pydantic 校验输入输出
from pydantic import BaseModel, Field, field_validator

class UserQuery(BaseModel):
    question: str = Field(..., min_length=1)
    language: str = Field("zh", pattern="^(zh|en)$")

    @field_validator("question")
    def no_evil(cls, v):

            raise ValueError("invalid query")
        return v

# 2. 用 env 管理 API Key(不写死在代码里)
import os
from dotenv import load_dotenv

load_dotenv()
api_key = os.getenv("OPENAI_API_KEY")

# ✅ 推荐

chain = LLMChain(llm=llm, prompt=prompt)

async def chat(text: str):

🎯 面试常考 ​

Q1：LangChain 的核心抽象是什么?

Runnable:任何实现了 invoke(input) → output 的东西都能被组合,Prompt、Model、Parser、Retriever 都是 Runnable,于是可以用 | 串起来。

Q2：LCEL 相比 Chain 类的优势?

① 每个环节可独立测试;② 支持并行(| 变 .pipe()、.parallel());③ 支持流式和异步;④ 错误处理可以局部重试。

🎯 关键 takeaway ​

✅ LangChain = LLM 应用的事实标准框架
✅ LCEL 用 | 串联组件(类似 Unix pipe)
✅ 所有组件都是 Runnable(统一 API)
✅ v0.1+ 拆分成多个包(langchain-core / langchain-openai / ...)
✅ 推荐用 LangSmith 做监控和调试
