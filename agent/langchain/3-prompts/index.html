🎯 面试常考

Section titled “🎯 面试常考”

Q1：PromptTemplate 和 ChatPromptTemplate 的区别?

前者渲染成字符串,后者渲染成消息数组(能区分 system/user/assistant),Chat 模型必须用后者。

Q2：Few-shot 示例放在哪里?

放在 system 或 user 消息的前面,作为「示例」段落。示例要覆盖边界情况,数量 2~5 个通常就够,太多会挤占 token 且收益递减。

Q3：怎么复用 Prompt 的一部分?

用 partial:prompt.partial(language='中文') 得到一个已固定部分变量的模板,常用于多语言/多角色场景。

📝 小结

Section titled “📝 小结”
  • PromptTemplate 用 f-string 风格占位符,支持模板文件(YAML/JSON)与f-string 模板两种来源。
  • 多消息模板用 ChatPromptTemplate.from_messages([...]),按顺序放 System / Human / AI 示例;few-shot 示例就放在消息列表里。
  • 动态占位符 MessagesPlaceholder 用于插入数量不定的消息(历史对话、检索到的片段)。
  • 输出解析器把字符串变成对象:StrOutputParser、JsonOutputParser、PydanticOutputParser(带校验,失败会报错而不是静默通过)。
  • 模板要参数化并外置(配置文件/环境变量),便于灰度与版本管理;敏感内容不要硬编码进模板。
  • 面试加分:讲清「Prompt 模板与输出解析是一对:模板负责生成,解析器负责把结果变成程序能吃的数据」。
