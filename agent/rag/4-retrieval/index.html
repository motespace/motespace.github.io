🎯 面试常考

Section titled “🎯 面试常考”

Q1：Naive RAG 和 Advanced RAG 的区别?

Naive 就是「切好直接检索 top-k」;Advanced 加了 Query 改写、HyDE、混合检索、重排序等环节,显著提升召回与准确率。

Q2：重排序(Rerank)为什么重要?

向量检索是粗排(快但不够准),Rerank 用更精细的交叉编码器对候选集重排,Top-3 的准确率往往能提升 10~20 个点。

Q3：混合检索指什么?

向量检索(语义)+ 关键词检索(BM25,精确词)并行,再融合排序。纯向量搜不到专有名词和代码标识符,纯关键词搜不到同义表达,混合最稳。

📝 小结

Section titled “📝 小结”
  • Naive RAG 只有「切分 → 向量检索 → 拼 Prompt」;Advanced RAG 在前后加改写、扩展、过滤、重排、压缩。
  • Query 改写:Multi-Query(生成多个角度再合并去重)、HyDE(先让模型生成假设答案,用假设答案去检索)、指代消解(「它的价格呢」要补全主语)。
  • 混合检索:向量(语义)+ BM25(关键词) 组合,能同时覆盖「同义表达」和「专有名词/型号」。
  • Rerank(重排)是用 cross-encoder 对初检结果精排,通常是性价比最高的一步提升。
  • 压缩与上下文拼装:只放最相关的片段、给每段编号并要求引用来源、给「资料不足时回答不知道」的约束。
  • 面试加分:能按「先修检索,再修生成」的顺序说清排查路径,并说出哪一步最值得投入。
