实战模板库(常见场景) ​

收藏可直接使用的 Prompt 模板。实战项目里复制改改就能用。

一、对话类 ​

1.1 通用聊天助手 ​

python
CHAT_PROMPT = """你是友好的 AI 助手。

特点:
- 简洁直接,避免冗长
- 用通俗语言,不用专业术语(除非用户用)
- 必要时给例子

回答风格:像跟朋友聊天,自然流畅。"""

1.2 多轮对话(带上下文) ​

python
# 在 LangChain 中
from langchain.memory import ConversationBufferMemory

memory = ConversationBufferMemory()

prompt = ChatPromptTemplate.from_messages([
    ("system", "你是友好的助手。"),
    # 之前的对话历史(自动从 memory 加载)
    ("placeholder", "{chat_history}"),
    ("human", "{input}"),
])

1.3 角色扮演 ​

python
ROLE_PROMPT = """你是 {character_name}。

角色设定:
{character_description}

说话风格:
{speaking_style}

对话要求:
- 保持角色一致性
- 可以引用角色的背景故事
- 用第一人称(我)说话

用户: {user_input}
{character_name}:"""

二、抽取类 ​

2.1 实体抽取(NER) ​

python
NER_PROMPT = """从文本中抽取实体。

实体类型:
- 人名(PERSON)
- 地名(LOCATION)
- 机构(ORG)
- 时间(DATE)
- 金额(MONEY)
- 产品(PRODUCT)

输出 JSON 数组:
```json
[
  {"type": "PERSON", "text": "...", "start": 0, "end": 5}
]

示例: 输入:张三在 2024 年 1 月 1 日加入阿里巴巴,年薪 50 万 输出:

json
[
  {"type": "PERSON", "text": "张三", "start": 0, "end": 2},
  {"type": "DATE", "text": "2024 年 1 月 1 日", "start": 3, "end": 14},
  {"type": "ORG", "text": "阿里巴巴", "start": 17, "end": 21},
  {"type": "MONEY", "text": "50 万", "start": 24, "end": 28}
]

实际输入:{text}"""
