Prompt 高级技巧(CoT / Few-shot / ReAct) ​

基础 Prompt 之外的高级技巧,能显著提升 LLM 在复杂任务上的表现。

一、Chain of Thought(CoT 思维链) ​

核心思想 ​

让 LLM 一步步推理,而不是直接给答案。

python
# ❌ 普通 Prompt:可能给错答案
prompt_normal = """
Q: 苹果 3 元一个,买 5 个多少钱?
A:
"""

# ✅ CoT Prompt:推理后再给答案
prompt_cot = """
Q: 苹果 3 元一个,买 5 个多少钱?
A: 让我一步步想:
1. 单价 3 元
2. 数量 5 个
3. 总价 = 3 × 5 = 15 元
所以答案是 15 元。
"""

实验对比 ​

问题:小明有 5 个苹果,给了小红 2 个,又买了 4 个,现在有几个?

❌ 普通(容易错):
A: 7

✅ CoT(更准):
A: 让我一步步想:
- 开始 5 个
- 给小红 2 个 → 5-2=3 个
- 又买 4 个 → 3+4=7 个
所以答案是 7 个。

实现方式 ​

python
# 1. 手动 Few-shot CoT(给示例)
prompt = """
Q: 3 个连续偶数之和是 18,这 3 个数分别是?
A: 让我一步步想:
- 设中间数为 x,则三个数为 x-2, x, x+2
- (x-2) + x + (x+2) = 3x = 18
- x = 6
- 所以三个数为 4, 6, 8。

Q: 一个两位数,个位和十位之和是 9,交换后新数比原数大 27,求原数。
A: 让我一步步想:
"""

# 2. Zero-shot CoT(不给示例,直接说"一步步想")
prompt_zero_shot_cot = """
Q: 一个两位数,个位和十位之和是 9,交换后新数比原数大 27,求原数。
A: 让我一步步想。
"""

# 3. LangChain 实现
from langchain.chains import LLMChain
from langchain.prompts import PromptTemplate

cot_template = """
{question}
A: 让我一步步想。
"""
cot_prompt = PromptTemplate(input_variables=["question"], template=cot_template)

# 4. Self-Consistency(多次采样,投票)
# 生成 N 个 CoT 答案,选最常见的(提高稳定性)
from collections import Counter

def self_consistency(question: str, n: int = 5) -> str:
    answers = []
    for _ in range(n):
        response = llm.invoke(prompt_cot.format(question=question))
        answers.append(extract_answer(response))

    # 投票
    counter = Counter(answers)
    return counter.most_common(1)[0][0]

CoT 适用场景 ​

✅ 数学推理、逻辑题 ✅ 多步骤任务 ✅ 需要解释决策 ✅ 复杂规划

❌ 不需要:简单查询、情感分类

二、Few-Shot Learning(少样本学习) ​

原理 ​

给 LLM 看几个示例,让它"悟"出规律,然后应用到新输入。

python
# Zero-shot(不给示例):效果可能差
prompt_zero = """
判断情感:这家餐厅服务很好吃
输出:
"""
# 输出可能是:positive(碰巧对)

# Few-shot(给 3 个示例):更稳定
prompt_few = """
判断情感。

示例 1:
输入:服务态度很好
输出:positive

示例 2:
输入:等位两小时
输出:negative

示例 3:
输入:味道还行
输出:neutral

实际输入:这家餐厅服务很好吃
输出:
"""
# 输出几乎一定是:positive

实战模板 ​

python
FEW_SHOT_TEMPLATE = """
你是 {role}。

任务:{task_description}

示例:
{examples}

实际输入:{input}
输出:
"""

# 用
prompt = FEW_SHOT_TEMPLATE.format(
    role="情感分析专家",
    task_description="判断文本情感(positive/neutral/negative)",
    examples="\n\n".join([
        "输入:这个产品太棒了!\n输出:positive",
        "输入:一般般,没什么特别\n输出:neutral",
        "输入:糟糕透了\n输出:negative",
    ]),
    input="今天天气真好",
)

几个示例就够 ​

0 个示例(Zero-shot): 60% 准确率
1 个示例(One-shot):  75%
3 个示例(Three-shot): 85%
5-10 个示例:          88%(再增加收益递减)

三、ReAct(Reasoning + Acting) ​

原理 ​

让 LLM 交替推理和行动:

  • 推理:我需要做什么
  • 行动:调用工具
  • 观察:工具返回的结果
  • 再推理:基于结果决定下一步
Thought: 用户想知道北京天气,我应该用 get_weather 工具
Action: get_weather(location="北京")
Observation: {"temp": 25, "condition": "晴"}
Thought: 现在我知道天气了,可以回答用户了
Action: Finish("北京今天 25 度,天气晴")

LangChain 实现 ​

python
from langchain_openai import ChatOpenAI
from langchain.agents import create_react_agent, AgentExecutor
from langchain_core.tools import tool
from langchain import hub

# 1. 定义工具
@tool
def get_weather(location: str) -> str:
    """查询天气信息"""
    return f"{location}:晴,25°C"

@tool
def search_docs(query: str) -> str:
    """搜索文档"""
    return f"关于 {query} 的文档..."

# 2. 创建 ReAct Agent
llm = ChatOpenAI(model="gpt-4")
tools = [get_weather, search_docs]

# 拉取官方 ReAct prompt
prompt = hub.pull("hwchase17/react")

agent = create_react_agent(llm, tools, prompt)
agent_executor = AgentExecutor(agent=agent, tools=tools, verbose=True)

# 3. 运行
result = agent_executor.invoke({"input": "北京天气怎么样?顺便查 LangChain 教程"})
print(result["output"])

verbose=True 会打印完整推理过程:

> Entering new AgentExecutor chain...
Thought: 用户想了解北京天气,我应该用 get_weather
Action: get_weather
Action Input: 北京
Observation: 北京:晴,25°C
Thought: 现在知道天气了,可以回答用户
Final Answer: 北京今天 25 度,天气晴朗。
> Finished chain.

ReAct vs Function Calling ​

维度ReActFunction Calling
推理过程显式(可以看)隐式(模型内部)
实现LangChain AgentOpenAI Native
适用复杂任务、可解释性简单工具调用
Token 消耗多(要输出 Thought)少

3. Self-Refine(自我修正) ​

python
prompt_refine = """
原答案:{initial_answer}
请审视原答案,找出错误或不足,生成改进版。

要求:
- 如果原答案正确,说"无需修改"
- 如果有错误,详细说明并修正
- 输出最终改进版
"""
# 多轮迭代
for _ in range(3):
    refined = llm.invoke(prompt_refine.format(initial_answer=refined))

# 适合:代码生成、复杂问题

4. Program of Thought(思维程序化) ​

# 让 LLM 生成 Python 代码来解决问题

Q: 鸡兔同笼,共 35 只,脚 94 只,鸡兔各几只?
A: 让我用 Python 求解:
```python
# x = 鸡数, y = 兔数
# x + y = 35
# 2x + 4y = 94
# 解:y = (94 - 70) / 2 = 12
# 所以鸡 23,兔 12
print("鸡:", 35 - 12, "兔:", 12)

"""

适合:数学问题、数据分析 ​


## 五、实战策略
  1. 先用 Zero-shot 看 LLM 是否能搞定
  2. 不行就加 Few-shot(3-5 个示例)
  3. 还不行就用 CoT(让 LLM 一步步想)
  4. 复杂决策用 ReAct(推理 + 工具调用)
  5. 数学/逻辑题用 Program of Thought(生成代码)
  6. 生产环境考虑 Self-Consistency(多采样投票)

## 🎯 关键 takeaway

✅ CoT(思维链):让 LLM 一步步推理,数学/逻辑必备 ✅ Few-shot:3-5 个示例比 1000 字描述更有效 ✅ ReAct:推理 + 行动,复杂 Agent 必备 ✅ Zero-shot CoT:不说示例,只说"一步步想" ✅ Self-Consistency:多采样投票,提升稳定性
