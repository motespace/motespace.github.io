🎯 面试常考

Section titled “🎯 面试常考”

Q1：常用的 Prompt 模式有哪些?

对话类、抽取类、分类类、生成类、推理类五类。每类的骨架不同:抽取类强调「只输出指定字段」,分类类强调「输出唯一标签」,推理类强调「先分析再结论」。

Q2：抽取类 Prompt 怎么写?

给出字段定义 + 「未找到时输出 null」+ 只输出 JSON 的约束 + 一个示例,四件套齐全才稳定。

Q3：分类类 Prompt 怎么写?

把候选标签列全、要求输出唯一标签、给「都不符合」的兜底标签,再配一个示例。

📝 小结

Section titled “📝 小结”
  • 按场景分六类模板:对话、抽取、分类、生成、推理、代码,每类给出可直接复用的 Prompt 骨架。
  • 抽取类:给 JSON Schema + 字段说明 + 缺失时用 null,再加「不确定就标 null」的约束。
  • 分类类:给互斥标签定义 + 边界样例,并要求输出单一标签;需要概率时让模型返回分数。
  • 生成类:给受众、语气、长度、结构四要素,再给 1~2 个示例定调。
  • 推理类:显式要求「先分析再结论」,并允许中间步骤。
  • 代码类:给语言版本、接口签名、边界约束、错误处理要求,并要求「先给思路再给代码」。
  • 面试加分:能说「Prompt 模板要参数化并集中管理,改文案不发版」——这是产品化落地的关键。
