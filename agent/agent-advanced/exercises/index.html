📝 小结

Section titled “📝 小结”
  • 练习覆盖:MCP Server、Supervisor 多 Agent、记忆抽取与注入、反思节点、HITL 中断恢复。
  • MCP 那题要跑通 mcp dev 并让 Claude Desktop 或自写 client 连上,理解「协议 + 传输 + 角色」三件事。
  • HITL 中断恢复那题最接近生产:中断后进程重启也能凭 checkpoint 恢复并继续。
  • 踩坑指南重点:记忆无限增长、反思循环不收敛、多 Agent 路由不明确、MCP 工具描述含糊导致选错。
  • 建议:每题都补上「成本与失败兜底」的思考,面试加分。
