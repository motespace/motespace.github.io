🎯 面试常考

Section titled “🎯 面试常考”

Q1：AI 应用成本怎么降?

① 换更便宜的模型做简单任务;② 减少 token(精简 prompt、截断历史、限制输出);③ 加缓存(语义缓存、prompt caching);④ 批量请求用 Batch API;⑤ 自部署开源模型替代高价 API。

Q2：自部署开源模型什么时候划算?

调用量大且稳定(能吃满 GPU)、对数据隐私有要求、或需要微调时。调用量小或波动大时,API 更划算。

Q3：怎么算成本?

总成本 = Σ(各模型输入 token × 单价 + 输出 token × 单价) + 基础设施成本。要按场景(用户/功能)拆开算才知道优化点在哪。

📝 小结

Section titled “📝 小结”
  • 成本 = 输入 token + 输出 token + 基础设施 + 人工返工;输出通常比输入贵好几倍。
  • 八大策略:模型分级路由、Prompt Caching(前缀命中)、限制 max_tokens、压缩上下文(裁历史)、缓存结果(语义缓存)、批处理接口、并发与异步化、限制 Agent 最大步数。
  • 语义缓存要注意命中率与错误命中的取舍(相似问题可能答案不同)。
  • 流式不降低 token,只改善首字延迟与体验——不要用「流式省钱」当理由。
  • 成本治理要落到看板 + 预算上限 + 异常告警,否则优化会被新功能吃掉。
  • 面试加分:能给出「用小模型做意图分类、大模型做生成」这类具体降本设计,并算出量级。
