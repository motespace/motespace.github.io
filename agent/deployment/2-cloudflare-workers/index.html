🎯 面试常考

Section titled “🎯 面试常考”

Q1：Cloudflare Workers 能跑 AI 应用吗?

能。它跑在 V8 isolate 上,支持 Workers AI(平台托管模型)和外部 API 调用,全球边缘分发,冷启动比传统 Serverless 更快。

Q2：Workers 的限制?

CPU 时间上限(免费版 10ms / 付费版 30s~5min)、无 Node 原生模块(需用 nodejs_compat)、内存 128MB、不能写本地文件。

Q3：什么场景最适合 Workers?

短文本处理、鉴权校验、路由分发、缓存层这种「毫秒级」的逻辑;不适合 RAG 检索和长上下文推理。

📝 小结

Section titled “📝 小结”
  • Workers 优势:全球边缘节点(用户就近访问)、冷启动极快(V8 isolate,毫秒级)、按请求计费、免费额度友好。
  • 限制也硬:没有 Node 原生 API(部分兼容层)、CPU 时间上限、不能跑大模型(只能调 API)、无长连接 SSE 之外的长任务。
  • 工具链:wrangler CLI 初始化、wrangler dev 本地调试、wrangler deploy 发布;配置在 wrangler.toml。
  • Worker 的典型职责:鉴权与限流、请求改写、缓存、代理模型调用、Stream 转发——而不是跑重逻辑。
  • 与外部服务配合:AI Gateway、KV(缓存)、R2(对象存储)、D1(SQLite)、Queues(异步)、Durable Objects(有状态)。
  • 面试加分:讲清「边缘层只做轻逻辑、重活交给区域 Worker + 队列」的分工,这是 Cloudflare 上的标准形态。
