⚡️内容大纲

0. Python 环境搭建(零基础起步) ​

完全没写过 Python?从这里开始。15 分钟配好环境,跑出第一行代码。

一、安装 Python ​

macOS / Linux ​

bash
# 方法 1:用 uv(2024 推荐,快 10-100 倍)
curl -LsSf https://astral.sh/uv/install.sh | sh

# 验证安装
uv --version
# 输出类似:uv 0.4.x

# 方法 2:用 pyenv(传统方式)
brew install pyenv  # macOS
pyenv install 3.12
pyenv global 3.12

# 验证
python3 --version
# Python 3.12.x

Windows ​

powershell
# 下载 Python 3.12
# https://www.python.org/downloads/

# 安装时勾选 "Add Python to PATH"
# 然后在 PowerShell 中:
python --version

二、选个编辑器 ​

推荐:VS Code + Python 扩展 ​

1. 下载 VS Code:https://code.visualstudio.com/
2. 安装扩展:
   - Python(微软官方)
   - Pylance(类型提示)
   - Python Debugger(调试)
3. 推荐设置(settings.json):
{
   "python.defaultInterpreterPath": "~/.local/bin/python3",
   "editor.formatOnSave": true,
   "python.testing.pytestEnabled": true
}

备选:Cursor(AI 辅助) ​

如果想用 AI 辅助写代码:Cursor
https://www.cursor.sh/

直接选 Python Interpreter,跟 VS Code 一样。

三、第一个 .py 文件 ​

第 1 步:创建项目目录 ​

bash
mkdir my-first-python
code my-first-python  # 在 VS Code/Cursor 中打开

第 2 步:创建 main.py ​

python
# main.py
print("Hello, Python!")
print("我是 AI Agent 开发者")
print(f"Python 版本:{__import__('sys').version}")

第 3 步:运行 ​

bash
# 在终端里
python3 main.py

# 或用 uv
uv run main.py

# 输出:
# Hello, Python!
# 我是 AI Agent 开发者
# Python 版本:3.12.x (...)

🎉 你的第一个 Python 程序运行成功了!

四、安装常用包(为 AI 开发准备) ​

bash
# 用 uv(推荐)
uv pip install langchain langchain-openai

# 或用 pip(传统)
pip install langchain langchain-openai

# 创建项目 + 自动装依赖(uv 推荐)
uv init my-agent
cd my-agent
uv add langchain langchain-openai python-dotenv

五、配置 API Key ​

bash
# 创建 .env 文件
cat > .env << EOF
OPENAI_API_KEY=sk-xxx
ANTHROPIC_API_KEY=sk-ant-xxx
EOF

# .gitignore(防止泄露)
echo ".env" >> .gitignore
python
# 加载 .env
from dotenv import load_dotenv
load_dotenv()

import os
api_key = os.getenv("OPENAI_API_KEY")
print(f"API key 加载成功:{api_key[:10]}...")

六、第一个 AI 程序(10 行) ​

python
# hello_ai.py
from openai import OpenAI

client = OpenAI()
response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "用一句话介绍 Python"}],
)
print(response.choices[0].message.content)
bash
# 运行
uv run hello_ai.py
# 输出:Python 是一种简洁易读的编程语言,广泛应用于 Web 开发、数据科学和 AI。

🎉 你已经用 Python 调通了 AI!

七、常见问题排查 ​

Q1:python3: command not found ​

bash
# macOS:装 pyenv 或用 brew
brew install python

# Ubuntu/Debian
sudo apt install python3 python3-pip

# Windows:重新安装 Python,勾选 "Add to PATH"

Q2:pip: command not found ​

bash
# 用 ensurepip
python3 -m ensurepip

# 或用 uv
curl -LsSf https://astral.sh/uv/install.sh | sh

Q3:ModuleNotFoundError ​

bash
# 用了虚拟环境但没装包?
# 激活环境后
source .venv/bin/activate
pip install <package-name>

# 或用 uv(自动管理 venv)
uv pip install <package-name>
uv run main.py  # uv run 会自动激活环境

Q4:VS Code 找不到 Python ​

Ctrl+Shift+P → "Python: Select Interpreter"
选择你安装的 Python 路径(用 uv 的话选 ~/.local/bin/python3)
