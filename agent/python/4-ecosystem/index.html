🎯 面试常考

Section titled “🎯 面试常考”

Q1：AI 应用的 Python 技术栈怎么配?

Web 层 FastAPI + Uvicorn;模型调用 LangChain/LangGraph;数据 Pydantic + SQLAlchemy + pgvector;工具 requests/httpx;观测 LangSmith;测试 pytest。

Q2：怎么在项目里组织这些依赖?

用 uv 或 poetry 管理,pyproject.toml 声明依赖,uv.lock 锁版本;开发依赖放 optional-dependencies 里分组。

Q3：从零搭一个 AI 项目的顺序?

① uv 建项目 ② FastAPI 起服务 ③ 接一个最简单的 LLM 调用 ④ 加 Prompt 模板 ⑤ 加工具 ⑥ 加 RAG ⑦ 加评测和监控。每步都能跑通再进下一步。

📝 小结

Section titled “📝 小结”
  • 虚拟环境解决依赖隔离:全局装多个项目会版本冲突;每个项目一个 venv,互不干扰。
  • 工具选择:uv(推荐,快且统一管理)、pip + venv(标准库,通用)、poetry/PDM(依赖声明与打包一体化)、conda(科学计算全家桶)。
  • 关键文件:pyproject.toml(项目与依赖声明)、uv.lock/requirements.txt(锁定版本)、.python-version(版本约束)。
  • 最佳实践:锁文件要提交到 git,CI 用 uv sync --frozen 保证环境可复现。
  • 常见坑:忘记激活 venv 导致装到全局、.env 里的密钥被提交、requirements.txt 不锁版本导致部署漂移。
  • 面试加分:讲「用锁文件保证本地、CI、生产三处依赖完全一致」,这是工程基本功。
