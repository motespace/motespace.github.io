📝 小结

Section titled “📝 小结”
  • 练习从语法基础一路到并发与 API,每题都有性能对比要求(用 time 计时),这个习惯很关键。
  • 写法对比题(while / for / sum)能把「可读性 vs 性能」讲清楚,面试时是常客。
  • 并发题教你区分串行 / asyncio / 线程池 / 进程池各自适合什么。
  • 踩坑指南重点:可变默认参数、循环里的闭包、浅拷贝、await 忘加、GIL 误用。
  • 建议:写完每题都用 time 跑一遍,能量化就不容易说错。
