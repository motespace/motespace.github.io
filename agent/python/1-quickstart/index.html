🎯 面试常考

Section titled “🎯 面试常考”

Q1：学 Python 对做 AI 应用有什么用?

AI 生态(Python)是主流:LangChain / LangGraph / FastAPI / PyTorch / Transformers / vLLM 全是 Python。工具链、数据处理、模型服务都在这一侧。

Q2：AI 开发要用到哪些 Python 特性?

类型提示、dataclass、异步(async/await)、装饰器、上下文管理器、f-string。类型提示在 LangChain 里尤其重要,链的输入输出全靠它标注。

Q3：从哪开始学?

先把语法和数据结构过一遍(1~2 周),重点是类型提示和异步;再直接进 FastAPI + LangChain 的项目,不要先啃算法。

📝 小结

Section titled “📝 小结”
  • Python 在 AI 生态的地位来自数据与模型生态(PyTorch、Transformers、NumPy)以及脚本与胶水语言的定位。
  • 运行方式:python file.py、REPL(python -i)、python -m module(用 -m 而不是直接跑文件,能保证 import 路径正确)。
  • 与 JS/TS 的对比:Python 缩进即语法、类型注解可选、动态鸭子类型;JS 是花括号 + 原型链 + 单线程事件循环 + 天然异步。
  • Python 的 GIL 让纯 CPU 密集任务难并行(要用 multiprocessing 或 C 扩展);IO 密集用 asyncio 就很好。
  • 面向对象是多态鸭子类型:duck typing——不检查类型,看有没有那个方法即可,这是 Python 灵活性的来源。
  • 面试加分:能说清「为什么 AI 后端生态在 Python 而前端生态在 JS」——模型库与数值计算的历史积累。
