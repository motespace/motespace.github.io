🎯 面试常考

Section titled “🎯 面试常考”

Q1：Python 环境怎么管理?

用 uv(Astral 出品,极快)或 pyenv + venv。uv 能一步完成创建虚拟环境、锁定依赖、装包,比 pip/venv 组合快一个量级。

Q2：为什么一定要虚拟环境?

隔离项目依赖,避免不同项目的包版本互相覆盖;也让 requirements.txt / pyproject.toml 能精确复现环境。

Q3：依赖文件怎么选?

应用用 pyproject.toml(声明式,现代标准);库用 pyproject.toml + hatchling;老项目继续用 requirements.txt 也行但要锁版本。

📝 小结

Section titled “📝 小结”
  • 推荐用 uv 管环境与依赖(2024 后的事实标准,比 pip 快 10~100 倍,自带虚拟环境与锁文件);老项目用 pyenv + venv 也完全可行。
  • 三层概念要分清:Python 版本(pyenv/uv python 管)、虚拟环境(隔离依赖)、包管理(uv/pip 装包与锁版本)。
  • 最小验证:能跑 python --version、建一个虚拟环境、安装并 import 一个包。
  • Windows 常见坑:路径分隔符、python 可能指向 Microsoft Store 的占位程序,要用 py 启动器或改 PATH。
  • 建议装 uv + ruff + python 插件**,把「环境管理」这一步彻底交给工具,别手动折腾。
  • 面试加分:能说清「为什么不用 conda」——conda 强在科学计算全家桶,纯 Web/AI 后端用 uv 更轻。
