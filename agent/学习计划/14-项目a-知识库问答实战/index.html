项目 A：AI 知识库问答系统

背景：解决团队文档散落、检索困难的问题。

技术栈：FastAPI · LangChain · ChromaDB · Docker · SSE 流式输出

  • 实现 SSE 流式输出，首 token 延迟 < 500ms

成果：日均处理 100+ 次问答，用户满意度 4.6/5

  • 项目目标:做一个可提问、可溯源的知识库问答系统,掌握 RAG 全链路。
  • 能力清单覆盖:文档加载与切分、Embedding 与向量库、检索与 Prompt 拼接、引用溯源、效果评估。
  • 第一步先理解 RAG 三阶段:索引(离线)→ 检索(在线)→ 生成,以及两阶段之间靠切分质量连接。
  • 分步推进:先「能问」(裸模型)→ 再「能检索」(向量库)→ 再「能用资料回答」(Prompt 约束 + 引用)→ 最后「能评估」。
  • 评估是这一项目的重点:准备 20~50 条问题,统计召回率、回答正确率、引用准确率,否则无法判断改动是变好还是变坏。
  • 面试加分:能讲「我做完这个项目最大的收获是学会先评估再优化」,这是方法论层面的收获。
