⚡️内容大纲

⚡ 5 分钟快速开始 ​

假设你已经有 MiniMax API Key（或者用 DeepSeek / OpenAI 也行）。

🎯 目标 ​

5 分钟内把项目 A（知识库问答）跑起来，完成第一个 RAG 问答。

📋 前置条件 ​

bash
# 1. Python 3.12+
python3 --version

# 2. uv（如果没有）
curl -LsSf https://astral.sh/uv/install.sh | sh

# 3. 一个 LLM API Key（推荐硅基流动，免费额度足够学习）
#    注册：https://cloud.siliconflow.cn

🚀 步骤 ​

Step 1：进入项目目录 ​

bash
cd "/Users/lvsj/Desktop/Agent develop/project/ai_agent_projects/01_knowledge_base/backend"

Step 2：安装依赖 ​

bash
uv sync

第一次运行会下载约 200MB 的依赖。

Step 3：配置环境变量 ​

bash
cp .env.example .env

编辑 .env：

ini
# LLM（任意 OpenAI 兼容服务）
OPENAI_API_KEY=your-llm-api-key
OPENAI_BASE_URL=https://api.deepseek.com/v1
OPENAI_MODEL=deepseek-chat

# Embedding（推荐硅基流动 + BGE）
EMBEDDING_API_KEY=your-siliconflow-key
EMBEDDING_BASE_URL=https://api.siliconflow.cn/v1
EMBEDDING_MODEL=BAAI/bge-m3

Step 4：导入示例文档 ​

bash
uv run python scripts/ingest.py --path ./data/samples

你应该看到：

📁 找到 3 个文件
📄 01-rag-introduction.md
   ✓ 8 个块
📄 02-langchain-basics.md
   ✓ 12 个块
📄 03-llm-fundamentals.md
   ✓ 10 个块
✅ 完成！本次 +30 块，总计 30 块

Step 5：启动 API ​

bash
uv run uvicorn app.main:app --reload

输出：

🚀 启动 AI Knowledge Base v0.1.0
   LLM: deepseek-chat @ https://api.deepseek.com/v1
   Embedding: BAAI/bge-m3
INFO:     Uvicorn running on http://0.0.0.0:8000

Step 6：测试问答 ​

打开浏览器：http://localhost:8000/docs

或者用 curl：

bash
curl -X POST http://localhost:8000/v1/chat \
  -H "Content-Type: application/json" \
  -d '{"question": "什么是 RAG？"}'

Step 7：体验前端 ​

打开 frontend/index.html：

bash

🐛 常见问题 ​

Q1：uv sync 报错 ​

A：检查 Python 版本（需 3.12+），或者删除 uv.lock 后重试。

Q2：LLM 调用报错 401 / 403 ​

A：检查 .env 里的 API Key 和 base_url 是否正确。

Q3：Embedding 报错 ​

A：Embedding 服务和 LLM 服务可能是不同的！比如 DeepSeek 没提供 embedding，需要用硅基流动或 OpenAI。

Q4：导入文档很慢 ​

A：第一次 Embedding 调用会慢（API 调用耗时），可加缓存（教程第四步有说明）。
