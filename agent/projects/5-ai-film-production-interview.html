AI 影视公司面试:部门领导会问什么 ​

这是面一家 AI 服务器厂商的 AI 短剧创作平台方向(部门领导终面)的完整准备清单,脱敏版。

按顺序过一遍大概 30-40 分钟。前四节是必须能答出来的,后面是查漏和临场工具。

一、自我介绍(90 秒) ​

骨架 ​

身份定位 → 三个代表作 → 收尾落到"我能给这个方向带来什么"

参考稿 ​

面试官好,我叫 XX,7 年前端,一直做 B 端中后台和可视化平台。

第一是复杂后台和可视化。 做过智能风控的规则引擎 —— 多层嵌套条件、组合逻辑、操作符的可视化配置,还带指标管理中台;也做过农业 IoT 大屏,对接温湿度、光照、CO2、土壤墒情这些传感器实时上报,还有多摄像头预览、分屏和云台控制。ECharts 大屏、地图点位联动、实时数据刷新这一套我熟到能直接上手。

第二是前端基建。 自己写过一套 RUM 错误监控和自动埋点 SDK —— React Fiber 往上遍历找事件处理器,实现零侵入点击采集,加了滑动窗口限流防雪崩。也做过 swagger 契约自动生成类型和统一请求 SDK。主导过 Vue2 到 Vue3 + Vite 的整体迁移,冷启动从 30 秒多降到 1 秒级,构建产物小了三成。

第三是安全和合规。 按钮级权限、动态路由、登录安全、请求加密、富文本安全渲染,在配合渗透测试整改的时候全套做过 —— 我知道政企、金融、网安这类客户对权限和审计的要求有多严。

再补一块最近的。 知道公司在往 AI 短剧方向走之后,我把主流的 AI 创作平台都用了一遍 —— WorkRally、腾讯云创意工坊、即梦、可灵,重点看它们的产品结构:剧本和分镜怎么组织、几千个生成任务怎么排队和反馈、多模型怎么统一接入、资产和成片怎么管。我还自己动手用 Next.js + FastAPI 写了个小工具,把"批量提交 → 队列 → SSE 推进度 → 候选对比 → 结果入库"这条链路串了一遍。

我看了贵司官网,最打动我的是"软硬件一体化技术架构与研-产-销-服全链路体系"和"专注 AI 垂直领域智能体的开发与应用" —— 不是单纯卖硬件,是把芯片、硬件、算法、场景一路串起来做成智能体。

这也是我想来的原因:纯做业务页面的活儿我做得够多了。我想接的是平台和场景层的东西 —— 而 AI 短剧这个方向,恰好是我看过、用过、还动手写了一点的东西。

注意:最后一段是核心,一定要落到"我能带来什么"。提到方向时用对方的原词(软硬一体、垂直智能体),领导一听就知道你真去看了。

二、通用软题(必问) ​

#问题答法方向
1简单介绍一下你自己见上一节,90 秒,收尾落到 AI 短剧
2⭐ 上一份工作为什么结束真实原因自己清楚就行,关键是整场面试用同一套说法。理由只讲一次,补充细节不换主线
3⭐ 为什么来这家、为什么不跟着推荐人去别家"方向认可,不是跟着人跑"。理由落在软硬一体 + 真落地场景 + AI 短剧方向
4你对我们公司了解多少官网定位原话 + 双品牌 + 三个软件平台 + 公司名含义(昇=昇腾、伟=英伟达、线程=算力最小单元)
5三到五年规划业务页面 → 基建体系 → 平台与场景层产品
6你的短板模型侧 + 生产级后端 + 硬件知识;给方法论:"先找到离我最近的抽象层"
7期望薪资给区间不给死数字,见第七节
8能接受创业公司节奏吗拿远程协作项目举证(没人催、靠自律)→ 说明适应力;末尾反问一句真实交付节奏
9会不会待不久用两段经历的时长举证 + 这次是方向选择不是机会选择
10带人/管理吗诚实:IC 优先,但带过组件库和技术规范

Q2 的三套答法(选一套,别混) ​

  • A. 远程协作项目结束/收缩

    "上一段是海外业务的远程协作项目,到 2026 年 8 月那波业务调整就自然收尾了。远程协作对自律要求高,我把这几年该沉淀的都沉淀下来了 —— 监控 SDK、请求层、组件库。现在想进一家实体团队,往平台方向再走一步。"

  • B. 个人/家庭原因(保持简短,别展开隐私)

    "主要是个人原因,那段时间也正好在看机会。说实话我关注的点很明确:想做平台和基建,不是纯业务需求交付。"

  • C. 想换方向

    "我想从纯业务前端往平台型前端转 —— 设备纳管、算力调度、可视化编排这类活儿,纯 CRUD 练不出来。我看到这边有异构算力调度和无人设备统一纳管,正好是我想深挖的方向。"

通用收尾句(三套都用):

"不过这都不是重点,我这次来是冲着具体方向来的 —— 这个软硬一体的路子是我认真看过之后的选择,不是海投。"

三、岗位相关题(这次的重头) ​

#问题答法方向
11了解 AI 影视吗?讲讲 WorkRally / 即梦 / 可灵WorkRally 定性:面向精品漫剧(及仿真人剧)的工业级 AI 流水线平台,不是单点生成工具;解决角色一致性 / 连镜 / 工具链割裂 / 产能瓶颈;指标产能约 5 倍、成本约 -50%。再报三个数:短剧市场规模、单集成本、集数时长
12简单模式和画布模式差别在哪简单模式 = 抽卡;画布模式 = 工程化,真正解决的是一致性(把角色/场景做成可绑定可复用的资产)。代价是复杂度,而复杂度就是前端的战场
13⭐ Agent 是怎么做的?唯一必须逐字背的一题,见 Agent 原理 的 1.1-1.4
14WorkRally 的"专家级 Agent"是什么多个专职 Agent(剧本/角色/分镜/提示词/超分)串成流水线,每个 Agent 是一个画布节点 —— 对应官网"垂直领域智能体"
15⭐ AI 短剧平台最难的技术问题是什么模型侧:一致性和多人同框对话戏(单人镜头是当前模型的舒适区,两人同框要动作自然、口型对上、身份不漂、空间关系正确);工程侧:把几千个任务的长链路变成人可用的工作台
16前端在这个平台里干什么画布编排、批量任务队列、候选版本对比、一致性绑定、成本可视化、资产库、流式渲染
17会 Python 吗?能写后端吗三明治:定位(前端为主能串起前后端)→ 已有(基础语法 + 接口形态认知)→ 马上能干的(FastAPI+SSE / 任务队列 / 调模型 API)→ 一周计划(FastAPI·asyncio·Pydantic·SQLAlchemy·Redis·Celery·ffmpeg·Docker)→ 杀手锏("过去两年没人教我,我自己做了三个 SDK")
18模型自研还是接第三方早期接第三方跑通形态,但要做一致性引擎必须有自己的编排层。对前端的意义:接第三方 = 界面要为"异步、时长不可控、参数各异"设计
19⭐ 为什么这家要做 AI 短剧一部剧 80-100 集 × 每集 60 镜头 × 候选倍数 = 万级 GPU 任务 → 消化自有液冷算力 + 验证集群能扛生产级负载 + 对外卖降本后的工业化产能。他们要卖的不是片子,是跑通流水线的算力和平台
20短剧成本怎么控制界面这块:把成本做成用户看得见的 —— 每集多少卡时、哪个模型更划算、哪类镜头抽卡最多、是否超预算
21一致性问题前端做什么工作流(参考图做成可复用绑定)+ 可视化校验(这镜头的角色版本和上一镜是不是同一个)+ 候选管理(达标的沉淀成标准资产)
22AI 生成内容的合规要求AIGC 显著标识 + 水印 + 溯源存证 + 送审链路,是产品硬功能不是法务文档。你做过渗透整改和权限审计,直接对口
23如果让你设计分镜编辑器四区联动(镜头列表 / 画面时间线 / 参数与一致性绑定),核心取舍是不让用户等:提交后立刻给位置感和可重试
24两种形态(真人仿真 / 漫剧)都做,架构怎么设计统一角色资产层 + 两条生成路线:底层角色ID/多视角参考图/绑定关系/版本历史共用,差异收在参数层;资产层和任务队列层必须共用。类比你做过的指标管理中台 —— 上面不同数据源,下面统一抽象

关于第 19 题的完整话术(可直接说出口) ​

"我算过一笔账:一部短剧 80-100 集,一集 60 个镜头,每个镜头还要生成好几个候选,推理量是万级 GPU 任务。所以 AI 短剧本质是个算力消耗大户。

这就解释了为什么要做它 —— 不是内容逻辑,是算力逻辑。液冷服务器公司的核心优势就是单位算力成本和高密度部署,正好对上短剧这种海量推理负载;而且跑通了真实的生产负载,才算证明这套集群能扛工业化生产 —— 这就是官网说的'研-产-销-服全链路'。再叠上'专注 AI 垂直领域智能体'这句,AI 短剧就是垂直智能体战略的第一个大场景。

他们要卖的不是片子,是跑通这条流水线的算力和平台。"

四、技术题(初面已过,备查) ​

部门领导一般不深挖,但会挑一两个问你"你的技术判断"。

五、反问(必问前四个) ​

  1. "这条线现在是从零开始,还是已经有人在做了?团队多少人、前端几个人?"
  2. "做的是真人仿真短剧还是漫剧?两个的一致性方案和前端形态差别很大。"
  3. "模型是自研还是接第三方?生成是分钟级还是小时级,界面设计完全不同。"
  4. ⭐ "如果用第三方模型 API,自家的液冷服务器在这条链上扮演什么角色?" —— 这题最高级:既证明你懂整盘业务逻辑,又在替他的服务器找位置,他会很想回答
  5. "GPU 算力是自建集群跑,还是先租用云上的?"
  6. "平台是从零做,还是基于某个开源工作流底座改?"
  7. "前端是纯 Web 工作台,还是要往剪辑类专业工具方向做?"
  8. "AIGC 标识和版权存证,产品侧怎么规划?"
  9. "深圳和成都怎么分工?前端团队在哪个城市、几个人?"
  10. "这个岗位职级和汇报对象是谁?"
  11. "入职后三个月你最希望我做出什么?"

不要问:上市/融资计划 · 加班和加班费 · 什么时候出结果 · 直接问薪资数字。

六、三个坑 ​

  1. 离职原因前后不一 —— 不需要跟谁对口径,但整场面试要用同一套说法。进面前把真实原因收敛成"一句话主线 + 一个补充细节"。
  2. 姿态错了 —— 部门领导面是"同事之间判断要不要一起干活",不是下属面试。少用"你们公司",多用"咱们这边";少说"都可以、听安排",多给判断。
  3. 谈钱谈早谈死 —— 给区间不给死数字,把话题从数字转向结构(绩效比例、职级、股权/期权)。

七、期望薪资 ​

原则:部门领导面尽量不谈死数字,谈区间 + 结构。

  • 简历上的口径如果明显偏低,提前调高;被问到时给区间并留出谈判空间
  • 不要在领导面前主动压价("您给多少都行"是自杀)
  • 把话题从数字转向结构:月薪 + 绩效比例 + 年终 + 职级 + 股权/期权
  • 上市公司母体的子公司,核心团队的股权激励是可以问的 —— 这是只有你知道公司背景才问得出的一句,直接拉高段位

被追问时的说法模板:

"我现在的诉求是月薪 XX-XXK 这个区间,具体看岗位职责和团队结构。另外我更关心整体的薪酬结构 —— 绩效和年终的比重、以及是否有面向核心团队的技术股权或期权激励,这块我都比较想了解。"

如果对方说给不了这么多:

"理解,那我想听听这个岗位的定位和空间 —— 如果职责本身有成长空间和成长速度,薪资我可以谈,但我需要一个能看到的路径,而不是只靠月薪数字。"

不要在第一轮就认输降价。

📝 小结 ​

  • 部门领导面考的不是"能不能写代码",是靠不靠得住、能不能扛事、会不会待得住、跟团队合不合。
  • 主线:用你做过的复杂工作流界面、实时数据、设备接入,去证明你能接住 AI 短剧平台的编排层。
  • 必须逐字背的只有一题:Agent 怎么做的。其余可以现场组织。
  • 必须准备的一个数字逻辑:万级 GPU 任务 → 算力逻辑。这道题答好了,后面所有技术讨论你都在他的频道里。
  • 反问里最值钱的一问:自家液冷服务器在这条链上扮演什么角色。
  • 心态:内部推荐 + 初面已过,你已经过了最难的两关。这场的及格线是让领导确认推荐人眼光准,不是表现惊艳。
