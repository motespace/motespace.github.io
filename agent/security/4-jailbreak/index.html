🎯 面试常考

Section titled “🎯 面试常考”

Q1：什么是越狱(Jailbreak)?

诱导模型绕过安全对齐,输出本应拒绝的内容。常见手法:角色扮演、虚构前提、编码绕过、逐步诱导、多轮拆解。

Q2：怎么防御?

输入侧做 jailbreak 模式识别(已知模板 + 语义分类);系统层反复声明边界;输出侧审核;关键动作人工确认。不要指望单靠 Prompt 能挡住。

Q3：为什么多轮越狱更难防?

每一轮单独看都很正常,恶意意图分散在多轮里。所以要维护会话级风险评分,而不是只看当前这一条输入。

📝 小结

Section titled “📝 小结”
  • Jailbreak vs 注入:注入是让模型执行它不该执行的指令;Jailbreak 是绕过模型的安全对齐(让模型做本不该做的事),手段是角色扮演、虚构场景、编码、分步拆解、越狱模板。
  • 常见技术:「祖母漏洞」式情感话术、假设性框架、Base64/ROT13 编码、多语言切换、逐步拆解任务(“先做第一步”)、伪造系统提示。
  • 检测思路:输入侧(模式匹配已知越狱模板 + 分类模型)+ 输出侧(内容审核 + 拒答模式识别)+ 行为侧(异常工具调用、异常频次告警)。
  • 商业检测服务:Lakera Guard、Protect AI、云厂商内容安全;但黑盒检测永远有漏,不能作为唯一防线。
  • 根本防线:模型侧用有安全对齐的模型 + 能力侧最小权限(危险工具要审批)+ 数据侧不喂敏感指令。
  • 面试加分:讲清「越狱没有银弹,靠纵深防御与持续对抗更新」,并能举一个你实际加的防护。
