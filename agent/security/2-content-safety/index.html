🎯 面试常考

Section titled “🎯 面试常考”

Q1：怎么防止模型输出违规内容?

三层:① 输入侧过滤明显违规请求;② 模型侧用系统提示约束 + 选对齐做得好的模型;③ 输出侧做分类器/审核模型二次校验。

Q2：审核模型怎么设计?

用一个小模型做二分类(安全/不安全 + 类别),比正则和关键词准得多。放在生成之后、返回用户之前。

Q3：误伤怎么处理?

分级:高危类别直接拦,中危走人工审核,低危只记录。高危类别要给出申诉和人工兜底通道。

📝 小结

Section titled “📝 小结”
  • 四大类有害内容:NSFW(色情)、暴力、仇恨歧视、违法/自残,不同地区法规要求不同,产品要按区域配置策略。
  • 检测分两层:输入侧(用户输入审核,拦住违规请求)与输出侧(模型生成审核,拦住违规回答)——只做输入侧不够。
  • 三种实现:调用平台自带审核 API(OpenAI moderation)、第三方内容安全服务(阿里云、腾讯云、Hive)、自建开源模型(关键词 + 分类模型)。
  • 工程要点:分级处置(直接拒绝 / 替换为安全回答 / 提示用户)、记录命中样本用于复核、误杀率与漏放率都要监控。
  • 合规要求:日志与样本要脱敏、命中情况要可审计、策略要能按地区与租户调整。
  • 面试加分:能说清「输入输出双向审核 + 分级处置 + 可审计」这三件事,这是内容安全的基本盘。
