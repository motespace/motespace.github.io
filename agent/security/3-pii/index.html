🎯 面试常考

Section titled “🎯 面试常考”

Q1：PII 是什么?

个人身份信息:姓名、手机号、身份证、邮箱、地址、银行卡、医疗和财务信息。在 LLM 场景里既涉及隐私合规,也涉及泄露风险。

Q2：怎么在链路里防 PII 泄露?

① 入站用 NER/正则识别并脱敏(替换成占位符);② 系统提示里禁止复述敏感字段;③ 出站再扫一遍;④ 日志不记录原始 PII;⑤ 优先用不训练数据的 API 或私有部署。

Q3：脱敏会不会影响效果?

会一点,但通常可接受:脱敏后模型看到的是「[手机号]」这种占位符,推理能力基本不受影响;关键是要在生成后把占位符还原回真实值。

📝 小结

Section titled “📝 小结”
  • PII 包括:姓名、手机号、身份证、邮箱、地址、银行卡、以及半结构化的自由文本(简历、病历、聊天记录里的个人信息)。
  • 合规要点:最小化收集、用途限定、加密存储、访问审计、保留期限与删除、跨境传输限制。
  • 检测手段:正则(手机号/身份证/银行卡)+ NLP 识别(姓名、地址这类非结构化信息);工具如 presidio-analyzer、正则引擎。
  • 脱敏策略:掩码(保留部分)、假名化/泛化(把精确地址降到城市级)、哈希(可关联不可还原)、完全删除。
  • 入模型前脱敏是关键动作:用户 prompt、日志、向量库入库都要过一遍;向量库里的 PII 同样受管控。
  • 面试加分:讲「RAG 场景最容易漏掉向量库里的 PII」——数据一旦入库就散落在 chunk 里,事后清理成本极高。
